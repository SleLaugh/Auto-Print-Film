# CPR 弯曲段等距偏移设计

## 问题

旧实现把所有 CPR 中心曲线沿同一个全局 `offset_axis` 做刚体平移。第一版修正
改为所有层共用中心曲线的局部法向。小范围时该方式成立，但当 offset 大于局部
曲率半径后，严格法向外推必然在内弯形成焦点：Localizer 表现为急弯后挤叠、
尖角或扇形回折，实际 CPR 也会沿同样的异常曲面采样。

真实结果中，`result` 的脊柱主体范围通常只到 `20–30 mm`，而 `result_full` 的
全量范围可到 `65 mm`。两者中心曲线相同，异常来自大 offset 对局部急弯的放大，
不是病例名称或 `full_label` 配置本身。

这不是单纯的定位图绘制问题。只改 Localizer 会让白线与实际切图不一致，因此
第六阶段总览、第七阶段 Localizer 和 `CurvedStackResampler` 必须共享同一套几何。

## 约束

- 不改变中心曲线、`offsets_mm`、切片张数、层厚、层间距或输出目录。
- 不包含病例名、部位特例或固定病人坐标；所有 `curved_stack` 使用同一算法。
- `offset=0` 必须严格保留原始中心曲线。
- 标准 `80 mm` 支撑范围内，主体范围和全量范围必须使用同一个偏移方向场；增加
  更远层时不得改变已经存在的层。
- 全部相邻 offset 曲线对应行距离必须精确等于配置间距，不能因远层稳定处理被
  拉大。
- 大范围 offset 遇到紧弯时不能形成尖点、回折或远层逐层变直的扇形。
- 当层厚等于层间距时，相邻厚层只能相接或轻微重叠，不能留下未采样间隙。
- 直线中心曲线必须退化为原有固定方向平移，不引入额外形变。

## 共享偏移方向场

中心曲线按输出行数做弧长重采样，记第 `i` 行为 `C[i]`，局部切向为 `T[i]`。
`offset_axis` 作为患者前后方向和首行朝向种子，不再作为每一行的固定平移向量。

1. 把首选方向投影到 `T[0]` 的正交平面，得到首行偏移方向 `D[0]`。
2. 后续每行把上一行 `D[i-1]` 投影到当前切向的正交平面并归一化，相当于沿
   曲线做离散平行输运，并保持方向符号连续。
3. 检查相邻方向差在标准 `80 mm` 偏移范围内对曲线前进方向的影响：

```text
change_ratio[i] = 80 mm * norm(D[i+1] - D[i]) / arc_step[i]
```

4. 若最大 `change_ratio` 不超过 `0.9`，直接使用原局部法向。否则按物理尺度平滑
   中心引导曲线，并用二分搜索求满足阈值所需的最小平滑尺度，再从该引导曲线
   重新计算一套共享方向场。

采用固定 `80 mm` 设计支撑范围，而不是读取当前计划最远层，是为了保证常见主体
范围和全量范围中的公共 offset 使用同一几何。若实际计划超过 `80 mm`，支撑范围
才随真实最大偏移扩展。

## 等距曲面

所有 offset 共用上节得到的单位方向场 `D`：

```text
C_d[i] = C[i] + d * D[i]
```

因此任意相邻 offset `d1`、`d2` 在对应行都满足：

```text
norm(C_d2[i] - C_d1[i]) = abs(d2 - d1)
```

该定义有三个重要性质：

- `C_0 = C`，中心 CPR 不移动；
- 相邻中心曲面严格保持配置层间距，层厚等于层间距时不会因曲面中心被拉开而漏采；
- 所有层保留同一弯曲趋势，不会出现越靠后越直的扇形。

共享方向场不要求始终是原始中心曲线的严格数学法向；紧弯病例会使用满足稳定
阈值的最小平滑法向。这是等距和不形成焦点之间的约束方式，但不会改变中心曲线。

## 厚层采样

每个 `C_d` 单独计算曲面切向。患者左右方向由曲面切向与共享偏移方向叉乘得到，
厚层子采样再沿当前 offset 曲面的逐行正交法向展开。`slice_thickness`
始终围绕当前实际曲面做算术平均，不把厚层错误地沿曲线纵向拖动。

`CurvedStackResampler._offset_curve_geometry` 是偏移曲面几何的共享内核，
`_offset_curve_samples` 是只返回中心曲线的轻量包装：

- 第六阶段 CPR 调试总览调用该入口；
- 第七阶段 DICOM Localizer 调用该入口；
- 第七阶段真实 CPR 重采样直接从共享内核取得曲面中心和该层引导法向。

定位图不再拥有一套独立的近似画法。

## 单计划几何复用

第七阶段为每个切片计划创建独立的 `CurvedStackResampler`。同一计划内所有 CPR
切片的中心曲线、输出行数、偏移轴和最大支撑范围相同，因此共享方向场只需准备
一次：

1. 从 `offsets_mm` 和 `slices[*].offset_mm` 汇总计划内全部偏移；
2. 按输出行数对中心曲线做一次弧长重采样；
3. 调用 `_offset_curve_geometry` 一次，生成全部 offset 的曲线和首选法向；
4. 后续逐张采样按 `offset_mm` 读取对应几何，继续执行原有曲面坐标系、厚层采样
   和三线性插值。

缓存只存在于单个重采样器实例中，不跨计划、病例或流水线共享。缓存键包含中心
曲线、输出行数、偏移轴、全部 offset 和有效支撑范围；任一几何输入变化都会重新
准备。日志 `[CPR几何准备]` 每个计划正常只出现一次，用于区分一次性几何耗时与
逐张 `[CPR采样性能]` 耗时。

这项复用不改变方向场算法、中心曲线、层位置、层厚、层间距、厚层子采样或 DICOM
空间信息，只消除同一方向场的逐张重复计算。

## 影响范围

- `plane_stack`、横状位区间切和矢状位直线 MPR 不受影响。
- CPR 中心曲线生成、端点修正和 L5/S1 锚点规则不受影响。
- offset 覆盖区间及张数规划保持现有规则，只改变紧弯 CPR 的偏移方向场。
- 直线 CPR 的局部方向恒定，采样结果与旧算法一致。
- 紧弯 CPR 的远层像素内容会随稳定曲面重新采样，这是本次有意修复，不能只修改
  Localizer 外观。
- 单计划几何复用只减少重复计算，不改变 `plane_stack` 或任何 CPR 切割结果。

## 验证

- 断言全部相邻 offset 曲线对应行距离等于配置间距。
- 断言层厚等于层间距时，相邻 slab 沿平均曲面法向不存在正间隙。
- 断言增加远层不会改变已有 offset 曲线。
- 断言大 offset 曲线的行进方向与中心曲线保持同向，不在内弯回折。
- 用急弯合成曲线对比原始法向外推，断言最外三组的最小投影间距显著改善。
- 捕获真实重采样物理点，逐行比对 Localizer 中心曲线。
- 对比复用前后的整组 CPR，断言像素数组、`Origin`、`Spacing` 和 `Direction`
  完全一致，并断言计划内 `_offset_curve_geometry` 只调用一次。
- 用 `result` 和 `result_full` 的 12 组真实 CPR 计划复算 Localizer，确认原本正常
  的颈胸椎基本不变，腰椎大范围外层不再在腰骶弯曲段挤成尖束。
