# 统一解剖姿态与三状位回正

2026-10-20 更新：颅脑新增有质量门槛的脑形态俯仰估计与脑部范围内的骨标签取景支持，
取代此前“所有启用部位均保留输入俯仰”的统一规则；其他部位规则保持不变。
详细门槛与诊断见[颅脑形态斜切设计](2026-10-20-颅脑形态斜切设计.md)。

## 范围

当前启用的 CT 部位，其整切 MPR 横、矢、冠状位都消费第五阶段同一套解剖坐标。
回正应用于真实物理采样，像素和最终 DICOM 位置、方向同步；不是只改显示标签。
普通 MPR 采用整体刚性坐标，不强行镜像、变形组织或把弯曲脊柱逐节拉直。冠状位和矢状位 CPR
均须显式指定 `SliceType=CPR`，其曲面展开与整体姿态回正是不同能力。

## 阶段边界

1. 第三阶段为脊柱汇聚可靠逐椎体镜像角，满足条件后生成 XY 候选 raw/seg，双文件
   成功写出才提升为统一工作空间。颅脑、髋骨和肺部不在此处重复整卷 XY 旋转。
2. 第四阶段在选定工作空间中计算全量标签定位；工作空间改变后不得复用旧坐标。
3. 第五阶段计算方向、完整覆盖边界、方法、可信度及质量回退诊断；脊柱复用已有
   标签稀疏索引，不按椎体另建整卷 Mask。颅脑、髋骨和
   肺部的姿态在此确定，不先旋转缓存图像。
4. 第六阶段按同一解剖轴生成三个状位的中心、行列方向及法向；第七阶段通用执行
   这些计划，并把实际成片几何写入 DICOM。

旧左右方向 PCA helper 保留兼容用途，正式姿态不以全 mask 的最长轴作为左右方向金标准。
颅脑俯仰使用已确定 LR 的正交 AP/SI 平面内二维 PCA，不用三维最长轴替换 LR。
索引使用 z/y/x 与 x/y/z 的明确换算；图像轴旋转通过方向矩阵映射到患者物理空间，
不能把图像 z 轴直接等同患者 LPS Z 轴。物理估计同时使用 origin、spacing、direction。

整切 MPR 的 `patient_reference_axes` 从存储轴的无向直线确定患者语义参考：SI 符号朝 LPS
`+Z`，LR/AP 选择接近患者左/后的成对符号，形成右手系。整切冠状位、矢状位
头侧向上，不能直接沿用负向存储轴或未经患者语义校准的叉积判定头侧。此步骤只
规范符号，不改变斜扫描角度；所有体素到物理点的换算仍使用原始 direction。

## 各部位方向

| 部位 | 整体左右方向与头脚方向 | 质量不足时 |
| --- | --- | --- |
| 颅脑 | 脑区边界镜像对称面的法向作为左右轴；完整脑区在 AP/SI 平面内的二维 PCA 另估计绕 LR 的俯仰 | LR 质量不足保留患者参考左右方向；俯仰质量不足保留基础 AP 投影，分别记录原因 |
| 髋骨 | 双侧最大主体边界的镜像对称面确定左右轴；顶部 AB 仅作诊断 | 重叠、严重单侧缺损或拟合不足时警告并保留输入轴 |
| 肺部 | 镜像质量通过，且两个主体分居候选面两侧、沿 LR 分离并反射跨主体对应后采用左右轴 | 单侧、连为一体、同侧碎块或证据不足时警告并保留患者参考轴 |
| 颈椎、胸椎、腰椎 | 汇聚可靠逐椎体 LR 法向，以输入 AP 投影和 LR×AP 构造整体三轴 | 无可靠 LR 时警告并保留患者参考三轴；首尾范围无效仍报错 |

全部部位先将患者参考 AP 轴投影到最终 LR 正交平面，SI 由 LR×AP 构造。
脊柱、肺部、髋骨的普通整切 MPR 保留输入前后倾角，不额外抬头、低头，
不根据左右对称性另行推断俯仰，
也不把首尾质心连线摆竖直。头脚符号校准只规范方向，本身不改变俯仰。

颅脑默认再从完整 `brain` 的物理体素估计 AP/SI 形态主轴，通过质量门槛后只绕 LR
旋转 AP/SI，三状位共同使用最终坐标。它不是听眦线或 AC-PC 线：没有定位外耳孔、
眼外眦或前后连合，脑底形态及分割质量会影响估计。拒绝时保留原 AP 投影，
不把俯仰失败等同于已可靠 LR 的失败。

脊柱配置首尾质心仅用于范围有效性检查和诊断，不再决定全局 SI。范围和中心
仍由配置内完整体素确定。没有可靠 LR 时保持完整患者参考三轴并明确告警；
`applied` 反映实际姿态变化，不能因为完成坐标构建就标记已回正。

普通胸椎 MPR 横状位与另外两个状位一样使用整体坐标；髋骨矢状位和冠状位也使用最终坐标，
不再单独固定为输入轴。颈椎 C1 仍参与首尾范围有效性检查与普通 MPR 覆盖，姿态角汇聚、
过滤主体及 CPR 的排除项继续由配置控制。

范围配置中的 S1 标准名不改写。执行时按本次实际 `label_targets` 优先选择
`vertebrae_S1`，不存在时回退 `sacrum`；整体轴端点及诊断、椎间主体配对、
`L5_S1` 计划和其 `source_labels` 均使用实际标签名。缺少两者时继续执行既有
缺标签校验，不拿其他椎体替代。整体配置仍保留标准名，供完整解剖顺序展开使用。

## 覆盖、局部几何与显示

拟合可使用有数量上限的边界采样点，但三个方向的覆盖边界必须重新投影完整保留
主体，不能由采样点或顶部 AB 代替。首尾配置外扩、层厚、层间距和数量规则照常应用。

颅脑方向与三状位基础范围只由完整 `brain` 体素决定，骨不参与几何估计或延长层组。
第六阶段沿用范围扩展，当前仅颅脑横状位 MPR 默认头侧补 `10 mm`、下侧 `0 mm`，
冠、矢状位不加这项余量；第五阶段 bounds 不变，`10 mm` 不保证所有病例颅顶完整。
同次明确的 `skull` 从当前模型 dataset.json 解析，不硬编码 ID 或新增模型；第七阶段
沿最终 SI 保留与脑区物理支撑范围正重叠的骨体素，横状位取景上界同步增加该计划
头侧余量，下界仍为脑区，辅助取景居中、防裁边，
不把远处面部、下颌加入切片范围。骨标签缺少或为空时仅用脑区取景并告警；
脑区接边时拒绝俯仰更新并报告扫描截断风险，不生成原图不存在的解剖结构。

颈椎、腰椎横状位椎间隙保留局部间隙位置与斜切法向，并使用相邻椎体可靠的局部
左右方向处理侧倾；质量不足时记录警告及回退原因，不把不可靠估计伪装成成功回正。
局部几何处理旋转与侧倾；显示符号仍保留原图横断面参考，切片顺序保持上位到下位。
整切 MPR 使用患者语义参考；椎间隙的排列顺序不决定画面上下。
脊柱普通整切保留俯仰不取消局部椎间隙的真实相向端面和相邻 LR 斜切，也不改变
CPR 的端点、中心曲线及曲面展开规则。

`FillPercent` 只调整取景；`localizer_plane`、`localizer_reference` 只选择参考背景。
它们不能重定姿态轴或替换正式切片几何。各窗共用相同物理采样几何。
正数 FillPercent 的椎间隙可使用可靠、明确的对称面点沿面内 LR 居中；
普通体素质心不是对称面点。倍率预计算时同时容纳新中心到两侧边界的最大距离，
保持整组及各窗统一物理比例，避免居中后裁掉长侧。质量不足、空层或切面几何不适用时
回退包围框中心；0/null/省略时保持既有行为。

## 质量与交付边界

镜像匹配检查三维范围、搜索边界、优化收敛、残差、改善程度及方向唯一性。涉及
许可 LR 方向的近重根子空间须检查低阶角向分布及径向轮廓，圆柱类形状不能把
采样相位当作姿态证据；许可角度内有相离等价面或平坦方向时拒绝更新。仅 AP/SI
等谱而 LR 独立时，不因面内俯仰不确定而否决左右法向。唯一性结果进入
`direction_uniqueness` 诊断。

肺部先通过上述镜像质量检查，再验证两个主体质心位于候选面两侧并沿 LR 充分
分离，且反射后的近邻主要落在另一主体；两个连通域的数量本身不能证明双侧肺。
这一步的结果进入 `bilateral_evidence`，不通过时同样拒绝姿态更新。

肺本体拟合仅因镜像形态质量不足被拒绝时，可用同一分割的明确 `pleural effusion`
语义标签补充胸膜腔外轮廓，执行第二次严格拟合。第五阶段从当前模型 dataset.json
解析实际标签 ID，只加入胸膜标签，不纳入心包/未知标签。辅助 Mask 必须包含全部
保留肺主体，主体过滤后仍须保留原肺，并通过相同的镜像、唯一性及跨双侧检查。
原肺已可靠或因不收敛、边界、方向歧义及双侧证据失败而拒绝时，不用辅助轮廓绕过。

辅助证据只确定姿态，中心、point_count 和三个方向覆盖边界仍从完整原肺主体计算；
不增加切割标签或修改配置范围。原肺拒绝保留在 `lung_symmetry`，辅助来源和检查结果
记录在 `pose_support`；采用后 method 为 `lung_pleural_envelope_symmetry`。
没有可用辅助标签或第二次仍不可靠时继续保留患者参考方向，不把真实左右差异强制抹平。

已接近患者参考方向时可以不作旋转。质量拒绝须保留可见的警告与原因。
拟合利用近似左右对称性估计姿态，
不能证明真实组织完全对称，也不应为消除正常解剖差异强行改变形状。
现有合成与少量真实病例验证不代表完成临床泛化验证，异常解剖和分割缺损仍须复核。
颅脑俯仰的门槛、中央带稳定性检查与回退原因在独立设计中维护；形态斜切的质量
通过只表示满足工程几何门槛，不能作为解剖标志线定位成功的证据。

基础环境增加 `scipy>=1.10,<2`。已有虚拟环境需执行
`python -m pip install -r requirements.txt`；可执行发布包需重新运行 `dev build`
并整体更新。第一、二阶段缓存可复用，已有 DICOM 成片须重新切割才采用新几何。
