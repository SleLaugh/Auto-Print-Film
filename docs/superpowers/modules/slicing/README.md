# 切片模块入口

本模块描述层厚、层间距、数量、有效范围、总范围和可配置范围扩展。当前规则以
2026-07-20 的完整覆盖设计为准。

## 当前有效规则

- 层厚、层间距和数量必须传入其中两项或全部传入，缺少项由有效范围计算。
- 任意采样参数为 `0` 时按未配置处理；处理后少于两个有效参数则拒绝请求。
- 总范围按 `层厚 + (数量 - 1) × 层间距` 计算，首末厚层外缘覆盖有效范围。
- 三项齐全时，总范围较大则首尾对称外扩；总范围较小则保持数量并均分层厚、
  层间距。
- 椎间隙数量按每个有效间隙分别应用。
- 可按部位、切割方式和状位配置额外范围扩展，单位固定为毫米。
