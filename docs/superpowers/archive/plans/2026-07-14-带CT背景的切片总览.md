# 带 CT 背景的切片总览实施计划

> **供执行人员使用：** 按任务逐项实施本计划，各步骤使用复选框（`- [ ]`）跟踪状态。

**目标：** Replace refined-grid label-only overviews with presentation NIfTI files containing resampled CT, thickness bands, and center lines.

**架构：** Reuse the existing per-plane overview reference and label painting logic. Resample `raw_for_reconstruction_path` onto that reference, burn label 15 regions above the CT maximum and label 14 regions higher still, then write a float32 presentation image while retaining native-grid label overviews.

**技术栈：** Python 3, NumPy, SimpleITK, unittest.

## 全局约束

- Presentation files are debug-only and never become stage-5 inputs.
- CT resampling uses linear interpolation and the source minimum as the default value.
- Existing native-grid overview files remain unchanged.
- Do not commit unless the user explicitly requests a commit.

### 任务 1：Burn CT and overlay labels into one presentation image

**文件：**
