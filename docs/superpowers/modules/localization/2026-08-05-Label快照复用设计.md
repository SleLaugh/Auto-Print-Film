# Label 快照复用设计

## 背景

拆分前的原第三阶段读取分割后，坐标提取、目标 bbox、逐椎体倾斜检测、解剖几何和
脊柱主体几何分别生成 Label Mask 或执行 `np.argwhere`。这些职责现在分别归入第三
阶段空间校正、第四阶段标签定位和第五阶段解剖分析。在腰椎 `512x512x400` 数据上，
坐标提取约 1.58 秒、倾斜检测约 3.01 秒，主体几何中再次寻找 Label bbox 约
1 秒。腰椎不生成统一解剖坐标，但当前仍会额外构造六张全尺寸 Label Mask。

## 目标

- 第一次坐标提取时保留每个 Label 的原始全局 `zyx` 索引和 bbox。
- 倾斜检测直接复用原始索引，保持 PCA 输入点及顺序不变。
- 主体几何使用缓存 bbox 截取局部分割，不再扫描全图查找相同 Label。
- 腰椎等不消费 `label_masks` 的部位不构造全尺寸 Label Mask。
- 回正生效后基于回正分割重新建立快照，禁止跨图像空间复用。

## 数据边界

快照由第三阶段建立，通过本次任务的 `ProcessingContext.metadata` 仅供第三至第五阶段
在同一进程内复用。单标签区域保留全局索引和 bbox，运行时工作区另保留图像、分割数组、
目标 mask 和配置解析信息；这些大对象不进入阶段 JSON、不跨病例保存，也不持久缓存 CPR。
第五阶段无论成功或异常均释放工作区；第七阶段需要取景时重新读取正式分割路径，
不能借用或延长这个快照的生命周期。外部 cache_dir 是另一套文件缓存。

原始分割和回正分割是两个独立快照世代：候选未提升时使用原始快照；候选提升后
立即丢弃原快照，并在重新提取坐标之前用回正 `seg_array` 建立新快照。

## 等价性

- 索引仍由现有 `np.isin` 和 `np.argwhere` 产生，数组顺序不变。
- bbox、体素数和质心继续从同一索引数组计算。
- PCA 只把现有 `_detect_axial_skew` 的索引入口拆出，不改变协方差、特征向量、
  角度归一化和阈值规则。
- 主体算法仍接收相同 bbox 范围的原始分割视图。
- 优化前后需比较完整 localization JSON、候选角、主体几何和正式计划。

## 非目标

- 不把全部 Label 改写成新的单遍统计算法。
- 不修改回正、PCA、主体筛选、四棱柱和 CPR 规则。
- 不增加线程池、全局缓存或第三方依赖。

## 实现结果

- `_LabelVoxelRegion` 保存每个目标 Label 的原始全局 `indices_zyx` 和 bbox。
- 第三阶段倾斜检测、第四阶段坐标提取和第五阶段主体局部裁剪复用同一份快照。
- 腰椎不再构造仅供颈椎、胸椎和髋骨解剖坐标使用的全尺寸 Label Mask。
- 回正候选提升后重新读取分割并建立第二代快照；未提升时只建立一次。
- 内部 helper 在未传快照时可自行构建局部索引，供独立调用和等价性验证使用。

## 实测结果

- 数据：`腰3_1mm`，分割尺寸 `512x512x400`，非 Debug 产物模式。
- 以下数字来自八阶段拆分前的原第三阶段，等价于当前第三至第五阶段相关职责的历史
  基线，不代表拆分后任一单独阶段的耗时。
- 原第三阶段独立复跑：`12.097s -> 6.703s`，减少 `5.394s`，约 `1.80x`。
- 完整 Pipeline 实跑：原第三阶段 `12.095s -> 7.407s`，减少 `4.688s`，约
  `1.63x`；Pipeline 总耗时 `115.30s -> 111.31s`，减少 `3.99s`。
- 完整实跑中，倾斜检测 `3.005s -> 0.037s`；腰椎无用 Label Mask 构造
  `0.513s -> 0s`；主体几何 `6.974s -> 5.761s`。
- 同次完整实跑的 nnUNet 分割比基线增加约 `0.647s`，原第四、第五阶段（现第六、
  第七阶段）合计增加约 `0.069s`，因此 Pipeline 总耗时降幅小于原第三阶段自身降幅。
- 本轮缓存路径的主体几何为 `49,422` 字节，SHA-256 为
  `d3c715f95b10d160d3308b5f0cb8e91d20fbc9aeef9e1511aaad4fd68f451bf3`；
  独立 helper 路径字节数和哈希完全相同。
- 缓存路径主体几何约 `5.518s`，独立 helper 路径约 `6.989s`；快照构建约
  `1.363s`，该结果同时供坐标和倾斜检测使用。
- 全量验证：`331 passed, 70 subtests passed`。
