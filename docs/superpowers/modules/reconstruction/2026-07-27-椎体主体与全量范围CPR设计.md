# 椎体主体与全量范围 CPR 设计记录

## 背景

nnUNet 的脊柱 label 是全量椎体结构，通常同时包含椎体主体、椎弓根、横突和棘突。全量 label 适合表达最终需要覆盖的解剖范围，但不适合直接计算 CPR 中心线：后方附件会把质心向后拉，使冠状位 CPR 的定位线和弧度偏离椎体排列。

因此，定位结果需要保留两套用途不同的几何信息，而不是用二次标注替换原始标注。

## 核心约定

### 1. 椎体主体几何：决定中心线和弧度

二次标注只保留椎体主体，用于：

- 计算每个椎体的主体质心；
- 生成 CPR 的中心路径点；
- 平滑和连接中心路径；
- 计算 CPR 及区间切的局部切线方向。

这部分几何不应被棘突、横突等后方附件影响。

### 2. 全量标注几何：决定覆盖范围

原始全量 label 继续用于：

- 定位目标和获取解剖范围；
- CPR 首尾沿头脚轴扩展到首末椎体的全量边界；
- CPR 每个位置沿左右方向扩展到全量标注边界；
- 保证区间切覆盖完整椎体及其附件结构。

最终效果是：

> 椎体主体决定“线怎么弯”，全量标注决定“切多大”。

### 3. C1 的边界

- C1 保留在颈椎定位坐标、bbox 和切图覆盖范围中；
- C1 不参与颈椎 CPR 中心路径；
- C1 不参与横状位姿态/回正角度统计；
- 其他状位仍可以覆盖和切到 C1。

## 数据流

```text
完整 nnUNet label
        |
        +--> 原始全量 bbox ------------------+
        |                                     |
        +--> 椎体主体二次 mask --> 主体质心 --+--> CPR 中心路径
                                              |
                                              +--> 局部切线/弧度

原始全量 bbox + 主体中心路径
        |
        +--> 首尾头脚方向扩展
        +--> 左右方向扩展
        +--> 完整范围 CPR / 区间切
```

## 当前提交状态

本次提交包含椎体主体 mask 的研发期 overlay、主体提取规则、C1 的作用域拆分，以及 CPR 首尾沿解剖头脚轴扩展的修正。主体 mask 当前首先作为 ITK-SNAP 校验产物保留，后续接入 CPR/区间切时应新增独立的主体质心字段，不能覆盖现有全量 `centroid` 和 `bbox`。

## 验收标准

1. 矢状位观察时，CPR 中心线贴近椎体主体，不跟随棘突向后偏移。
2. 冠状位 CPR 的首尾覆盖全量椎体范围，不因主体 mask 过窄而丢失附件。
3. 左右扩展覆盖全量 label 的边界，但扩展方向跟随主体中心路径的局部切线。
4. C1 仍能出现在定位和其他状位切图中，但不改变颈椎 CPR 的曲线。
5. 主体 mask 质量不足时，不修改原始定位结果，并保留可回退路径。
