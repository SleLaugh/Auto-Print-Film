# 阶段三脊柱几何性能优化设计

## 背景

腰椎非 Debug 流程中，阶段三 `build_spine_body_geometry` 耗时约 23.26 秒，
是分割之外最大的单项耗时。另一组 512x512x326 腰椎数据的 `cProfile`
显示，18.75 秒几何构建中有 15.23 秒用于主体和四棱柱区域生成。

## 目标

- 保持椎体主体筛选、S1 特殊处理、四棱柱和端面算法不变。
- 保持 `spine_geometry` 字段结构和值不变。
- 将主体筛选和连通域运算限制在每个 label 的局部包围盒内。
- 每个椎体只计算一次矢状四边形，并供棱柱、矢状面和序列化结果复用。
- 将 SI 柱高的逐体素 Python 扫描改成等价的 NumPy 批量计算。

## 设计

### 局部 Label 区域

新增内部 helper，从完整分割中找到目标 label 的最小闭区间包围盒，返回全局
`zyx` 起点和该区域的数组视图。普通椎体与 S1 主体算法只消费该局部数组，
生成的局部主体坐标在进入物理几何计算前加回全局起点。

局部区域边界就是 label 的完整边界，不裁掉任何前景体素。连通关系、行宽、
前后位置分簇和边缘高度规则都具有平移不变性，因此算法输入中的有效信息不变。

### SI 柱高

对布尔 mask 沿 z 轴一次计算每根柱是否存在前景、首个前景位置和末个前景
位置，柱高仍定义为 `z_max - z_min + 1`。后续每个 AP/LR 位置的 75 百分位、
边缘阈值和裁剪规则保持不变。

### 矢状几何复用

主体区域生成时计算每个椎体的 `_sagittal_body_quadrilateral`，通过本次调用的
局部缓存传给棱柱栅格化和结果组装。缓存不跨任务、不跨图像，也不写入全局状态。

## 等价性验证

- 合成数据验证局部区域包含全部且仅包含目标 label，并正确恢复全局坐标。
- 合成 mask 验证批量柱高与原逐柱定义一致，包括孔洞柱和空柱。
- spy 验证完整几何构建中每个椎体只计算一次矢状四边形。
- 运行现有阶段三、阶段四和阶段五相关测试。
- 对保留的真实腰椎分割分别运行优化前后代码，递归比较几何结果，并记录耗时。

## 实测结果

### 离线等价性基准

- 数据：`腰1_1mm`，分割尺寸 `512x512x326`。
- 几何构建：`16.894195s -> 4.762148s`，加速 `3.55x`。
- 优化前后结果 JSON 均为 `53,556` 字节，SHA-256 均为
  `23edb1fd8e6d06cbde480b518d901ffe40a6f0e0e1e327668a750466254545ad`。

### 完整 Pipeline 实跑

- 数据：`腰3_1mm`，非 Debug 产物模式。
- `build_spine_body_geometry`：`23.259s -> 6.974s`，减少 `16.285s`
  （`70.0%`），加速 `3.34x`。
- 阶段三：`28.374s -> 12.097s`。
- 排除分割后的总耗时：`40.621s -> 24.361s`，减少约 `40.0%`。
- Pipeline 总耗时：`132.76s -> 115.30s`。
- 计划数量、各计划切片数、CPR 14 张、`609x279` 输出、28 个厚层子曲面、
  offset 范围和 `219.612mm` 曲线长度均保持不变。

## 非目标

- 不调整主体筛选阈值、CPR 曲线、层厚采样数或窗宽窗位。
- 不增加椎体级、CPR 切片级线程池。
- 不修改正式 DICOM 图像生成逻辑。
