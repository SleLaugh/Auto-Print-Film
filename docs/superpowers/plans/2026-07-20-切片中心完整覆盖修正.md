# 切片中心完整覆盖修正实施计划

> **供执行人员使用：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项实施本计划。各步骤使用复选框（`- [ ]`）跟踪状态。

**目标：** 让所有直线切片计划的首末成片中心覆盖目标边界，修复肺部掩膜为 `z=103..522` 时输出中心仅到约 `105..520` 的问题。

**架构：** 保留阶段三原始目标边界和阶段五重建职责，仅修改阶段四通用 `cover_segment_range`。切片数量只由目标长度与中心间距决定，超出量首尾对称分配；层厚继续只影响第五步厚层采样。

**技术栈：** Python、SimpleITK、NumPy、unittest。

## 全局约束

- 所有部位、三个直线状位、整切与区间切共享同一中心覆盖规则。
- 相邻切片中心严格保持请求的 `slice_spacing`。
- 首末中心允许超出目标，不允许位于目标边界内侧。
- 不修改阶段三定位或阶段五 MPR 采样逻辑。
- 不修改或提交用户的 `.vscode/launch.json`，本次不执行 Git 提交。
