# CPR 端点原始标注边界延伸设计

## 目标

在现有 CPR 首尾端线方向已经正确的基础上，只延长端线长度，使端点到达当前白线沿线穿出首末椎体原始标签的位置。

首末标签来自阶段三解析后的实际配置范围。胸椎默认是 C7 和 L1，两者分别负责
胸椎 CPR 的首尾出口；不能改用固定 T 段或跳过配置首尾标签。

## 已确认根因

首末椎体的全量 `bbox` 包含椎弓、棘突等偏离白线的结构。使用其全局头足极值，会把端点拉到并不位于白线上的远端角落。本病例首端实际沿线出口约为终端质心外 `8.2 mm`，bbox 算成 `33.1 mm`；尾端实际约为 `13.9 mm`，bbox 算成 `37.4 mm`，因此视觉上上下各多出约一个椎体。

## 行为约束

- 保留现有端面查找和反弧回正结果，不重新计算端点方向。
- 只沿“终端质心指向当前端点”的射线向外延长。
- 使用首末椎体在原始分割中的标签体素判断沿线出口，不再使用 bbox 极值。
- 当前端点必须位于对应原始标签内；否则保持当前端点，不猜测补偿。
- 短暂的单体素孔洞不视为标签出口；连续离开超过一个体素对角线才确认出口。
- 返回连续离开前最后一个仍位于标签内的采样点，避免把线画到相邻结构。
- 缺少原始分割、标签 ID、有效端线或有效出口时保持当前端点。
- 中间质心、平滑曲线算法和端线拼接方式保持不变。

## 几何方法

1. 在 `_build_annotation_centroid_path` 完成端面选择和反弧回正后，取得现有首尾端点。
2. 读取 `seg_for_reconstruction_path` 指向的原始分割图像，一次读取供首尾共同使用。
3. 以终端质心 `C` 和当前端点 `P` 建立单位外延方向 `D = normalize(P - C)`。
4. 从 `P` 开始，以不大于最小体素间距一半的步长沿 `D` 向外采样。
5. 用 SimpleITK 物理坐标变换查询采样点所在体素是否属于当前终端标签 ID。
6. 标签内更新最后有效点；标签外累计离开距离。连续离开距离达到体素对角线时，返回最后有效点。
7. 搜索距离上限使用图像物理对角线，防止异常数据造成无界循环。

## 验证

- bbox 极值远离白线时，首尾只到达原始标签沿线出口。
- 延长前后的端线方向严格共线且同向。
- 单体素孔洞不会导致提前终止。
- 原始分割或标签缺失时保持现有端点。
- 既有反弧回正、曲线平滑及完整测试集继续通过。
- 当前病例复算中，首端由 `2.163 mm` 延长到 `8.022 mm`，尾端由
  `12.752 mm` 延长到 `13.728 mm`，两端延长前后方向点积均为 `1.0`。
