> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为颈椎、胸椎、腰椎的矢状位/冠状位请求生成并执行第一版 `curved_stack` CPR。

**Architecture:** 阶段四新增脊柱 CPR planner，第一版从阶段三 `coords` 的椎体质心和 bbox 生成中心曲线、偏移 offset 和 `curved_stack` plan。矢状位按左右方向展开，冠状位按前后方向展开。阶段五新增 `CurvedStackResampler`，并按 `geometry_type` 分发到直线 MPR 或 CPR 重采样器。失败或点数不足时阶段四降级到现有直线整切。

**Tech Stack:** Python、NumPy、SimpleITK、unittest；不新增第三方依赖。

## Global Constraints

- 文档、提交信息和面向用户的错误信息使用中文。
- CPR v1 支持颈椎、胸椎、腰椎的矢状位和冠状位。
- CPR v1 不实现手动画线、厚层融合 CPR、椎间盘区间精切。
- 区间切代码不作为本计划的依赖，不扩大区间切改动。
- 胸椎输出目标段按 T1-T12 限定；C7/L1 只作为方向辅助，不扩大 CPR 曲线或胸椎冠状位重建范围。
- CPR 定位线和调试总览必须画在矢状位背景上，使用 `curve_points + offset_axis * offset_mm` 投影后的曲线，不复用普通平面切片交线。矢状位左右 offset 在矢状位背景上重合为一条曲线；冠状位前后 offset 应显示为多条弯曲线。
