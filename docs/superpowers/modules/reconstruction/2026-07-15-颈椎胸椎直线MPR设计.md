# 颈椎与胸椎直线 MPR 设计

## 当前范围

- 颈椎整切配置默认 C1 至 C7；C1 参与全量定位和直线切图覆盖，但不参与
  过滤标注质心、CPR 和横状位姿态统计。
- 胸椎整切配置默认 C7 至 L1，第四阶段展开并定位 C7、T1–T12、L1。
- 配置首尾由 `src/config/slice_part_config.json` 的具名区域提供，不在 planner
  重复硬编码。

## 第五阶段三维坐标

颈椎和胸椎使用配置开始、结束椎体的全量物理质心建立整体脊柱轴，并结合 DICOM
左右方向构造正交三维坐标。范围使用配置内全部有效椎体的全量 Mask 投影；过滤
标注/四棱柱质心只供冠状位 CPR，不覆盖这套直线坐标。

开始或结束椎体缺失、两点重合、方向无法归一化或坐标无法正交化时明确报错，不能
回退到看似正常的默认 XYZ 方向。中间标签缺失时使用实际可用范围并写 warning。

## 第六阶段状位

- 颈椎横状位：法向使用整体脊柱轴。
- 胸椎横状位：按临床规则保持输入 DICOM 默认水平横切。
- 颈椎、胸椎矢状位：使用包含整体脊柱轴的直线 `plane_stack`，输出上下方向
  使用投影到切片平面的 DICOM 头脚轴；定位图背景为冠状位。
- 冠状位：不使用本直线方案，交给脊柱 `curved_stack` CPR。

直线计划的中心、范围、层间距和定位图方向全部在第六阶段确定。第七阶段只根据
`SlicePlan` 执行 MPR 和写盘，不增加颈椎/胸椎业务分支。

## 验证

- 配置范围内首尾标签和全部中间标签被第四阶段正确展开。
- 胸椎 C7/L1 同时进入全量定位、直线范围和冠状位 CPR。
- 颈椎 C1 只从过滤质心/CPR 排除，不从直线覆盖范围删除。
- 胸椎横状位保持默认水平，矢状位保持整体脊柱方向。
- DICOM `ImageOrientationPatient`、`ImagePositionPatient` 和 Localizer 交线
  与第六阶段计划一致。
