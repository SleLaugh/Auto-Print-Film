# 椎体主体外包络四棱柱与端部恢复设计

## 当前结论

第五阶段不把椎体改造成图像轴对齐的正方体或长方体。普通椎体先从完整 label 中
提取前方主体，再用可信矢状投影拟合保留椎体倾斜角度的四边形，最后沿左右方向
挤出为填满的四棱柱。

真实长扫描病例证明，以下两个极端都不稳定：

- 只保留最大三维/二维连通块，会在单层薄断点处误删有效椎体端部；
- 强制包住主体候选的全部投影，会把后方附件或高支撑碎块重新带回四边形。

普通椎体当前采用“核心投影 + 可信端部恢复”，判断依赖连通关系、相对体量、
头脚位置和横向重合度。C2 旧筛选为空时另有符合其齿突解剖形态的受限恢复，
见下文；所有路径均不读取病例目录名、患者名或扫描协议名称。

## 不变项

- 原始分割和完整 `coords` 的质心、bbox 不修改。
- 椎弓根、横突、棘突等后方附件不参与普通椎体四棱柱。
- 颈椎任务的 C1 仍不进入过滤主体、四棱柱和颈椎 CPR；全脊柱按配置确定范围，当前从 C2 开始，
  S1 继续使用专用主体规则。
- 四棱柱保持斜四边形的四条直边，不能退化为图像轴对齐矩形。
- `椎体主体掩膜.nii.gz`、`椎体四棱柱掩膜.nii.gz` 和既有 JSON 字段保持稳定。
- 第六、七阶段只消费第五阶段几何，不按病例增加补丁。

## 普通椎体主体提取

### 逐层主体候选

每个 label 只在自己的局部 bbox 内计算。每个横状位层面从前向后选择第一段稳定
宽行，再选择最接近左右中心的连续 x 段；分裂的后方行、离中心较远的侧向段和
宽度突增段在这里排除。

主体候选随后依次经过：

1. 原始 label 小三维连通块清理；
2. 主三维连通块与可信端部块选择；
3. 头脚两端连续低支撑薄层裁剪；
4. 左右边缘 SI 高度断崖裁剪；
5. 再次执行端部薄层裁剪，处理边缘裁剪后暴露的薄片残留。

### 后方短横桥的物理厚度保护（2026-11-04）

`_select_vertebral_body_support(...)` 增加仅限关键字参数
`reject_posterior_sheets=True`。它不放宽原有 AP/LR `0.35` 和体量 `10%` 的筛选
规则，而是在紧凑候选选择前排除额外一种错误：稳定前方主体因 AP/LR 偏扁而落选，
宽而短的后桥稍超残块体量阈值后抢占主体。

在既有左右居中候选集合中（无居中候选时使用全部候选），以体量最大的候选作为
优势参考。新排除条件必须同时成立：

1. 待判候选的 AP 中位位置在优势参考后方；
2. 待判候选的连续 SI 支撑不足参考的一半；
3. 待判候选的物理 SI 支撑长度乘以 `2`，仍小于其物理 AP 深度与 LR 宽度中的较小值；
4. 优势参考自身的物理 AP 深度至少达到其 SI 长度与 LR 宽度较小值的 `0.35`，
   证明参考是有三维厚度的前体，不能让大前薄片否决真正后体。

各物理长度均使用当前 spacing；少数层但层厚足够的后方实体不会仅因层数少而
被这一新条件排除。前方薄片与完整后方实体的反例（包括六层矮实体）继续使用
原选择逻辑。主体阶段调用时，对 C2 显式设 `reject_posterior_sheets=False`，保留
C2 既有候选选择及下节仅在最终为空时执行的恢复。

这项保护适用于通用候选形态，不依赖 C7、患者名或目录名；它可能纠正符合条件的
其他椎体，不能据此承诺所有主体结果不变。`10000549` 第二序列的 C7 为本次真实
验证触发点，原陡斜间隙在 C2 补丁前已存在。冻结输入下的四序列计划与 48 个
mask 对照范围见[颈椎椎间隙设计](../cutting/2026-08-21-颈椎椎间隙设计.md)。

### 旧 C2 主体为空时的恢复（2026-11-04）

通用主体筛选可能偏向 C2 的窄长齿突，且基底关节翼会把前方主体拆成多个候选。
仅在通用筛选与裁剪全部结束后主体为空、且标签语义为 C2 时，尝试
`c2_inferior_body_recovery`；正常 C2 和其他椎体不进入该路径。

恢复只从原标签中选择体素，不外扩标签或改变 `coords`：

1. 各 SI 层寻找穿过左右中心的连续 LR 段，取具有足够物理宽度和深度的前方带，
   防止越过椎管进入后方附件；
2. 按真实 spacing 计算三维内接球，要求有足够厚实的基底，再只保留与该球种子
   相连的前方连通体，孤片和中间断开的窄尾不能作为齿突证据；
3. 核实基底半峰宽区间具有足够物理高度，另一侧存在足够长且明显更窄的连续齿突；
   SI 索引反向时仅在局部翻转分析，结果映回原数组；
4. 取宽基底半峰宽的上界截断齿突，继续执行原端部、左右边缘和横向密度裁剪；
   最终须保留内接球种子、足够主体体量及头脚跨度，否则恢复失败。

恢复主体仍按既有方法拟合四边形和四棱柱。但插入恢复 C2 时，先计算不含它的
既有四棱柱结果，再与包含它的结果逐体素比较；只有所有既有四棱柱完全一致时
才接受新增 C2，可以只裁剪新增 C2 自身。若需改动既有四棱柱，放弃新增 C2
四棱柱及该恢复间隙，不牺牲原间隙几何。

该恢复 mask 可以出现在第五阶段调试产物中，但恢复 annotation 单独存入
`interspace_recovered_annotations`，不加入全局 `filtered_annotation_centroids`。
恢复不改变全局姿态、CPR 或其他 interval 的输入；仅当原标签和 CT `density_drop`
共同核实 C2/C3 两个相向自然单面后，由 `C2_C3` 的局部视图消费。字段契约见
[主体几何输出设计](2026-07-27-脊柱主体几何输出设计.md)，验收范围与取景影响见
[颈椎椎间隙设计](../cutting/2026-08-21-颈椎椎间隙设计.md)。

### 可信端部三维块

最大三维连通块始终是主块。其他块只有同时满足以下条件才补回：

- 体素数至少为主块的 `10%`；
- 完全位于主块头侧或脚侧，不与主块 SI 范围交叠；
- 中间最多相隔 `1` 个空 SI 层；
- 自身至少跨 `2` 个 SI 层；
- AP 和 LR 包围盒分别与主块重合至少 `75%`，分母取两者较短跨度。

这些阈值由 `_is_aligned_terminal_component_bbox(...)` 统一判定。三维主体恢复和
二维投影恢复必须调用同一个判定，避免出现“主体已补回、四边形又把它丢掉”的
规则漂移。

## 矢状核心与四边形

### LR 支撑核心

对主体体素按 `(z, y)` 统计 LR 方向体素数。支撑阈值为：

```text
max(2, ceil(最大 LR 支撑数 * 0.35))
```

达到阈值的投影点按八邻域分组。主二维块按投影点数、LR 支撑总和、到全部支撑点
加权中心的距离依次排序选择。远端高支撑碎块默认不参与拟合。

若存在被薄断层隔开的投影端部块，只有在以下条件全部成立时才与主二维块合并：

- 投影点数和 LR 支撑总和都至少为主块的 `10%`；
- 满足相同的 `1` 层 SI 间隙、`2` 层 SI 跨度条件；
- AP 包围盒重合至少 `75%`。

三维阶段已同时检查 LR 重合，因此二维阶段不单独放宽左右条件。S1 调用该投影
函数时不启用普通椎体端部追加。

### 保持倾斜的外包络

1. 将可信投影点转换到当前图像的物理矢状平面；
2. 计算凸包并简化为四个主角点；
3. 沿四条边的外法向平移，直到全部可信投影点位于四边形内部或边界；
4. 若外移边交点退化，使用主体主方向约束的定向外接四边形回退；
5. 沿图像 LR 方向，以主体实际左右物理范围挤出三维四棱柱；
6. 按四棱柱八个物理角点计算局部栅格范围并填满内部体素。

回退仍是定向四边形，不是图像轴对齐 bbox。低 LR 支撑挂渣不属于“可信投影点”，
因此不会为了满足外包络而把附件重新包进去。

## 相邻四棱柱

四棱柱扩大后可能与相邻椎体外包络重叠。当前使用两组受保护主体矢状投影的
最大间隔直线作为单一分隔面，并在物理 spacing 下判断归属：

- 普通外包络重叠按该直线拆分，边界不能被逐体素距离顶成凹口；
- 两侧主体体素均受保护，拆分不能删除属于自身的主体体素；
- 优先使用完整线性分离；若少量分割边缘使投影不再严格可分，则遍历主体凸包边法向，
  先寻找两侧各自越线的唯一 `(z, y)` 投影点比例都不超过 `5%` 的最优直线；
- 上述路径均失败时，才检查投影丢失 LR 支撑信息的窄回退：按每个 `(z, y)` 点实际
  占用的 LR 体素数加权，两侧各自越线主体体素仍不得超过 `5%`，并同时满足下述
  共同 LR 层顺序和侵入深度约束；
- 容差回退仍以一条直线分隔，直线上的体素按稳定标签顺序归属，结果不能随字典遍历
  顺序改变；
- 严格分离、唯一投影容错和受限三维支撑回退均失败，或两个三维主体占用同一体素时，
  两侧四棱柱一起标记失败；
- S1 四棱柱先与 S1 专用主体 mask 做全局 bbox 交集，再参与相邻处理。

原有唯一投影 `5%` 路径保持不变；新增回退只接受真实三维整数主体体素，使用
LR 占用数恢复投影前的体素支撑，并要求：

- 至少有两个共同 LR 层，且共同层数占两侧各自已占用 LR 层数均不低于 `50%`；
- 对每个共同 LR 层，沿同一候选矢状法向，两侧主体投影严格有序：左侧最大值小于
  右侧最小值。各 LR 层可以有不同分隔位置，但不能在同层内交织；
- 两侧最深越线距离均不超过两个投影体素宽度，即
  `2 * (abs(n_z) * spacing_z + abs(n_y) * spacing_y)`，法向在物理坐标下归一化。

这允许左右不同位置的浅薄边缘在压缩为唯一 YZ 投影后略超限，同时保留真实三维
顺序证据；只在 LR 方向分家的两个主体、同层交织或深入的细尾不能据此恢复。
所有容错路径仍使用 `5%` 上限，且不放宽主体保护或棱柱零重叠要求，不修改原始
标签、主体 mask、椎间切面角度算法或 `spine_geometry` 协议。

第五阶段还在相邻过滤主体的局部包围盒内计算三维最近点对，保存到
`spine_geometry.interspace_body_pairs`。每个区间记录最小物理距离、最近点支撑数量
和中点物理坐标。该字段只提供椎间位置参考，不修改主体掩膜、四棱柱或标签归属；
计算使用局部距离图，避免为每个区间分配整幅 CT 大小的距离场。

### 大投影点集去重稳定性

主体 LR 支撑统计、矢状四边形拟合和相邻主体分隔都会处理大量重复二维点。
这些路径不得直接使用大规模 `np.unique(..., axis=0)`：NumPy 会把行转为
结构化 dtype 后调用原生排序，在多进程批量执行中可能以 `SIGABRT` 终止。

实现先将两列整数坐标平移到非负范围，再无损打包为一维 `int64` 键并去重：

- 键的数值顺序与原二维坐标字典序一致；
- `inverse` 和 `counts` 保持 NumPy 原契约，LR 支撑阈值不变；
- 矢状物理点仍按 `0.001 mm` 量化，四边形输入不变；
- 打包可能溢出 `int64` 时改用 Python 整数的确定性回退，不允许坐标碰撞。

该处理只替换去重计算方式，不修改主体筛选、四边形拟合、相邻分隔或 CPR
规划规则。第五阶段日志会记录“矢状投影去重: 一维整数键（稳定路径）”。

## 第六阶段区间切

第六阶段仍从相邻 `sagittal_body_quadrilateral` 解析椎间几何，但不直接使用最短距离
落在角点上的点对。当前做法是：

1. 找到两椎体相向的端边；
2. 在两条端边共同切向覆盖区间内选择有正间隙的代表性中点；
3. 用这对边界点生成有序头脚区间和斜横切法向；
4. 外包络只有轻微局部穿入时允许使用相向端边恢复顺序；十字穿越或完整包含仍
   判为无效并回退 bbox；
5. 若四棱柱代表范围比主体最近间隙小超过 `1mm`，且最近点至少有 8 个体素支撑，
   沿既有法向平移区间中心，使中心平面通过主体最近间隙中点。该步骤保持法向、
   有效长度、层厚、层间距和数量不变。

这样可避免角点最近距离把正常椎间线拉成锐角，同时仍保留每节椎体自身倾斜。

## CPR 连续性

CPR 使用四棱柱体素质心。中间质心反向回正必须先于首末端面路径构造执行，随后
首末直线段方向作为样条端点切向传入，避免直线端段与曲线连接处形成折角。靠近
末端的异常残差只在方向连续、幅度明显异常且调整不超过相邻间距 `10%` 时限幅；
S1 等真正末端锚点不移动。

## 为什么能适用于新图

普通椎体端部恢复没有病例名或 `L5` 分支。新图是否补回由上述相对几何决定：

- 小、远、横向错位的块继续被当作附件或碎片；
- 紧邻、宽度相符且有稳定厚度的端部块会被主体和四边形同时恢复；
- 分割严重粘连、端部缺失超过一层或几何证据不足时，规则宁可不补并走既有回退，
  不通过扩大固定 bbox 猜测缺失区域。

这些阈值仍是经验性保护边界。不同模型或极端层厚可能需要重新标定，但调整必须
基于一组病例的分布和回归测试，不能加入目录名、患者名等病例特判。
C2 的新增分支以齿突和基底形态为前提，只处理原主体为空的情况，不能据此
放宽其他椎体或省略形态与 CT 证据。

## 新病例排查顺序

按以下产物逐级定位，不能只看最终切线：

1. `标签掩膜.nii.gz`：确认模型原始 label 是否完整、是否粘连；
2. `椎体主体掩膜.nii.gz`：确认附件是否排除、有效端部是否保留；
3. `椎体四棱柱掩膜.nii.gz`：确认四条矢状边为直线、内部填满且无相邻覆盖；
4. `localization_result.json`：比较 `body_bbox`、`prism_bbox`、质心和端面；
5. `slice_plans.json` 与第七阶段 `Localizer`：确认区间方向和 CPR 连续性。

若问题出现在第 1 步，应优先处理模型分割；第 2 步才评估主体阈值；第 3 步检查
投影支撑、四边形和相邻分隔面；前面三步正确时才调整第六阶段规划。
