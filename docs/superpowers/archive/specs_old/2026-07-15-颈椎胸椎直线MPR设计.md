# 颈椎与胸椎三维直线 MPR 设计

> **历史设计：** 本文记录冠状位 CPR 实现前的三状位直线方案。当前直线 MPR
> 规则见
> [`../../modules/reconstruction/2026-07-15-颈椎胸椎直线MPR设计.md`](../../modules/reconstruction/2026-07-15-颈椎胸椎直线MPR设计.md)，
> 冠状位现在可以显式选择 MPR 或 CPR；CPR 规则见
> [`../../modules/reconstruction/2026-07-22-脊柱冠状位CPR设计.md`](../../modules/reconstruction/2026-07-22-脊柱冠状位CPR设计.md)。

## 目标

颈椎和胸椎共用一套整体脊柱直线坐标算法：连接配置范围内开始椎体与结束椎体的物理质心，得到完整 XYZ 三维脊柱轴。横状位切片全部与该轴垂直；矢状位和临时冠状位切片平面全部与该轴平行。

本轮只实现互相平行的直线 MPR。冠状位 CPR 暂缓，不能在本轮引入局部弯曲路径或不平行切片。

## 当前部位范围

- 颈椎切图整体范围：`C1 → C7`；C1 保留用于切图覆盖，但不参与 CPR 和横断位姿态判断。
- 胸椎整体范围：`C7 → L1`，使用 C7 和 L1 作为胸椎上下边界。
- 首尾标签继续由 `localization_config.json` 提供，算法不得在代码中重复硬编码。

## 统一处理原则

颈椎和胸椎使用同一个计算器和同一种 `AnatomicalGeometryResult`，部位差异只来自配置中的开始标签、结束标签和实际分割坐标。

不分别计算“冠状角度”和“矢状角度”。阶段三只产生一条完整三维脊柱轴；不同视图中看到的倾斜，是同一条三维轴在对应参考平面上的投影。

## 阶段职责

### 阶段三：解剖坐标计算

阶段三负责确定脊柱的位置、整体方向及覆盖范围：

1. 根据当前部位配置取得开始椎体、结束椎体以及范围内全部椎体标签。
2. 从每个标签 Mask 计算患者物理坐标质心。
3. 使用“结束椎体质心减开始椎体质心”得到三维脊柱轴。
4. 使用 DICOM 左右方向作为辅助参考，构造稳定的右手正交坐标系。
5. 将范围内全部有效椎体体素投影到最终三轴，计算目标边界。
6. 输出统一 `AnatomicalGeometryResult.global_frame` 和脊柱专属诊断信息。

此外，阶段三对颈椎、胸椎生成过滤标注及独立的
`spine_geometry.filtered_annotation_centroids`（标注质心）。该字段只
为后续 CPR 提供标注质心；本设计中的直线 MPR 仍使用完整 `coords` 和
`AnatomicalGeometryResult`，不能把标注质心混入普通定位结果。

阶段三不计算层厚、层间距、切片数量、画面像素大小和窗宽窗位。

### 阶段四：切片规划

阶段四读取阶段三的统一坐标系，根据请求的层厚、层间距和状位生成 `SlicePlan`：

- 横状位平面垂直于三维脊柱轴；
- 矢状位平面包含三维脊柱轴；
- 冠状位暂时使用同样包含三维脊柱轴的直线平面；
- 每个状位内部的全部切片严格平行；
- 使用全部椎体投影范围确定首尾边界和画面中心；
- 使用满足完整覆盖的最少切片数，并将不可整除产生的超出量对称分配到首尾；
- 按请求的固定层间距展开切片中心，不追加不等距尾片，也不遗漏目标边界。

阶段四 Debug 图必须绘制计划中的真实物理切片平面，不能重新使用默认 XYZ 轴画示意线。

### 阶段五：执行与定位图

阶段五不增加颈椎或胸椎判断，只执行阶段四传入的通用平面字段：

- `center`：单张切片中心；
- `normal`：单张切片法向；
- `row_dir`：输出图像水平方向；
- `col_dir`：输出图像垂直方向。

`PlaneStackResampler` 根据上述字段执行真实斜向 MPR。正式 DICOM 的 `ImageOrientationPatient` 和 `ImagePositionPatient` 必须与实际切片平面一致。

`Localizer.dcm` 继续使用原始 CT 的标准正交参考层作为背景，再计算每张真实切片平面与参考层的交线。只要计划带角度，定位线就必须显示为相同角度的斜线。定位图不跟随切片平面一起旋转，否则会隐藏切片相对原始人体的倾斜关系。

定位图参考层不能使用为了整图显示而平移后的 MPR 画面中心。阶段四应额外输出
`localizer_reference`，保存目标部位中心的患者物理坐标；阶段五优先使用该点在
定位面固定轴上的索引选择原始正交层。这样矢状位定位图会经过椎体中心，而不是
经过胸腔显示中心。该字段只决定定位图背景层，不改变 MPR 切片中心和方向。

## 三维坐标计算

### 脊柱轴

设开始椎体物理质心为 `start_center`，结束椎体物理质心为 `end_center`，先计算两点确定的无向直线：

```text
raw_spine_axis = normalize(end_center - start_center)
```

该直线同时保留左右、前后和头脚三个物理分量，不丢弃任何方向的倾斜。由于当前配置通常从上位椎体指向下位椎体，而统一解剖实体必须保持稳定的患者方向，最终轴符号与 DICOM 头侧方向对齐：

```text
spine_axis = raw_spine_axis
if dot(spine_axis, dicom_superior_inferior) < 0:
    spine_axis = -spine_axis
```

翻转单位轴只改变向量符号，不改变首尾质心确定的空间直线和切片角度。阶段四另行根据目标投影边界明确横状切片的上到下输出顺序。

### 左右辅助轴

直接使用 DICOM 左右轴可能与 `spine_axis` 不正交，因此先去掉其在脊柱轴上的分量：

```text
left_right_axis = normalize(
    dicom_left_right
    - dot(dicom_left_right, spine_axis) * spine_axis
)
```

随后使用 DICOM 左右方向固定符号，防止相同数据在不同运行中发生左右翻转。由于 `spine_axis` 已与 DICOM 头侧方向对齐，按下式构造的前后轴应与 DICOM 前后方向同向；若方向矩阵不满足该关系，应判定坐标构造异常，不能单独翻转前后轴破坏右手系。

### 前后轴

通过叉积构造第三根轴，并使用 DICOM 前后方向固定符号：

```text
anterior_posterior_axis = normalize(
    cross(spine_axis, left_right_axis)
)
```

最终三轴必须为单位向量、两两正交并满足右手坐标系。为了复用现有 `AnatomicalFrame` 字段：

- `left_right_axis` 保存校正后的患者左右轴；
- `anterior_posterior_axis` 保存校正后的患者前后轴；
- `superior_inferior_axis` 保存 `spine_axis`。

### 原点和范围

`origin` 使用范围内全部有效椎体体素的物理中心，不使用整幅图像中心，也不只使用首尾质心中点。

`bounds` 使用范围内全部有效椎体物理点在三个最终坐标轴上的最小、最大投影：

```text
projection = physical_point · unit_axis
```

因此首尾质心只负责确定方向，全部椎体 Mask 负责确定实际覆盖范围和画面中心。

## 三状位映射

### 横状位

- `normal = spine_axis`；
- `row_dir = left_right_axis`；
- `col_dir = anterior_posterior_axis`；
- 从全部椎体在脊柱轴上的头侧最大投影边界向足侧最小投影边界推进；
- 全部横状切片互相平行，并与三维脊柱轴垂直。

颈椎横状位使用上述垂直于脊柱轴的倾斜规则。胸椎横状位不再与颈椎共用
角度：使用原图 DICOM 默认横状位方向，从胸椎 C7–L1 目标范围的头侧向足侧
水平切割。胸椎矢状位和临时冠状位仍使用胸椎整体轴，不受该例外影响。

### 矢状位

- 切片平面由 `anterior_posterior_axis` 与 `spine_axis` 张成；
- 法向为校正后的左右轴；
- 从患者一侧向另一侧平行推进；
- 在冠状参考定位图上，切片交线与三维脊柱轴的冠状投影平行。
- 切片平面和定位线继续使用上述真实倾斜角度，但输出画面的上下方向不再直接
  使用脊柱轴；应把原图 DICOM 头脚轴投影到当前矢状平面，作为画面上下方向，
  再由该方向与平面法向计算左右方向。这样切割几何不变，成片按原图默认姿态
  摆正，脊柱自身的真实倾斜保留在画面内容中。

### 冠状位（临时直线 MPR）

- 切片平面由 `left_right_axis` 与 `spine_axis` 张成；
- 法向为校正后的前后轴；
- 从前向后平行推进；
- 本轮不沿脊柱局部弯曲路径展开。

## CPR 暂缓边界

真正的冠状位 CPR 需要每个椎体或连续中心线的局部方向，并沿曲线重采样。它与本轮“首尾两点确定一条整体直线、全部切片互相平行”的规则不同。

本轮不得：

- 为不同椎体生成不同横状位法向；
- 沿局部中心线改变切片角度；
- 把冠状位直线 MPR 命名为 CPR；
- 修改第五步协议以加入部位专属 CPR 字段。

后续 CPR 应作为独立设计，在现有 `local_frames` 或新的曲线路径协议上实现。

## 异常处理

### 首尾椎体缺失

开始椎体或结束椎体任一缺失时，不能自动回退到默认 XYZ 方向，因为这会生成外观正常但医学方向错误的结果。阶段三应明确报告缺失标签并终止当前部位处理。

### 首尾质心距离无效

当两质心距离过小、包含非有限值或无法归一化时，阶段三应停止并报告“脊柱整体方向无效”。

### 中间椎体缺失

如果首尾椎体存在但部分中间标签缺失，可以继续计算方向和实际范围，同时在 `warnings` 及 Debug 诊断中记录缺失标签。范围只使用实际找到的目标体素，不伪造缺失椎体位置。

### 正交坐标构造失败

当 DICOM 左右轴与脊柱轴近似平行，导致辅助轴无法归一化时，应停止并报告方向构造失败，不使用任意默认轴掩盖问题。

## 调试与验证输出

Debug 模式至少保留以下信息：

- 开始、结束椎体名称和物理质心；
- 参与范围计算的椎体列表及缺失列表；
- 完整 XYZ 三维脊柱轴；
- 脊柱轴相对 DICOM 三轴的方向差；
- 最终左右、前后、脊柱三轴；
- 三轴投影范围、物理中心和置信度；
- 三状位十字中线图；
- 三状位真实切片线图；
- 含原始 CT 的三状位切片总览；
- 第五步每个输出序列对应的 `Localizer.dcm`。

自动化测试必须覆盖：

- 具有前后和左右双向倾斜的合成椎体质心；
- 横状位法向与脊柱轴一致；
- 矢状位、冠状位平面包含脊柱轴；
- 每个状位内部切片严格平行、间距一致；
- 首尾对称外扩、完整覆盖且切片数量最少；
- 翻转 DICOM 方向矩阵后输出符号稳定；
- 首尾缺失、质心重合和中间椎体缺失；
- Debug 定位线与阶段四计划方向一致；
- 第五步 DICOM 方向标签与实际 MPR 平面一致。

## 兼容性

- 继续复用 `AnatomicalFrame`、`AnatomicalGeometryResult` 和现有 `SlicePlan`。
- 阶段五不增加颈椎、胸椎业务分支。
- 肺部保持当前标准 DICOM 方向和肺主体范围逻辑，不受本轮修改影响。
- 腰椎区间切保持现状，不在本轮复用整体脊柱轴。
- 颅脑角度设计暂缓。
