# 通用直线切割流程设计

> **当前适用边界：** 整切和区间切仍复用本文流程，但方向步骤已允许读取第五阶段
> 部位专属解剖坐标。表格中的“零角度默认方向”只表示通用兜底，不覆盖颈椎、
> 胸椎和髋骨等专属规则；脊柱冠状位 CPR 走独立 `curved_stack` 流程。

## 目标

第六阶段统一处理整切和区间切的直线规划，使二者只在“生成多少个待切区间”上存在差异，后续方向、图像范围、层厚、层间距和切片展开全部复用同一条流水线。

本轮实现默认零角度直线和 `full_plane`、`target_bbox` 两种图像范围。曲线切、人体回正和真实椎间角度识别不在本轮范围内。

## 概念边界

“范围”拆成两个不同概念，代码和日志中不能混用：

- `CutSegment` 表示沿切片排列方向“从哪里切到哪里”。整切产生一个区间，区间切产生多个区间。
- `line_extent_mode` 表示每张输出图像在平面内“切多大”。`full_plane` 覆盖原图空间，`target_bbox` 覆盖当前区间的目标区域。

切割方式、方向和图像范围相互独立：

| 维度 | 当前选项 | 职责 |
| --- | --- | --- |
| 切割方式 | `whole_range`、`interspace` | 生成一个或多个 `CutSegment` |
| 输出状位 | 横状位、矢状位、冠状位 | 提供默认直线坐标系 |
| 方向策略 | 本轮为零角度默认方向 | 后续可按区间产生独立角度 |
| 图像范围 | `full_plane`、`target_bbox` | 决定每张图的宽、高和中心 |
| 采样参数 | 层厚、层间距 | 决定厚层采样和切片中心数量 |

## 自上而下处理流程

1. 读取请求和定位结果。
2. 根据 `cut_mode` 生成 `CutSegment` 列表。
3. 针对每个区间、每个请求状位分别解析默认直线方向。
4. 根据 `line_extent_mode` 选择原图范围或当前区间目标范围。
5. 将范围投影到当前直线方向，计算输出宽、高和平面内中心。
6. 根据区间起止、层厚和层间距展开切片中心。
7. 生成既有 `SlicePlan`，交给第七阶段统一 MPR。

流程图见 `2026-07-13-直线切割流程.svg`。其中“确定从哪里切到哪里”在本设计中具体表现为“生成一个或多个 `CutSegment`”。

## 内部模型

### CutSegment

`CutSegment` 是第六阶段内部的不可变结构，至少包含：

- `group_name`：整切使用 `whole_range`，区间切使用 `L1-L2` 等稳定名称。
- `target_start`、`target_end`：当前目标区间沿默认堆叠方向的物理边界点。
- `target_region_bbox`：当前区间执行 `target_bbox` 时使用的体素范围。
- `source_labels`：产生当前区间的 label，用于调试和报告。

整切 resolver 返回一个 `CutSegment`，目标范围使用 `correction_scope_bbox`。

腰椎区间 resolver 返回多个 `CutSegment`。默认区间优先使用相邻椎体 bbox 相向表面的中心作为起止边界；缺少 bbox 时才回退到现有质心。`target_region_bbox` 默认使用相邻两个椎体 bbox 的并集，使范围切能够覆盖椎间区域及相邻结构。

### StraightPlaneFrame

`StraightPlaneFrame` 是第六阶段内部的不可变结构，包含：

- `row_dir`：输出图像横向物理方向。
- `col_dir`：输出图像纵向物理方向。
- `normal`：切片法向。

本轮只根据输入图像方向矩阵和横、矢、冠状位产生零角度方向，不增加外部角度参数。

以后增加角度时仍返回同一个结构，不修改范围计算、切片展开或第七阶段。不同椎间区间必须分别解析 `StraightPlaneFrame`，不能共用一个腰椎整体角度。

### ProjectedExtent

范围解析不能只返回固定坐标轴的 `width/height`，而应把范围角点投影到 `row_dir/col_dir`：

- `full_plane` 使用原图体素中心范围的八个物理角点。
- `target_bbox` 使用当前 `CutSegment.target_region_bbox` 的八个物理角点。
- 投影最小值和最大值决定宽、高。
- 投影中点决定每张切片的平面内中心，避免部位不在原图中心时整面切一侧覆盖不足。

本轮方向仍与输入图像轴对齐，因此投影结果应与现有无角度宽高一致。这个统一计算入口为以后带角度直线保留扩展能力。

## 整切

整切对 `correction_scope_bbox` 生成一个 `CutSegment`，并为请求中的每个状位调用通用直线计划构造器。

- `full_plane`：切片区间仍由目标部位决定，每张图宽高和中心覆盖原图平面。
- `target_bbox`：切片区间和每张图范围都使用目标部位框。
- 横状位继续按患者物理坐标头侧到足侧输出。

## 椎间区间切

区间切只输出横状位。医生在矢状位上确定区间和倾斜方向，但生成的是横状位或斜横状位图像；“矢状位确定方向”不能被误写成“输出矢状位”。

每个腰椎间区间独立执行：

1. 解析当前相邻椎体对应的 `CutSegment`。
2. 解析当前区间自己的横状位 `StraightPlaneFrame`。
3. 按当前区间计算 `full_plane` 或 `target_bbox` 图像范围。
4. 按当前区间的层厚、层间距展开切片。
5. 输出一个独立 `SlicePlan`。

本轮 `StraightPlaneFrame` 使用零角度横状位。后续端板或椎间角度算法只替换第 2 步：在矢状参考平面内围绕左右方向旋转 `col_dir/normal`，每个区间分别计算角度。

## 第七阶段执行契约

继续使用现有 `geometry_type="plane_stack"`、`PlannedSlice.center/row_dir/col_dir/normal` 和 `extent_mm`。

第七阶段已经根据这些字段执行一般方向的 SimpleITK 重采样，整面、范围、零角度和未来带角度直线不需要不同重建器。状位串行和状位内多窗位并行逻辑保持不变。

## 错误处理

- 缺少整切 `correction_scope_bbox` 时明确失败。
- 某个区间缺少两个端点 label 时跳过该区间并记录 warning，不影响其他完整区间。
- `interspace` 请求非横状位时由能力预检拒绝，不在 planner 中静默生成错误状位。
- 范围角点、方向向量或投影结果无效时带 `group_name` 抛出明确异常。

## 测试与验收

- `line_extent_mode` 未传时仍默认为 `full_plane`。
- 整切对横、矢、冠三个状位都能生成 `full_plane` 和 `target_bbox` 计划。
- `target_bbox` 的宽高使用当前状位对应投影，输出中心位于目标范围中心。
- 目标部位偏离原图中心时，`full_plane` 的输出中心调整到原图投影中心，不再一侧覆盖不足。
- 腰椎区间切生成多个 `CutSegment` 和多个独立横状位计划。
- 区间默认起止优先使用相邻椎体 bbox 相向边界，缺少 bbox 时回退质心。
- 区间 `target_bbox` 使用当前相邻椎体 bbox 并集，而不是腰椎整体 bbox。
- 整切与区间切都调用同一个通用直线计划构造器。
- 第七阶段继续直接消费重构后的计划，并保持现有窗位并行行为。
- 完整测试集通过。
