# 切片模块入口

本模块描述层厚、层间距、数量、有效范围、总范围和可配置范围扩展。当前规则以
[完整覆盖设计](2026-07-20-切片区间完整覆盖设计.md)为准，采样参数规则已于
2026-11-18 更新为至少提供一项。

## 当前有效规则

- 层厚、层间距和数量至少传入一项，缺少项由有效范围计算。
- 任意采样参数为 `0` 时按未配置处理；处理后没有有效参数则拒绝请求。
- 数量的非零值必须是正整数；仅数量时支持一张，零范围或均分后不大于 `0.001 mm`
  则报错。参数定义、完整公式和其他边界统一见[完整覆盖设计](2026-07-20-切片区间完整覆盖设计.md)。
- 只传数量时，层厚和层间距均取有效范围除以数量；只传层厚或层间距时，两者取同一值，
  再计算最少覆盖数量。提供两项时仍由有效范围计算第三项。
- 总范围按 `层厚 + (数量 - 1) × 层间距` 计算，首末厚层外缘覆盖有效范围。
- 三项齐全时，总范围较大则首尾对称外扩；总范围较小则保持数量并均分层厚、
  层间距。
- 椎间隙数量按每个有效间隙分别应用。
- 可按部位、切割方式和状位配置额外范围扩展，单位固定为毫米。
- 椎间隙上下扩展继续作用于层组，前后左右扩展在取景共同倍率确定后扩大成片面内画布，
  不改变层组、层厚、间距和张数；使用既有配置，无需新开关，详见[范围扩展设计](2026-07-20-切片范围扩展配置设计.md#数据流与职责)。
- 当前颅脑仅横状位 MPR 默认头侧扩展 `10 mm`、下侧 `0 mm`，冠、矢状位不加该余量；
  基础范围仍来自脑区，不将整个头骨或下颌作为层组目标。该工程余量不保证所有病例
  颅顶完整，也不能补出源扫描截断。定位线表示中心面，覆盖应核对首末厚层外缘。
