# 整组居中与 FillPercent 取景设计

补录于 2026-10-08，对应 `a48e47b`。此前讨论过的逐张自动拉满方案已被整组统一取景替代。
2026-10-16 更新：椎间隙改为同一部位、同一项状位配置共享图片矩阵和物理比例，各间隙独立居中。

## 概念与协议

每项 plane_configs 可传 FillPercent，有限数字范围 [0,100]，拒绝 bool、字符串和非有限值。
请求序列化与交付报告对整数比例输出整数，例如 100.0 回显为 100；真实小数保留精度。
该调整只影响 JSON 数字写法，不改变取景算法；字段名严格为 `FillPercent`，末尾不能带空格。
省略、null、0 均仅按整组目标范围居中，保留基础像素间距，不放大也不缩小；
正数让整组目标包围框宽或高先达到指定图像占比，另一方向不得超过它。
100 不是“原始倍率”，而是一方向的目标外边界贴到图像外边界；
0 才是保留原采样倍率。旧 line_extent_mode 字段和枚举已移除，传入会报错。

占比的参照物是输出图像，不是屏幕，也不是 ITK 的百分比。
目标原本占 60%，设 80 会放大为原来的 80/60 倍；原本占 95%，设 80 会缩小。
目标范围来自所选分割标签，不来自窗位后的亮像素，也不等于整个人体外轮廓。

## 分组和中心

| 切法 | 取景范围 | 不变部分 |
| --- | --- | --- |
| 普通 MPR | 当前计划全部目标标签在切面轴上的投影并集 | 切面方向和沿法向层位置 |
| 椎间隙 | 同配置各间隙共用矩阵及比例，按各自相邻椎体完整标签（含附件）居中 | 每个间隙原有斜横角度、层位置 |
| CPR | 全部厚层目标掩膜在共同展开图坐标内的并集 | 曲面路径、offset 及厚层采样定义 |

普通平面使用全部目标体素的投影极值，包含位置偏移和半体素外缘，而不是只挑面积最大的一层。
同组面内中心投影相同，只沿法向移动。末端小截面和空白层仍使用这组范围，
不逐张移到自己的中心或单独放大；不能要求组内每张都达到 80%。
缺少目标 label_ids、分割中没有目标或 CPR 整组掩膜为空时明确失败，不用背景兜底。

## 等比例公式

设输出矩阵为 Nx、Ny，原像素间距为 sx、sy，目标范围为 Tx、Ty，正数占比 p=P/100：

```text
f = max(Tx / (Nx*sx), Ty / (Ny*sy)) / p
new_spacing = (sx*f, sy*f)
线性放大倍率 = 1/f
```

占比以像素外边界定义，用 N×spacing；采样矩阵的中心跨度仍是 (N−1)×spacing。
两轴使用同一倍率，保留原像素纵横比；普通 MPR、CPR 输出矩阵不变。
目标中心由包围框中点确定，不是质量重心，也不是肉眼认定的椎体中心。
极小百分比若使物理视野无法有限表示，采样前明确报错。

椎间隙以前面各组画布为基准：按有效计划顺序，取末组之前各组基础矩阵的逐轴中位数，
按 NumPy rint 取整后作为同一部位、同一配置的共同 Nx、Ny；单个有效间隙使用自身基础矩阵。
再把各间隙在各自切面内的投影目标尺寸逐轴取最大值得到共同 Tx、Ty，正数 FillPercent 按上式计算一次。
末组的较窄或偏高画布不决定共同矩阵，避免把所有间隙一起缩小；
正数 FillPercent 下，全部目标尺寸仍参与比例计算以保证覆盖，不因末组排除画布参考而裁掉其目标结构。
不能把不同间隙的物理坐标包围框直接合并，否则层位置差会错误扩大视野。
各间隙保留自己的面内中心，共用 Rows、Columns、PixelSpacing 和物理视野；
解剖本身大小不同仍会显示大小差异，不通过拉伸改变真实比例。
0、null、省略时同样统一矩阵，保留原像素间距，scale=1，不额外按目标范围适配；
共同矩阵比某组原矩阵更小时，该组周边视野随之减少。
配置由 config_id、输出状位和部位隔离；旧计划缺 config_id 时按输出状位与部位分组。
仅实际生成的有效间隙参与统计；已生成计划缺少目标标签仍明确报错。

## 执行顺序

第六阶段仅透传 fill_percent，仍产生基础视野与原切面计划。
第七阶段从定位结果的分割路径读取目标，不能延长第三至五阶段临时 label 快照的生命周期。

普通 MPR/间隙先调整采样几何，再从原 HU 体数据直接重采样；
CPR 先在原曲面上采样 HU 和标签掩膜，再用组范围对展开图线性重采样。
CPR 掩膜用最近邻、厚层取并集；HU 用线性插值、厚层平均，两者不能混用。
CPR 不需要额外展开全体标签的三维点数组来计算平面投影。

取景发生在正式切片窗化前，各窗共用同一份成片几何及未取整的重建 HU，
随后按各自实际窗宽窗位生成显示灰度并写入对应标签。
原计划不被原地修改，重建结果逐层 framing 记录 mode=group、source=group_target、
目标尺寸、实际中心、间距与倍率，用于排查。
椎间隙另记录 output_size_xy、scale_scope=interspace_config、shared_target_size_mm、
shared_plan_ids，分别表示共同矩阵、比例适用范围、共同目标尺寸和参与计划。
canvas_reference_plan_ids 记录用于确定共同画布的前面各组计划。
预计算逐计划释放完整目标点云，随后仍逐计划采样 HU，不同时持有多组图像。

## DICOM 与已知限制

写出实际 PixelSpacing、ImagePositionPatient、ImageOrientationPatient；
SliceLocation 使用实际成片平面的法向投影。层厚、层间距、数量不因 FillPercent 改变。
普通平面组保持统一面内几何，避免逐张 spacing 变化引发体加载异常。
CPR 是展开图，不能由这些标签把原始弯曲解剖恢复成规则三维体，不能承诺与原 CT 精确三维联动。

取景包含裁取视野与重采样，不是简单改变查看器缩放，也不会创造原始细节。
100 可能保留另一方向的空白；不通过拉伸变形强行铺满宽高。
查看器自动对比度、物理比例与屏幕黑边另见
[请求级窗位与 DICOM 显示设计](../viewer/2026-10-08-请求级窗位与固定灰度显示设计.md)。
定位图不应用取景；调试时可输出原有定位图 PNG，不新增正式成片 PNG。
