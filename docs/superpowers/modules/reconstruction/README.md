# 重建模块入口

肺部、髋骨三状位普通 MPR 默认按所选标签取景，每侧余量 `5 mm`。
肺部、髋骨全部普通MPR状位统一使用原标签整组包络中心，整组固定中心、倍率与矩阵。
保留第六阶段原CT投影画框及物理宽高比，100容纳所选标签+余量；70、50同心向四周扩展视野。
0/null/省略、其他部位、CPR、椎间隙与定位图保留原规则。详见[整组取景设计](2026-10-08-整组居中与FillPercent取景设计.md)。

本模块覆盖第六阶段切片规划到第七阶段 MPR 执行，以及各部位直线 MPR 和脊柱 CPR。

## 当前有效规则

- 第七阶段消费第六阶段输出的 `SlicePlan`，不再按部位或切割方式重新规划切面、层厚、间距和张数。
- `FillPercent`对每个计划共用整组倍率。肺/髋正数普通MPR统一按原标签整组包络固定中心，
  保留原CT投影画框及物理宽高比；末端小标签和空层也固定。其他部位按厚层原目标与
  有界上下文联合居中，CPR按当前展开掩膜居中，联合范围为空时回退整组中心。
  椎间隙同一部位、同一项状位配置共用上下裁空前的矩阵与物理比例；
  共同矩阵取末组之前各组基础矩阵的逐轴中位数并取整，末组沿用，单组回退自身矩阵；
  投影目标尺寸取全部间隙逐轴最大值，正数 FillPercent 统一适配并确保目标覆盖。
  CPR 在展开图上求整组掩膜并集决定比例。0、null 或省略的目标取景保持既有整组居中和基础像素间距，
  正数按共同取景尺寸适配；肺/髋以所选部位为主，其他部位继续使用原获准显示支持。定位图背景不应用此
  取景。MPR 定位线直接由第六阶段真实平面求交，仅裁到底图边界，有效交线横穿底图，
  不表示正式切片的有限视野。切换 FillPercent 不改变底图几何、定位线位置或长度；
  CPR 定位线投影实际采样的 offset 中心曲线，绘线不回写原计划。
- 切割 `source_labels` 与显示上下文分开。脊柱正数取景从本次模型标签表补充同类椎体，
  并限定在原目标沿 LPS 头脚轴的物理外边界内；不混入无关器官或未显式选中的 sacrum。
  当前厚层按原目标与有界上下文联合居中，倍率逐轴覆盖原组投影与各层联合尺寸，
  必要时只统一放宽整计划或同配置所有间隙。CPR 先加入有界上下文再沿计划采样路径展开。
  0/null/省略不应用上述脊柱上下文，保留基础像素间距；平面成片仍执行上下裁空，颅脑有界骨取景按下述规则处理。
- 肺/髋正数普通MPR以所选标签整组投影包络加每侧 `5 mm` 为目标，整组固定中心、倍率和矩阵。
  统一使用 `selected_region`、缺省group中心、`canvas=original`，不再逐层追随目标或选择肺参考层。
  保留第六阶段原CT投影画框的Rows、Columns与基础像素纵横比，在原画框物理宽高比内等比适配目标。
  100完整容纳所选标签及余量，70和50在同一组中心宽高同时扩为100的1/0.7、2倍。
  直接从完整原CT采样，不预裁外围组织；不以完整人体限制倍率，目标框外皮肤、肋骨或骶尾结构允许越框。
  所有层、占比及窗位共用固定矩阵，不执行逐张上下ROI；小截面和不限制适配的一轴仍可留空气。
  不拉伸解剖、不将小目标逐张拉满；原切面、法向层位、范围、厚度、间距、张数和定位图不变。
  0/null/省略仍保留完整源切面、基础间距、scale=1 和整组中心，必要时扩大共同矩阵。
  其他部位、CPR、椎间隙和 Localizer 保留各自规则，显式身体 API 不属于生产排臂路径。
  `framing_target_size_mm`记录标签覆盖尺寸加余量，`selected_region.centering`记录中心类型；
  默认肺/髋全部为`group_selected_region`，包括小/空目标层；selected_region.canvas为original，无参考层字段。
  当前正数策略不记录人体保护/skin_edge字段；0/null保留complete_source_slab诊断。
  具体公式和全部诊断见[整组取景设计](2026-10-08-整组居中与FillPercent取景设计.md)。
- 椎间隙在 0、null 或省略时也统一上下裁空前的图片行列数，但保留基础像素间距。
  同配置各间隙在裁空前共用 Rows、Columns、PixelSpacing 和物理视野；裁后 Rows、
  垂直视野及中心可逐层不同，Columns、PixelSpacing 不变，同层各窗几何一致。真实解剖大小
  差异仍保留，不能强行把椎体拉成相同大小。不同配置、普通 MPR 和 CPR 独立计算。
  预计算逐计划释放目标点云，仅保存公共几何，HU 图像仍逐计划串行采样。
- `plane_stack` 厚层只平均有效源采样：轴对齐按实际支持厚度归一，斜切按有效子平面数归一。
  真实空气参与平均，越界填充值不参与；零支持像素保留 `-1024 HU`，不补出扫描外组织。
  原切面、厚层范围和张数不变，CPR 曲面融合不受这项规则影响。
- 除肺部、髋骨普通 MPR 外，`plane_stack` MPR 和椎间隙在 HU 厚层采样后、窗化前，
  逐张以 ROI 裁去首尾完全无源支持的行，
  保留全部有效像素、Columns、PixelSpacing 和采样网格相位，以裁后整幅图的物理中点作为显示中心；
  不按 HU 或窗化黑色裁剪，不取全组最短高度，不拉伸或补框。0/null/省略也执行；CPR 和 Localizer 不裁。
  整张无源支持的层保持原样并标记 `no_source_support`。这只消除上下完整无数据边带，
  不能消除斜切首末层图内完全超出源 CT 的局部黑区；完整横截面需要另行调整切割范围或方向。
  查看器的外框和铺满效果仍取决于 fit 设置与显示格宽高比。
- 取景后的实际位置、像素间距和方向逐张写入 DICOM；逐层居中和上下裁空均可能使相邻切片出现
  面内位置平移，不能假定为固定面内原点的规则直角三维体。CPR 是展开图，不能据此恢复原解剖三维结构。
- `plane_stack` 是当前已实现的直线 MPR 主协议。
- 当前启用部位的整切三状位共用第五阶段解剖坐标。颅脑、髋骨和可靠双侧肺使用
  左右对称面；颈椎、胸椎、腰椎、脊柱汇聚可靠逐椎体 LR，以输入 AP 投影和 LR×AP 构造三轴。胸椎横状位不再
  固定输入轴，髋骨冠/矢状位也使用最终坐标。质量不足时记录警告和回退原因。
- 颅脑默认以完整脑区在 AP/SI 平面内的形态主轴估计俯仰，只绕 LR 更新三状位共享坐标；
  质量不足时保留原 AP 投影并记录 `anatomical_geometry_diagnostics.pitch`。方向来自 `brain`，
  三状位基础范围和 `source_labels` 同样只用 `brain`。颅脑横状位 MPR 当前通过
  `range_extension` 默认头侧补 `10 mm`、下侧 `0 mm`，冠、矢状位不加这项余量；
  第六阶段以 `framing_superior_extension_mm` 快照传递头侧余量，第七阶段筛选同次明确
  `skull` 时仅同步增加最终 SI 上界，下界仍为脑区，辅助取景、居中和防裁边；所有 FillPercent
  均使用此有界取景目标，骨不能延长层组到面部、下颌。缺骨仅用脑区取景并警告，
  脑区接边报告截断风险，不补全扫描外组织。这不是听眦线或 AC-PC 对齐，原请求与模型无需调整。
  `10 mm` 是当前工程余量，不保证所有病例颅顶完整。首末厚层外缘表示覆盖边界，
  Localizer 线表示中心面，不能用第一条中心线替代上界判断。
- 脊柱、肺部、髋骨的普通整切 MPR 保留输入前后倾角，脊柱首尾质心仅用于范围有效性
  检查和诊断，不再决定全局 SI。无可靠 LR 时保持患者参考三轴并告警，`applied`
  反映实际姿态变化。头脚符号校准不等于抬头、低头。回正只改变
  刚性采样方向，不强行镜像、变形或拉平真实解剖。肺部通过镜像质量后还须验证
  两主体分居对称面两侧、沿 LR 分离且反射跨主体对应；两个连通域本身不能证明双侧。
  统一规则见[统一姿态设计](2026-10-16-统一解剖姿态与三状位回正设计.md)。
- 患者方向符号由 `patient_reference_axes` 统一确定，SI 朝 LPS `+Z`，冠状、矢状
  成片头侧向上；体素物理坐标仍按原 direction 换算。符号校准本身不改变斜扫描角，
  颅脑形态俯仰由第五阶段单独估计。
- 所有矢状位 MPR 与脊柱矢状位 CPR 沿患者前后方向显示，前方在左、后方在右，
  与原图的解剖方向一致；脊柱表现为椎体在左、棘突在右。像素采样与 DICOM 方向同步，
  兼容旧定位结果时也必须保持该方向。
- LR 方向唯一性检查识别涉及 LR 的近重根、圆柱角向信息不足和许可范围内等价面；
  LR 独立、仅 AP/SI 等谱不因此拒绝。拒绝结果保留质量原因与回退告警。
- `SliceType` 省略时默认 `MPR`；颈椎、胸椎、腰椎、脊柱冠状位和矢状位只有显式请求 `CPR`
  才沿椎体中心曲线生成偏移序列。冠状位沿前后方向偏移、横向覆盖左右，默认使用
  矢状位定位图；矢状位沿左右方向偏移、横向覆盖前后，默认使用冠状位定位图。
  偏移范围扩展读取当前输出状位的 CPR 规则。
- 矢状位 CPR 只展开冠状面的左右侧弯，保留矢状面的前后生理曲度。新计划以患者
  AP 作为 `curve_projection_axis`，将真实三维中心线投影到全组固定 AP 参考面，按
  LR–SI 投影弧长安排输出行，固定 AP 横向及不含 AP 分量的厚层方向；不承诺原图
  SI 毫米位置完全不变。冠状位 CPR 保持原三维曲线展开。
- `curve_points` 始终保存真实三维解剖路径。矢状位 CPR 的 offset 覆盖、横向宽度、
  采样和定位线共用投影几何；冠状定位背景仍读取真实路径的前后深度。旧计划缺少
  `curve_projection_axis` 时保持原三维展开，必须重新规划和重建才能应用新语义。
- 显式 CPR 规划条件不足时任务失败，不允许静默降级为 MPR。
- 脊柱 CPR 标签按第四阶段 `resolved_cut_configs["whole_range"]` 的首尾完整展开；
  当前整体默认范围为颈椎 C1–T1、胸椎 C7–L1、腰椎 T12–S1、脊柱 C7–S1，三状位 MPR 和两状位 CPR
  共用整体目标。颈椎 CPR 仍排除 C1，使用 C2–T1；胸椎使用 C7、T1–T12、L1，
  脊柱使用 C7、T1–T12、L1–L5、S1 共 19 个椎体，非颈椎任务不额外删除配置首尾标签。
  CPR 排除项不缩小三状位 MPR 的完整目标范围。整体范围扩展不新增既有五组颈椎、五组腰椎椎间隙；
  新增“脊柱”只注册三状位 MPR 和冠、矢状位 CPR。
- S1 标准配置不改写，运行时按实际 `label_targets` 优先选择 `vertebrae_S1`、否则
  使用 `sacrum`；整体轴诊断、三状位 MPR/CPR 的完整目标及椎间主体配对使用实际名。
  CPR、胸椎与脊柱冠状位 MPR、`L5_S1` 计划的显式 `source_labels` 使用实际标签名；
  其他整体 MPR 可用全局范围标记，由重建阶段读取全量定位目标。冠状位 MPR 必须先解析实际标签，
  再合并完整目标 bbox，不能因标准名缺失漏掉 S1；
  第七、八阶段消费已解析的计划，不重新按标准终点名寻找标签。
- 第五阶段输出的 `spine_geometry.filtered_annotation_centroids`（标注质心）负责 CPR
  中心线和弧度；第四阶段完整 `coords.*.bbox` 负责 CPR/区间切的覆盖范围。
- CPR 中间质心只有形成与相邻趋势相反的局部折返时才回正到双邻点预测位置；正常 C 型弯曲保持不动，L5 可修正而 S1 末端锚点不移动。
- 中间质心回正先于首末端面和原始 label 出口路径构造，避免下游仍读取未回正锚点；
  靠近末端的同向异常残差只允许在相邻间距 `10%` 内保守限幅。
- CPR 首末端面只有越出局部正常弧线区间时才回正到质心外延射线；正常连续弧线保持不动。
- 首末直线端段方向作为曲线样条的端点切向，保证直线与曲线相切连接，不在拼接处
  形成锐角。
- 回正后的首末端线保持方向不变，并沿原始分割搜索到白线穿出首末椎体标签的位置；不使用全量 bbox 极值决定端线长度。
- 平滑后的终端原始标签覆盖另按实际采样方向检查：新矢状位以冠状投影单位切向
  确定外缘和安全垫距离，再除以原三维单位切向的投影长度，沿原三维切线延伸。
  真实端段保持方向，投影后覆盖完整首末标签；无原始分割或标签体素时不按 bbox 补长。
- MPR、CPR 和椎间隙统一使用层厚、层间距、数量三选二规则；三项齐全时按有效范围
  执行对称外扩或保持数量后重算层厚、层间距。
- 脊柱冠状位和矢状位 CPR 的有效范围由原始标注体素外缘决定，再使用统一规则计算偏移位置。
- 矢状位 CPR 的基础横向视野覆盖完整标签相对各偏移曲面中心两侧的最大距离，
  新计划以整组固定 AP 参考为中心，包含生理曲度、前后不对称的后方附件；先完整
  采样，再执行 FillPercent 展开图取景。
- 椎间隙数量按每个有效间隙计算，例如 5 个间隙、每个 20 张会生成 100 张；缺失
  间隙不会把数量转移给其他间隙。
- 颈椎横状位椎间隙按统一切割部位配置生成；当前只生成 `C2_C3` 至 `C6_C7`。C1
  继续参与原始分割、整体定位和普通 MPR，但不生成 `C1_C2` 椎间隙计划。
- 颈椎、腰椎椎间隙以相邻椎体可靠的局部左右方向处理侧倾，并保留局部斜切位置；
  方向质量不足时记录警告并回退。区间几何解析及颈椎法向约束完成后统一确定显示坐标；必要时
  同时反转上下轴和法向，像素采样与 DICOM 几何同步改变，保留切面倾角、位置、
  层厚、层间距、张数以及上位到下位的排列顺序。已有输出需重新切割才会更新。
- CPR 全部 offset 共用一套经过紧弯约束的单位偏移方向场，对应行严格保持配置
  层间距；层厚等于层间距时相邻曲面不能留下未采样间隙。
- 偏移方向场使用固定 `80 mm` 标准支撑范围；全量范围增加常见外层时，不会改变
  主体范围中已经存在的 CPR 曲面，也不会让远层逐层变直形成扇形。
- 第七阶段 Localizer 和实际 CPR 重采样复用同一个偏移曲线入口，不能只修正
  定位线外观。
- 第七阶段会实际写出冠状位和矢状位 CPR 切片及 Localizer；CPR 曲面使用批量物理坐标换算与三线性插值，保持原有输出间距、厚层子采样数和算术平均语义，不通过降低采样密度换取速度。
- 第七阶段为每个 CPR 计划只准备一次共享偏移方向场和全部 offset 曲线；计划内
  各切片复用该几何，不能逐张重复平滑和搜索方向场。该复用不得改变像素、
  `Origin`、`Spacing` 或 `Direction`，日志以 `[CPR几何准备]` 标记一次性耗时。
  缓存键必须包含曲线投影轴与固定 AP 参考等全部采样几何输入，避免复用旧展开几何。
- CPR Localizer 对投影曲线使用与 SimpleITK 等价的 NumPy 批量仿射坐标换算，
  不逐线段重复进入 SimpleITK 原生单点转换；日志以 `[CPR定位图性能]`
  记录曲线数、点数与转换方式，正式切片几何和采样不受影响。
- Localizer 的背景图和定位线覆盖率分开保存。定位线按连续体素坐标做亚像素采样和
  双线性覆盖，窗位映射完成后再叠加到背景；DICOM 白线与 debug PNG 红线共用同一
  掩膜，避免斜直线显示成逐像素台阶。该掩膜只用于显示，不参与正式 MPR/CPR
  重采样、层厚融合或切片计划；定位线退化时也不能阻断正式切片写出。
- 同一计划的正式切片可按窗并行写出；各窗 Localizer 必须复用主线程冻结的三维
  位置和行列方向并串行写出，不能因窗位线程不同而退回二维默认方向。
- 正式切片各窗共用未取整的重建 HU，再按实际窗宽窗位分别生成 uint16 灰度；
  GDCM 写盘后补入实际窗位、`LINEAR_EXACT` 及对应 Rescale 标签。窗外数值已截断，
  定量数据应读取原始 CT 序列。Localizer 保留窗化背景与白线，以 Rescale 标签配合实际窗位显示；
  它是合成显示数据，不能用于定量 HU 测量，调试 PNG 显示不变。
- 第七阶段输出摘要必须随每个计划透传 `geometry_type`、`slice_thickness` 和
  `slice_spacing`，供第八阶段把最终 DICOM 标签与实际计划做硬校验。
- 第六阶段只把全部 MPR、CPR 和椎间隙计划写入 `slice_plans.json`，不再生成任何
  规划 NIfTI 调试图；定位核对看第七阶段 `Localizer.dcm`/`Localizer.png`。
- 默认脊柱矢状位保持既有直线 MPR 切图逻辑；显式请求 `SliceType=CPR` 时，矢状位也使用
  `curved_stack`，定位线仍画在冠状位背景上。
- 颈椎、胸椎、腰椎、脊柱矢状位 MPR/CPR 使用冠状定位背景时，保留原始 x/z 显示网格，
  沿脊柱前后深度 y(z) 逐行采样，不使用 MIP。CPR 深度来自计划真实 `curve_points`，
  MPR 来自第五阶段有效四棱柱/主体质心，几何不足回退原单层背景。
- 曲面背景上的 MPR 定位线由第六阶段真实无限平面与曲面求交，包含斜切，仅按曲面
  显示网格裁线，不按正式 MPR 取景矩形裁剪；CPR 维持实际 offset 中心曲线的 x/z 投影。
  背景和线仅用于定位图，不得改变正式切片的采样、
  范围、offset、层厚、间距或数量。
- 曲面 Localizer 是派生定位示意，DICOM 注明曲面采样和非平面空间语义；保留的
  空间标签只描述显示参考网格，不能据此当作普通原始冠状平面做精确三维联动。
  其余状位的定位图仍使用原正交背景。
- 腰椎五个横状位椎间计划仍按整体标签范围（当前 T12–S1）选择并共享矢状位主体
  中心层，只保留各计划自己的定位线；原统一参考点也作为单层回退依据。
- `localizer_plane` 和 `localizer_reference` 只选择定位图背景，不得改变
  `slices`、切片方向、切片范围、层厚或层间距。
- 颈椎、胸椎、腰椎、脊柱的首尾配置保留范围有效性检查和诊断职责，不承担全局方向估计；
  当前颈椎配置使 CPR 和椎间隙规划排除 C1，全量覆盖和首尾有效性检查仍保留 C1。
- 脊柱普通整切保留俯仰不改变局部椎间隙依据真实相向端面及相邻 LR 的斜切，也不改变
  CPR 中心曲线、端点和展开规则。
- 髋骨三状位方向由双侧主体边界镜像拟合决定，AB 仅作诊断；三个方向的覆盖边界
  均投影完整保留主体计算，不能用拟合采样点代替完整范围。
- CPR 规划的基础三维向量运算集中在 `planning/spine_cpr_math.py`；
  `spine_cpr.py` 保留规划流程和兼容的私有辅助名称，拆分不改变 SlicePlan 契约。
