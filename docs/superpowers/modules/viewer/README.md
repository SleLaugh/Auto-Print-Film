# 显示模块入口

本模块描述窗宽窗位和定位图展示。不负责 MPR 几何和 DICOM 写盘安全。

## 当前有效规则

- 每项状位配置按名称选择窗位，请求级 `window_presets` 可覆盖默认值或定义新名称。
- 查找优先级为本次覆盖表、默认 JSON；请求覆盖不改写默认配置。
- 正式切片直接按实际窗宽窗位把重建 HU 映射为 uint16 灰度，不先取整 HU；
  GDCM 写盘后补入实际窗宽窗位、`LINEAR_EXACT` 及对应 Rescale 标签，保持显示一致。
  窗外数值已截断，定量数据应读取原始 CT 序列。
- `Localizer.dcm` 保留窗化背景与定位线，使用 Rescale 标签配合实际窗宽窗位显示；
  它是 `RescaleType=US` 的合成显示数据，不能用于定量 HU 测量。调试 PNG 显示不变。
- 比较取景前后时应固定实际窗宽窗位。旧输出需重新切割才能更新像素和窗位标签。
- 第六阶段不生成 NIfTI 调试总览，切片位置检查使用 `Localizer.dcm`、
  `Localizer.png` 或 `metadata/slice_plans.json`。
- 调试模式下 metadata 目录只保留标签、椎体主体和椎体四棱柱三种 NIfTI 掩膜。
