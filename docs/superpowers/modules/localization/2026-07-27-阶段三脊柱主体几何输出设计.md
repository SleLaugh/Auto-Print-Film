# 阶段三脊柱主体几何输出设计

## 定位

该步骤属于**阶段三定位**，不是预处理、全局回正，也不是阶段五重建。它只在颈椎、胸椎、腰椎任务中执行；肺部、头骨、髋骨等部位不生成该结果。

## 输入与输出

阶段三继续读取完整的 nnUNet 分割，并同时输出两套互不覆盖的几何：

```text
完整 seg.nii.gz
  ├─ coords.*.centroid / coords.*.bbox
  │    完整 label 几何：定位、覆盖范围、首尾边界
  │
  └─ spine_geometry.body_centroids
       椎体主体几何：后续 CPR 中心线和弧度
```

`coords` 是既有定位契约，必须保持全量 label 的结果；主体提取不能回写其中的 `centroid` 或 `bbox`。

阶段三正式输出的 `spine_geometry` 包含：

- `method`：主体提取算法版本；
- `body_centroids`：每个可用椎体的主体体素质心和物理质心；
- `excluded_from_body_geometry`：明确记录排除的 C1；
- 完整几何的来源说明，指向 `coords` 和 `coords.*.bbox`。

## C1 规则

- C1 仍然进入 `coords`、定位 bbox 和切图覆盖范围；
- C1 不进入 `spine_geometry.body_centroids`；
- C1 不参与颈椎 CPR 中心线；
- C1 不参与横状位姿态/回正角度统计；
- 其他状位仍可切到 C1。

## 阶段边界

阶段三只负责从完整分割中派生主体质心，不负责生成 CPR 曲线、切片数量或重建图像。

阶段四读取 `spine_geometry.body_centroids` 生成 CPR 中心路径，同时读取 `coords.*.bbox` 扩展全量覆盖范围。阶段五只执行阶段四生成的 `SlicePlan`。

主体提取失败时，阶段三不修改原始定位结果；阶段四可以根据缺失主体质心触发降级或回退策略。
