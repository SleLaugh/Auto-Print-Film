# 脊柱 CPR 层厚层间距覆盖设计

## 背景

当前脊柱冠状位和矢状位 CPR 使用过滤椎体主体标注生成中心曲线，并使用原始首末标签沿线出口控制端点长度。本设计说明厚层覆盖：`offsets_mm` 决定各层偏移中心，冠状位沿前后方向、矢状位沿左右方向，`slice_thickness` 参与覆盖判定和厚层图像融合。

层厚、层间距和张数按统一规则计算，使 CPR 图像序列完整覆盖配置范围内的原始椎体标注体素，包括椎体主体、附件、骨刺和原始分割中的完整结构，同时保留既有中线弧度。

## 已确认约束

- 中线弧度保持不变，不重新拟合、不按原始全量标注重算质心。
- 首尾长度可以沿现有首尾切线方向延伸，保证覆盖原始标注的头足外缘。
- 覆盖区间使用现有 CPR 的 `offset_axis` 标量坐标；实际曲面以该方向为首行种子，
  使用紧弯稳定后的共享单位方向场按 offset 等距展开。
- 层厚参与覆盖判定，每张 CPR 图实际覆盖 `offset ± slice_thickness/2`。
- 偏移范围可以不对称，负侧和正侧分别按原始体素外缘计算。
- 偏移中心按有效范围和统一参数规则等距生成，不强制保留 `offset=0` 的中心层。
- 所有覆盖判定基于当前部位配置内的原始标签体素；排除项读取
  `spine_cpr.excluded_labels`，当前颈椎配置排除 C1，胸椎默认 C7 至 L1 全部参与。
- 不能因为延伸或覆盖计算把配置范围外的上下相邻椎体纳入 CPR 曲线或张数边界。
- 宁可最外层向外多覆盖几毫米，也不能少包任何配置范围内的原始体素。

## 方案比较

### 方案一：原始体素相对中心曲线覆盖，推荐

读取 `seg_for_reconstruction_path` 的原始分割，只抽取当前配置标签的体素物理点。每个体素点关联到现有中心曲线上的最近弧长位置，再计算它相对该位置在 `offset_axis` 上的有符号距离。所有体素点的最小、最大有符号距离形成相应状位的偏移覆盖区间。

优点是覆盖边界直接来自原始体素，和用户在 ITK-SNAP 中看到的标注一致；中线仍由过滤椎体主体决定，不被碎渣或附件拉歪。缺点是比 bbox 投影多一次 mask 点采样，需要做抽样或边界点优化。

### 方案二：完整 bbox 角点投影

沿用当前做法，把配置标签的 bbox 八角点投影到全局 `offset_axis`。实现简单、速度快，但 bbox 会把局部曲线、附件和远端空白一起放大，容易多切；当中心曲线弯曲明显时，bbox 全局投影不能表达“沿曲线两侧”的真实宽度。

### 方案三：全局 mask 投影

读取原始 mask，但只把体素直接投影到全局 `offset_axis`，不关联中心曲线位置。它比 bbox 更贴近真实体素，但仍忽略局部曲线，弯曲较大的胸椎容易出现局部少包或多包。

本设计采用方案一。

## 几何设计

### 1. 头足范围

现有 CPR 中线由过滤主体端面、全部过滤标注质心和首尾沿原始标签出口延伸得到。新逻辑在此基础上增加一次原始体素外缘检查：

1. 读取配置范围内全部原始标签体素。
2. 将每个体素点投影到 CPR 中线弧长方向，判断是否落在当前曲线的头足覆盖范围内。
3. 如果头侧或足侧仍有配置标签体素超出当前曲线端点，则只沿对应端点的现有切线方向继续延伸。
4. 延伸后不改变中间质心、不改变平滑曲线、不改变首尾方向。

这一步只保证长度到达原始标注外缘，不把相邻未配置标签纳入范围。
实现时只使用配置首末标签分别约束头侧和足侧延伸，并在原始体素投影外缘外再
保留约一个体素量级的小安全垫，避免定位线和 CPR 行采样刚好擦边；中间椎体或
配置外相邻椎体不能把整条 CPR 头足范围拉长。

### 2. 当前状位的 offset 覆盖区间

对每个配置标签体素点 `P`：

1. 在当前 CPR 中线上找到最近的曲线采样点 `C`，最近距离搜索忽略 `offset_axis` 分量，比较面内横向和头足弧长方向的接近程度。
2. 计算有符号偏移 `d = dot(P - C, offset_axis)`。
3. 用所有体素点的 `min(d)`、`max(d)` 作为需要覆盖的偏移区间，再应用当前输出状位 CPR 规则的 `range_extension`。

为避免整块 mask 的内部点带来不必要计算，实现时可以只使用原始标签边界体素，或按体素间距抽样后再加安全余量。安全余量不得小于半个体素对角线。

## 数量与层厚规则

原始体素相对中心曲线的最小、最大有符号偏移共同形成 CPR 有效范围。层厚参与
覆盖判定，每张 CPR 图像覆盖其中心曲面法向两侧各半个层厚；总范围按
`层厚 + (数量 - 1) × 层间距` 计算。

层厚、层间距和数量必须传入其中两项或全部传入，CPR 与直线 MPR、椎间隙共用
统一计算：

- 传层厚和层间距时，计算完整覆盖有效范围的最少数量；
- 传层厚和数量时，计算层间距；
- 传层间距和数量时，计算层厚；
- 三项全部传入且总范围大于有效范围时，把超出部分均分到偏移范围两端；
- 三项全部传入且总范围小于有效范围时，保持数量，层厚和层间距都调整为
  `有效范围 ÷ 数量`。

最终偏移从总范围的起点按实际层间距严格等距生成。统一算法不强制保留偏移为零
的中心层；偏移覆盖不对称时，整个等距序列随有效范围中心移动。首张和末张图像的
厚层外缘必须覆盖有效范围边界。层间距大于层厚时允许配置本身造成中间物理空档。

## 厚层重采样

第七阶段 `CurvedStackResampler` 从“单个 offset 采样一张曲面”扩展为“每个 offset 采样一个厚层 slab”：

1. 用共享等距方向场和当前 `offset` 计算中心曲面。
2. 为当前中心曲面重新计算逐行切向、面内横向和曲面正交法向。冠状位面内横向
   表达患者左右方向，矢状位表达前后方向。
3. 在当前层中心前后各半个层厚的范围内，按输入图像最小体素间距沿曲面法向取
   若干子采样面。
4. 每个子采样面沿当前 CPR 曲面、面内横向和局部头足方向采样 HU。
5. 对同一输出像素的多个 HU 值做算术平均，得到厚层 CPR 图像。

第一版只实现平均融合；MIP、MinIP 或其他融合模式后续再作为显式配置加入。

## 第六阶段输出

`curved_stack` 继续输出 `curve_points`、`offset_axis`、`offsets_mm`、`slice_thickness` 和 `slice_spacing`。

新增或明确以下内部语义：

- `offsets_mm` 已按原始标注体素和层厚计算，不能只按 bbox 中心或固定范围生成。
- `SlicePlan.slices` 中每个 CPR slice 的 `offset_mm` 对应厚层中心 offset。
- 日志记录原始标签 offset 区间，sampling_details 记录有效范围、总范围和实际采样参数；
  不承诺存在旧方案的负侧/正侧计数或兜底补张字段。
- 第七阶段 DICOM Localizer 只绘制全部 offset 中心线，并复用实际 CPR 的曲线
  弧长重采样和共享等距方向场。最外厚层边界只参与覆盖计算，不作为额外
  白线绘制。
- 第六阶段不写出任何规划 NIfTI；相关几何以 `slice_plans.json` 和第七阶段
  Localizer 为准。

## 降级与保护

- 规划 helper 在原始分割不可用时可回退 bbox 估算；正式重建取景仍要求有效分割，
  不能把 helper 的估算路径理解成允许无分割交付。
- 配置标签在原始分割中缺失时，只使用实际存在的配置标签，并写 warning。
- 有效质心少于 3 个时无法形成 CPR 计划；显式 CPR 请求失败，不静默替换为 MPR。
- `slice_thickness <= 0` 或 `slice_spacing <= 0` 时视为配置错误，不生成厚层 CPR。
- 原始 mask 体素数量异常大时允许抽样，但必须增加半个体素对角线以上的安全余量。

## 测试策略

第六阶段测试：

- 层厚和层间距计算出的数量必须让首末厚层外缘完整覆盖有效范围。
- 层厚和数量、层间距和数量两种组合均能计算出缺失参数。
- 三项全部传入时，分别验证总范围过大时偏移范围两端均分外扩、总范围过小时保持数量并
  重算层厚和层间距。
- 偏移覆盖不对称时，等距序列按有效范围中心定位，不要求包含零偏移中心层。
- 原始 mask 边界宽于过滤主体方块时，offset 区间使用原始 mask，不使用过滤标注。
- 胸椎默认 C7 至 L1 全部参与覆盖计算；当前颈椎配置使 CPR 排除 C1。
- 单独验证规划 helper 的 bbox 回退，同时验证正式重建在目标分割缺失时失败。

第七阶段测试：

- 按实际子采样数验证厚层均值；1 mm 层厚不意味着一个采样面，步长上限为 0.25 mm。
- 厚层平均对简单体数据输出可预测均值。
- 全部相邻中心曲面逐行保持配置间距；层厚等于层间距时没有未采样间隙，远层
  不形成焦点或扇形，且 Localizer 与实际中心采样点一致。
- 多个 offset 写出多张 DICOM，InstanceNumber 和文件顺序与 `offsets_mm` 一致。
- DICOM `SliceThickness` 和层间距相关元数据使用第六阶段计算出的实际值。

集成验收：

- ITK-SNAP 中冠状位和矢状位 CPR 均覆盖配置范围内全部原始椎体标注，不因过滤主体方块过短而丢首尾。
- 标注存在附件或碎渣时，中线弧度不被拉偏；只影响需要覆盖的宽度和张数。
- 最外层允许多覆盖，但不能少覆盖原始体素。
