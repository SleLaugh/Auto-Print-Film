# 脊柱冠状位与矢状位 CPR 设计

本文描述颈椎、胸椎、腰椎、脊柱显式请求的冠状位与矢状位 CPR。两者共用真实三维
解剖中心线和 `curved_stack` 重采样器，分别使用前后、左右偏移方向。冠状位沿三维
中心线展开；矢状位只展开冠状面的左右侧弯，保留矢状面前后生理曲度。省略
`SliceType` 或指定 `MPR` 时仍生成普通直线 MPR。

## 背景

当前第六阶段、第七阶段已经稳定支持 `plane_stack` 直线 MPR。颈椎、腰椎区间切
使用局部椎间隙几何生成斜横状位；该几何对终板、附件、骨刺和分割毛刺较敏感，
需要结合主体、四棱柱和定位图持续校验。

脊柱 CPR 使用过滤标注得到的椎体主体几何：按解剖顺序组织配置范围内
全部标注质心，首尾约束到首末椎体主体端面，中间质心链平滑，首尾端段保持直线，
最后按输出状位生成多张偏移 CPR 图像。冠状位沿前后方向偏移，矢状位沿左右方向
偏移；每张图的横向分别表达左右、前后结构。冠状位纵向沿三维中心曲线弧长，
矢状位纵向沿中心线在固定 AP 参考面内的 LR–SI 冠状投影弧长。

## 范围

当前 CPR 的支持范围：

- 支持部位：颈椎、胸椎、腰椎、脊柱；脊柱整体范围为 C7–S1。
- 支持状位：冠状位和矢状位 CPR。
- 输出形态：一组偏移 CPR DICOM 图像序列。
- 曲线来源：自动从椎体 mask 和定位结果生成，不提供手动画线入口。
- 视野范围：覆盖目标椎体主体和两侧附件、骨刺等结构。

本设计不包含：

- 椎间盘区间精切。
- MIP/MinIP 等非平均厚层融合模式。
- 手动画线或交互式编辑。
- 基于神经网络的椎管中心线。

## 用户可见行为

颈椎、胸椎、腰椎或脊柱冠状位与矢状位只有显式传入 `SliceType=CPR` 时生成 CPR 计划；
省略或传入 `MPR` 时生成普通直线 MPR。默认冠状位 CPR 的定位线画在矢状位背景上，
矢状位 CPR 的定位线画在冠状位背景上，实际选择来自各自规则的 `localizer_plane`。
颈椎、腰椎横状位只有显式传入 `SliceType=椎间隙` 时生成椎间计划。

输出目录保持按状位、窗位组织的结构，交付报告中的重建区域使用 `default`：

```text
矢状位/
  骨窗/
    1.dcm
    2.dcm
    ...
    Localizer.dcm
    Localizer.png   # debug 模式
冠状位/
  骨窗/
    1.dcm
    2.dcm
    ...
    Localizer.dcm
    Localizer.png   # debug 模式
```

冠状位 CPR 图像沿前后方向展开，矢状位 CPR 沿左右方向展开。是否含零偏移曲面由
有效范围与采样参数决定，不保证中间一张恰好经过基准曲线。
矢状位采样将中心线的前后坐标统一到整组固定参考值，横向保持患者前后方向，
因此图中保留原有前后弯曲幅度。纵向使用冠状投影弧长，不承诺所有结构与原图的
头脚毫米位置完全相同。这项修复不改变普通 MPR 或冠状位 CPR 的采样方式。
两端厚层覆盖目标标签在相应偏移方向上的外缘，便于观察
椎体、椎弓根、横突、骨刺和其他附件位置。

CPR 标签由第四阶段的 `resolved_cut_configs["whole_range"]` 决定。胸椎默认配置为 C7 至 L1，
因此 C7、T1–T12、L1 均进入 CPR 曲线和所请求状位的覆盖范围；腰椎及其他脊柱
任务也按配置范围完整使用。排除项读取 `spine_cpr.excluded_labels`，当前颈椎
配置排除 C1，不在代码中固定。
“脊柱”使用 C7–S1 的完整 19 椎体目标；S1 按本次实际 `label_targets` 优先使用
`vertebrae_S1`，不存在时使用 `sacrum`，曲线、覆盖与 `source_labels` 均使用实际名。
三状位 MPR 共用整体范围，CPR 排除项不缩小 MPR 的完整目标。

各脊柱部位冠状位 CPR 默认使用矢状位定位图，矢状位 CPR 默认使用冠状位定位图，
绘制配置目标段的全部 offset 中心线。矢状位 CPR 的冠状背景先在原图 x/z 显示网格
按真实计划 `curve_points` 的前后深度 y(z) 逐行采样 CT，再按
[通用定位图规则](../dicom/2026-10-08-定位图状位配置与取景隔离设计.md)细化粗显示轴，
保留固定参考点、方向、首末像素物理范围和物理路径映射，不使用 MIP；几何不足时
保留原单层背景。该优化也用于各脊柱部位矢状位 MPR，见
[曲面定位背景设计](2026-08-11-腰椎统一中心定位图设计.md)。
定位线复用实际 CPR 的采样路径、弧长重采样和共享等距偏移方向场；矢状位使用
冠状投影路径，不能直接将真实三维解剖中心线当作采样路径。紧弯处对方向场做
满足标准偏移范围稳定性所需的最小平滑，全部 offset 对应行严格保持配置间距，
避免焦点、回折和远层逐层变直。每条线都对应实际采集的一张 CPR 中心面。
曲线投影到定位图后使用连续索引的亚像素覆盖掩膜绘制，不再把每个采样点独立
取整成像素台阶；这一处理只改善 `Localizer.dcm` 和 `Localizer.png` 的显示边缘，
不改变共享方向场、offset、实际 CPR 曲面或输出切片内容。
曲面背景上的 CPR 线仍为实际 offset 采样中心曲线的 x/z 投影。曲面定位图属于派生定位示意，
DICOM 注明非平面采样，保留的空间标签不能将其还原为普通原始冠状平面。

Debug 输出保留当前仍用于排查和交付核对的内容：

- `slice_plans.json` 中的 CPR 曲线字段。
- debug 模式下，每个窗位目录的 `Localizer.dcm` 旁边额外写 `Localizer.png`，便于不用 ITK-SNAP 也能快速看定位线。
- warnings，包括缺失椎体、降级原因、标注质心回退和局部定位线连接信息。

第六阶段不再写出任何规划 NIfTI 调试总览，相关绘制方法和路径字段已经删除。
需要看定位线时，以第七阶段的 `Localizer.dcm`/`Localizer.png` 为准。

## 曲线生成

第六阶段从第四、第五阶段结果读取两套几何：

- 第五阶段 `spine_geometry.filtered_annotation_centroids`：由过滤标注得到的标注质心、局部头脚轴和主体端面中心，用于中心路径和曲率；
- 第四阶段 `coords.*.bbox`：完整 nnUNet label 的包围盒，用于左右/前后偏移覆盖和降级
  范围；首尾白线长度由原始首末标签的沿线出口决定。

第六阶段不从完整 label 的全量质心计算 CPR 中心线。过滤标注和标注质心由第五阶段
生成，第六阶段只负责使用这些几何生成计划。

每个椎体的主体 mask 在第五阶段完成提取：

- 第五阶段输出主体 mask 派生的物理质心；
- 第六阶段读取标注质心生成中心线；
- 第六阶段继续使用完整椎体 bbox（包括附件和骨刺）计算偏移覆盖范围；回正后的
  首尾端线从原始分割中搜索配置首末标签的沿线出口。

按本次整切配置确定椎体序列：

- 颈椎：展开配置范围后排除 `spine_cpr.excluded_labels` 指定的标签；当前配置
  排除 C1，当前整体默认范围 C1 至 T1，因此 CPR 使用 C2 至 T1。三状位 MPR 和
  冠状位、矢状位 CPR 共用该整体目标，既有五组颈椎椎间隙不随整体终点扩展。
- 胸椎：默认配置 C7 至 L1，展开得到 C7、T1–T12、L1。
- 腰椎：使用实际配置范围，当前默认 T12 至 S1，不在代码中固定某一组标签。
- 脊柱：默认 C7 至 S1，包含 C7、T1–T12、L1–L5、S1，共 19 个椎体。
- 定位结果缺少 `resolved_cut_configs["whole_range"]` 时，不生成 CPR，并由显式
  CPR 请求的校验返回失败；不使用代码内默认标签列表回退。

有效椎体点少于 3 个时，不生成 CPR，显式 CPR 请求直接失败。

有效标注质心达到 3 个后，在物理空间生成 CPR 基准路径：

- 每个椎体只贡献一个过滤标注质心。
- 第六阶段先按头侧到足侧生成 CPR 锚点：中间为相邻椎体标注质心。
- 如果首末椎体存在主体四面几何，则路径锚点为“首端面中点 → 全部标注质心 → 末端面中点”；首尾端面约束来自过滤主体矢状投影轮廓四边形的四条大边：第六阶段先找相邻质心线进入首末椎体的入射面，再取同一轴上的对侧大面中心，避免选到 PCA 外接矩形角点或斜边。输入缺少四面几何时，才回退到端部候选中心，不使用全量 bbox 角点。
- 先按反向折返、局部折角和末端限幅规则修正必要的中间质心，真正首尾质心不移动；
  修正后的质心作为 Hermite 硬锚点。首尾端面只有越出局部正常弧线区间
  或回折时才修正到端部质心外延方向的 `0°` 射线，正常连续弧线保持不动。
- 反弧修正后保持“终端质心 → 当前端点”的方向，沿原始首末标签向外搜索到白线
  实际穿出标签的位置；不使用全量 bbox 极值拉长端线。
- 平滑后的 `curve_points` 还会用配置首末标签的原始体素做头足兜底：若终端原始
  标签仍有体素超出采样路径端点，则只沿当前真实三维首尾切线继续延伸，并额外
  保留体素级安全垫。冠状位按原三维单位切向计算所需距离；新矢状位按去掉 AP
  分量后的冠状投影单位切向计算距离 `d`，再除以原三维单位切向的投影长度，
  换算真实三维延伸量。这样投影端点也覆盖标签外缘，真实端段保持共线同向，
  不移动中间质心。缺少原始分割、标签 ID 或实际标签体素时不执行兜底，不能用
  bbox 猜测补长。详见[端点覆盖设计](2026-07-29-CPR端点原始标注边界延伸设计.md)。
- `SlicePlan.curve_points` 基于上述锚点生成圆滑加密中心线：全部修正后质心硬锚点精确
  保留，中间质心链平滑，首尾端点到终端质心的区段保持直线，第七阶段继续按曲线
  采样路径的弧长生成最终 CPR 图像行。该字段始终保留真实三维路径；矢状位另用
  `curve_projection_axis` 在采样时投影到固定 AP 参考面，不覆盖真实路径。
- `local_superior_inferior_axis` 和 `local_superior_inferior_extent_mm` 暂存为后续局部定位线阶段的输入，本阶段不把它们展开为椎体内线段。
- CPR/区间切的范围可以继续使用全量标注 bbox，但范围端点不进入基准中心线。

## CPR 坐标系

先确定采样路径：冠状位使用原三维 `curve_points`；矢状位新计划设置患者 AP
方向的 `curve_projection_axis`，沿该轴把真实路径投影到全组固定的 AP 参考面。
参考值来自计划切片中心的 AP 坐标，各层相同。投影后的路径仅随 LR 和 SI 变化，
AP 生理弯曲由组织在固定 AP 横向上的位置差保留，不能再逐行跟随真实路径的 AP
坐标居中。原始真实路径继续供冠状定位背景的 y(z) 深度采样。

每个采样路径点都有一个局部坐标系：

- `tangent_dir`：沿采样路径头脚方向。
- `offset_axis`：冠状位取输入图像前后轴，矢状位取输入图像左右轴，均通过
  图像方向矩阵换算到物理空间，作为共享局部偏移方向场的朝向种子。
- `row_dir`：垂直当前曲面切向和偏移方向的面内横向，冠状位表达左右方向；
  矢状位固定为患者前后方向，不随原有 AP 生理弯曲旋转。

CPR 输出图像的阅读方向：

- 图像行方向（左到右）：冠状位沿患者左右方向，矢状位沿患者前后方向。
- 矢状位横向符号与普通 MPR 的患者前后参考一致，椎体在左、棘突在右；
  原始存储轴反向不改变这一阅读方向。
- 图像列方向（上到下）沿采样路径从头侧到足侧的弧长方向；矢状位为冠状投影
  弧长，不等于原三维弧长，也不承诺原图 SI 毫米坐标逐点不变。
- 每个层沿共享单位方向场按 offset 生成曲面中心；当前 offset 曲面按自身切向
  构造逐行 `row_dir` 和厚层法向。矢状位厚层方向保持在 LR–SI 平面，不含 AP
  分量，避免厚层采样再次把前后曲度展开。
- 重采样按计划 `row_dir` 统一选择逐行横向的符号，同时反转对称厚层法向，
  保持图像方向矩阵为右手系；`offset_axis`、偏移覆盖、中心曲线和切片顺序不变。

这样输出上下保持头脚一致，横向表达对应状位的面内解剖方向，避免图像随曲线局部扭转。

两种状位的 CPR 都按共享等距方向场生成曲面：

- 自动计算配置范围内原始椎体 label 体素相对中心曲线的最小、最大偏移：
  冠状位沿前后方向，矢状位沿左右方向。
- 根据层厚、层间距、数量和有效范围生成严格等距的厚层 CPR 偏移曲面，最外层
  必须完整覆盖原始体素外缘。
- 偏移覆盖不对称时，整组偏移位置跟随有效范围中心移动，不强制包含零偏移曲面。
- `slice_rules.<输出状位>.CPR.range_extension` 在相应偏移轴上扩展负向、正向边界，
  不改变中心线使用的首尾椎体。首尾范围由 `localization.regions` 决定。
- Localizer 只绘制全部 offset 中心曲线；其曲线采样点和共享偏移
  方向场必须与实际 CPR 重建一致。

## 第六阶段协议

新增 `geometry_type = "curved_stack"`。

第一版 CPR plan 至少包含：

```json
{
  "geometry_type": "curved_stack",
  "curve_points": [{"x": 0, "y": 0, "z": 0}],
  "curve_spacing_mm": 1.0,
  "curve_projection_axis": {"x": 0, "y": 1, "z": 0},
  "offset_axis": {"x": 1, "y": 0, "z": 0},
  "offsets_mm": [-20, -15, -10, -5, 0, 5, 10, 15, 20],
  "extent_mm": {"width": 120, "height": 300},
  "output_spacing_mm": {"x": 1, "y": 1, "z": 0},
  "slice_thickness": 3.0,
  "slice_spacing": 5.0
}
```

字段含义：

- `curve_points`：由修正后的端面约束和质心链生成的真实三维圆滑加密中心线，按头脚顺序排列，并精确保留修正后的硬锚点；矢状位也不在此字段内覆盖 AP 坐标。
- `curve_projection_axis`：仅新生成的矢状位 CPR 设置，为患者 AP 方向；采样时沿该轴投影到整组固定参考面。这是内部计划字段，不是新请求参数或配置开关。冠状位省略；缺少该字段的旧计划保留原三维展开行为，需重新规划和重建才能采用新矢状位语义。
- `curve_spacing_mm`：采样路径弧长方向输出采样间距；矢状位为冠状投影弧长方向。
- `offset_axis`：冠状位 CPR 的患者前后、矢状位 CPR 的患者左右首选方向；用于覆盖区间和各层局部法向
  的朝向种子，不直接作为所有曲线行的固定平移向量。
- `offsets_mm`：每张 CPR 图相对中心曲线的偏移。
- `extent_mm.width`：输出图横向覆盖范围，冠状位表达患者左右方向，矢状位表达患者前后方向。
- `extent_mm.height`：输出图头脚方向采样路径弧长覆盖；矢状位使用冠状投影弧长，冠状位使用原三维弧长。

矢状位的基础横向视野使用与重采样相同的投影几何检查完整标签 bbox 的体素外缘，
以标签相对整组固定 AP 参考两侧的最大距离确定宽度，包含原有前后生理曲度。
棘突等后方附件使前后范围不对称时，也必须先完整
采样，再由第七阶段应用 FillPercent 取景；只使用 bbox 总跨度并围绕主体中线对称
展开会裁掉后方结构，取景缩放无法恢复。冠状位保持既有横向宽度算法。

`SlicePlan.slices` 对 `curved_stack` 不再表示普通平面切片，而表示每个对应状位偏移
CPR 图的索引和偏移中心。为避免误用，第七阶段必须按 `geometry_type` 分发到专用
`CurvedStackResampler`。

`curved_stack` 的 `localizer_plane` 来自当前部位切法配置，仓库默认冠状位 CPR 为
`矢状位`、矢状位 CPR 为 `冠状位`，并非硬编码。
第七阶段 DICOM Localizer
直接绘制实际 CPR 使用的采样路径弧长重采样和共享等距 offset 曲线，而不是计算普通
切片平面与定位面的交线；不额外绘制厚层边界。
第六阶段只保留计划 JSON，不生成任何规划 NIfTI。普通 `plane_stack` 的定位线仍由
第七阶段按平面交线逻辑生成。

## 第七阶段重采样

新增 `CurvedStackResampler`。

它对每个 `offset_mm` 生成一张 CPR 图：

1. 根据 `curve_projection_axis` 选择原三维路径或固定 AP 参考面内的冠状投影路径，
   再将采样路径按弧长重采样成均匀点。
2. 从 `offset_axis` 出发平行输运采样路径局部法向，并在标准偏移范围内检查
   方向变化稳定性。
3. 必要时用最小物理平滑尺度生成共享方向场，再按每个 offset 等距生成当前层
   中心曲线和局部采样坐标系。矢状位横向固定为 AP，厚层法向位于 LR–SI 平面。
4. 沿输出图每个像素计算其三维物理坐标。
5. 根据输入图像的 origin、spacing 和 direction，把整张曲面的物理坐标批量
   换算成连续体素索引，并执行三线性插值采样 HU。
6. 输出 size 为 `(columns, rows, 1)` 的单层 3D 图像；由整组展开掩膜确定共同倍率，正数 FillPercent 按当前展开掩膜居中，空掩膜回退组中心；0/null/省略保持组中心与基础间距。随后以未取整的重建 HU 按实际窗宽窗位生成 uint16 灰度，写出正式切片及配套显示标签。

当前 CPR 已支持厚层平均。第六阶段先按原始配置标签体素外缘确定有效范围，再按
层厚、层间距、数量三选二规则计算偏移序列；三项齐全时执行对称外扩或保持数量后
重算层厚、层间距。第七阶段对每个偏移位置的厚层范围做算术平均，DICOM 元数据
写入第六阶段计算出的实际层厚和层间距。MIP/MinIP 等融合模式仍作为后续显式配置
处理。

### 重采样性能与数值语义

CPR 的输出分辨率和厚层子采样数不能为了性能而减少。第七阶段先生成整张基础曲面
坐标，每个 slab offset 只做一次 NumPy 批量坐标换算和三线性插值；禁止在
Python 行列循环中为每个像素调用
`TransformPhysicalPointToContinuousIndex`。以 `436 × 237` 输出、36 个厚层
子采样面为例，单张图仍计算约 372 万个采样点，但计算从逐点函数调用改为批量
数组运算。

批量采样保持以下语义：

- 使用与输入 CT 相同的 origin、spacing 和 direction 逆矩阵完成物理坐标换算，
  不假设方向矩阵必须严格正交。
- 使用周围 8 个体素做三线性插值，体积外采样继续返回 `-1024 HU`。
- 对接近体积边界的机器精度尾差使用极小容差，避免把有效边界体素误判为空气；
  真正越界的点不做夹取回填。
- 每个子采样面仍独立采样，最终继续按 slab 数量做算术平均。
- 第七阶段先串行完成同一计划的全部 HU 重采样，再按窗位并行准备和写出独立序列，
  各窗共用未窗化 HU，正式切片各自生成显示灰度并写入实际窗宽窗位和配套 Rescale 标签；
  当前不额外叠加 CPR 切片线程池。

2026-08-05 的同尺寸合成基准中，优化前日志为约 `38–57 秒/张`，批量实现为约
`0.35–0.42 秒/张`。该数字用于定位性能回归，不作为跨机器时延承诺；正式验收
仍以真实病例日志和新旧图像差分为准。

## 降级和错误处理

以下情况导致显式 CPR 请求失败：

- 有效椎体点少于 3 个。
- 目标分割图缺失。
- 目标 label id 缺失。
- 曲线长度过短。
- 曲线拟合失败。

以下情况可以继续生成 CPR，但写 warning：

- 中间椎体缺失。
- 四棱柱不可用但过滤主体质心可用时，退回过滤主体质心。
- 只有输入完全没有过滤标注契约时，才安全回退到全量质心。

规划或采样失败时不发布成功报告；单张 DICOM 采用原子写入，但整个任务不是多文件事务。
某个窗位写盘途中失败仍可能留下此前成功写出的文件，不能仅凭目录存在就判断任务成功。
原始分割不可读时，部分规划 helper 可用 bbox 估算；正式重建取景仍要求有效分割和目标标签，
不能据此承诺无分割也可成功交付 CPR。

## 测试策略

第六阶段测试：

- 三个以上椎体质心生成 `curved_stack`。
- 颈椎、胸椎、腰椎、脊柱均能按配置选择正确椎体序列。
- 缺少中间椎体仍能生成 CPR 并写 warning。
- 少于三个椎体时明确失败，不得静默改成 MPR。
- 各状位的 offset 覆盖完整椎体 mask 沿当前偏移轴的投影范围。
- 冠状位和矢状位分别使用各自 CPR 规则的范围扩展与定位图配置。
- 矢状位对前后不对称的完整标签保留足够基础横向视野，包含后方附件；同时核对
  原始采样与正数 FillPercent 取景，避免只检查计划字段而漏掉成片裁切。

第七阶段测试：

- `CurvedStackResampler` 对直线曲线应等价于相同方向、厚层定义和几何的平面采样。
- 弯曲曲线输出中，采样路径弧长方向像素随曲线连续采样。
- 矢状位同时包含 LR 侧弯与 AP 生理弯曲时，消除 LR 侧弯后仍保留 AP 弯曲幅度；
  AP 横向坐标不随输出行居中，厚层方向不得出现 AP 分量。
- 新矢状位计划包含 `curve_projection_axis`，投影后高度与宽度和真实采样一致；
  缺字段的旧计划仍使用原三维展开语义。
- 多个 offset 生成独立 DICOM 文件，顺序与计划 offsets 一致，冠状位沿前后偏移、
  矢状位沿左右偏移。
- `curved_stack` 的 DICOM Localizer 应在配置背景上画出基准弯曲线，冠状位 CPR
  默认使用矢状位背景、矢状位 CPR 默认使用冠状位背景，不能退化
  成斜直线。
- 全部相邻 offset 曲线对应行的物理距离等于配置层间距；大 offset 在紧弯处
  不能形成焦点、扇形或沿中心曲线方向回折。
- 增加更远 offset 不得改变已经存在的层。
- Localizer 投影点必须与真实 CPR 曲面的中心采样点逐行一致。
- 颈椎、胸椎、腰椎、脊柱矢状位 CPR 的冠状背景沿真实中心曲线前后深度采样；几何不足回退单层，
  正式 CPR 像素、offset、厚度、间距和数量不受定位背景优化影响。
- 未知或缺字段的 `curved_stack` plan 明确报错。

集成测试：

- 腰椎显式请求横状位椎间隙、矢状位 MPR 和冠状位 CPR 时分别生成对应计划。
- 颈椎显式请求横状位椎间隙时只生成 `C2_C3` 至 `C6_C7`；颈椎、胸椎显式请求
  矢状位 MPR、冠状位 CPR 时生成对应计划；全部省略
  `SliceType` 时只生成 MPR。
- 颈椎、胸椎、腰椎、脊柱显式请求矢状位 CPR 时均生成 `curved_stack`，并保留现有 MPR、
  椎间隙和冠状位 CPR 的规划行为。
- 第七阶段 CPR Localizer 在 ITK-SNAP 中应显示目标椎体段的弯曲中心线。

## 能力边界

中间质心修正见 [反向回正设计](2026-08-06-CPR中间质心反向回正设计.md) 和
[局部折角设计](2026-08-06-CPR腰椎局部折角压制设计.md)；最终成片取景及三维加载限制见
[FillPercent 设计](2026-10-08-整组居中与FillPercent取景设计.md)。

CPR 与椎间隙是两种独立的显式能力：CPR 处理颈椎、胸椎、腰椎、脊柱冠状位及矢状位曲线重建；
椎间隙只处理颈椎、腰椎横状位多区间斜横切。两者可以在同一次请求中出现，但必须分别读取
`resolved_cut_configs["whole_range"]` 和 `resolved_cut_configs["interspace"]`，不能
互相替代或静默回退成 MPR。
