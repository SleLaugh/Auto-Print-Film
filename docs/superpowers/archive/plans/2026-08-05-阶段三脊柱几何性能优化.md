**Goal:** 在不改变脊柱几何结果和正式图像效果的前提下，减少阶段三椎体主体与四棱柱构建耗时。

**Architecture:** 将每个椎体的主体算法限制在该 label 的局部包围盒，结果坐标恢复到全局图像空间；将 SI 柱高统计批量化；使用仅限单次函数调用的字典复用矢状几何。公共结果契约和调用阶段保持不变。

**Tech Stack:** Python 3.11、NumPy、SimpleITK、unittest/pytest

## Global Constraints

- `spine_geometry` 的结构和值必须保持一致。
- 不修改主体筛选、四棱柱、CPR 曲线和厚层采样规则。
- 不增加新的线程池或第三方依赖。
- 性能测试使用真实保留分割，正确性测试必须可独立运行。
