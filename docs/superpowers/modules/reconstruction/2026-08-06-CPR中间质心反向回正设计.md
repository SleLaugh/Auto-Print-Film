# CPR 中间质心反向回正设计

## 背景

脊柱冠状位 CPR 当前使用每个椎体四棱柱质心作为 Hermite 曲线硬锚点。真实病例中，
单个椎体的分割不对称或四棱柱边界会使质心在横向产生局部反向偏移；Hermite 会忠实
穿过该点，在 Localizer 上形成不符合整体走向的波浪。

颈椎 `颈1_1mm` 的 C2-C7 质心相对最佳直线最大偏离约 `3.75 mm`，而 Hermite 相对
原始折线的额外鼓出只有约 `0.43 mm`。因此需要处理的是局部反向质心，不是替换
Hermite 或把整段脊柱强制拉直。

腰椎到 S1 通常存在正常的 C 型趋势。L5 仍可被修正，但只有它相对 L4/S1 的局部
弯曲方向与前方腰椎趋势相反时才触发；S1 作为末端锚点始终保持原坐标。

## 目标

- 消除与相邻曲率趋势相反的单点波浪。
- 保留颈椎、胸椎、腰椎正常连续弯曲，尤其保留 L1-L5-S1 的 C 型走向。
- 不使用固定毫米上限；触发后只移动足以消除该点反向曲率的距离。
- 保持首末端面延伸、CPR 覆盖范围、offset 计算和阶段五重建不变。

## 几何判定

设按头脚方向排序的质心为 `P[0]...P[n-1]`，纵向单位轴为现有
`longitudinal_axis`。对每个中间点 `P[i]`：

1. 用 `P[i-1]`、`P[i+1]` 在纵向坐标上的距离，对两点做加权插值，得到该点的
   局部预测位置 `E[i]`。预测位置与 `P[i]` 具有相同的纵向坐标，只表达横向趋势。
2. 令局部曲率残差为 `R[i] = P[i] - E[i]`。
3. `|R[i]|` 小于最小图像 spacing 时视为体素级噪声，不回正。
4. 对内部点，以相邻残差 `R[i-1]`、`R[i+1]` 中方向一致的非零残差建立局部趋势。
   若 `R[i]` 与该趋势点积为负，则该点为反向折返。
5. 当前点残差强度必须不小于可参考相邻残差强度，否则视为被更强相邻异常点拖出的
   肩部，不回正。这样可避免 L5 异常时把正常 L4 一起拉走。
6. 对靠近端点的中间点，只使用存在的一侧趋势。故 L5 在 `L4-L5-S1` 中仍会与
   前一腰椎曲率比较；S1 本身不属于可修改的中间点。
7. 无法得到有效趋势、纵向顺序异常或点重合时，不修改任何质心，沿用现有安全路径。

靠近末端的倒数第二个质心另有一层保守限幅。只有它未触发上述反向回正、残差与
前一点同向、原始折线路径仍跨过残差方向反转、残差超过前一点两倍且前方残差没有
继续放大时，才把残差限制为前一点的 `1.5` 倍；实际移动还必须不超过两侧较短
相邻间距的 `10%`。该规则只削弱孤立末端尖峰，不移动真正末端锚点。

## 回正

反向折返触发后，把 `P[i]` 移到 `E[i]`。这恰好移除 `R[i]`，是满足“局部不再
反向”条件的最小移动；没有固定 `2 mm` 或其他绝对上限。

所有 `E[i]`、`R[i]` 和触发判定必须基于同一份原始质心链计算，再一次性应用修改。
禁止边修一个点边用修改后的结果判断下一个点，避免顺序依赖。

回正后的质心链先参与首末端面路径构造，再进入 Hermite 插值，禁止端面和原始 label
出口继续引用未回正质心。首末端面到首末质心的直线方向同时作为 Hermite 的端点
切向，使直线端段与曲线相切连接；之后再沿原始标签搜索出口并完成范围计算。

## 兼容与边界

- 只有中间质心链参与；首尾质心和端面不移动。
- 正常 C 型曲线的相邻残差方向一致，不触发；L5 可以保留正常腰骶转折。
- L5 如果形成与前方腰椎趋势相反的单点折返，则允许回正到 L4/S1 的预测位置。
- 倒数第二点的同向异常尖峰只做相对残差和相邻间距约束下的小幅限幅，不把正常
  腰骶转折拉直。
- 颈椎仍排除 C1；胸椎和腰椎仍遵循阶段三解析出的实际标签范围。
- 质心未触发反向判定时，曲线点应与当前实现完全一致。

## 测试与验收

1. 三点直线和正常单向 C 型曲线不改变任何质心。
2. 中间单点反向偏移被移动到两侧点的纵向加权预测位置，曲线不再穿过原始波峰。
3. 连续多个点的 C 型曲率方向一致时，保持全部锚点。
4. `L1-L5-S1` 正常 C 型样例保持 L5 与 S1；L5 反向异常样例只移动 L5，S1 坐标不变。
5. 纵向顺序无效、相邻点重合、残差低于图像分辨率时安全回退且不报错。
6. 首末直线段与 Hermite 曲线连接处切向连续，回正后的质心参与端面路径构造。
7. 倒数第二点异常残差限幅不超过相邻间距 `10%`，正常末端曲率保持不变。
8. 颈1病例重新规划后，Localizer 不再出现由反向质心造成的局部波浪，原始覆盖范围
   和 CPR 切片数量保持不变。
