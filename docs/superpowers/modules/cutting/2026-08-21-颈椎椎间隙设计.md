# 颈椎横状位椎间隙设计

## 目标

颈椎显式传入 `SliceType=椎间隙`、`Plane=横状位` 时，按统一切割部位配置引用的
相邻椎体区域生成独立斜横切区域。当前配置为：

1. `C2_C3`
2. `C3_C4`
3. `C4_C5`
4. `C5_C6`
5. `C6_C7`

C1 为环椎，当前配置不定义 `C1_C2`。这项排除只属于椎间隙规划，不从原始分割、
整体定位、颈椎整体坐标或普通 MPR 覆盖范围删除 C1。当前整体范围为 C1–T1，
椎间隙仍为以上五组，不新增 `C7_T1` 或 `T1_T2`。

## 阶段边界

- 第二阶段保留模型输出的完整分割，包括整体配置所需的 C1 至 T1。
- 第三至第五阶段合并 `whole_range` 与 `interspace` 标签目标，当前定位 C1 至 T1；
  C1 保留在全量范围和整体坐标诊断中，首尾质心不决定全局头脚方向。
- 第五阶段按 `spine_cpr.excluded_labels` 跳过 C1 主体四棱柱。
- 三状位 MPR 与冠状位、矢状位 CPR 共用 C1–T1 整体目标；CPR 排除 C1 后使用
  C2–T1，仍只保留既有五组椎间区域。
- 第六阶段颈椎规划器读取 `slice_rules` 引用的椎间区域；当前为 `C2_C3` 至
  `C6_C7`，并复用腰椎已经验证的相向端边、四棱柱、端面和 bbox 回退链路。
- 第七、八阶段继续按通用 `plane_stack`、窗位和 `RegionList` 契约执行，不增加
  颈椎专用输出格式。

## 约束

- 能力表只注册颈椎横状位椎间隙；矢状位和冠状位请求必须在预检阶段拒绝。
- 每个有效间隙独立应用层厚、层间距和数量配置；数量不是五个间隙的总和。
- 某一相邻标签或几何缺失时只跳过该间隙并记录告警，不得补出 `C1_C2`，也不得把
  数量转移到其他间隙。
- 批量测试按部位和状位保留所有匹配配置，颈椎横状位同时输出 MPR 和椎间隙，
  其他状位按配置选择 MPR 或 CPR。

## C2 主体缺失时的受限恢复（2026-11-04）

原始 nnUNet 标签完整，不代表第五阶段主体筛选、四棱柱及端面拟合一定成功。
`C2_C3`、`C3_C4` 等区间仍分别依赖两侧主体几何；任一侧缺失或无效，仍可按原规则
跳过。C2 恢复补丁只处理旧 C2 主体筛选最终为空的情况；这一恢复路径不放宽其他
椎体或所有间隙的规则，也不证明既有主体算法在其他病例上都正确。

第五阶段先核实 C2 标签中有宽基底、与基底连续的窄长齿突，以及按物理 spacing
计算的足够大内接球，再提取基底主体。正常 C2 不进入这一恢复路径；
其余椎体的主体选取也不由该路径替换。具体边界见
[主体与四棱柱设计](../localization/2026-08-06-椎体主体外包络四棱柱设计.md)。

恢复主体不会直接加入 `filtered_annotation_centroids`。第五阶段另存
`spine_geometry.interspace_recovered_annotations`，并且只有 C2、C3 两侧都存在有效
四棱柱，且原 label 与原 CT 的 `density_drop` 同时核实各自相向自然端面时，才为
恢复 C2 附加两侧端面证据。每侧只拟合当前间隙需要的一面，不要求 C2 齿突端或
C3 下缘也通过。支持 SI 索引反向，端面选择按当前两主体的相对位置确定。

第六阶段仅为当前 `C2_C3` 建立局部 annotation 视图，读取恢复 C2 和配对 C3
的自然端面。原来的全局 C3 annotation 不被覆盖，恢复信息不进入全局姿态、CPR、
其他间隙的输入或全局主体体量统计。任一侧缺少原标签端面、CT 密度证据或有效
四棱柱时，保留原跳过结果，不以 bbox 补造该组。

新增 C2 四棱柱还须满足既有四棱柱逐体素不变。若容纳 C2 必须改动任何既有
四棱柱，放弃新增组；允许只裁剪新增 C2 自身。该约束保护已有间隙的几何，
不改变第七阶段的共享取景规则：新增组后，同一配置的共同矩阵和显示倍率会
重新计算，因此既有椎间隙图像的显示缩放可能改变，不能承诺其像素逐张相同。

### C2 补丁的先前快照验证

病例 `10000604` 的两个序列分别恢复 `C2_C3` 四张切片及一张定位图；既有四组
的切片中心、方向、数量完全相同，各序列的 120 张普通 MPR 像素和几何逐张一致。
另有 33 个既有正常主体 mask 逐体素不变。相关回归当轮为 426 项通过及 64 个
子测试。验证证据保存在项目输出目录
`outputs/cervical-c2-10000604-20261104/verification_summary.json` 和
`c2_gap_qa_after.png`；未覆盖原病例缓存或部署可执行文件。
该证据对应当时输入快照；后台后来更新了源缓存，不能把这组旧对照当成当前缓存的
最新验证。最终合并修正的验证范围见下节冻结输入对照。

这些证据覆盖上述病例、正常 mask 和受限恢复条件，不代表其他病例的 `C3_C4`
等区间不会缺组，也不保证既有切线角度没有问题。排查仍应依次核对原标签、主体、
四棱柱、端面证据和最终定位图，并用相同 raw/seg 的补丁前后重放区分新增回归与既有缺陷。

对应自动测试为 `tests/test_c2_inferior_body_recovery.py`、
`tests/test_c2_supported_endplates.py` 和 `tests/test_c2_interspace_isolation.py`，
覆盖正常 C2 不替换、其他椎体不放宽、连续性不足拒绝、各向异性与 SI 反向、
单面原标签和 CT 证据，以及恢复信息不污染已有间隙。

## 后方薄片误作主体的通用保护（2026-11-04）

病例 `10000549` 第二序列的 `C6_C7` 陡斜切面来自既有主体候选选择：真正前方
C7 主体的 AP/LR 比偏低，后方短横桥略超原残块体量阈值，反而抢占主体；
后续角度保护又使用了错误主体中心，不能修复这一上游错误。
针对该例用相同 raw/seg 分别重放 C2 补丁前后代码，两序列各 7 个计划逐项相同；
2026-11-03 保存的第二序列基线也已有约 `65.66°` 的定位线。因此此缺陷独立于
C2 恢复补丁处理，不以补丁前后相同证明原角度正确。

修正在第五阶段通用主体选择中完成，不按 C7 或病例名称分支。候选位于优势前方
主体后方、连续 SI 支撑不足其一半，且其物理 SI 长度的两倍仍小于 AP/LR 中较小
尺寸时，才额外拒绝后方薄片。优势前体自身还须有足够三维 AP 厚度，避免前薄片
排挤真正后方实体；物理尺寸而非层数决定薄片判断。原 AP/LR `0.35`、体量 `10%`
及既有残块规则不放宽。C2 显式退出这项新保护，保留原选择及为空才触发的专属恢复。
具体条件和反例见[主体与四棱柱设计](../localization/2026-08-06-椎体主体外包络四棱柱设计.md)。

## 异常几何容错

颈椎内固定、金属伪影或分割缺损可能使单节椎体主体明显偏小，继而放大四棱柱端面
角度误差。椎间规划保留原四棱柱为主几何，只在以下条件同时满足时限制法向：

1. 当前间隙任一端主体体素数低于本次颈椎主体体素中位数的 75%；
2. 四棱柱法向与相邻过滤主体质心连线在矢状面内的偏差超过 10°。

触发后保留原间隙中心和有效长度，仅把法向限制到主体中心线附近 10°，并记录带
区间名称的告警。正常体积的椎体、偏差不超过阈值的区间，以及非颈椎椎间规划均不
应用该修正。相向端边的共同覆盖中点仅在仍保留至少 75% 代表间隙时使用，避免
中心偏向一端的同时，不牺牲明显的有效间隙宽度。

四棱柱是矢状外包络，局部交叠时可能把区间范围压得远小于三维主体的真实间隙。
第五阶段因此额外记录相邻主体最近间隙。真实间隙比四棱柱范围大超过 `1mm` 且至少
有 8 个最近点支撑时，第六阶段只沿当前法向平移切片位置，并记录告警；角度、有效
长度和采样参数保持不变。该位置修正适用于脊柱椎间公共链路，不依赖具体病例或
固定的 `C6_C7` 名称。

颈椎当前末端 `C6_C7` 另有一层受限位置保护。四棱柱范围未被明显压窄，但切片中心
沿相邻过滤主体中心中面偏上超过 `0.25mm` 时，将中心移动到主体中面下方
`0.5mm`；只平移位置，不修改角度和有效长度。已经由真实最近间隙完成修正的区间
优先使用前一条规则，不叠加末端下移。代码按解析后椎间区域列表的最后一项识别
末端，不固定 `C6_C7` 名称，也不按病例名称判断。
