# 历史文档中文化实施计划

> **供执行人员使用：** 按任务逐项实施本计划，各步骤使用复选框（`- [ ]`）跟踪状态。

**目标：** 将 `docs/` 下历史文档的文件名和说明性正文统一改为中文，并保持全部引用有效。

**架构：** 先建立旧文件名到中文文件名的唯一映射，再批量重命名并更新引用；随后逐份清理 Markdown 中的英文说明，最后通过路径扫描和项目测试验证结果。

**技术栈：** Markdown、SVG、Git、ripgrep、Python unittest。

## 全局约束

- 代码块、命令、路径、代码标识符和必要技术名称不翻译。
- 不修改程序业务逻辑。
- 不修改用户的 `.vscode/launch.json`。
- 本轮不执行 Git 提交。

---

### 任务 1：重命名历史文档并更新引用

**文件：** `docs/` 下全部历史文档、流程图及仓库内引用这些文件的位置。

- [ ] **步骤 1：建立无冲突的中文文件名映射。**
- [ ] **步骤 2：重命名文件并替换全部旧路径引用。**
- [ ] **步骤 3：确认旧英文文件名和引用均不存在。**

### 任务 2：中文化历史文档正文

**文件：** `docs/**/*.md`。

- [ ] **步骤 1：翻译标题、固定栏目和任务步骤。**
- [ ] **步骤 2：翻译剩余说明性英文段落。**
- [ ] **步骤 3：扫描确认英文剩余仅为代码、命令和技术名称。**

### 任务 3：全量验证

- [ ] **步骤 1：运行 `.venv/bin/python -m unittest discover -s tests -q`。**
- [ ] **步骤 2：运行 `.venv/bin/python -m compileall -q src tests`。**
- [ ] **步骤 3：运行 `git diff --check` 并检查工作区状态。**
