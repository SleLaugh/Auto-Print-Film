# 校正、定位与解剖分析模块入口

本模块描述第三阶段空间校正、第四阶段标签定位和第五阶段解剖分析。
它不负责第六阶段切片展开和第七阶段 MPR。

## 当前有效规则

- 第三阶段唯一决定后续使用的 raw/seg 空间。脊柱使用可靠逐椎体镜像角汇聚生成
  XY 候选；颅脑、髋骨、肺部保持原工作图像，延后在第五阶段估计方向、第七阶段采样。
- 第四阶段根据目标 label 提取全量 bbox、centroid、顺序和目标整体范围。
- 第五阶段为当前启用部位生成整体解剖坐标系，颈椎横状位 MPR 另有专属坐标；脊柱额外生成过滤主体、四棱柱、端面和
  `spine_geometry.filtered_annotation_centroids`（沟通简称“标注质心”）。
- 脊柱整切按配置首尾标签展开完整解剖范围；当前默认颈椎 `C1 → T1`、胸椎
  `C7 → L1`、腰椎 `T12 → S1`、胸腰椎 `C7 → S1`、全脊柱 `C2 → S1`，不固定裁掉配置首尾椎体。
  胸腰椎完整目标为 C7、T1–T12、L1–L5、S1，共 19 个椎体；
  全脊柱完整目标为 C2–C7、T1–T12、L1–L5、S1，共 24 个椎体。三状位 MPR 与冠状位、
  矢状位 CPR 共用整体目标；颈椎 CPR 仍由配置排除 C1，使用 C2–T1，CPR 排除项不缩小普通 MPR
  范围，整体范围扩展不新增椎间隙。
- S1 按本次实际 `label_targets` 解析，优先 `vertebrae_S1`，不存在时使用 `sacrum`。
  标准配置不改写，整体轴端点、诊断、椎间主体配对及计划使用实际标签名；两者均缺失
  时沿用缺标签校验，不能替换成其他椎体。
- `slice_part_config.json` 中 `localization.regions` 使用具名区域描述首尾标签；
  `slice_rules` 决定每种状位和切法使用哪些区域。阶段内部把整体区域整理为
  `whole_range`，把椎间区域整理为 `interspace` 数组，解析结果才使用 `intervals` 字段。
- 混合请求通过 `resolved_cut_configs` 同时转交整切和椎间定位范围；MPR/CPR 使用
  `whole_range`，椎间隙使用 `interspace`，不能共用一个可变的当前范围。
- 第三至第五阶段合并当前部位全部范围方案的标签目标。颈椎仅请求椎间隙时仍定位
  当前整体配置的 `C1-T1`，首尾标签用于范围有效性检查；第六阶段再按 `interspace`
  配置生成区域，当前仍为 `C2_C3` 至 `C6_C7` 五组，不增加 `C7_T1` 或 `T1_T2`。
- 标注质心只供第六阶段 CPR/区间切几何使用，不覆盖第四阶段的全量 `coords`。
- 过滤主体进一步规则化为保持椎体倾斜角度的填充四棱柱，CPR 优先使用实际
  四棱柱 Mask 的体素质心；矢状四边形使用 LR 支撑核心，并只补回与主体紧邻、
  体量足够且横向高度重合的端部断连块，避免“最大块截短”和“全投影带回附件”
  两种极端。
- 旧主体最终为空的 C2 可根据宽基底、连续齿突和物理内接球受限恢复，该路径不替换
  正常 C2 及其他椎体的主体。新增 C2 四棱柱不得改动既有四棱柱；恢复 annotation
  另存 `interspace_recovered_annotations`，不加入全局姿态、CPR 或其他间隙。
  只有原 label 和 CT 同时核实 C2/C3 相向自然单面，才供当前恢复间隙局部使用；
  证据不足保留跳过，详见[主体与四棱柱设计](2026-08-06-椎体主体外包络四棱柱设计.md)。
- 通用主体选择增加受限后方薄片排除：前方优势主体须有足够三维 AP 厚度，后方
  候选须 SI 支撑不足其一半且物理 SI 长度两倍仍小于 AP/LR 较小尺寸。C2 显式
  退出新增保护；原 AP/LR `0.35` 和体量 `10%` 规则不放宽。修正可能改变被纠正
  椎体和共享定位背景，不能视为 C2 的局部恢复契约；详见
  [主体与四棱柱设计](2026-08-06-椎体主体外包络四棱柱设计.md)。
- 椎间隙请求另建立按组隔离的主体/端板核验结果，保存到
  `interspace_validated_annotations`、`interspace_validated_body_pairs`；诊断为
  `interspace_validation`。不回写共享主体、棱柱或全量定位，正常路径不额外读取 CT。
  主体候选仍须通过双端板 CT 与正间隙核验，见
  [局部核验设计](../cutting/2026-11-13-椎间隙局部主体与端板核验设计.md)。
- 普通椎体三维主体恢复和二维投影恢复共享同一套端部几何判定；相邻四棱柱使用
  保护主体的单一矢状分隔直线拆分，不能形成逐体素距离造成的凹口。严格分离失败
  时先允许两侧各不超过 `5%` 的唯一矢状投影侵入；仍失败时，仅对共同 LR 层有
  足够覆盖、逐层严格有序且侵入不深于两个投影体素宽度的主体，按真实 LR 体素
  支撑验证每侧 `5%` 侵入上限。三维主体体素真的重叠仍整体失效，标签和几何协议不变。
- 椎体主体筛选、连通域和边缘高度统计只在对应 label 的局部 bbox 内执行；
  输出索引在进入物理几何计算前恢复为全局 `zyx`，因此该优化不能改变主体 Mask、
  四棱柱或 `spine_geometry`。同一椎体的矢状四边形在一次构建中只计算一次。
- 大规模二维投影点统一使用无损打包的一维整数键去重，避免 NumPy
  结构化行排序在并发批处理中异常终止；字典序、反向索引、计数和 `0.001 mm`
  量化契约保持不变，所以不改变四棱柱和后续切割几何。
- 同一任务内，第三至五阶段共享不序列化的 Label 体素索引与 bbox 快照；
  任一阶段独立执行时可由前置路径重建。校正候选被提升后必须从新分割重建快照，
  禁止跨图像空间复用。同一只读快照还可复用逐椎体对称性结果，匹配索引对象、
  图像几何和采样上限；校正生效时丢弃，第五阶段结束时释放。
- 当前颈椎配置将 C1 放在 `spine_cpr.excluded_labels` 中，并且椎间隙规则从
  `C2_C3` 开始：C1 仍保留在原始分割、全量定位、整体坐标和普通 MPR 覆盖范围，
  但不进入过滤标注质心、四棱柱和颈椎 CPR，也不生成 `C1_C2`；排除项和输出间隙
  以后都通过配置调整，不在代码中固定。
- 第三阶段对接受的横状位 XY 回正候选写出 raw/seg NIfTI，调试输出另含诊断 overlay。
  接受条件满足且候选 raw/seg 双文件存在时，它们成为第四至七阶段的工作输入；
  判断是否提升以 `correction_applied` 为准，不凭非零角度推断。
- `patient_reference_axes` 先把存储轴符号校准为患者参考，SI 朝 LPS `+Z`；不改
  原 direction 的物理点换算及已有斜角，冠状、矢状成片头侧向上。
- 颅脑、髋骨和可靠双侧肺以物理左右对称面定左右轴，患者参考 AP 轴在对称面内的
  投影提供基础前后轴。颅脑默认再用完整 `brain` 物理体素在 AP/SI 平面内的二维 PCA
  估计俯仰，只绕 LR 更新 AP/SI；质量不足保留基础 AP 投影，原因进入
  `anatomical_geometry_diagnostics.pitch`。这是脑形态估计，不代表听眦线或 AC-PC 对齐。
  除颈椎横状位外，脊柱、肺部、髋骨的普通整切 MPR 保留输入前后倾角，不额外抬头、低头；
  头脚符号校准本身不改变已有俯仰基准。肺部先通过镜像
  质量，再验证两主体分居候选面两侧、沿 LR 分离且反射跨主体匹配，不能只数连通域。
  质量不足明确警告并保留患者参考方向。拟合不强行镜像或变形组织。
- 颅脑方向、三轴范围及原有 `coords`、`label_targets`、`correction_scope_bbox` 保持
  `brain` 目标；第五阶段仅另以 `framing_source_labels`、`framing_label_ids` 提供同次
  明确 `skull` 的语义与 ID，不将骨标签加入切割目标。第六阶段再应用范围扩展：当前
  仅颅脑横状位 MPR 默认补头侧 `10 mm`、下侧 `0 mm`，不改第五阶段脑区 bounds。
  第七阶段沿最终 SI 筛选与脑区支撑范围正重叠的骨体素，上界增加该计划头侧余量，
  下界仍为脑区；仅辅助取景，不延长层组到面部、下颌。缺骨仅用脑区
  取景并告警；脑区接边时拒绝俯仰更新并报告截断风险，余量不补出扫描外组织。基础范围重新投影全部
  脑体素物理外缘计算，不能用 PCA 采样点代替。
- 肺本体仅因镜像形态质量不足时，可按本次 dataset.json 的 `pleural effusion` 语义标签
  补充姿态轮廓并重做同一严格检查；不使用数字 ID 猜测，不纳入心包标签。
  `target_mask`、coords 及原肺切割范围不变，辅助 Mask 仅在第五阶段内使用。
- 镜像方向唯一性检查针对涉及 LR 的近重根、圆柱角向信息不足及许可范围内等价面；
  LR 独立而 AP/SI 等谱时不因此误拒。拒绝原因记录于 `direction_uniqueness`。
- 颈椎、胸椎、腰椎、胸腰椎、全脊柱的 `global_frame` 汇聚可靠逐椎体 LR，以输入 AP 投影和 LR×AP 构造
  三轴；首尾质心仅用于范围有效性检查和诊断，不再决定全局 SI。无可靠 LR 时
  保留患者参考三轴并告警，`applied` 反映实际姿态变化。局部椎间隙的真实端面
  斜切及 CPR 曲线几何不变。胸椎横状位及髋骨冠/矢状位同样使用最终整体坐标。
- 颈椎横状位 MPR 是例外：第五阶段另建 `local_frames["axial_mpr"]`，以配置首尾全量标签质心连线
  确定 SI 法向，将 LR 正交投影后以 SI×LR 构造 AP，完整配置标签重新投影 bounds。
  第六阶段仅颈椎横状位 MPR 使用它，切面垂直整体颈椎长轴，整组平行，不逐椎体改变角度。
  颈椎整体范围仍为 C1–T1（包含 C1–C7），终点侧 `5 mm` 余量不变；胸腰椎与全脊柱按配置把上下高度各延长
  `50 mm`，该余量供三种 MPR 和两种 CPR 共用，CPR 只直线延伸脊柱首尾；其余状位、部位按原规则。
- 正式脊柱 XY 候选使用镜像对称角并检查逐椎体离散度；旧 PCA helper 仅保留兼容
  用途。索引按 z/y/x 还原为 x/y/z，物理旋转轴通过 direction 换算，不能混用图像
  z 轴与患者 LPS Z 轴；raw、seg 和后续物理几何始终使用同一空间。
- 切片规划依赖第四/五阶段输出的目标范围和几何，不应在重建阶段重新定位。
- 定位阶段的配置解析、结果序列化与医学几何保持职责分离：
  `stages/localization_contracts.py` 负责共享契约，`stage_localization.py` 保留阶段类型入口
  和几何算法；原有 `LocalizationOperations` 方法名及导入路径继续兼容。
- 脊柱几何基础工具（包围盒、凸包、四边形和点面判断）集中在
  `stages/localization_geometry.py`，通过 mixin 注入定位操作类。
- `LocalizationStage.execute` 的上下文编排集中在 `stages/localization_execution.py`；
  `LocalizationOperations` 继续提供配置解析和医学计算，阶段入口保持不变。
