# 通用切片区间完整覆盖设计

2026-11-18 规则更新：层厚、层间距、数量由至少提供两项改为至少提供一项，
单参数按层厚等于层间距补全；原有双参数、三参数计算保持不变。本文是当前采样规则的
权威设计，文件名中的 2026-07-20 为最初设计日期。

## 目标

第六阶段生成切片计划时，首张和末张图像的厚层外缘必须完整覆盖有效范围边界。
该规则适用于所有部位、MPR、CPR、椎间隙、整切和区间切。

## 统一覆盖规则

以下统一使用 `t`、`s`、`c` 和 `L`：

| 符号 | 请求字段 | 含义 |
| --- | --- | --- |
| `t` | `SliceThickness` | 层厚，单张图沿法向覆盖的厚度，单位 mm |
| `s` | `SliceSpacing` | 层间距，相邻切片中心面沿堆叠方向的距离；CPR 为相邻曲面的偏移间距，单位 mm |
| `c` | `SliceImageCount` | 每个实际切割区域的切片数量，非零值必须为正整数 |
| `L` | 无，规划阶段计算 | 当前区域沿堆叠或偏移方向的有效范围，包含已配置的范围扩展，单位 mm |

层间距 `s` 不是两张图厚层边缘之间的空隙。对平行切片，`s=t` 时厚层相接，`s<t`
时重叠，`s>t` 时保留间隙；CPR 弯曲处仍可能有局部重叠。输出图的面内取景中心可能移动，
因此不能以画布中心之间的
三维直线距离代替堆叠方向的层间距。

三个请求字段至少提供一项。数值 `0`、省略和 `null` 均表示未配置；三项全为 `0`、
全省略或混合这些未配置值时，均拒绝请求。非零 `t`、`s` 必须是正有限数值，
非零 `c` 必须是正整数；负数、布尔值、非有限值和非整数数量均不合法。
`L` 必须是非负有限数值。总范围 `R` 按 `t + (c - 1) × s` 计算：

- 只传数量时，严格输出该数量的切片，层厚和层间距均取 `有效范围 ÷ 数量`；
- 只传层厚时，令 `s=t`，再按层厚和层间距计算最少覆盖数量；
- 只传层间距时，令 `t=s`，再按层厚和层间距计算最少覆盖数量；
- 传层厚和层间距时，计算完整覆盖有效范围的最少数量；
- 传层厚和数量时，计算层间距；
- 传层间距和数量时，计算层厚；
- 三项全部传入且总范围大于有效范围时，把超出部分均分到开始和结束方向；
- 三项全部传入且总范围小于有效范围时，保持数量，层厚和层间距都调整为
  `有效范围 ÷ 数量`。

例如 `L=100 mm` 时，`(t,s,c)` 为 `(0,0,20)`、`(5,0,0)` 或 `(0,5,0)`，
实际结果均为 `(5 mm,5 mm,20)`。`L=103 mm` 而只传 `t=5` 或 `s=5` 时，
实际生成 21 张，层厚和层间距均为 5 mm，总范围 105 mm，首尾各外扩 1 mm。

最终从第一张图像中心开始按实际层间距严格等距展开指定数量。DICOM 斜向方向余弦
和坐标只有有限小数位，`0.001mm` 内的物理坐标差异按同一边界处理，不能因数微米
舍入误差多生成一张图像。层间距大于层厚时，调用参数造成的中间物理空档继续保留。

## 代码边界

统一参数求解入口为 `src/planning/sampling.py:resolve_sampling`。
缺少参数的补全发生在第六阶段取得 `L` 后，请求校验阶段不提前写入推导值。
用 `δ=0.001 mm` 表示现有范围容差：

| 原始请求中的有效参数 | 实际参数计算 |
| --- | --- |
| 仅 `c` | 保持 `c`，令 `t=s=L/c` |
| 仅 `t` | 先令 `s=t`，再使用下方 `t+s` 的数量公式 |
| 仅 `s` | 先令 `t=s`，再使用下方 `t+s` 的数量公式 |
| `t+s` | `c=max(1, ceil((L-t-δ)/s)+1)` |
| `t+c` | 要求 `c>1`，`s=(L-t)/(c-1)` |
| `s+c` | `t=L-(c-1)*s` |
| `t+s+c` | `R<L-δ` 时保持 `c` 并令 `t=s=L/c`；其余保留原参数 |

两参数和三参数组合保持原规则：推导出的厚度或间距不大于 `δ` 时拒绝；三项齐全且
`R>L` 时按 `(R-L)/2` 首尾对称外扩，`L-δ≤R≤L` 时接受容差内的差异。
这些规则同样适用于单参数补全后的数量计算。

### 单张与零范围边界

- 仅传 `c=1` 时允许生成一张，`t=s=L`，中心位于有效范围中点；此时没有下一张图，
  `s` 仍按规则记录为 `L`。仍需满足 `L>δ`。
- 仅传数量时，若 `L=0` 或 `L/c≤δ`，不能得到有效层厚和层间距，应明确报错，
  不减少请求张数，也不自行使用默认厚度。
- 仅传 `t`、仅传 `s` 或仅传 `t+s` 时，若 `L≤t+δ`（包括 `L=0`），生成一张；
  保留请求或复制得到的厚度和间距，超过目标的厚层范围在首尾均分。
- `t+c` 且 `c=1` 仍按旧规则报错，因为该双参数组合不能唯一求出间距；
  `s+c` 且 `c=1` 时计算 `t=L` 并保留 `s`，要求 `L>δ`。
- `t+s+c` 且 `c=1` 仍使用上表的三参数规则。零有效范围不覆盖、删除或改写已请求的数量。

在 `src/planning/straight.py` 增加通用方法 `cover_segment_range(...)`，由
`build_straight_slice_plan` 和解剖坐标整切共同调用。肺部、髋骨、颈椎、胸椎、
腰椎及颅脑不得各自复制覆盖算法。第七阶段继续只读取已经展开的切片中心，不加入
部位判断。

`range_start`、`range_end` 表示计算后第一张和最后一张切片中心；
`target_start`、`target_end` 继续保留原始目标边界，方便调试诊断计算实际超出
或遗漏长度。

## 调试信息与 DICOM

第六阶段在 `sampling_details` 中记录实际层厚、层间距、数量、有效范围、总范围、
首尾外扩和参数调整原因。原有覆盖诊断字段继续记录厚层外缘及中心相对目标边界的
关系，相邻切片中心距离必须统一。

第七阶段写出的 DICOM 应使用第六阶段计算后的实际 `SliceThickness` 和
`SpacingBetweenSlices`。
GDCM 先写同目录临时文件，pydicom 在临时文件内校正两个数值标签，全部成功后
才原子替换正式路径，避免异常时留下标签错误的半成品。派生文件统一声明
`ISO_IR 192`，让 GDCM 写出的 UTF-8 中文与 DICOM 字符集声明一致，患者姓名和
检查描述必须能被标准 pydicom 读取器正确解码。

## 验证场景

- 三种单参数组合：只传数量时均分有效范围，只传层厚或间距时令两者相等后计算最少覆盖数量。
- 仅传 `c=1`：合法有效范围生成一张，`t=s=L`，中心位于范围中点。
- 省略或为 0 的字段按未配置处理；三项均未配置时拒绝请求。
- 数量为负数、布尔值或非整数时拒绝；仅数量时验证 `L/c=0.001 mm` 的拒绝边界。
- 三种两参数组合：分别正确计算数量、层间距或层厚。
- 三项全部传入且总范围较大：数量和传入参数不变，首尾均等外扩。
- 三项全部传入且总范围较小：数量不变，层厚和层间距均分有效范围。
- 名义长度存在数微米斜向坐标误差：不额外增加一整张图像。
- 仅传层厚、仅传间距或仅传层厚和间距时，范围短于层厚（含零长度）生成一张；
  只传数量时，零长度或均分后不大于 0.001 mm 的范围不能得到有效层厚和层间距，应拒绝；
  同时提供数量和其他采样参数时仍按原有两参数/三参数规则处理，
  不能声称零长度目标总会覆盖调用方的数量配置。
- 层间距大于层厚：保持请求间距，同时保证第一张和最后一张包住边界。
- 倾斜切片：沿最终切片法向计算物理长度和外扩，不依赖默认 XYZ 轴。
- MPR、CPR 和脊柱椎间隙：均使用同一参数计算；椎间隙数量按每个间隙应用。
- DICOM 回读：`0018,0050` 等于层厚，`0018,0088` 等于层间距。
- DICOM 中文与失败路径：pydicom 正确读取 UTF-8 患者/检查字段，标签校正失败时
  不产生正式切片文件。
