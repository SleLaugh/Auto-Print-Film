# 椎体主体外包络四棱柱实施计划

> 状态：已完成并归档。当前有效规则见
> `../../modules/localization/2026-08-06-椎体主体外包络四棱柱设计.md`。

## 原始目标

让阶段三四棱柱保持四条斜直边并稳定覆盖可信椎体主体，继续排除附件，同时改善
相邻椎间切线和 CPR 连续性。

## 实施结果

- [x] 增加倾斜楔形主体、四边形包含和实际角点范围栅格化测试。
- [x] 实现四边形逐边外移及定向外接四边形回退，没有使用轴对齐矩形。
- [x] 为相邻四棱柱增加受保护主体和单一最大间隔矢状分隔面。
- [x] 修正 S1 局部 mask 与全局棱柱区域的交集。
- [x] 以相向端边共同中段替代容易落在角点的最近点切线。
- [x] 调整 CPR 质心回正顺序、末端残差保护和直线端段切向连续性。
- [x] 增加普通椎体三维端部块恢复，并同步二维投影端部恢复。
- [x] 完成六组真实腰椎数据的规则开关 A/B 检查。
- [x] 阶段三、阶段四和全仓自动测试通过。

## 与原计划的关键差异

原计划曾假设“四棱柱应强制包含主体候选的完整投影”。真实颈到盆长扫描验证表明，
主体候选仍可能含有高支撑碎块，完整投影会把这些块重新带入四边形，导致顶部多块、
相邻切线变形。因此最终没有采用无条件完整投影，而是改为：

```text
LR 支撑核心 + 严格几何约束下的可信端部恢复
```

另一处真实问题来自单层薄断点：只保留最大三维连通块会截短有效 L5。最终用相对
体量、SI 邻接、SI 厚度及 AP/LR 重合度识别端部块，并让三维主体与二维投影复用
同一包围盒判定。实现没有病例名、患者名或椎体名称分支。

- CPR 长度变化约 `0.001 mm`，没有新增局部折角。
