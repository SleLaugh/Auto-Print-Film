# 脊柱过滤标注与标注质心输出设计

## 定位

该步骤属于**第五阶段解剖分析**，不是第三阶段空间校正、第四阶段标签定位或
第七阶段重建。它只在颈椎、胸椎、腰椎、胸腰椎、全脊柱任务中执行；其他部位不生成脊柱专用几何。

术语固定如下：

- **全量标注**：nnUNet 原始 label；
- **过滤标注**：从全量标注中过滤出的椎体主体 mask；
- **标注质心**：由过滤标注计算出的质心，作为 CPR 中间中心线和椎间隙定位的输入；首末椎体另外保存主体端面几何，供第六阶段把中心线首尾约束到椎体表面。

## 输入与输出

第四、第五阶段从同一工作分割中形成两套互不覆盖的几何：

```text
完整 seg.nii.gz
  ├─ 第四阶段 coords.*.centroid / coords.*.bbox
  │    完整 label 几何：定位、覆盖范围、首尾边界
  │
  └─ 第五阶段 spine_geometry.filtered_annotation_centroids
       标注质心：当前 CPR 基准中心线和弧度
       单椎体局部头脚轴/范围：后续局部定位线阶段
```

`coords` 是既有定位契约，必须保持全量 label 的结果；主体提取不能回写其中的 `centroid` 或 `bbox`。

目标标签范围来自第四阶段定位结果中的已解析整切配置。第五阶段按 C1–C7、
T1–T12、L1–L5、S1 的统一解剖顺序展开，并按当前模型实际提供的 label 取值。
胸椎默认配置 `C7 → L1`，因此 C7、T1–T12、L1 都进入本阶段输出；胸腰椎默认
`C7 → S1`，C7、T1–T12、L1–L5、S1 共 19 个椎体均参与主体几何构建；
全脊柱默认 `C1 → S1`，C1–C7、T1–T12、L1–L5、S1 共 25 个椎体均按配置参与。
腰椎及其他非颈椎任务也按配置范围完整使用。不能在解剖分析阶段另行固定裁掉配置首尾椎体。
S1 按实际 `label_targets` 优先解析为 `vertebrae_S1`，不存在时使用 `sacrum`，
后续主体几何以实际标签名保存；原始配置仍保留标准名。

第五阶段输出的 `spine_geometry` 包含：

- `filtered_annotation`：过滤标注的算法版本、来源和目标结构；
- `filtered_annotation_centroids`：每个可用椎体的标注体素质心、物理质心、局部头脚轴/范围、端面平面内范围中点 `local_superior_inferior_face_centroids.min/max`、首尾端部的一组 `local_superior_inferior_face_candidates`，以及矢状投影轮廓四边形主体 `sagittal_body_faces`；第六阶段优先先识别相邻标注质心连线进入椎体的那一面，再取同一轴上的对侧大面中心作为首尾端点，不固定使用内缩距离，也不使用 PCA 外接矩形角边；
- `excluded_from_annotation_centroids`：明确记录配置排除的标签；
- 完整几何的来源说明，指向 `coords` 和 `coords.*.bbox`。

## 标签排除规则

以下 C1 排除规则适用于颈椎任务；全脊柱按自己的配置保留 C1。

- C1 仍然进入 `coords`、定位 bbox 和切图覆盖范围；
- C1 不进入 `spine_geometry.filtered_annotation_centroids`；
- C1 不参与颈椎 CPR 中心线；
- C1 不参与横状位姿态/回正角度统计；
- 其他状位仍可切到 C1。

排除项读取 `slice_part_config.json` 的 `spine_cpr.excluded_labels`。当前颈椎配置只
排除 C1；全脊柱不排除 C1，胸椎的 C7/L1、腰椎、胸腰椎和全脊柱的配置首尾标签
以及其他模型实际提供的脊柱标签均按
配置参与过滤标注质心和后续 CPR。

## 阶段边界

第五阶段只负责从全量标注生成过滤标注、计算标注质心、单椎体局部头脚轴、主体端面中心和端部候选平面中心，不负责生成 CPR 曲线、切片数量或重建图像。

第六阶段优先读取有效 prism_centroid_physical，其次使用过滤主体 centroid_physical。
质心链经反向/局部折角修正后构建端面路径，执行 Hermite 加密并保留修正后的硬锚点；
SlicePlan.curve_points 保存真实三维密集曲线而非固定锚点折线。第七阶段按
`curve_projection_axis` 采样：冠状位以第五阶段整体坐标 LR 为投影轴、同一
坐标 AP 为偏移轴，无解剖几何时成对回退患者 LR/AP，展开 AP–SI 投影并保留
LR–SI 侧弯；矢状位仍沿患者 AP 投影到固定 AP 参考面，展开 LR–SI 投影并
保留前后生理曲度。两者按各自投影弧长采样，覆盖、横向 FOV 和定位线共用
相同投影几何。冠状定位背景仍从真实三维曲线读取 y(z)，不以采样投影代替。
完整标签与 bbox 继续用于覆盖，不能拿过滤主体替代全量取景目标。

过滤标注提取失败时，第五阶段不修改第四阶段定位结果；第六阶段根据缺失标注质心
跳过缺失点或采用允许的质心回退；显式 CPR 最终不足三个有效点时失败，不改成 MPR。
