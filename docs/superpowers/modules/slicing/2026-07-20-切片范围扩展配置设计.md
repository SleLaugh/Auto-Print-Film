# 切片范围扩展配置设计

## 目标

允许在 `src/config/localization_config.json` 中，按部位、切割方式和状位分别配置切片开始端与结束端的额外覆盖距离。配置单位固定为毫米；未配置时保持现有逻辑不变。

## 配置格式

扩展配置放在对应切割方式下，字段名为 `slice_range_extension`：

```json
{
  "targets": {
    "肺部": {
      "whole_range": {
        "start": "lung",
        "end": "lung",
        "slice_range_extension": {
          "横状位": {
            "start": 3.0,
            "end": 3.0
          }
        }
      }
    }
  }
}
```

- `横状位`、`矢状位`、`冠状位` 直接使用现有 `PlaneTypeEnum` 的中文值。
- `start` 表示从原始第一张切片方向向外增加的距离。
- `end` 表示从原始最后一张切片方向向外增加的距离。
- `start`、`end` 的单位固定为毫米，允许零和正数，不允许负数、布尔值或非有限数。
- 状位未配置、整个 `slice_range_extension` 未配置或某一端未配置时，对应值为 `0`，保持当前行为。
- 配置能力不限定部位、切割方式或状位；只要对应定位配置存在，就可以按需增加。
- 当前仓库为肺部、髋骨横状位配置 `start=3.0`、`end=3.0`，这是当前默认值而不是允许列表。

## 数据流与职责

第三阶段解析 `cut_configs`，按 `whole_range`、`interspace` 保存当前部位的全部切割
配置；第四阶段连同原始定位边界转交 `cut_config`、`cut_configs` 和
`resolved_cut_config`。这样腰椎一次请求同时包含横状位区间切与矢/冠整切时，
第六阶段也能按每个计划自己的切割方式取得正确配置。

第六阶段在生成等间距中心范围前，先按当前计划的 `cut_mode` 和 `plane` 读取扩展值，再沿 `target_start -> target_end` 的单位方向分别向两端扩展；随后仍使用现有中心覆盖算法处理无法整除层间距的余量。`SlicePlan.target_start/target_end` 保留原始部位边界，`range_start/range_end` 记录扩展和等距补齐后的实际中心范围。

第七阶段只消费第六阶段产生的切片中心，不读取该配置，也不增加部位业务逻辑。斜向切片沿自身切片序列方向扩展，因此不依赖固定 XYZ 轴。

## 校验与测试

第三阶段读取定位配置时校验状位名称、对象结构、字段名称和值域。每个状位对象允许只配置 `start` 或 `end`，缺少的一端按零处理，但不允许其他未知字段。测试覆盖：缺省零扩展、当前肺部和髋骨横状位 3/3 默认值、任意已有状位的按需配置、正向和反向路径、斜向路径、固定层间距、无效配置、混合切割方式读取，以及未配置状位保持原有结果。
