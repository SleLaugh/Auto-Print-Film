# CPR 腰椎局部折角压制设计

## 背景

`腰3_1mm` 的 Localizer 仍可见轻微波浪。只读检查显示当前反向回正规则没有修改
任何质心，CPR 曲线仍穿过 L1-L5/S1 全部原始质心。

该病例的局部残差为：

- L2: `1.383 mm`
- L3: `3.107 mm`
- L4: `1.142 mm`
- L5: `5.606 mm`

L3 相对 L2/L4 的纵向加权预测位置外凸约 `3.1 mm`。这不是单纯“B 走反方向”的
模式，因为 L3 一侧邻居残差方向冲突，现有规则会保守跳过。

## 决策

采用“缩回局部凸点”方案，不主动把 L2/L4 往外推。

理由：

- 只动一个疑似造成折角的点，改动范围最小。
- 不改变相邻椎体的切片中心，避免为了视觉弧线牺牲多个正常锚点。
- L5/S1 的腰骶自然弯曲保持保守，不用全局拟合拉直。

## 几何规则

在现有反向折返规则之外，增加“局部折角压制”：

1. 只考虑同时存在左右残差的中间点，即不处理首尾，也不处理靠近端点的 L5/S1 单侧场景。
2. 当前点残差必须达到图像最小 spacing。
3. 左右相邻残差都有效，但方向互相冲突，因此无法形成可靠连续趋势。
4. 当前点残差必须分别强于左右相邻残差，说明它是局部折角主峰，而不是被相邻异常点拖出的肩部。
5. 原始路径在当前残差方向上的左右相邻段必须同向前进；若一进一出，则视为合法 S 型或复合曲率拐点，不压制。
6. 当前点与其中一个邻居残差同向、与另一个邻居反向时，把当前点移动到双邻点的纵向加权预测位置。

该规则会命中 `腰3_1mm` 的 L3，不会命中 L5，因为 L5 只有前一侧残差可参考。

## 验收

- `腰3_1mm` 夹具中只缩回 L3，L2/L4/L5/S1 保持原坐标。
- 合法 S 型峰值保持原坐标，避免把真实拐点压成直线。
- 既有正常 C 型曲线仍不移动任何质心。
- 既有 C4 反向折返、L5 反向异常测试继续通过。
- 第六阶段测试和全量测试通过。
