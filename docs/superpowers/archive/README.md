# 历史文档入口

本目录保存已经完成的实施计划和被新规则替代的旧设计，用于追溯当时的决策、
验证过程和迁移原因。

归档正文可能与当前代码不同，不能作为当前业务规则使用。确认当前能力时应从
[`../README.md`](../README.md) 进入，再读取对应 `architecture/` 或 `modules/`
文档；发生冲突时，以运行时代码、实际配置和自动测试为准。

## 目录

- `plans/`：已经完成的实施过程，复选框状态只反映当时执行情况。
- `specs_old/`：已经被后续设计替代的旧规范，文件顶部应注明当前替代入口。

历史文件原则上保留原文。只有当文件可能被搜索结果直接打开并误判为现状时，
才在顶部补充历史属性和替代链接。
