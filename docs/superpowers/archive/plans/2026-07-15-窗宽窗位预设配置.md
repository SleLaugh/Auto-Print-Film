**目标：** Make the JSON configuration the only source of supported window preset names and values.

**架构：** `src/models/window.py` loads and validates `src/config/window_presets.json`, then exposes immutable `WindowPreset` values through the existing lookup API. Request models carry plain preset-name strings so adding a configured preset never requires a Python enum change.

**技术栈：** Python dataclasses, JSON, unittest.

## 全局约束

- External requests continue to pass only preset names.
- Each configured entry contains only `name`, `window_width`, and `window_center`.
- `WindowPresetEnum` is removed.
- Line color is outside this change.
