# 架构文档入口

优先读本文件。只有任务涉及跨阶段契约、请求结构、框架生命周期或 DICOM 写盘并发时，才继续读取本目录具体设计。

## 当前有效规则

- 六阶段主链仍是 `Request -> Pipeline -> Stage[] -> Response`。
- 框架能力围绕配置、预检、任务状态、产物管理、标准错误和 manifest 收口。
- 外部请求的状位配置属于系统契约，具体重建、切片和显示规则分别在模块目录维护。
- GDCM 写盘串行保护是跨模块安全约束，CT 成片和定位图写盘都应遵守。
