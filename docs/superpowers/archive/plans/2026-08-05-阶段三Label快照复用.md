# 阶段三 Label 快照复用 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 复用阶段三首次坐标扫描结果，消除同一分割空间中的重复全图 Label 扫描。

**Architecture:** 建立只在单次阶段三执行内有效的 Label 体素快照，坐标、脊柱倾斜和主体几何共享原始索引与 bbox；回正提升后重建快照。只有实际需要统一解剖坐标的部位才构造全尺寸 Label Mask。

**Tech Stack:** Python 3.11、NumPy、SimpleITK、unittest/pytest

## Global Constraints

- 现有定位 JSON、PCA 角度、候选状态和脊柱几何必须保持一致。
- 回正后的计算不得复用原始分割快照。
- 不增加长期缓存、线程或第三方依赖。
