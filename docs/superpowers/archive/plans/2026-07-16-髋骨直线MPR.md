# 髋骨三状位直线 MPR 实施计划

> **供执行人员使用：** 按任务逐项实施本计划，各步骤使用复选框（`- [ ]`）跟踪状态。

**目标：** 实现髋骨外侧顶部 AB 倾斜横切、默认矢冠切片和明确的定位图参考状位。

**架构：** 阶段三新增髋骨专属解剖计算器并输出统一坐标；阶段四按部位和
状位选择倾斜或默认 frame，同时写入通用定位图字段；阶段五只消费计划字段。

**技术栈：** Python、NumPy、SimpleITK、unittest。

## 全局约束

- 只有髋骨横状位增加角度。
- 矢状位和冠状位保持默认 DICOM 方向。
- 第五步不得新增髋骨业务判断。
