**目标：** 支持按部位、切割方式和状位分别配置可选的首尾切片范围扩展值，单位为毫米；未配置时保持现有行为不变。

**架构：** 配置保存在 `localization_config.json` 现有的切割方式对象内。第三阶段校验所选部位的全部切割方式对象，并通过 `cut_configs` 向后传递；第四阶段按当前计划的切割方式和状位读取扩展值，在原有等间距中心覆盖计算前扩展目标区间。第五阶段保持不变。

**技术栈：** Python 3、JSON 配置、`unittest`，以及项目现有的 NumPy/SimpleITK 几何模型。

## 全局约束

- 配置键固定为 `slice_range_extension`。
- 状位键使用现有 `PlaneTypeEnum` 的值：`横状位`、`矢状位`、`冠状位`。
- 每个状位仅支持 `start` 和 `end` 两个键，数值按毫米解释。
- 配置缺失或某一端字段缺失时按 `0.0` 处理，保持现有规划行为。
- 该配置适用于所有部位、切割方式和现有状位，仅在需要额外覆盖时按需添加。
- 当前仓库默认给 `肺部.whole_range.横状位` 和 `髋骨.whole_range.横状位` 配置 `start=3.0`、`end=3.0`；这些默认值不是允许列表。
- 负数、布尔值、非数字及非有限数值必须拒绝。
- `SlicePlan.target_start/target_end` 继续保存未扩展的解剖目标边界。
- 层间距、层厚、角度、定位图行为和第五阶段执行逻辑保持不变。
- 新增或修改的源码类和方法必须提供正常的中文注释或文档字符串。
- 每个状位的扩展对象可以省略 `start` 或 `end`，但不能包含这两个名称之外的键。
