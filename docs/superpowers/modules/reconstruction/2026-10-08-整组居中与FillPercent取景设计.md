## 概念与协议

每项 plane_configs 可传 FillPercent，有限数字范围 [0,100]，拒绝 bool、字符串和非有限值。
请求序列化与交付报告对整数比例输出整数，例如 100.0 回显为 100；真实小数保留精度。
该调整只影响 JSON 数字写法，不改变取景算法；字段名严格为 `FillPercent`，末尾不能带空格。
省略、null、0 的目标取景均按整组范围居中，保留基础像素间距，不放大也不缩小；
肺/髋普通 MPR 以扩大共同矩阵保护原 CT 切面，其他适用模式随后仍执行平面成片上下裁空；
正数根据整组目标及获准显示支持计算比例；未启用下述 `selected_region` 的肺/髋普通 MPR 的 100 另以完整人体与目标的
紧致包络取景。肺部仍整组共同平移，髋骨由当前厚层目标中心作必要的安全居中修正；
其余比例及模式按原目标中心规则。裁空前组内矩阵和像素间距一致，
不按每层目标大小重新计算倍率。请求占比用于共同取景尺寸，每张实际目标不一定达到它。
100 不是“原始倍率”。未启用 `selected_region` 的肺/髋普通 MPR 的 100 以完整人体与目标的紧致包络决定共同视野，
优先去掉偏心中心造成的外部空气；目标部位可能不再位于绝对正中。肺部肩臂仍可决定
整组共同宽度，其他较小截面保留自然大小，不保证每张或任意胶片格两轴都贴边。
未启用 `selected_region` 时，80 等 `0<FillPercent<100` 继续按共同标签目标尺寸及既定中心适配，并受完整人体保护限制。
0 才是保留原采样倍率。旧 line_extent_mode 字段和枚举已移除，传入会报错。

占比的参照物是输出图像，不是屏幕，也不是 ITK 的百分比。
共同取景基准原本占 60%，设 80 会放大为原来的 80/60 倍；原本占 95%，设 80 会缩小。
肺部基准包含固定参考平移下全组覆盖需求，不能直接用参考层自身 bbox 代入。
上述目标公式用于肺/髋的 `0<FillPercent<100`，还受完整人体保护限制；
100 使用独立的紧致包络公式，不能继续代入旧标签对称视野公式。
目标范围来自所选分割标签，不来自窗位后的亮像素，也不等于整个人体外轮廓。
颅脑配置目标为 `brain`，有可用同次 `skull` 时，只保留其沿最终 SI 与脑区物理支撑
范围正重叠的体素；横状位 MPR 计划用 `framing_superior_extension_mm` 快照同步扩大
取景上界，当前默认为 `10 mm`，下界仍为脑区。筛选后的骨与脑区组成有界取景目标；
骨只影响取景，不能扩大切割范围或
把远处下颌、面部骨加入层组。正数 FillPercent 按有界目标确定共同倍率、逐层居中；
0/null/省略也以有界目标的整组中心居中，保留基础像素间距。骨缺失时只用脑区并警告。
这项有界骨取景对所有 FillPercent 生效，与下文只在正数时应用的脊柱上下文不同。
方向和基础范围仍仅由脑区估计，头侧余量只来自现有 `range_extension`，
详见[颅脑形态斜切设计](2026-10-20-颅脑形态斜切设计.md)。

### 可配置的所选部位取景

在普通 MPR 的 `slice_rules.<状位>.MPR` 中可选配置：

```json
"framing_policy": { "basis": "selected_region", "margin_mm": 5.0 }
```

这是统一部位配置，不是请求字段，也不按部位硬编码倍率。配置对象只允许 `basis` 和
`margin_mm`，两者必需；`basis` 当前只能是 `selected_region`，`margin_mm` 必须是
非负有限数字，拒绝 bool、字符串、负数、NaN 和无穷值。CPR、椎间隙不允许配置该对象。
第六阶段按当前状位的普通 MPR 规则深拷贝到 `SlicePlan.framing_policy`，仅非 None 时序列化；
第七阶段在所有正数 `FillPercent` 下读取它；0、null 或省略忽略该策略，保留各部位原有行为，
默认髋骨冠状位仍保留基础间距及完整源切面保护。

当前仅髋骨冠状位默认启用此分支，横状位、矢状位及肺部配置不变。以本计划所选原目标
标签的全组物理外包络为取景依据，投影到实际行、列轴后得到边界 `[L,U]`。设每侧余量为 m，正数占比为 p：

```text
共同面内中心 = (L + U) / 2
共同目标基准 T = U - L + 2m
共同物理视野 = T / (p / 100)
```

使用统一等比例 PixelSpacing 和共同 Rows、Columns 适配该视野，像素数向上取整并保持
原矩阵奇偶性。整组每张均使用上述面内投影中心，保留各自的法向深度；小标签末层、空
目标层也沿用固定中心和倍率，不逐层追随残余标签。此分支不再扩大到完整人体支持，不以
每层体表或像素亮暗决定中心，也不执行后续单侧上下 ROI。它优先容纳本次所选标签包络，
允许腹部、外围皮肤、大腿及目标包络之外的股骨远端越框；这属于获准裁取外围组织。

诊断使用 `framing.center_source=group_selected_region`，并在 `framing.selected_region`
记录 `basis`、`margin_mm`、`lower_in_plane_mm`、`upper_in_plane_mm`；两组边界是未加余量的
原标签整组包络，顺序为行、列方向。`framing_target_size_mm` 是原包络尺寸加 `2*margin_mm`，
`slice_target_size_mm` 仍记录当前厚层尺寸或空值。此路径不加入自动相邻标签、人体支持，
也不产生 `source_preservation` 或 `skin_edge` 诊断；不能按人体保护公式解释它的倍率。

100优先完整容纳所选部位；降低正数占比时，以相同固定中心从完整原 CT 重采样更大的
物理视野。原 CT 没有先裁到标签框，外围皮肤、腹部和大腿会随着视野扩大逐渐露出；
80不承诺包含全部体表，超出源 CT 的位置保留正常无数据背景，不伪造组织。

`source_labels`、层面与方向、法向范围、层厚、层间距、数量和定位图均不变；实际成片
中心和 DICOM 原点按最终几何写出。该配置可供其他部位的普通 MPR 复用，不能据此声称
没有单独标签的结构得到普遍保护：当前模型 294 只有左右髋骨/股骨相关标签，没有独立
`sacrum`、`coccyx`。本次两份真实髋部源数据另经人工核对骶骨中线、髋臼和股骨头，
这项病例核对不构成所有骶尾结构都有标签保护的保证。

| --- | --- | --- |
| 其他部位普通 MPR | 保留原组投影范围，结合逐层原目标与有界显示上下文的联合尺寸决定倍率与中心 | 切面方向和沿法向层位置 |
| 肺部普通 MPR | 先以最大目标 bbox 面积层定共同平移；100 再加整组相同的紧致包络校正，其他正数保持原平移与人体保护；不做后续单侧 ROI | 原目标、切割范围、层面与方向；0/null/省略保护完整源切面并保间距，必要时扩共同矩阵 |
| 髋骨普通 MPR | 冠状位正数默认按 `selected_region` 固定组中心、视野按目标基准除以占比连续变化；未配置时100将必要坐标移入完整人体合法区间，其他正数保持目标中心及人体保护；不做后续单侧 ROI | 原目标、切割范围、层面与方向；0/null/省略保护完整源切面并保间距，必要时扩共同矩阵 |
| 椎间隙 | 同配置各间隙共用裁空前矩阵及比例，每张按相邻椎体完整标签（含附件）与有界上下文的厚层内联合范围居中 | 每个间隙原有斜横角度、层位置 |
| CPR | 原曲面展开原目标加有界上下文，全部厚层展开掩膜并集决定倍率，当前展开掩膜决定中心 | 曲面路径、offset 及厚层采样定义 |

其他部位普通平面使用全部目标体素的投影极值，包含位置偏移和半体素外缘，
而不是只挑面积最大的一层。肺部参考层共同平移和髋骨逐轴最大厚层尺寸规则见下文。
除肺部正数普通 MPR 使用参考层共同平移及 `selected_region` 的固定组中心外，其他正数取景先选取物理支撑范围与当前厚层
相交的目标体素，再将其在行列方向的包围框中点
移动到画布中心；体素中心到层中心的法向距离小于半层厚加体素法向半支撑范围时视为相交，
仅接触厚层边界而没有正厚度重叠的体素不参与。
面内包围框包含半体素外缘，不能只按体素中心是否落在厚层内筛选。
该平移仅沿行列方向进行，不改变法向深度、方向、倾角、层厚、间距或张数。
MPR 定位线直接按第六阶段真实无限平面与背景求交，仅裁到底图边界；
端点和长度不随取景变化，定位线不表示正式切片的有限视野。
CPR 正数时在当前厚层展开掩膜上求中心，不修改曲面采样路径。
肺部有参考层时，包括空目标层在内均沿用同一平移；只有所有计划实际厚层均无可用目标时
才回退组目标中心。其他模式当前厚层内原目标与有界上下文均为空、或当前 CPR 掩膜为空时，
回退整组目标中心，仍使用共同倍率；原目标为空但有上下文时仍按联合范围居中。
0、null 或省略的目标取景继续使用整组中心和基础像素间距；肺/髋普通 MPR 必要时扩大共同矩阵，
不做上下 ROI；其他适用平面后续上下裁空仍可改变最终图像中心。
末端小截面仍保持自然大小，不单独放大；不能要求组内每张都达到 80%。
缺少目标 label_ids、分割中没有目标或 CPR 整组掩膜为空时明确失败，不用背景兜底。

## 切割目标与显示上下文

`source_labels` 继续决定第六阶段切面、法向范围及切片数量；第七阶段的显示上下文
只影响取景中心与共同视野，不能回写或扩大切割目标。

肺部正数普通 MPR 采用参考层共同平移，其他部位沿用正数逐层目标居中；下述脊柱额外
上下文按解剖家族识别。当前识别脊柱椎体家族时，
从本次推理模型的 `dataset.json` 标签表加载同类椎体标签，不硬编码模型数字 ID，
不把全部前景或无关器官当作目标。`sacrum` 仅在原始目标显式选中时保留，不自动加入。
无同类家族或没有可用模型标签表时沿用原目标；存在但损坏的标签表明确报错。

脊柱上下文仅保留与原 `source_labels` 目标沿患者 LPS 头脚轴的物理外边界有正重叠的体素，
范围包含体素物理支撑外缘；该轴是患者物理头脚轴，不是随切面倾角变化的法向或数组轴。
不能加入整条相邻椎体的远端结构来扩大视野。各当前厚层再按原目标与这些有界上下文
体素的联合包围框居中；这样即使计划末端原目标仅剩附件，同层相邻椎体主体仍参与取景。
原目标的法向覆盖、层厚、间距、数量、方向和定位背景取样保持不变；MPR 定位线
仅按背景显示边界裁剪，不使用正式成片视野。

例如胸椎原目标截至 L1，尾层 L1 只剩后方附件，但该厚层的 L2 主体仍实际可见。
只将 L1 残余附件居中会把 L2 主体推到画外；在原目标头脚范围内纳入 L2 显示上下文，
即可对当前可见结构居中。该病例尾六张联合范围均可装入既有约 125.23 mm 视野，无需改变倍率。

CPR 正数时先将有界上下文加入标签取景掩膜，再按原曲面展开；曲面路径和厚层 HU 采样不变。
0、null 或省略不加载上述脊柱显示上下文，保留原目标取景和基础间距；平面成片仍执行下述上下裁空。
颅脑有界骨支持按最终 SI 筛选，对所有 FillPercent 生效，具体规则见前述颅脑段落。

### 肺部参考层与髋骨逐层目标取景

本节不适用于已启用 `selected_region` 的正数计划，后者使用前述固定整组标签包络。

两部位正数 `FillPercent` 的 `plane_stack` MPR 均以选定目标及获准有界标签为显示基准，
厚层 bbox 包含半体素物理外缘。目标决定原始中心及标签占比基准，人体不参与标签 bbox
或肺参考层选择。`0<FillPercent<100` 时人体只约束安全视野；100 则以人体与目标并集
的紧致包络同时确定安全视野及必要的面内中心校正。
无法识别人体的源层局部回退完整源盒，不产生 `BODY_FRAMING_SUPPORT_UNAVAILABLE` 告警。

肺部在每个状位计划的实际厚层中，按联合 bbox 宽×高面积最大值选参考层；这不是标签
像素面积，空目标层不参与比较。面积相同取计划中最早的层，只允许浮点舍入容差。
设该层原计划面内中心为 Cref、bbox 中点为 Mref，则整组平移 delta=Mref−Cref。
100 校正前，每层（包括空目标层）的面内中心为原计划中心加同一 delta，不逐层追随标签，
保留原有层间位移。仅全部实际厚层均无目标时，使用原整组目标中心回退，不设置参考字段。

固定参考平移可能使其他层目标超出参考层范围。对第 i 层，设平移后中心为 Ci，
实际联合 bbox 为 [Li,Ui]，整组共同尺寸逐轴计算：

```text
reference_area_i = (Ui.x - Li.x) * (Ui.y - Li.y)
delta = reference_bbox_midpoint - reference_planned_center
Ci = planned_center_i + delta
required_size_i = 2 * max(Ui - Ci, Ci - Li)
(Tx, Ty) = 各非空实际厚层 required_size_i 的逐轴最大值
```

据此计算共同目标尺寸，再结合下述人体保护统一计算倍率和画布，必要时只将全组视野放宽一次，不能裁掉其他层目标，
也不能单独改变某张倍率或平移。这些标签尺寸仍用于诊断及其他正数比例；100 的实际共同视野按下一节紧致包络计算，
不能为了贴边删掉其他层目标。末端小截面保留自然大小。

髋骨校正前以当前厚层联合 bbox 中点逐层部位居中，Tx、Ty 取实际各厚层联合尺寸逐轴最大值，
不把跨层位置漂移算进目标尺寸；当前厚层无目标与获准支持时回退组目标中心。
两部位三状位普通 MPR 均按下述保护范围及共同画布规则取景，不执行逐张上下无源支持行 ROI。
100 采用下述共同偏移或合法区间校正；其他正数保持肺部共同平移或髋骨逐层目标中心；
0/null/省略保持整组目标中心和基础间距，仅在必要时扩共同矩阵。
其他部位、切法仍保留各自规则。

### 人体支持与显式内部工具

未启用 `selected_region` 的肺/髋正数普通 MPR 从第七阶段实际采样 CT 按 HU 提取完整人体支持，每个源只提取一次。
外部空气和可可靠分离的薄床板不纳入保护；肩膀、手臂及双腿仍完整保留，不能只保留最大
连通躯干或因排臂缩框。人体外缘加 `2 mm` 余量，内部肺气和空腔不影响重建 HU。
无法识别人体的源层局部使用完整源盒，与身体相连或无法可靠分离的设备保守保留。
`build_body_framing_support`、`trunk_framing.py` 及 `TargetFramer` 显式 `body_support`
参数仍保留内部工具语义；躯干排臂和显式工具的中心策略不属于生产默认取景。
人体支持不重写标签目标、原 HU 或参考层；100 可校正面内中心，其他正数只约束 FOV。
它不能补全扫描外组织。
任何显式调用仍不得改变原切面、法向层位置、方向、顺序、层厚、层间距、数量或 Localizer。

## 等比例公式

设输出矩阵为 Nx、Ny，原像素间距为 sx、sy，目标范围为 Tx、Ty，正数占比 p=P/100。
以下目标适配公式不用于肺/髋普通 MPR 的 100；该情况使用下一节独立紧致视野公式：

```text
f = max(Tx / (Nx*sx), Ty / (Ny*sy)) / p
new_spacing = (sx*f, sy*f)
线性放大倍率 = 1/f
```

占比以像素外边界定义，用 N×spacing；采样矩阵的中心跨度仍是 (N−1)×spacing。
两轴使用同一倍率，保留原像素纵横比；普通 MPR 默认保留裁空前输出矩阵，CPR 输出矩阵不变。
肺部、髋骨普通 MPR 且 p>0 时，再按下一节收紧共同画布，不能在收紧后重新计算倍率。
默认目标中心由包围框中点确定，不是质量重心，也不是肉眼认定的椎体中心。
正数 FillPercent 下，椎间隙两椎体有通过质量检查的明确对称面时，
沿切面内 LR 投影将包围框中心移到该面，其余面内分量和法向位置保持不变。
不从一般 global_frame.origin 推断面点；拒绝姿态、面点落出有效范围、空层或 LR 主要
指向切面法向时保留默认策略。该约束不改变切片方向或原始前后倾角。
极小百分比若使物理视野无法有限表示，采样前明确报错。

其他部位普通平面的 Tx、Ty 逐轴取原始目标整组投影尺寸与每个厚层原目标加有界上下文联合尺寸的
最大值。原整组投影基准不能因逐层目标变小而缩小，也不能只移动中心却忽略新增上下文的覆盖需求。
肺部正数普通 MPR 的 Tx、Ty 为参考层固定平移下完整覆盖所有实际厚层目标的对称尺寸，
按前述 required_size_i 逐轴取最大值；髋骨仍取实际各厚层联合尺寸逐轴最大值，不把跨层
位置漂移计入尺寸。两者的 Tx、Ty 仍是标签尺寸，人体不混入目标基准；实际倍率另受人体保护限制。
若联合尺寸需要放宽视野，整个计划只统一计算一次新倍率；不得让各层 PixelSpacing 不一致。
应用对称面居中时，尺寸逐轴使用新中心到完整联合边界的最大距离乘二；所有层预先参与
整组/间隙配置的倍率统计，FillPercent=100 时也必须容纳长侧，不能先缩放再单独平移造成截断。

### 肺部、髋骨三状位共同画布

本节人体保护与 `skin_edge` 公式排除前述 `selected_region` 分支；默认髋骨冠状位正数使用标签包络加5mm余量并除以请求占比。

肺部、髋骨的正数 `plane_stack` MPR 对横、冠、矢三状位先保护完整人体切面，再确定共同画布，
不逐张独立放大。人体支持及其几何来自第七阶段实际采样 CT，不能用分割图范围代替。
源层人体支持包含半体素物理外缘及 `2 mm` 余量，并按实际斜切方向与厚层采样投影到行、列轴，
得到各层保护包围范围 [Si.lower, Si.upper]。近轴厚层还覆盖实际参与平均的源层中心。
`0<FillPercent<100` 围绕既定中心 Ci 求对称保护尺寸并逐轴取最大值 S；
100 则按下述人体与目标并集的紧致包络确定中心和共同视野。无源支持的层不增加人体约束。
该约束保护目标标签外的皮肤、骨骼及四肢，不按窗化黑色删像素，不因肺参考层较小而排除肩臂。
人体识别失败的源层局部回退完整半体素源盒，设备不能可靠分离时保留，不补全扫描外内容。
人体支持保留较小的独立肢体和体表组件；仅过滤距已确认人体超过 `3 mm`、面积不足
`4 mm²` 的孤立阈上噪点，避免低剂量 CT 的体外噪声重新撑满源画布。该距离只从
已确认人体计算一次，不从新增组件迭代扩散。独立薄床须满足整个组件位于人体后缘之外，
或有跨越人体中央左右带、位于人体后缘之外的床面证据。前者覆盖被源 FOV 截断的左右
床片段，后者允许床侧翼向前翘起，不以整体 AP bbox 重叠直接否决。
与身体相连的床板不拆分；不能可靠判断的组件继续保留。
0/null/省略不使用人体缩框，仍以完整源半体素边界盒与实际厚层交集求 S。
两条路径均不改变法向范围和层数。

`0<FillPercent<100`（例如 80）保持原目标中心与原公式：

```text
protected_required_i = 2 * max(Si.upper - Ci, Ci - Si.lower)
S = 各有支持厚层 protected_required_i 的逐轴最大值
required_field_of_view = max((Tx, Ty) / p, S)
```

100 使用独立公式。先把每层人体保护范围与该厚层目标 bbox 取并集，记作 `[Li, Ui]`，
`Ci` 为原目标取景中心。人体已包含 `2 mm` 保护余量，源层回退仍参与同一计算。
肺部保持整组相同的面内平移，并额外应用同一个校正；所有层和空目标层均沿用：

```text
a = min_i(Li - Ci)
b = max_i(Ui - Ci)
center_adjustment = (a + b) / 2
actual_center_i = Ci + center_adjustment
required_field_of_view = b - a
```

髋骨使用各层完整并集尺寸的逐轴最大值作为共同视野，仅移动原中心中无法容纳人体的坐标：

```text
required_field_of_view = max_i(Ui - Li)
legal_center_lower_i = Ui - required_field_of_view / 2
legal_center_upper_i = Li + required_field_of_view / 2
actual_center_i = clip(Ci, legal_center_lower_i, legal_center_upper_i)
center_adjustment_i = actual_center_i - Ci
```

它不盲目跟随每层体表中心；原坐标已在合法区间内时不动。髋冠位尤其可消除目标中心沿 SI
漂移造成的额外空气，完整保留源范围内的人体。100 不再取旧标签对称视野与人体视野的
较大值，否则偏心标签中心产生的空气会重新撑大画布。`framing_target_size_mm` 仍记录原标签
基准，不能把它当作 100 的实际视野。肺部参考层索引仍由最大目标 bbox 面积决定，
实际共同偏移包含紧致取景校正；肩臂可能决定整组宽度，较小层不单独放大。

三条正数路径确定完整共同物理视野后，都在原矩阵下求唯一的等比例间距及倍率，再收紧共同画布：

```text
f = max(required_field_of_view / ((Nx, Ny) * (sx, sy)))
new_spacing = (sx, sy) * f
scale = 1 / f
required_size_xy = required_field_of_view / new_spacing
output_size_xy = 向上取整 required_size_xy
output_size_xy += (原矩阵 - output_size_xy) % 2
extent_mm = (output_size_xy - 1) * new_spacing
```

取整只消除浮点误差，不得向下裁掉真实支撑；每轴至少一个像素且不大于原矩阵。
向上补到与原矩阵各轴相同的奇偶性，最多额外保留一个像素空气。共同画布相对各层
最终实际中心对称；100 可能改变原目标中心相对源图的网格相位，不能宣称只对原图作整数 ROI。
new_spacing、scale 和像素纵横比不再重算，组内所有层及所有窗共用 Rows、Columns。
首像素位置按实际矩阵和最终中心重算，之后不执行逐张上下无源支持行 ROI。

肺/髋普通 MPR 在 0/null/省略时不计算上述目标适配倍率，保留原间距、scale=1 和整组目标中心；
共同矩阵逐轴取原矩阵与 `ceil(S / spacing)` 的较大值，再保持原奇偶性，可超过原矩阵。
之后不执行上下 ROI，不能通过改变间距或裁源内容维持原矩阵。
其他部位、椎间隙、CPR 和 Localizer 不应用此共同画布调整。切面、法向层位、
方向、层厚、层间距、顺序、数量不改变。人体保护优先于请求占比，100% 也不能裁掉皮肤、
肋骨或骶尾骨来填满画面。实际目标占比可能明显降低，不保证参考层、髋骨最大目标层、
每张小截面或任意胶片格的宽高同时铺满；不通过拉伸变形填满画面。

### 椎间隙共同画布

椎间隙以前面各组画布为基准：按有效计划顺序，取末组之前各组基础矩阵的逐轴中位数，
按 NumPy rint 取整后作为同一部位、同一配置的共同 Nx、Ny；单个有效间隙使用自身基础矩阵。
再把各间隙的原整组投影尺寸与逐层原目标加有界上下文联合尺寸逐轴取最大值得到共同 Tx、Ty，
正数 FillPercent 按上式计算一次，必要的视野放宽同时应用于同配置所有间隙。
末组的较窄或偏高画布不决定共同矩阵，避免把所有间隙一起缩小；
正数 FillPercent 下，全部目标尺寸仍参与比例计算以保证覆盖，不因末组排除画布参考而裁掉其目标结构。
不能把不同间隙的物理坐标包围框直接合并，否则层位置差会错误扩大视野。
各间隙在上下裁空前共用 Rows、Columns、PixelSpacing 和物理视野，正数时每张按自身厚层内标签居中；
解剖本身大小不同仍会显示大小差异，不通过拉伸改变真实比例。
0、null、省略时同样统一裁空前矩阵，保留原像素间距，scale=1，不额外按目标范围适配；
共同矩阵比某组原矩阵更小时，该组周边视野随之减少。
配置由 config_id、输出状位和部位隔离；旧计划缺 config_id 时按输出状位与部位分组。
仅实际生成的有效间隙参与统计；已生成计划缺少目标标签仍明确报错。

### 平面成片上下无源支持行裁剪

除肺部、髋骨的普通 MPR 外，`plane_stack` MPR 和椎间隙
在完成 HU 厚层采样后、窗化前，调用
`vertical_support.py` 的 `crop_vertical_padding`。它按源 CT 几何、实际输出列和厚层
采样点判断每行是否存在源支持，仅裁掉首个有效行之前和末个有效行之后的完整空行。
常规路径仅通过连续源索引的几何区间判断。半体素边界附近 strict/loose 判断有分歧时，
直接复用实际 source 和完整 `Columns×Rows×1` reference，只读取不确定行的结果；不能
缩成单行或移动 reference 原点，否则 ITK 快速扫描线的浮点舍入可能改变边界支持判定。
复核按实际厚层子平面取支持并集，全部不确定行获得支持后即停止，不重新计算 HU 厚层平均，
也不创建整卷常数掩膜；NaN、+Inf 双越界哨兵区分越界与源像素本身的 NaN/Inf，避免按 HU 值误判。
不按 HU 阈值或窗化后的黑色判断，不能把真实空气、窗位黑色或斜切角部当作无数据带。
裁剪使用 ROI 保留原有效行及其 HU、Columns、PixelSpacing 和采样网格相位，不重新采样、拉伸或补黑框；
左右允许留白，整幅裁后图像的物理中点作为最终显示中心。

启用 `selected_region` 的计划及肺部、髋骨普通 MPR 跳过此步骤，以保留共同矩阵；前者使用固定组中心，其余使用 100 的 skin_edge 中心或其他正数的肺部参考平移、髋骨逐层目标中心、
0/null/省略时的整组目标中心；其余适用平面
在 0/null/省略和正数 FillPercent 下均执行。CPR、Localizer 背景及定位线不执行。各层首尾空行数可能不同，故最终 Rows 和垂直物理视野
可以逐层不同；同层所有窗位仍共用裁后的几何与 HU。同组共同倍率和 PixelSpacing 不变。
不能使用全组最短有效高度统一裁剪，否则会删除其他层的有效内容；也不为恢复共同 Rows 补框。
整张均无源支持的层保持原样，并标记 `vertical_source_support.status=no_source_support`，
不能伪造有效内容。裁空前的普通平面厚层平均只纳入有效源采样，轴对齐按有效重叠厚度、
斜切按有效子平面数归一；真实空气参与，越界填充值不参与。它能恢复部分支持却被填充值
压黑的组织，但不能恢复所有采样点均在源 CT 外的位置，也不改变既定切面、范围或张数。
该裁剪只去掉上下完整无数据带，不能消除首末斜切层图内的局部零支持黑区。
外部查看器的额外黑框仍由 fit 设置和格子
宽高比决定；完整保留内容、保持比例时，后端无法保证任意格子四边均铺满。

## 执行顺序

第六阶段透传 fill_percent，并为普通 MPR 深拷贝当前状位的可选 framing_policy，仍产生基础视野与原切面计划。
第七阶段从定位结果的分割路径读取目标，不能延长第三至五阶段临时 label 快照的生命周期。

普通 MPR/间隙先调整采样几何，再从原 HU 体数据直接重采样；肺部、髋骨普通 MPR
保留共同画布；已启用 selected_region 的正数计划使用固定标签组中心，其余100使用 skin_edge 中心，其他正数保持肺参考平移或髋逐层目标中心，0/null/省略保持组目标中心，
其他适用平面随后逐张裁去上下无源支持行；
CPR 先在原曲面上采样 HU 和标签掩膜，再按整组范围确定共同间距，
正数时使用当前展开掩膜中心对展开图线性重采样，空层回退组中心。
CPR 掩膜用最近邻、厚层取并集；HU 用线性插值、厚层平均，两者不能混用。
CPR 不需要额外展开全体标签的三维点数组来计算平面投影。
新矢状位 CPR 的原曲面指固定 AP 参考面内的冠状投影采样几何：只展开左右侧弯，
保留前后生理曲度。取景使用同一几何采样出的 HU 与掩膜，只作整张图的共同缩放
和面内平移，不能再次逐行跟随真实三维 `curve_points` 的 AP 坐标居中来消除曲度。

定位图直接读取第六阶段原始计划的真实平面位置和法向，不依赖正式成片中心或
`framing.extent_mm`。普通 MPR 将无限平面与背景平面的交线裁到底图边界；曲面背景
按同一真实平面与曲面求交，只裁到曲面显示网格。定位图保留原图网格和固定
`localizer_reference`，不随正式取景缩放、裁切或逐层移动。相同输入、窗位及计划下
切换 FillPercent，背景矩阵、像素间距、参考点、取样及 MPR 交线端点/长度均不变。
定位线不表示正式切片的有限视野，CPR 中心曲线仍投影真实计划路径，绘线不回写原计划。

取景发生在正式切片窗化前，各窗共用同一份成片几何及未取整的重建 HU，
随后按各自实际窗宽窗位生成显示灰度并写入对应标签。
原计划不被原地修改，重建结果逐层 framing 记录 mode=group、source=group_target、
整组目标尺寸、实际中心、间距与共同倍率，用于排查。mode/source 表示共同目标取景的来源，
未启用 selected_region 的肺/髋普通 MPR 的实际倍率和矩阵还受人体保护（正数）或完整源保护（0/null/省略）约束，
不单独规定切片的面内中心。selected_region 诊断见前节，以下 center_source 和人体保护字段不用于该分支。裁空前另记录 center_source：
肺部有实际参考层时，其他正数比例的所有层（含空目标层）为 group_reference_slice，
100 为 group_skin_edge。记录 reference_slice_index、reference_shift_mm（最终实际共同面内偏移，
不是绝对中心）和 reference_target_size_mm（参考层目标 bbox 尺寸）；100 新增
reference_target_shift_mm 保存校正前标签偏移。全部实际厚层均无目标时原目标来源为 group_fallback，
不记录 reference 字段。髋骨其他正数及其他逐层模式有目标时为 slice_target，空层为 group_fallback；
0/null/省略为 group_target。100 的髋骨为 slice_skin_edge；两部位 100 另用 target_center_source、
target_center_before_skin_edge 保留校正前的中心来源和物理中心。生产不自动记录身体支持字段。
显式 body_support 工具仍可产生自身诊断字段，但不属于默认请求路径。

可靠对称面居中为 slice_symmetry_plane，另在 symmetry_centering 记录面点、法向、来源标签、
状态和实际面内平移；此状态仅描述取景，不代表重新估计或修改了姿态。
slice_target_size_mm 记录当前厚层目标尺寸或空值；肺部参考平移模式仍逐层记录，不能当成参考层尺寸。
context_label_ids 记录实际参与取景的额外标签；普通平面的 framing_target_size_mm
记录共同目标基准：其他部位为原组范围与逐层上下文覆盖需求的逐轴最大值，肺部正数普通
MPR 为参考平移下覆盖全组目标的对称尺寸，髋骨为实际厚层选定目标与获准有界标签联合尺寸逐轴最大值。target_size_mm 保留原组投影尺寸，
便于区分原切割目标和额外显示需求。CPR 记录 context_label_ids，其取景尺寸来自加入上下文后的展开掩膜。
未启用 selected_region 的肺/髋生产普通 MPR 另记录 source_preservation：正数为 mode=complete_body_slab，
body_margin_mm=2，fallback_source_slice_count 记录人体不可识别而回退完整源盒的源层数；
0/null/省略为 mode=complete_source_slab。两者均记录 required_size_mm（共同保护尺寸）、
field_of_view_mm（输出矩阵乘实际间距）和 zoom_limited（保护范围是否限制目标适配倍率）。
100 另记录 canvas_mode=skin_edge、centering_policy（肺为 group_offset，髋为 nearest_body_fitting_center）
及该层 center_adjustment_mm（沿行、列方向的实际校正毫米数）。100 的 required_size_mm 是
人体与目标并集的紧致共同视野，其他正数仍为既定中心下的对称保护尺寸。
framing_target_size_mm 不混入人体或源盒尺寸，scale 始终表示实际倍率。
普通平面的 output_size_xy 记录实际输出列数、行数，包含肺部、髋骨三状位共同画布收紧，
或其他适用平面上下裁空后的矩阵。
上下裁空后同步更新 center、extent_mm、output_size_xy 和实际 DICOM 原点；
center_source 改为 source_supported_image，原目标中心来源保存在 target_center_source。
vertical_source_support 以 mode=source_support_crop 记录 crop_top_rows、crop_bottom_rows、
original_rows 和 original_center。无须裁空时保留既有 framing；整张无支持时仅记录上述状态。
椎间隙另记录 scale_scope=interspace_config、shared_target_size_mm、shared_plan_ids，
分别表示比例适用范围、共同目标尺寸和参与计划。
canvas_reference_plan_ids 记录用于确定共同画布的前面各组计划。
预计算逐计划释放完整目标点云，随后仍逐计划采样 HU，不同时持有多组图像。

## DICOM 与已知限制

`selected_region` 正数计划使用前述固定组中心与标签包络除以占比的共同视野，外围组织允许越框；下述人体保护中心规则仅指未启用该配置的计划。

写出实际 PixelSpacing、ImagePositionPatient、ImageOrientationPatient；
SliceLocation 使用实际成片平面的法向投影。层厚、层间距、数量不因 FillPercent 改变。
普通平面组保持统一 PixelSpacing 和 Columns；肺部、髋骨普通 MPR 还保持共同 Rows。
100 肺部保持含校正的整组共同平移、髋骨保持最近合法中心，其他正数保持原目标中心，
0/null/省略保持组目标中心；其他适用平面上下裁空后 Rows 可逐层不同，
所有 FillPercent 下相邻切片均可能有面内 ImagePositionPatient 平移。
每张空间标签必须真实反映采样几何；不能把这些切片假定为固定面内原点的规则直角三维体，
需要三维重建的读取方应尊重逐张位置并重新栅格化，不能忽略面内位移后直接堆叠。
CPR 是展开图，不能由这些标签把原始弯曲解剖恢复成规则三维体，不能承诺与原 CT 精确三维联动。

取景包含裁取视野与重采样，不是简单改变查看器缩放，也不会创造原始细节。
100 允许像素取整与较小截面留白；肺/髋以完整人体及目标并集的紧致包络取景，
目标可能偏离图像绝对正中。肺最大肩臂仍决定共同宽度，不保证每张小层两轴严格铺满。
共同画布收紧后也不承诺任意胶片格两个方向铺满，
不通过拉伸变形或裁掉选定目标强行填满宽高。
查看器自动对比度、物理比例与屏幕黑边另见
[请求级窗位与 DICOM 显示设计](../viewer/2026-10-08-请求级窗位与固定灰度显示设计.md)。
定位图不应用取景缩放，背景保留原图网格和固定参考点；MPR 线段仅按底图边界
或曲面显示网格裁剪，长度不随 FillPercent 变化。调试时可输出原有定位图 PNG，不新增正式成片 PNG。
