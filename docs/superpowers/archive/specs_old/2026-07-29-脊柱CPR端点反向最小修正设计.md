# 脊柱 CPR 端点反向最小修正设计

> **历史设计：** 本文记录早期“投影到最近合法边界”的方案，不代表当前代码。
> 当前端点规则以
> [`../../modules/reconstruction/2026-07-29-CPR端点反弧回正设计.md`](../../modules/reconstruction/2026-07-29-CPR端点反弧回正设计.md)
> 为准。

## 背景

脊柱冠状位 CPR 的中心路径按解剖顺序使用：

`首端面中心 → 全部椎体质心 → 末端面中心`

阶段四目前先根据首末椎体主体几何选择端面中心，再把端面中心和质心作为硬锚点
送入曲线平滑。主体四面优先路径主要根据面法线寻找入射面的对侧面；当椎体主体
或四棱柱质心存在偏差时，最终选出的端面中心可能落在局部质心弧线的反侧。由于
端面中心也是硬锚点，平滑不会消除这段反向连接，定位线上便会形成首端或末端的
折钩。

本次不调整椎体主体、四棱柱质心或端面识别算法，只在首末端面中心全部解析完成
后，对最终端点做最小方向修正。

实际病例表明，只检查端面连接是否继续“向外前进”并不充分。端面连接与末段质心
方向的点积可以为正，但它在矢状面上的有向转角仍可能与内部质心弧线的转角符号
相反。这种情况不会折返，却会在弧线末端形成反向弯折，视觉上仍然是反弧线。
即使转角符号相同，端面转角明显大于内部质心转角时也会留下可见折角。

## 目标与边界

目标：

- 首端的“首端面中心 → 首个质心”转角必须位于零角与首段质心弧线转角之间。
- 末端的“末个质心 → 末端面中心”转角必须位于零角与末段质心弧线转角之间。
- 端面转角超出合法区间时，仅移动对应端面中心，并使用进入合法区间所需的最小
  位移。
- 全部椎体质心继续作为不可移动的硬锚点。
- 转角原本位于合法区间内的端面中心保持原坐标。

不在本次范围内：

- 不重新生成或修正椎体四棱柱质心。
- 不改变主体四面和候选端面的选择优先级。
- 不修改中间质心链的 Hermite 曲线平滑规则。
- 不引入要求端点明显顺向的角度余量；有向转角等于零即满足最低要求。

## 方向定义

端点反向是矢状位定位图上的 AP–SI 方向问题。判定前先从相关向量中去掉图像
左右轴分量，只使用矢状投影，避免左右方向的小偏差掩盖可见的反向折钩。

设：

- 任一端部质心为 `C`，向内相邻的两个质心依次为 `A1`、`A2`；
- 对应端面中心为 `F`；
- `project_sagittal(v)` 表示从向量 `v` 中移除单位左右轴分量后的结果。
- `turn(a, b)` 表示两个单位矢状向量叉积在左右轴上的有向分量。

统一按“内部质心 → 端部质心 → 端面”的向外方向计算：

`V0 = normalize(project_sagittal(A1 - A2))`

`V1 = normalize(project_sagittal(C - A1))`

`D = project_sagittal(F - C)`

使用 `atan2(turn(a, b), dot(a, b))` 计算带符号转角：

- 内部质心弧线转角为 `A = signed_angle(V0, V1)`；
- 端面连接转角为 `B = signed_angle(V1, normalize(D))`。

端面连接只有在 `B` 位于 `0` 与 `A` 组成的闭区间内时才属于同一局部弧线。
这同时覆盖两类异常：

- `A`、`B` 符号相反：端面连接反弧；
- `A`、`B` 符号相同，但 `abs(B) > abs(A)`：端面连接弯曲过度，仍会形成
  可见折角。

此外保留原有向外方向约束：`dot(D, V1)` 不得小于 `-1e-6 mm`。因此“没有
折返但转向相反”“同向但弯曲过度”和“直接向内折返”都会进入同一个最短投影
修正。

## 最短射线投影修正

当端点违反转向约束时，先在合法角区间的两个边界 `0`、`A` 中选择与 `B`
角距离最近的边界角 `T`。把向外切向 `V1` 绕左右轴旋转 `T`，得到最近合法
边界射线 `R`。

当端点仅违反向外方向约束，或局部质心转角无法可靠计算时，使用 `T = 0`，
即以质心末段向外切线作为边界射线。

随后将端面矢状位移正交投影到射线 `R`：

`length = max(dot(D, R), 0)`

`D' = length * R`

`F' = C + original_left_right_component(F - C) + D'`

因为 `R` 已位于矢状平面，这个修正：

- 把端面移动到最近的合法局部弧线边界上；
- 反弧时修正后的端面转角为零；
- 同向但弯曲过度时，修正后的端面转角恰好等于内部质心弧线转角；
- 正投影落在射线前方时，移动距离是端面到延长射线的最短距离；
- 正投影落在射线后方时，夹紧到端部质心，这是向外射线上最近的合法位置；
- 保留端面中心的左右坐标，消除导致反弧的切向垂直矢状分量；
- 不改变任何质心。

为避免浮点噪声反复触发，方向点积绝对值或带符号转角与合法边界的差值不大于
`1e-6` 时视为位于边界。该容差只吸收浮点误差，不提供额外角度余量。

## 数据流与退化处理

修正放在阶段四 `_build_annotation_centroid_path` 内，位于：

1. 读取全部过滤质心；
2. 解析首末端面中心；
3. **对已解析的首末端面中心执行方向校验和最小修正；**
4. 把端面中心插入质心锚点链；
5. 只对全部质心组成的内部路径执行现有 Hermite 曲线平滑；
6. 首端面到首个质心、末个质心到末端面分别按直线加密；
7. 去掉拼接处重复质心后，组成最终 `curve_points`。

端面不再参与 Hermite 切线计算。原因是当端面位移沿局部质心切向的投影刚好为
零时，质心处指向下一质心的非零 Hermite 导数会迫使三次曲线先进入负投影区域
再返回质心；锚点本身不反向并不能保证最终采样曲线不反向。端部改为直线后，每
个端部采样步都与已校验的端面—质心连线同向，因此不会重新产生负向过冲。

端部直线使用与现有 Hermite 曲线相同量级的采样密度。端面缺失或修正后与端部
质心重合时，不生成对应端部直线；最终路径直接从端部质心开始或结束。

如果端部三个质心中任一必要矢状线段退化，无法定义可靠的内部转向，则只执行原有
的向外方向检查；端面已经向外时沿用当前端面结果。内部转角绝对值小于
`1e-6 rad` 时视为直线，合法角区间退化为零角切线。

如果修正后的端面中心与端部质心在三维空间内重合，则不重复插入该端面锚点。
这样既满足“不反向”，也避免零长度首末段使现有单调性检查退化为原始折线。

## 测试

阶段四回归测试至少覆盖：

1. 首端面虽继续向外但转向与首段质心弧线相反时，仅首端面被最短投影到质心
   延长射线。
2. 末端面虽继续向外但转向与末段质心弧线相反时，仅末端面被最短投影到质心
   延长射线。
3. 端面转向同号但角度大于内部质心转角时，端面被最短投影到内部转角边界。
4. 首末端面转角已位于零角与内部转角之间时，端面坐标完全不变。
5. 修正前后所有椎体质心坐标完全不变，并继续出现在最终 CPR 曲线中。
6. 左右方向存在偏差时，反向判定仍以 AP–SI 矢状投影为准。
7. 修正点与端部质心重合时不产生重复锚点。
8. 最终 `curve_points` 的首端直线每一步均不背离首段质心切向，末端直线每
   一步均不背离末段质心切向。
9. 质心链内部仍保持现有 Hermite 平滑和全部质心硬锚点。
10. 现有端面选择、质心优先级、配置范围和阶段五重建测试继续通过。
