# 颈椎横状位椎间隙设计

## 目标

颈椎显式传入 `SliceType=椎间隙`、`Plane=横状位` 时，按统一切割部位配置引用的
相邻椎体区域生成独立斜横切区域。当前配置为：

1. `C2_C3`
2. `C3_C4`
3. `C4_C5`
4. `C5_C6`
5. `C6_C7`

C1 为环椎，当前配置不定义 `C1_C2`。这项排除只属于椎间隙规划，不从原始分割、
整体定位、颈椎整体坐标或普通 MPR 覆盖范围删除 C1。当前整体范围已延展到 T1，
椎间隙仍为以上五组，不新增 `C7_T1`。

## 阶段边界

- 第二阶段保留模型输出的完整分割，包括整体配置所需的 C1 至 T1。
- 第三至第五阶段合并 `whole_range` 与 `interspace` 标签目标，当前定位 C1 至 T1；
  C1 保留在全量范围和整体坐标诊断中，首尾质心不决定全局头脚方向。
- 第五阶段按 `spine_cpr.excluded_labels` 跳过 C1 主体四棱柱。
- 第六阶段颈椎规划器读取 `slice_rules` 引用的椎间区域；当前为 `C2_C3` 至
  `C6_C7`，并复用腰椎已经验证的相向端边、四棱柱、端面和 bbox 回退链路。
- 第七、八阶段继续按通用 `plane_stack`、窗位和 `RegionList` 契约执行，不增加
  颈椎专用输出格式。

## 约束

- 能力表只注册颈椎横状位椎间隙；矢状位和冠状位请求必须在预检阶段拒绝。
- 每个有效间隙独立应用层厚、层间距和数量配置；数量不是五个间隙的总和。
- 某一相邻标签或几何缺失时只跳过该间隙并记录告警，不得补出 `C1_C2`，也不得把
  数量转移到其他间隙。
- 批量测试按部位和状位保留所有匹配配置，颈椎横状位同时输出 MPR 和椎间隙，
  其他状位按配置选择 MPR 或 CPR。

## 异常几何容错

颈椎内固定、金属伪影或分割缺损可能使单节椎体主体明显偏小，继而放大四棱柱端面
角度误差。椎间规划保留原四棱柱为主几何，只在以下条件同时满足时限制法向：

1. 当前间隙任一端主体体素数低于本次颈椎主体体素中位数的 75%；
2. 四棱柱法向与相邻过滤主体质心连线在矢状面内的偏差超过 10°。

触发后保留原间隙中心和有效长度，仅把法向限制到主体中心线附近 10°，并记录带
区间名称的告警。正常体积的椎体、偏差不超过阈值的区间，以及非颈椎椎间规划均不
应用该修正。相向端边的共同覆盖中点仅在仍保留至少 75% 代表间隙时使用，避免
中心偏向一端的同时，不牺牲明显的有效间隙宽度。

四棱柱是矢状外包络，局部交叠时可能把区间范围压得远小于三维主体的真实间隙。
第五阶段因此额外记录相邻主体最近间隙。真实间隙比四棱柱范围大超过 `1mm` 且至少
有 8 个最近点支撑时，第六阶段只沿当前法向平移切片位置，并记录告警；角度、有效
长度和采样参数保持不变。该位置修正适用于脊柱椎间公共链路，不依赖具体病例或
固定的 `C6_C7` 名称。

颈椎当前末端 `C6_C7` 另有一层受限位置保护。四棱柱范围未被明显压窄，但切片中心
沿相邻过滤主体中心中面偏上超过 `0.25mm` 时，将中心移动到主体中面下方
`0.5mm`；只平移位置，不修改角度和有效长度。已经由真实最近间隙完成修正的区间
优先使用前一条规则，不叠加末端下移。代码按解析后椎间区域列表的最后一项识别
末端，不固定 `C6_C7` 名称，也不按病例名称判断。
