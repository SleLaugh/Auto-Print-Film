# 第六阶段报告实施计划

> 历史计划（2026-10-08 核对）：以下正文保留当时过程，阶段编号和规则不作为现状。
> 当前入口：[2026-10-08-交付报告与响应契约设计](../../architecture/2026-10-08-交付报告与响应契约设计.md)。

> **供执行人员使用：** 按任务逐项实施本计划，各步骤使用复选框（`- [ ]`）跟踪状态。

**目标：** 完善阶段六的报告、输出清单和第五步产物一致性检查，不改变任何重建图像。

**架构：** `ReportingStage` 只消费上下文中已有的 `mapping` 与 `reconstruction` 结果，以及输出目录中的最终 DICOM 文件。正常 `report.json` 只提供部位、检查类型和带实际张数/窗位路径的 `plane_configs`；完整计划与校验细节只在 debug 模式写入 `metadata/处理报告_调试.json`。

**技术栈：** Python、JSON、`pathlib`、SimpleITK（只读取 DICOM 元数据用于校验）。

## 全局约束

- 第六步不得重新计算切割线、切片数量、层厚或层间距。
- 第五步生成的 DICOM 目录结构保持不变。
- `report.json` 是正常交付文件，不受 debug 文件清理影响。
- 校验失败只写入 debug 报告，不修改已经生成的 DICOM。
