# 直线切割模块入口

部位取景策略：普通 MPR 可配置 `framing_policy`，默认仅髋骨冠状位启用 `selected_region`、每侧 `5 mm`。
任意正数占比 p 的共同视野为“整组原标签包络尺寸+两侧余量”除以 `p/100`，固定面内中心、整组共用倍率。
100优先完整显示所选部位；占比降低时从未预裁的原 CT 逐渐显示更大外围，不保证80已露出全部皮肤，超源处保留正常无数据背景。
本文完整人体保护、`skin_edge` 及髋部逐层合法中心说明均指未启用该策略的计划；0/null和肺部正式策略保持原行为。字段、覆盖边界及诊断见[整组取景设计](../reconstruction/2026-10-08-整组居中与FillPercent取景设计.md)。

整组取景的公式及边界见 [FillPercent 设计](../reconstruction/2026-10-08-整组居中与FillPercent取景设计.md)，
多配置批处理见 [批量执行设计](../../architecture/2026-10-08-批量执行与配置透传设计.md)。
同目录旧流程 SVG/PNG 展示历史范围模式，不作为当前 FillPercent 的实现说明。

本模块描述第六阶段如何把基础 MPR 和椎间隙切片统一到直线切割流程。

## 当前有效规则

- 整切和区间切只在“生成多少个待切区间”上不同。
- 后续方向、图像范围、层厚、层间距和切片展开复用通用直线流程。
- `line_extent_mode` 已移除。每项可选 `FillPercent`（0 到 100），
  第七阶段统一计算整组倍率；肺部正数普通 MPR 用参考层共同平移，髋100按合法区间修正、其他模式按原目标规则居中，
  空层按各自策略处理。0、null 或省略维持整组居中、不缩放；肺/髋普通 MPR 必要时扩共同矩阵保源，其他适用平面仍执行上下裁空。详见根目录 README。
- 部位 planner 负责解析目标区间；第七阶段不改变切面、层厚、间距或张数，
  只更新平面内取景几何，包括中心、采样间距及椎间隙的共同画布。
- `source_labels` 保持原切割目标；正数取景可加入限定在原目标 LPS 头脚物理范围内的
  同类椎体显示上下文，避免末层仅剩附件时裁掉同层相邻主体。该补充不扩大切割范围；
  共同倍率覆盖原组投影及各层联合尺寸，0/null/省略不应用上下文。
- 椎间隙第七阶段按同一部位、同一项状位配置统一上下裁空前的图片行列数及物理比例，
  各间隙使用自己的相邻椎体标签，正数时按每张厚层内范围居中。共同矩阵取末组之前各组基础矩阵的逐轴中位数，
  取整后供所有间隙使用，单组时回退自身矩阵；全部间隙原组投影及各层有界上下文联合尺寸逐轴取最大值，
  统一计算 FillPercent。0、null 或省略保留基础像素间距，同时统一裁空前矩阵。
- 肺/髋普通 MPR 的 80 等 `0<FillPercent<100` 保持原目标中心与公式：肺部由最大实际目标
  bbox 面积参考层确定整组平移，髋骨按当前厚层目标居中；共同视野取标签目标尺寸/比例与
  既定中心下人体保护尺寸的逐轴较大值。100 则独立采用人体与目标并集的紧致视野，
  不再与旧标签对称视野取较大值：肺部给所有层追加同一个包络中心校正，髋骨共同视野取
  各层并集尺寸最大值，仅把原中心超出合法区间的坐标移入区间，合法坐标不动。
  100 的目标部位可偏离绝对正中，肺部肩臂仍可决定整组宽度，不逐层拉满小截面。
  正数每源提取一次完整人体支持，按实际源几何、厚层采样和 `2 mm` 余量保护皮肤、肋骨、
  骶尾骨、肩臂及双腿；外部空气与可可靠分离薄床板不限制倍率。人体不参与标签尺寸或
  肺参考层选择。人体不可识别的源层局部回退完整源盒，不能可靠分离的设备保守保留。
  同组各层各窗共用倍率、Rows、Columns 和 PixelSpacing，保留矩阵奇偶性，不执行后续上下 ROI。
  100 可校正面内中心，不能宣称相对源图只作整数 ROI 或保持原目标网格相位；DICOM 逐张记录
  实际中心、原点和方向。原计划法向、层位、范围、厚度、间距、张数和定位图保持不变。
  肺/髋普通 MPR 的 0/null/省略仍保完整源切面、不做上下 ROI，保持基础间距、scale=1 和整组中心，
  必要时扩大共同矩阵并保持奇偶性。
- 除上述肺部、髋骨普通 MPR 外，三状位 `plane_stack` MPR 和椎间隙在 HU 采样后、
  窗化前逐张以 ROI 裁去首尾完全无源支持行，
  保留全部有效像素、Columns、PixelSpacing 和网格相位，以裁后整幅图的物理中点居中。
  Rows、垂直视野及中心可逐层不同，同层各窗几何一致；不按 HU 黑色裁剪、不取全组最短高度、不补框。
  0/null/省略同样裁空，CPR 和 Localizer 不裁；整张无源支持层保留原样并标记 `no_source_support`。
- 颈椎、腰椎区间切优先使用第五阶段 `spine_geometry.filtered_annotation_centroids` 的
  `sagittal_body_quadrilateral` 识别两条相向端边，在共同切向覆盖区间内选择有正
  间隙的代表性中点对，并以该连线确定每段斜横切方向；不再让角点最短距离主导
  整条切线。输出平面仍覆盖完整 label 的 bbox 并集。
  四边形缺失时回退 faces，再回退 bbox 规则；存在但无效的四边形直接回退
  bbox，不再使用 faces 绕过失效判定。外包络轻微局部穿入可由相向端边恢复有序
  区间，十字穿越和完整包含仍判无效。S1 使用专用左右支撑筛选和一层相连上缘补回。
- 相邻主体体素量相差超过四倍、四棱柱前后投影无交集、候选法向偏离输入头脚轴
  超过 60° 三项同时成立时，跳过小残块侧壁形成的伪间隙，不再用坏标签的 bbox
  或质心补造切面；保留其他有效区间，并在交付报告 `Message` 中说明跳过原因。
- 椎间隙内部几何法向按上位到下位定向；局部几何处理旋转与侧倾，最终显示符号
  仍参考原图横断面；整切 MPR 使用患者语义参考。
  颈椎法向约束完成后，必要时同步反转显示上下轴和法向，使像素与 DICOM
  几何一致；切片位置、斜切角度和上位到下位的输出顺序保持不变。
- S1 范围配置保留标准名，运行时按实际 `label_targets` 优先使用 `vertebrae_S1`、
  否则回退 `sacrum`；主体配对与 `L5_S1` 计划的 `source_labels` 使用实际标签。
- 每项状位配置通过 `SliceType` 显式选择切法，省略时默认 `MPR`。
- `CPR` 和 `椎间隙` 是能力表约束的附加能力，不允许根据部位自动替换 MPR。

## 当前限制

- 椎体主体 mask 仍由形态启发式生成，不同体型、椎体倾角、退变和原始分割质量可能
  造成边缘少量欠分或过分。
- 主体误差会继续影响矢状四边形、相向端边和最终切线；调试时先按
  `标签掩膜 → 椎体主体掩膜 → 椎体四棱柱掩膜` 检查几何；主体选择由颈、胸、腰椎
  及整段脊柱共用，修改后需同时回归 CPR 和椎间隙。再通过第七阶段
  `Localizer.dcm`/`Localizer.png` 核对实际切片线。
- 当前相向端边和代表性法向的几何链路已经建立；后续优化重点是主体标注的自适应阈值、
  局部解剖轴和多病例稳定性，而不是重新回到全量 bbox 或面中心法向方案。
