# 通用切片区间完整覆盖设计

## 目标

第六阶段生成任意直线切片计划时，首张和末张切片的中心位置都必须到达或越过
目标区间边界。允许首尾中心略微超出目标部位，但不能只依靠厚层外边缘包住
目标，因为厚层平均会让肺尖、肺底等小区域在首末成片中被淡化。该规则适用于
所有部位、所有直线状位、整切和区间切。

## 统一覆盖规则

设目标首尾边界中心之间的物理长度为 `L`，层间距为 `S`。连续切片中心保持
严格的 `S` 毫米间距，`N` 张切片首末中心之间的跨度为：

```text
center_span = (N - 1) * S
```

选择满足 `center_span >= L` 的最小整数 `N`，即非零区间使用
`N = ceil(L / S) + 1`；零长度或长度不超过 `0.001mm` 坐标容差的目标只生成一张。
DICOM 斜向方向余弦和坐标只有有限
小数位，因此当 `L` 与最近一个合法覆盖长度的差值不超过 `0.001mm` 时，将其视为
同一物理边界，并把该微小残差对称分配到两端；不能因为数微米的坐标舍入误差
额外增加一整张切片，也不能把残差全部留在某一端。

首末中心跨度超过目标长度的部分为：

```text
center_overflow = center_span - L
```

将 `center_overflow / 2` 对称分配到目标首端和尾端。由此反算第一张和最后一张切片
中心，再按固定层间距展开全部中心。最终必须满足：

- 第一张切片中心不位于目标首端内侧；
- 最后一张切片中心不位于目标尾端内侧；
- 所有相邻中心距离均等于请求的层间距；
- 使用满足上述条件的最少切片数量。

层厚 `T` 不参与中心数量和中心范围计算，只在第七阶段决定每张厚层采样范围以及
DICOM `SliceThickness`。当层间距大于层厚时，切片之间由调用参数主动设置的
物理间隔继续保留，本设计不擅自修改层间距。

## 代码边界

在 `src/planning/straight.py` 增加通用方法 `cover_segment_range(...)`，由
`build_straight_slice_plan` 和解剖坐标整切共同调用。肺部、髋骨、颈椎、胸椎、
腰椎及头骨不得各自复制覆盖算法。第七阶段继续只读取已经展开的切片中心，不加入
部位判断。

`range_start`、`range_end` 表示对称外扩后第一张和最后一张切片中心；
`target_start`、`target_end` 继续保留原始目标边界，方便调试诊断计算实际超出
或遗漏长度。

## 调试信息与 DICOM

第六阶段增加 `leading_center_overflow_mm`、`trailing_center_overflow_mm` 及对应
`center_uncovered` 字段，明确记录首末中心相对目标边界的关系；原有
`leading_overflow_mm`、`trailing_overflow_mm` 继续表示厚层外边缘超出量。新计划
的中心遗漏量必须均为 `0`，相邻切片间距必须统一。

第七阶段写出的 DICOM 应保留请求中的 `SliceThickness` 和 `SpacingBetweenSlices`。
GDCM 先写同目录临时文件，pydicom 在临时文件内校正两个数值标签，全部成功后
才原子替换正式路径，避免异常时留下标签错误的半成品。派生文件统一声明
`ISO_IR 192`，让 GDCM 写出的 UTF-8 中文与 DICOM 字符集声明一致，患者姓名和
检查描述必须能被标准 pydicom 读取器正确解码。

## 验证场景

- 肺部目标长度 272.35mm、层厚 5mm、层间距 5mm：生成 56 张，首末中心跨度
  275mm，中心在首尾各超出 1.325mm。
- 目标长度恰好可被层间距整除：首末中心恰好位于两个目标边界，不多生成切片。
- 名义 10mm、层间距 5mm 的斜向区间产生数微米长度误差：仍生成 3 张切片、
  保持 2 个 5mm 中心间隔，并保持中点对称。
- 非零目标短于层厚：仍以中心覆盖规则计算；零长度或长度不超过 `0.001mm`
  坐标容差的目标生成一张中点切片。
- 层间距大于层厚：保持请求间距，同时保证第一张和最后一张包住边界。
- 倾斜切片：沿最终切片法向计算物理长度和外扩，不依赖默认 XYZ 轴。
- 整切与腰椎区间切：均使用同一覆盖方法。
- DICOM 回读：`0018,0050` 等于层厚，`0018,0088` 等于层间距。
- DICOM 中文与失败路径：pydicom 正确读取 UTF-8 患者/检查字段，标签校正失败时
  不产生正式切片文件。
