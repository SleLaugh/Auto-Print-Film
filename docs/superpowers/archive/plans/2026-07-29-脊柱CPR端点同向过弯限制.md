# 脊柱 CPR 端点同向过弯限制 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 端面连接与质心弧线同向但弯曲角度过大时，最小移动端面到局部质心转角边界。

**Architecture:** 阶段四继续只移动端面中心。用带符号角把合法方向限定在零角与内部质心转角之间；超出区间时，选择最近边界角并把端面矢状位移正交投影到该边界射线。

**Tech Stack:** Python 3、现有 `Point3D` 几何工具、NumPy、`unittest`

## Global Constraints

- 只移动首末端面中心，不移动任何椎体质心。
- 只在 AP–SI 矢状投影上判断和修正，保留左右坐标。
- 带符号转角与合法边界的差值不大于 `1e-6 rad` 时视为位于边界。
- 不改变端面解析优先级、质心选择、配置范围、Hermite 平滑或阶段五重建。
- 本轮不执行 `git add`、`git commit` 或其他提交操作。

```python
def _signed_angle_around_axis(
    first: Point3D,
    second: Point3D,
    axis: Point3D,
) -> float:
    return math.atan2(
        _dot(_cross(first, second), axis),
        _dot(first, second),
    )


def _rotate_around_axis(
    vector: Point3D,
    axis: Point3D,
    angle_radians: float,
) -> Point3D:
    cosine = math.cos(angle_radians)
    sine = math.sin(angle_radians)
    return _add(
        _add(
            _scale(vector, cosine),
            _scale(_cross(axis, vector), sine),
        ),
        _scale(axis, _dot(axis, vector) * (1.0 - cosine)),
    )
```

在 `_correct_endpoint_face_to_local_arc` 中，把当前转向乘积判定替换为合法角区间：

```python
inner_angle = _signed_angle_around_axis(
    normalize_vector(inner_segment),
    outward,
    left_right,
)
face_angle = _signed_angle_around_axis(
    outward,
    normalize_vector(sagittal_face_delta),
    left_right,
)
minimum_angle = min(0.0, inner_angle)
maximum_angle = max(0.0, inner_angle)
target_angle = None
if face_angle < minimum_angle - 1e-6:
    target_angle = minimum_angle
elif face_angle > maximum_angle + 1e-6:
    target_angle = maximum_angle
if outward_component < -1e-6:
    target_angle = 0.0
```

`target_angle is None` 时保留原端面。否则用 `_rotate_around_axis` 得到合法边界
射线，将端面矢状位移正交投影到该射线，负投影长度夹紧为零；左右轴分量保持
原值。
