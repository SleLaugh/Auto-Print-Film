# 三状位参数请求实施计划

> **给后续执行者：** 按任务逐项执行，每个任务都要先写验证、再改实现、再重新验证。任务列表使用复选框，方便追踪进度。

**目标：** 给请求参数新增三平面配置，让整切重建能够按状位读取层厚、层间距和窗宽窗位预设。

**架构：** 参数契约集中放在 `src/models`。枚举负责限定合法字符串，`PlaneConfig` 负责单个状位的解析和序列化，`Request` 负责跨状位校验。`main.py` 把命令行传入的 JSON 字符串解析成 `PlaneConfig`，报告阶段统一使用 `Request.to_dict()`，避免新增字段后漏写报告。

**技术栈：** Python dataclass、标准库 `json`、标准库 `argparse`、标准库 `unittest`。

## 全局约束

- 新增 `WindowPresetEnum`，枚举值固定为 `骨窗`、`肺窗`、`纵隔窗`。
- 复用已有 `PlaneTypeEnum`，枚举值为 `横状位`、`矢状位`、`冠状位`。
- 新增 `Request.plane_configs: list[PlaneConfig]`。
- 未传 `plane_configs` 时，默认输出三个状位，每个状位使用 `slice_thickness=1`、`slice_spacing=1`、`window_presets=["骨窗"]`。
- 拒绝空 `plane_configs`、重复状位、非正层厚、非正层间距和空窗宽窗位列表。
- 命令行参数使用 `--plane_configs`，同时支持别名 `--plane-configs`；参数值是 JSON 数组字符串。
- 本轮不新增 `--plane_config_file`。
- 本轮不实现 MPR 重建，也不实现 DICOM 输出目录。
- 文档、计划、代码注释和测试注释使用中文；接口名、字段名和命令保持代码原名。

        self.assertEqual(config.slice_thickness, 5.0)

        self.assertEqual(config.window_presets, [
            WindowPresetEnum.骨窗,
            WindowPresetEnum.肺窗,
            WindowPresetEnum.纵隔窗,
        ])

    def test_request_from_dict_parses_plane_configs_and_to_dict_serializes_values(self):
        request = Request.from_dict({
            "dicom_dir": "/tmp/dicom",

                    "slice_thickness": 5,

        self.assertIs(request.plane_configs[0].plane, PlaneTypeEnum.冠状位)
        self.assertEqual(request.to_dict()["plane_configs"], [
