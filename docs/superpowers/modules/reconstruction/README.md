# 重建模块入口

本模块覆盖第六阶段切片规划到第七阶段 MPR 执行，以及各部位直线 MPR 和脊柱 CPR。

## 当前有效规则

- 第七阶段只消费第六阶段输出的 `SlicePlan`，不再按部位或切割方式重新规划。
- `plane_stack` 是当前已实现的直线 MPR 主协议。
- `SliceType` 省略时默认 `MPR`；颈椎、胸椎、腰椎冠状位只有显式请求 `CPR`
  才沿椎体中心曲线生成前后偏移序列。
- 显式 CPR 规划条件不足时任务失败，不允许静默降级为 MPR。
- 脊柱 CPR 标签按第四阶段 `resolved_cut_configs["whole_range"]` 的首尾完整展开；胸椎默认使用
  C7、T1–T12、L1，非颈椎任务不额外删除配置首尾标签。
- 第五阶段输出的 `spine_geometry.filtered_annotation_centroids`（标注质心）负责 CPR
  中心线和弧度；第四阶段完整 `coords.*.bbox` 负责 CPR/区间切的覆盖范围。
- CPR 中间质心只有形成与相邻趋势相反的局部折返时才回正到双邻点预测位置；正常 C 型弯曲保持不动，L5 可修正而 S1 末端锚点不移动。
- 中间质心回正先于首末端面和原始 label 出口路径构造，避免下游仍读取未回正锚点；
  靠近末端的同向异常残差只允许在相邻间距 `10%` 内保守限幅。
- CPR 首末端面只有越出局部正常弧线区间时才回正到质心外延射线；正常连续弧线保持不动。
- 首末直线端段方向作为曲线样条的端点切向，保证直线与曲线相切连接，不在拼接处
  形成锐角。
- 回正后的首末端线保持方向不变，并沿原始分割搜索到白线穿出首末椎体标签的位置；不使用全量 bbox 极值决定端线长度。
- MPR、CPR 和椎间隙统一使用层厚、层间距、数量三选二规则；三项齐全时按有效范围
  执行对称外扩或保持数量后重算层厚、层间距。
- 脊柱冠状位 CPR 的有效范围由原始标注体素外缘决定，再使用统一规则计算偏移位置。
- 椎间隙数量按每个有效间隙计算，例如 5 个间隙、每个 20 张会生成 100 张；缺失
  间隙不会把数量转移给其他间隙。
- 颈椎横状位椎间隙按统一切割部位配置生成；当前只生成 `C2_C3` 至 `C6_C7`。C1
  继续参与原始分割、整体定位和普通 MPR，但不生成 `C1_C2` 椎间隙计划。
- CPR 全部 offset 共用一套经过紧弯约束的单位偏移方向场，对应行严格保持配置
  层间距；层厚等于层间距时相邻曲面不能留下未采样间隙。
- 偏移方向场使用固定 `80 mm` 标准支撑范围；全量范围增加常见外层时，不会改变
  主体范围中已经存在的 CPR 曲面，也不会让远层逐层变直形成扇形。
- 第七阶段 Localizer 和实际 CPR 重采样复用同一个偏移曲线入口，不能只修正
  定位线外观。
- 第七阶段会实际写出冠状位 CPR 切片和 Localizer；CPR 曲面使用批量物理坐标换算与三线性插值，保持原有输出间距、厚层子采样数和算术平均语义，不通过降低采样密度换取速度。
- 第七阶段为每个 CPR 计划只准备一次共享偏移方向场和全部 offset 曲线；计划内
  各切片复用该几何，不能逐张重复平滑和搜索方向场。该复用不得改变像素、
  `Origin`、`Spacing` 或 `Direction`，日志以 `[CPR几何准备]` 标记一次性耗时。
- CPR Localizer 对投影曲线使用与 SimpleITK 等价的 NumPy 批量仿射坐标换算，
  不逐线段重复进入 SimpleITK 原生单点转换；日志以 `[CPR定位图性能]`
  记录曲线数、点数与转换方式，正式切片几何和采样不受影响。
- Localizer 的背景图和定位线覆盖率分开保存。定位线按连续体素坐标做亚像素采样和
  双线性覆盖，窗位映射完成后再叠加到背景；DICOM 白线与 debug PNG 红线共用同一
  掩膜，避免斜直线显示成逐像素台阶。该掩膜只用于显示，不参与正式 MPR/CPR
  重采样、层厚融合或切片计划；定位线退化时也不能阻断正式切片写出。
- 同一计划的正式切片可按窗并行写出；各窗 Localizer 必须复用主线程冻结的三维
  位置和行列方向并串行写出，不能因窗位线程不同而退回二维默认方向。
- 第七阶段输出摘要必须随每个计划透传 `geometry_type`、`slice_thickness` 和
  `slice_spacing`，供第八阶段把最终 DICOM 标签与实际计划做硬校验。
- 第六阶段只把全部 MPR、CPR 和椎间隙计划写入 `slice_plans.json`，不再生成任何
  规划 NIfTI 调试图；定位核对看第七阶段 `Localizer.dcm`/`Localizer.png`。
- 脊柱矢状位保持既有直线 MPR 切图逻辑，切片定位线画在冠状位背景上，不走 `curved_stack`。
- 腰椎直线矢状整切的冠状定位图使用 L1-S1 椎体主体共同中心层；腰椎五个横状位
  椎间计划共享同一张矢状位主体中心层，只保留各计划自己的定位线。
- `localizer_plane` 和 `localizer_reference` 只选择定位图背景，不得改变
  `slices`、切片方向、切片范围、层厚或层间距。
- 颈椎、胸椎使用配置首尾椎体质心建立三维直线坐标系；当前颈椎配置使 CPR 和
  椎间隙规划排除 C1，整体坐标仍保留 C1。
- 髋骨横状位由 AB 决定倾斜角度，完整左右髋骨主体在最终法向上的投影决定覆盖范围。
