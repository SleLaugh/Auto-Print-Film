# 椎体主体与全量范围 CPR 设计记录

## 背景

nnUNet 的脊柱 label 是全量椎体结构，通常同时包含椎体主体、椎弓根、横突和棘突。全量 label 适合表达最终需要覆盖的解剖范围，但不适合直接计算 CPR 中心线：后方附件会把质心向后拉，使冠状位 CPR 的定位线和弧度偏离椎体排列。

因此，定位结果需要保留两套用途不同的几何信息，而不是用过滤标注替换原始全量标注。

## 核心约定

### 1. 过滤标注与标注质心：决定中心线和弧度

过滤标注只保留椎体主体；由它计算出的标注质心用于：

- 计算每个椎体的标注质心；
- 生成 CPR 的中心路径点；
- 平滑和连接中心路径；
- 计算 CPR 及区间切的局部切线方向。

这部分几何不应被棘突、横突等后方附件影响。

### 2. 全量标注几何：决定覆盖范围

原始全量 label 继续用于：

- 定位目标和获取解剖范围；
- CPR 首尾沿头脚轴扩展到首末椎体的全量边界；
- CPR 每个位置沿左右方向扩展到全量标注边界；
- 保证区间切覆盖完整椎体及其附件结构。

最终效果是：

> 椎体主体决定“线怎么弯”，全量标注决定“切多大”。

### 3. C1 的边界

- C1 保留在颈椎定位坐标、bbox 和切图覆盖范围中；
- C1 不参与颈椎 CPR 中心路径；
- C1 不参与横状位姿态/回正角度统计；
- 其他状位仍可以覆盖和切到 C1。

## 数据流

```text
完整 nnUNet label
        |
        +--> 原始全量 bbox ------------------+
        |                                     |
        +--> 过滤标注 --> 标注质心 -----------+--> CPR 中心路径
                                              |
                                              +--> 局部切线/弧度

原始全量 bbox + 主体中心路径
        |
        +--> 首尾头脚方向扩展
        +--> 左右方向扩展
        +--> 完整范围 CPR / 区间切
```

## 当前实施边界

阶段三现在负责从全量标注派生过滤标注和 `spine_geometry.filtered_annotation_centroids`，并保留过滤标注 overlay 供 ITK-SNAP 校验。该结果已经进入阶段三正式定位契约，但阶段四的 CPR planner 尚未切换到标注质心。

下一步 CPR 接入必须读取这套标注质心；不能重新在阶段四从全量 label 计算中心线，也不能覆盖现有全量 `centroid` 和 `bbox`。

## 验收标准

1. 矢状位观察时，CPR 中心线贴近椎体主体，不跟随棘突向后偏移。
2. 冠状位 CPR 的首尾覆盖全量椎体范围，不因主体 mask 过窄而丢失附件。
3. 左右扩展覆盖全量 label 的边界，但扩展方向跟随主体中心路径的局部切线。
4. C1 仍能出现在定位和其他状位切图中，但不改变颈椎 CPR 的曲线。
5. 主体 mask 质量不足时，不修改原始定位结果，并保留可回退路径。
