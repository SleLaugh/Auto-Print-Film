# 髋骨倾斜直线切完整投影覆盖实施计划

> **供执行人员使用：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项实施本计划。各步骤使用复选框（`- [ ]`）跟踪状态。

**目标：** 保持髋骨 AB 倾斜角度不变，并让横状位范围完整覆盖左右髋骨最大连通主体。

**架构：** 阶段三继续用左右外侧顶部区域中心 A、B 计算横状位三轴，但不再把 AB 平面作为头侧边界；三轴确定后，用全部保留点在最终头脚法向上的最小、最大投影生成 `AnatomicalFrame.bounds`。阶段四、调试图、定位图和阶段五继续使用统一计划，不增加髋骨业务分支。

**技术栈：** Python、NumPy、SimpleITK、unittest。

## 全局约束

- AB 只决定角度，覆盖范围只能来自完整左右髋骨主体。
- 只修改髋骨横状位边界；AB、矢状位、冠状位方向保持不变。
- 孤立误分割仍由每侧最大连通域过滤，不得进入角度或范围。
- 配置的 `slice_range_extension` 在完整掩膜边界之外继续生效。
- 第四步和第五步不得增加髋骨专属范围修补逻辑。
- 所有新增诊断字段和方法修改必须有中文注释。
- 本轮不执行 Git 提交，完成后保留差异等待用户审批。
