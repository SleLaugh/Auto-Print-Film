**Goal:** 让腰椎横状位 `interspace` 使用相邻四棱柱矢状边界的最近点对生成每个椎间独立的斜横切计划，并在几何不可用时兼容回退现有 bbox 算法。

**Architecture:** 阶段三保存四棱柱矢状四边形和左右挤出范围；阶段四在公共脊柱 resolver 中求相邻凸四边形最近点对，将最近连线作为法向；`CutSegment` 携带可选的 `StraightPlaneFrame` 和“保留目标位置”标记，腰椎 planner 继续复用通用直线计划构造器。全量 bbox 并集继续决定平面内覆盖范围。

**Tech Stack:** Python 3、NumPy、SimpleITK、unittest/pytest

## Global Constraints

- 仅改变腰椎横状位 `interspace`，不改变整切、CPR、其他部位或第五阶段采样协议。
- 不使用四棱柱轴对齐 bbox 估计椎间距；使用矢状凸四边形最近点。
- S1 不套用普通腰椎主体过滤，使用专用左右支撑筛选和局部上缘补回。
- `coords.*.bbox` 的全量范围继续用于 `target_region_bbox`。
- 旧阶段三结果缺少四边形时兼容 faces/bbox；存在但失效的四边形直接回退 bbox。
- 所有几何方向使用物理坐标和有限值检查。
