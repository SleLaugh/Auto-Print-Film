# 椎体主体与全量范围 CPR 设计记录

## 背景

nnUNet 的脊柱 label 是全量椎体结构，通常同时包含椎体主体、椎弓根、横突和棘突。全量 label 适合表达最终需要覆盖的解剖范围，但不适合直接计算 CPR 中心线：后方附件会把质心向后拉，使 CPR 的定位线和弧度偏离椎体排列。

因此，定位结果需要保留两套用途不同的几何信息，而不是用过滤标注替换原始全量标注。

## 核心约定

### 1. 过滤标注与标注质心：决定基准中心线和弧度

过滤标注只保留椎体主体；由它计算出的标注质心用于：

- 计算每个椎体的标注质心；
- CPR 锚点按头侧到足侧组织为“首端面中点 → 全部标注质心 → 末端面中点”；首末椎体质心既用于查找端面，也保留在最终 CPR 路径中；
- 首末椎体优先使用过滤主体在矢状投影上抽象出的轮廓四边形大面作为路径端点来源；第六阶段先按相邻标注质心连线判断质心线进入椎体的入射面，再取同一轴上的对侧大面中心。这样端点落在对应端面的中线附近，而不是落到 PCA 外接矩形角点或与入射面相邻的斜边。输入缺少四面几何时，才回退到端部候选平面中心，不直接使用全量 bbox 角点或固定内缩距离；
- 保留局部头脚轴和主体范围，供端面识别及后续局部定位线使用；
- 计算 CPR 及区间切的局部切线方向。

这部分几何不应被棘突、横突等后方附件影响。

### 2. 全量标注几何：决定覆盖范围

原始全量 label 继续用于：

- 定位目标和获取解剖范围；
- CPR 首尾端线沿当前方向搜索原始首末标签的实际出口；
- CPR 每个位置沿左右方向扩展到全量标注边界；
- 保证区间切覆盖完整椎体及其附件结构。

当前基准中心线只使用过滤主体的首末端面约束和配置范围内全部标注质心，不使用
全量 bbox 端点。第六阶段按顺序组织“首端面中心 → 全部标注质心 → 末端面中心”：
中间质心链先按反向/局部折角保护规则修正，再执行限制过冲的平滑，修正后的质心作为硬锚点保留，首尾端点到终端质心的
区段保持直线。`curve_points` 保存真实三维路径。第七阶段按
`curve_projection_axis` 准备投影采样路径：冠状位沿第五阶段整体坐标 LR 投影到
固定 LR 参考面，使用同一坐标的 AP 偏移，仅展开 AP–SI、保留 LR–SI 侧弯；
无解剖几何时成对回退患者 LR/AP。矢状位仍沿患者 AP 投影到固定 AP 参考面，
展开 LR–SI、保留 AP–SI 前后生理曲度。两者按各自投影弧长采样。全量几何只负责
CPR/区间切覆盖范围，避免棘突、横突等附件参与中心线定位；后续局部定位线也不得
直接使用全量 bbox 的头脚长度。

腰椎当前默认范围 T12 至 S1 全部可用时，基础路径通常由两个端面和七个质心构成；
`curve_points` 保存后续 Hermite 加密及端点外缘延伸后的密集曲线，点数不固定为锚点数量。
不能用逐坐标夹紧制造平台；首尾直线与中间曲线按端点切向连续衔接。
端点外缘延伸使用终端原始标签。两状位均按各自投影单位切向计算覆盖距离，
再除以原三维单位切向的投影长度，沿真实三维切线延伸；这样原路径和投影路径的
端段均保持原方向，且投影端点不漏裁。无原始标签时不使用 bbox 补长。

最终效果是：

> 椎体主体决定“线经过哪里、每段怎么倾斜和整体怎么弯”，全量标注决定“切多大”。

### 3. C1 的边界

以下排除规则适用于颈椎任务；全脊柱按自己的配置确定范围，当前从 C2 开始。

- C1 保留在颈椎定位坐标、bbox 和切图覆盖范围中；
- C1 不参与颈椎 CPR 中心路径；
- C1 不参与横状位姿态/回正角度统计；
- 其他状位仍可以覆盖和切到 C1。

## 数据流

```text
完整 nnUNet label
        |
        +--> 原始全量 bbox ------------------+
        |                                     |
        +--> 过滤标注 --> 标注质心 -----------+--> 按椎体顺序连接成基准 CPR 路径
        |                                     |
        |                                     +--> 后续：每个椎体的局部定位线
        |                                     |
        |                                     +--> 局部切线/弧度

原始首末标签 + 主体中心路径
        |
        +--> 首尾沿线出口延伸

原始全量 bbox + 主体中心路径
        |
        +--> 左右/前后方向覆盖
        +--> 完整范围 CPR / 区间切
```

## 当前实施边界

第五阶段负责从全量标注派生过滤标注和 `spine_geometry.filtered_annotation_centroids`，
并保留过滤标注 overlay 供 ITK-SNAP 校验。该结果属于正式解剖分析契约，第六阶段
CPR planner 直接读取标注质心。

第六阶段 CPR 已读取这套过滤标注质心、主体端面几何和端部候选中心；当前
`curve_points` 保存平滑后的密集中心线，精确保留必要修正后的椎体质心，并把修正后的
首尾端段拼接为直线。本阶段仍不生成每个椎体的局部定位线。任何阶段都不能覆盖
现有全量 `centroid` 和 `bbox`。
两状位 CPR 的固定横向采样投影均不覆盖 `curve_points`；冠状定位背景继续用其
真实前后深度，实际定位线则跟随采样投影及等距 offset 曲线。

第七阶段写出 CPR Localizer 时，必须在 GDCM 写盘后恢复第六阶段计算出的
`ImagePositionPatient` 和 `ImageOrientationPatient`。二维定位图的内部轴不能覆盖
矢状位的三维物理行列方向，否则查看器会把正确的质心中心线显示成上下倒置或错误状位。

## 验收标准

1. 矢状位观察时，CPR 中心线贴近椎体主体，不跟随棘突向后偏移。
2. 冠状位和矢状位 CPR 的首尾覆盖全量椎体范围，不因主体 mask 过窄而丢失附件。
3. 左右扩展覆盖全量 label 的边界，但扩展方向跟随主体中心路径的局部切线。
4. C1 仍能出现在定位和其他状位切图中，但不改变颈椎 CPR 的曲线。
5. 主体 mask 质量不足时，不修改原始定位结果，并保留可回退路径。
