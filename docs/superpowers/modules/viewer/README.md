# 显示模块入口

本模块描述窗宽窗位、调试总览和带 CT 背景的展示图。不负责 MPR 几何和 DICOM 写盘安全。

## 当前有效规则

- 外部请求仍只传窗宽窗位名称。
- 支持的窗宽窗位名称和值以 JSON 配置为唯一来源。
- 第六阶段 NIfTI 调试总览只保留当前仍用于定位排查的计划；普通横/矢整切和
  脊柱冠状位 CPR 不再默认生成第六阶段 NIfTI 调试图。
- 仍需手工调用总览 helper 时，三状位总览按横状位、矢状位、冠状位分别输出，
  不混在同一个 NIfTI。
- 带 CT 背景的总览是研发辅助文件，不作为第七阶段重建或交付报告输入。
