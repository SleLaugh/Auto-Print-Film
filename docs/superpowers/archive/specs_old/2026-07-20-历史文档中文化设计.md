# 历史文档中文化设计

> 历史设计：本文只记录当时的文档重命名过程。当前维护规则见
> [文档与代码一致性审阅设计](../../architecture/2026-07-29-文档与代码一致性审阅设计.md)，
> 文档入口见[总索引](../../README.md)。

## 目标

将 `docs/` 下历史文档的文件名和说明性正文统一改为中文，保持文档内容、代码示例和技术语义不变，并同步更新仓库内所有交叉引用。

## 范围

- 重命名历史 Markdown 文档及流程图文件，使日期后的说明部分使用中文。
- 将标题、章节名、任务步骤、说明段落等自然语言改为中文。
- 保留代码块、命令、路径、字段名、函数名、类名以及 DICOM、MPR、GDCM、SimpleITK 等技术名称。
- 更新 README、文档、源码和测试中指向旧文件名的引用。
- 不修改程序业务逻辑，不处理 `docs/` 之外与文档引用无关的历史英文内容。

## 校验

重命名后检查旧英文文件名不存在、仓库内不存在旧路径引用、Markdown 说明性英文已清理，并运行全量测试、Python 编译及 `git diff --check`。
