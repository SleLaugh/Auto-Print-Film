# 显示模块入口

本模块描述窗宽窗位、调试总览和带 CT 背景的展示图。不负责 MPR 几何和 DICOM 写盘安全。

## 当前有效规则

- 外部请求仍只传窗宽窗位名称。
- 支持的窗宽窗位名称和值以 JSON 配置为唯一来源。
- 三状位调试总览应按横状位、矢状位、冠状位分别输出，不混在同一个 NIfTI。
- 带 CT 背景的总览用于 ITK-SNAP 直接查看，表达真实层厚覆盖带和切片中心线。
