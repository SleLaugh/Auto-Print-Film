# 层厚与层间距修正实施计划

> **供执行人员使用：** 按任务逐项实施本计划，各步骤使用复选框（`- [ ]`）跟踪状态。

**目标：** Make axial whole-range slices use true thickness coverage, strictly uniform center spacing, and a diagnostic overview that shows both centers and thickness bands.

**架构：** Keep generic center interpolation in `src/planning/geometry.py`, but pass it the valid center interval computed by the axial bbox planner. Remove endpoint injection from interpolation. Extend mapping diagnostics from serialized slice centers and paint thickness bands beside center lines in the overview overlay.

**技术栈：** Python 3, unittest, NumPy, SimpleITK

## 全局约束

- `slice_thickness` is physical coverage along the slice normal in millimetres.
- `slice_spacing` is the physical distance between adjacent output centers in millimetres.
- Never append a terminal center that violates `slice_spacing`.
- Preserve spacing, origin, and direction-aware coordinate conversion.
- Do not change request configuration values.
- Do not run `git commit`; leave changes for user review.
