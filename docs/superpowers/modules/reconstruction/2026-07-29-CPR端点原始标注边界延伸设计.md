# CPR 端点原始标注边界延伸设计

## 目标

在现有 CPR 首尾端线方向已经正确的基础上，只延长端线长度。先搜索当前白线沿线
穿出首末椎体原始标签的位置，再在平滑后按实际采样方向兜底覆盖终端原始标签外缘。
冠状位 CPR 以 AP–SI 矢状投影、矢状位以 LR–SI 冠状投影检查头足覆盖，并换算
回原三维切线延伸量，避免去掉对应横向分量后端点缩短而漏掉首末标签。

首末标签来自第四阶段转交的实际配置范围。胸椎默认是 C7 和 L1，两者分别负责
胸椎 CPR 的首尾出口；不能改用固定 T 段或跳过配置首尾标签。

## 已确认根因

首末椎体的全量 `bbox` 包含椎弓、棘突等偏离白线的结构。使用其全局头足极值，会把端点拉到并不位于白线上的远端角落。本病例首端实际沿线出口约为终端质心外 `8.2 mm`，bbox 算成 `33.1 mm`；尾端实际约为 `13.9 mm`，bbox 算成 `37.4 mm`，因此视觉上上下各多出约一个椎体。

## 行为约束

- 保留现有端面查找和反弧回正结果，不重新计算端点方向。
- 只沿“终端质心指向当前端点”的射线向外延长。
- 使用首末椎体在原始分割中的标签体素判断沿线出口，不再使用 bbox 极值。
- 沿线出口搜索要求当前端点位于对应原始标签内；否则不执行这一步搜索。
- 沿线搜索时，短暂的单体素孔洞不视为标签出口；连续离开超过一个体素对角线才确认出口。
- 沿线搜索返回连续离开前最后一个仍位于标签内的采样点；后续原始体素外缘兜底
  可继续沿同一切线延长，并包含体素级安全余量。
- 缺少原始分割、标签 ID、有效端线或标签体素时保持当前端点，不用 bbox 猜测
  延伸。出口搜索未找到有效出口时保留该步输入，再由可用原始体素决定是否兜底。
- 中间质心、平滑曲线算法和端线拼接方式保持不变。

## 沿线出口搜索

1. 在 `_build_annotation_centroid_path` 完成端面选择和反弧回正后，取得现有首尾端点。
2. 读取 `seg_for_reconstruction_path` 指向的原始分割图像，一次读取供首尾共同使用。
3. 以终端质心 `C` 和当前端点 `P` 建立单位外延方向 `D = normalize(P - C)`。
4. 从 `P` 开始，以不大于最小体素间距一半的步长沿 `D` 向外采样。
5. 用 SimpleITK 物理坐标变换查询采样点所在体素是否属于当前终端标签 ID。
6. 标签内更新最后有效点；标签外累计离开距离。连续离开距离达到体素对角线时，返回最后有效点。
7. 搜索距离上限使用图像物理对角线，防止异常数据造成无界循环。

## 平滑后终端外缘兜底

`_extend_curve_endpoints_to_terminal_raw_labels` 在密集曲线生成后检查配置首末标签的
原始体素。两状位均传入 `projection_axis`，冠状位为第五阶段整体坐标 LR
（无解剖几何时为患者 LR），矢状位为患者 AP，使外缘检查与实际采样投影一致：

1. 取当前端点指向外侧的原三维单位切向 `T`，将其去掉对应投影轴分量得到
   `project(T)`，令 `s = |project(T)|`、`V = project(T) / s`。
2. 将该终端标签的全部原始体素相对端点投影到单位方向 `V`，取最远距离，加上
   体素外缘与额外安全垫，得到需要覆盖的投影距离 `d`。
3. 当 `d > 0` 时沿真实三维切向 `T` 延伸 `d / s`。这样真实 `curve_points` 的
   端段仍共线同向，投影后的端点恰好达到所需覆盖外缘。
4. 没有投影轴时 `s = 1`、`V = T`，维持原有三维外缘算法；投影切向退化时保持
   当前端点，不产生无穷延伸。

仅配置首末标签分别决定头侧和足侧延伸，中间或范围外椎体不能拉长路径。原始
分割、标签 ID 或实际标签体素缺失时不执行该兜底，也不按 bbox 扩展。

## 验证

### 同次规划的数据复用

每次 CPR `build` 在局部缓存中保存成功读取的分割图像，沿线出口、平滑后
终端覆盖和偏移范围计算共用该图像。缓存通过内部参数传递，不进入计划或
定位结果；冠、矢状位各自构建，新请求及同路径更新后的下一次构建均重新读取。
读取失败不缓存，后续步骤仍按原行为重试或降级。

终端覆盖步骤对每组首末标签只提取一次物理点云，供端点归属和沿切线延伸共用。
点云只读并在该步骤结束后释放；保留完整标签、`argwhere` 顺序、物理坐标换算和
投影算式，不修改覆盖边界、搜索参数、平滑或插值规则。正常完整流程每个平面的
分割读取由三次降至一次，原始标签点云提取由五次降至三次。

`tests/test_cpr_planning_reuse.py` 覆盖冠、矢状位计划一致、图像释放、同路径更新、
读取失败重试及斜向反射网格的端点延伸；真实数据验证还需比较完整计划和输出像素。

### 几何行为

- bbox 极值远离白线时，首尾只到达原始标签沿线出口。
- 延长前后的端线方向严格共线且同向。
- 单体素孔洞不会导致提前终止。
- 原始分割或标签缺失时保持现有端点。
- 新矢状位含较大 AP 端部倾角时，投影端点仍覆盖完整终端原始标签及安全垫，
  真实三维端线保持原切向；不能仅沿原三维切向距离直接平移同样的毫米数。
- 新冠状位含 LR 端部倾角时，矢状投影端点仍覆盖完整终端标签；未传投影轴
  的旧兼容路径沿用原三维外缘算法。
- 既有反弧回正、曲线平滑及完整测试集继续通过。
- 当前病例复算中，首端由 `2.163 mm` 延长到 `8.022 mm`，尾端由
  `12.752 mm` 延长到 `13.728 mm`，两端延长前后方向点积均为 `1.0`。
