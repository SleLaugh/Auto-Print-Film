## 3. 结构迁移与新增能力

旧 `whole_range.start_label/end_label` 已迁移为显式 `target_labels` 和 `bounds`。
脊柱旧首尾标签之间的连续椎体全部展开，上界使用这些标签上缘的最大值，下界使用
下缘的最小值，两侧 `offset_mm` 均为零；非脊柱使用原单标签或双髋标签集合。

| 部位 | 保留的基础区域 |
| --- | --- |
| 颅脑 | `brain` |
| 颈椎 | C1–T1，共 8 个椎体；5 个椎间隙 C2_C3 至 C6_C7 |
| 胸椎 | C7–L1，共 14 个椎体 |
| 腰椎 | T12–S1，共 7 个椎体；5 个椎间隙 L1_L2 至 L5_S1 |
| 胸腰椎 | C7–S1，共 19 个椎体 |
| 全脊柱 | C2–S1，共 24 个椎体 |
| 肺部 | `lung` |
| 髋骨 | `hip_left`、`hip_right` |

回正输入独立放入 `localization.pose`。5 个脊柱部位各新增独立 `cpr_range`，保持旧首尾
标签；对应冠状位、矢状位 CPR 共 10 条规则的区域引用从 `default` 改为 `cpr_range`。
这使普通 MPR 的完整区域与 CPR 路径分离，原 CPR 全标签和排除项继续生效。

新上腹部、下腹部、全腹部及模型 701 的 RAS 输入方向约定继续保留。它们不在旧基准
配置内，不应为匹配旧文件而删除。三个腹部部位外扩均为零；下腹部肾上方 `30 mm`
属于区域基础上界偏移。全腹部仍为肝上界至双股骨较高上界，详见
[腹部接入设计](../../architecture/2026-11-18-上下腹部接入设计.md)。

新旧配置的 `schema_version` 都是 `1`，但结构不能混用。部署时应使用与新版程序配套
的当前配置，而不是将旧文件直接覆盖到新版目录，详见
[回正与区域配置分离设计](../../architecture/2026-11-18-回正与区域配置分离设计.md)。

## 4. 代码执行路径

- [face_extension.py](../../../../src/planning/face_extension.py) 按状位和切法读取
  `slice_rules` 中的六方向值；头侧增加 SI 上界，脚侧减少 SI 下界，左右与前后分别
  扩展对应解剖轴。零值保持零，不用部位硬编码替代配置。
- [whole_range.py](../../../../src/planning/whole_range.py) 在完整区域求解后调用
  `expand_anatomical_bounds`，将余量纳入实际 MPR 计划；颈椎横状位先选用专属局部
  坐标，再执行相同扩展，因此 C1–T1 底侧 `5 mm` 进入层组范围。
- [straight.py](../../../../src/planning/straight.py) 将椎间隙左右各 `20 mm` 转为
  成片平面余量，由 [framing.py](../../../../src/reconstruction/framing.py) 应用，
  不把横向余量误投影为椎间层组厚度。
- [spine_cpr.py](../../../../src/planning/spine_cpr.py) 读取 CPR 自身规则，按首末段
  切线延长上下端点；胸腰椎、全脊柱的 `50 mm` 上下余量进入 CPR 路径，不作为横向偏移。
