# 阶段四重建规划设计

## 职责

阶段四是临床几何规则层。它读取阶段三定位结果和请求状位配置，输出统一
`SlicePlan[]`；不采样原始 CT，也不写 DICOM。阶段五只执行计划，不重新判断
部位、切法、方向、范围或切片数量。

## 输入

- 阶段三全量 `coords`、目标 bbox 和图像物理空间；
- 部位专属 `anatomical_geometry`；
- 脊柱 `spine_geometry` 过滤标注/四棱柱质心；
- `raw_for_reconstruction_path` 和 `seg_for_reconstruction_path`；
- 请求中的状位、层厚、层间距和窗位。

脊柱标签范围使用阶段三 `resolved_cut_config`。胸椎默认完整展开 C7 至 L1；
腰椎及其他非颈椎任务按配置使用；颈椎 CPR 唯一固定排除 C1。

## 计划类型

### `plane_stack`

用于直线 MPR。计划明确每张切片的 `center`、`normal`、`row_dir`、`col_dir`，
并按通用完整覆盖算法生成严格等距中心。当前腰椎横状位自动使用区间切；脊柱
矢状位以及其他直线状位使用整切或部位专属直线坐标。

### `curved_stack`

当前用于脊柱冠状位 CPR。计划包含 `curve_points`、`curve_spacing_mm`、
`offset_axis` 和 `offsets_mm`。中心线使用配置范围内过滤标注/四棱柱质心，
中间质心链平滑，首尾端段保持直线。

## 范围与切片

- 全量 bbox/Mask 决定直线计划和 CPR 偏移方向的覆盖范围。
- CPR 首尾端线沿原始首末标签搜索白线实际出口，不使用 bbox 极值拉长。
- `slice_spacing` 决定相邻计划中心；`slice_thickness` 只供阶段五厚层采样。
- 非零直线目标必须让首末中心到达或越过目标边界；不可整除的超出量对称分配。
- `slice_range_extension` 在目标边界之外按当前计划方向增加毫米范围。

## 降级和警告

缺少中间标签时保留实际可用标签并写 warning。脊柱冠状位有效质心少于 3 个、
曲线无效或必要分割缺失时，阶段四生成直线冠状位降级计划；不能把半成品
`curved_stack` 交给阶段五。

## 输出契约

每个 `SlicePlan` 至少明确：

- `plan_id`、`body_part`、`cut_mode`、`plane`、`group_name`；
- `geometry_type`、目标范围和物理方向；
- `extent_mm`、`output_spacing_mm`、`slice_thickness`、`slice_spacing`；
- 正式 `slices`、`source_labels`、定位图参考面和诊断 warnings。

阶段五和阶段六只能消费这些字段，不得再次读取部位配置重建计划。
