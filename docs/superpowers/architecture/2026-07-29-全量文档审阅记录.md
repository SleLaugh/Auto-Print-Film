# 全量文档审阅记录

## 审阅目标

本次审阅以 2026-07-29 当前代码、配置和自动测试为事实源，覆盖根 README、
`docs/superpowers/` 下全部当前设计、实施计划和历史归档。目标不是把历史过程
改写成现状，而是确保当前入口准确、历史入口清晰，并防止旧规则重新进入当前文档。

## 代码依据

### 标签范围

- `src/config/localization_config.json`：颈椎默认 C1 至 C7，胸椎默认 C7 至 L1。
- `LocalizationStage._collect_label_names/_expand_vertebrae_range`：把脊柱配置首尾
  展开为模型实际提供的全部中间标签。
- `configured_spine_cpr_labels`：优先使用 `resolved_cut_config` 展开 CPR 标签；
  只有颈椎删除 C1。
- `test_thoracic_coronal_cpr_uses_configured_c7_l1_range`：验证胸椎 C7、T 段和 L1
  均进入 CPR `source_labels` 与曲线。

### CPR 和 MPR

- `build_spine_sagittal_cpr_plan` 当前只对冠状位返回 `curved_stack`；函数名是
  历史命名，不代表矢状位 CPR。
- `SingleLabelWholeRangePlanner` 把脊柱矢状位保留为直线 `plane_stack`，冠状位
  才尝试 CPR。
- `_smooth_cpr_centroid_path_with_straight_endpoints` 平滑中间质心链，同时保持
  首尾端点区段为直线。
- `_correct_endpoint_face_to_local_arc` 只修正反弧/回折端点到 `0°` 外延方向；
  `_extend_existing_endpoint_to_original_label_exit` 再沿相同方向搜索原始首末
  标签出口。

### 其他模块

- `cut_mode_for_plane`：当前只有腰椎横状位使用 `interspace`。
- `cover_segment_range`：所有直线计划使用首末中心完整覆盖和严格等距规则。
- `ReconstructionStage`：按 `geometry_type` 分发 `plane_stack`/`curved_stack`，
  正式 DICOM 使用数字文件名并单独写 `Localizer.dcm`。
- 髋骨 AB 只决定横状位角度，完整左右髋骨主体投影决定覆盖范围。
