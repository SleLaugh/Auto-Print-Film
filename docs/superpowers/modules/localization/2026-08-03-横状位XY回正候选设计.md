# 横状位 XY 回正候选设计

## 背景

当前第三阶段保留回正字段，但默认不执行真实图像旋转。真实病例中可能出现横状位
平面内左右轴倾斜：在 ITK-SNAP 横状位视图中，目标结构呈左下到右上的斜向，而
不是与图像 x/y 轴基本对齐。这类倾斜会影响依赖图像轴的主体提取、LR 支撑筛选、
矢状四边形拟合和椎间切方向，S1 尤其明显。

本设计只处理横状位平面内的 XY 刚性旋转候选，不处理三维俯仰、侧弯、逐层非刚性
回正。候选 raw/seg 双文件成功写出后，第三阶段会把它们提升为统一工作空间；第四
阶段在该空间提取定位坐标，第五阶段生成解剖与脊柱几何，第六、七阶段继续消费同一
空间中的图像与几何。

## 目标

- 从第三阶段可用的脊柱 label 或主体 mask 估计一个横状位 XY 回正角。
- 输出回正诊断 metadata，记录角度、置信度、方法、参与 label 和拒绝原因。
- 输出候选回正后的 `raw_corrected_candidate.nii.gz` 和
  `seg_corrected_candidate.nii.gz`。
- 候选 raw/seg 双文件存在时，`raw_for_reconstruction_path` 和
  `seg_for_reconstruction_path` 指向候选文件；第四阶段基于候选 seg/image 重新
  计算 `coords` 和目标 bbox，第五阶段重新计算椎体主体、四棱柱和
  `spine_geometry`。

## 非目标

- 不在候选文件缺失、写出失败或候选被拒绝时切换主流程输入。
- 不复用旧的全椎体 XY PCA 角度作为唯一可信来源。
- 不做矢状位或冠状位回正。
- 不做逐张切片独立旋转。
- 不修改 nnUNet 原始 label id 语义。

## 角度估计

当前实现按目标类型分两条路径：

- 脊柱目标：优先逐椎体计算 XY 投影 PCA 主轴，排除统一切割部位配置指定的标签、
  体素过少和贴边截断的 label，再对可用椎体做加权轴向平均。当前颈椎配置排除
  C1；多个椎体的候选角必须彼此接近；默认最大
  离散阈值为 `correction_max_label_angle_spread_degrees=15.0`。
- 非脊柱目标：头骨、肺部、髋骨等没有椎体顺序，继续使用目标整体 mask 的 XY
  投影 PCA，但必须超过更高的高置信阈值
  `correction_non_spine_angle_threshold_degrees=8.0` 才生成候选。这样 3-4 度
  的头骨形态偏差会被拒绝，明显歪斜仍可输出候选。

基础角度由 `_detect_axial_skew` 计算：把目标体素投影到图像 XY 平面，用 PCA 找
主轴，再取它相对最近标准轴 `0°/90°` 的偏差。角度定义为绕图像 z 轴的平面内
旋转角，记录在 `correction_angle_degrees` 和 `correction_params.angle_degrees`
中。

## 输出产物

第三阶段输出以下诊断和候选产物：

- `spatial_correction` 阶段结果：包含 `correction_params` 诊断详情和工作图像路径。
- `nifti/raw_corrected_candidate.nii.gz`：候选回正 CT。
- `nifti/seg_corrected_candidate.nii.gz`：候选回正分割。

同一开关开启时，第五阶段写出的 `metadata/localization_result.json` 会汇总第三至第五阶段
的校正、定位和专用几何结果；它不是第三阶段的交接文件。

后续阶段契约包含：

- `correction_status`：候选诊断中为 `candidate`、`rejected` 或 `disabled`；
  候选文件提升为主流程后，最终 `correction_params.correction_status` 为
  `applied`，并通过 `source_correction_status` 保留原候选状态。
- `correction_applied`：候选 raw/seg 双文件提升后为 `true`；否则为 `false`。
- `correction_angle_degrees`：候选角；拒绝或禁用时为 `0.0`。
- `correction_params`：角度、置信度、参与 label、拒绝原因、阈值、插值方式、
  旋转中心和产物路径。
- `candidate_raw_path`、`candidate_seg_path`：只有 `correction_status="candidate"`
  时写入候选 NIfTI 路径；拒绝或禁用时为空字符串。
- `corrected_raw_path`、`corrected_seg_path`：候选提升后等于候选 raw/seg；
  未提升时等于原始 raw/seg。

## 候选 NIfTI 生成

候选回正围绕目标整体 bbox 的中心执行一次刚性旋转。输出网格沿用原图像的
size、spacing、origin 和 direction；该版本不扩展网格。候选 raw/seg 双文件均存在
时，会进入主流程，后续所有几何都在候选图像空间重新计算。

- CT raw 使用线性插值，背景填充采用原图低值或 SimpleITK 默认外部值。
- 分割 seg 使用最近邻插值，保持整数 label id。
- raw 和 seg 使用同一变换、同一输出网格。
- 写出失败时不切换主流程输入；候选路径保持为空或保留诊断中的失败状态。

## 数据流

```text
raw_0000.nii.gz + seg.nii.gz
  |
  +--> XY 回正候选估计
         |
         +--> spatial_correction / correction_params
         +--> raw_corrected_candidate.nii.gz
         +--> seg_corrected_candidate.nii.gz
                    |
                    +--> 候选双文件存在时提升为主流程 raw/seg
                             |
                             +--> 第四阶段重新提取 coords、bbox
                             +--> 第五阶段重新生成主体 mask、四棱柱
                             +--> 第六阶段 MPR/CPR/椎间隙规划
                             +--> 第七阶段重建
```

候选提升后，后续阶段读取：

```text
raw_for_reconstruction_path = raw_corrected_candidate.nii.gz
seg_for_reconstruction_path = seg_corrected_candidate.nii.gz
```

候选缺失、被拒绝或任一文件不存在时，后续阶段仍读取原始 raw/seg。

## 失败与安全策略

- 候选角拒绝时不报错，记录 `correction_status="rejected"` 和原因。
- 角度绝对值低于最小阈值时视为无需回正。
- 脊柱椎体角度离散过大时拒绝，避免把曲度、附件或局部形态误判为整体体位旋转。
- 非脊柱整体 PCA 只在超过高置信阈值时输出候选，避免头骨等正位小角度误触发。
- raw/seg 任一候选写出失败时，不得提升任何一个候选路径进入主流程。
- 候选回正不得修改原始文件，也不得覆盖现有 debug overlay。

## 测试验收

- 合成一个在 XY 平面内旋转的腰椎 label，能估计出接近真实的候选角。
- 正位样例角度低于阈值时，输出 `rejected` 或 `disabled`，不生成误导性候选。
- 角度离散大的样例被拒绝。
- 非脊柱低角度整体 PCA 被拒绝，高角度整体 PCA 可生成候选。
- 候选 raw 使用线性插值，候选 seg 使用最近邻插值且 label id 保持整数。
- 候选 raw/seg 使用同一输出网格。
- 候选 raw/seg 双文件存在时，`raw_for_reconstruction_path` 和
  `seg_for_reconstruction_path` 指向候选路径。
- 候选提升后，第四阶段的 `coords`、目标 bbox 和第五阶段的 `spine_geometry`
  均基于候选 seg/image 重新计算。
- 十字线 overlay 能在原始网格上显示原始轴和候选轴。
