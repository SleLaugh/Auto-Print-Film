# 颈椎横状位椎间隙设计

## 目标

颈椎显式传入 `SliceType=椎间隙`、`Plane=横状位` 时，按相邻椎体几何生成五个
独立斜横切区域：

1. `C2_C3`
2. `C3_C4`
3. `C4_C5`
4. `C5_C6`
5. `C6_C7`

C1 为环椎，不生成 `C1_C2`。这项排除只属于椎间隙规划，不从原始分割、整体定位、
颈椎 C1/C7 坐标系或普通 MPR 覆盖范围删除 C1。

## 阶段边界

- 第二阶段保留模型输出的完整 C1-C7 分割。
- 第三至第五阶段合并 `whole_range` 与 `interspace` 标签目标，始终定位 C1-C7；
  C1 继续参与颈椎整体坐标计算。
- 第五阶段沿用既有规则，不为环形 C1 生成主体四棱柱。
- 第六阶段颈椎规划器只读取 `C2_C3` 至 `C6_C7`，并复用腰椎已经验证的相向端边、
  四棱柱、端面和 bbox 回退链路。
- 第七、八阶段继续按通用 `plane_stack`、窗位和 `RegionList` 契约执行，不增加
  颈椎专用输出格式。

## 约束

- 能力表只注册颈椎横状位椎间隙；矢状位和冠状位请求必须在预检阶段拒绝。
- 每个有效间隙独立应用层厚、层间距和数量配置；数量不是五个间隙的总和。
- 某一相邻标签或几何缺失时只跳过该间隙并记录告警，不得补出 `C1_C2`，也不得把
  数量转移到其他间隙。
- 批量测试按部位和状位显式选择切片方式，颈椎横状位使用椎间隙，其他状位仍按配置
  选择 MPR 或 CPR。

## 异常几何容错

颈椎内固定、金属伪影或分割缺损可能使单节椎体主体明显偏小，继而放大四棱柱端面
角度误差。椎间规划保留原四棱柱为主几何，只在以下条件同时满足时限制法向：

1. 当前间隙任一端主体体素数低于本次颈椎主体体素中位数的 75%；
2. 四棱柱法向与相邻过滤主体质心连线在矢状面内的偏差超过 10°。

触发后保留原间隙中心和有效长度，仅把法向限制到主体中心线附近 10°，并记录带
区间名称的告警。正常体积的椎体、偏差不超过阈值的区间，以及非颈椎椎间规划均不
应用该修正。相向端边的共同覆盖中点仅在仍保留至少 75% 代表间隙时使用，避免
中心偏向一端的同时，不牺牲明显的有效间隙宽度。

四棱柱是矢状外包络，局部交叠时可能把区间范围压得远小于三维主体的真实间隙。
第五阶段因此额外记录相邻主体最近间隙。真实间隙比四棱柱范围大超过 `1mm` 且至少
有 8 个最近点支撑时，第六阶段只沿当前法向平移切片位置，并记录告警；角度、有效
长度和采样参数保持不变。该位置修正适用于脊柱椎间公共链路，不依赖具体病例或
固定的 `C6_C7` 名称。

颈椎末端 `C6_C7` 另有一层受限位置保护。四棱柱范围未被明显压窄，但切片中心沿
当前法向仍高于 C6、C7 过滤主体中心中面超过 `0.25mm` 时，将中心移动到主体中面
下方 `0.5mm`；只平移位置，不修改角度和有效长度。已经由真实最近间隙完成修正的
区间优先使用前一条规则，不叠加末端下移。该规则按 `C6_C7` 解剖区间生效，不按
病例名称判断，且不影响 `C2_C3` 至 `C5_C6`。
