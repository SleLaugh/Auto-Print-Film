# 重建模块入口

本模块覆盖阶段四规划到阶段五 MPR 执行，以及颈椎、胸椎、髋骨等部位专属直线 MPR。

## 当前有效规则

- 阶段五只消费阶段四输出的 `SlicePlan`，不再按部位或切割方式重新规划。
- `plane_stack` 是当前直线 MPR 主协议；曲线切和 CPR 不在当前主线里。
- 颈椎、胸椎使用脊柱首尾椎体质心建立三维直线坐标系。
- 髋骨横状位有 AB 倾斜角度，覆盖范围以后续完整投影覆盖计划为准。
