# 脊柱矢状位 CPR 设计

## 背景

当前阶段四、阶段五已经稳定支持 `plane_stack` 直线 MPR。腰椎区间切尝试用局部椎间隙几何生成斜横状位，但真实病例对终板、附件、骨刺和分割毛刺非常敏感，短期内不适合作为主要推进方向。

下一步先实现脊柱矢状位 CPR。目标是在颈椎、胸椎、腰椎上沿椎体整体走向生成一条平滑曲线，并在左右方向生成多条偏移曲面，输出一组从左到右覆盖椎体两侧的矢状位 CPR 图像。

## 范围

本设计只覆盖第一版 CPR：

- 支持部位：颈椎、胸椎、腰椎。
- 支持状位：矢状位 CPR。
- 输出形态：一组左右偏移的 CPR DICOM 图像序列。
- 曲线来源：自动从椎体 mask 和定位结果生成，不提供手动画线入口。
- 视野范围：覆盖目标椎体主体和两侧附件、骨刺等结构。

本设计不包含：

- 冠状位 CPR。
- 椎间盘区间精切。
- 厚层融合 CPR。
- 手动画线或交互式编辑。
- 基于神经网络的椎管中心线。

## 用户可见行为

当请求颈椎、胸椎或腰椎的矢状位时，系统生成 CPR 计划，而不是默认直线矢状位整切。

输出目录保持现有按状位、窗位组织的结构，并在切割组中使用 `CPR`：

```text
矢状位/
  骨窗/
    CPR/
      001.dcm
      002.dcm
      ...
```

图像顺序从患者左侧到右侧。中间一张经过脊柱中心曲线。两端图像覆盖椎体左右外侧，便于观察椎体、椎弓根、横突、骨刺和其他附件位置。

Debug 输出至少包含：

- CPR 中心曲线 overlay。
- 左右覆盖边界 overlay。
- `slice_plans.json` 中的 CPR 曲线字段。
- warnings，包括缺失椎体、降级原因、曲线平滑信息。

## 曲线生成

阶段四从阶段三定位结果和重建用分割图读取目标椎体。

每个椎体先提取主体 mask：

- 优先复用现有 `_vertebral_body_mask()` 去除后方附件对中心线的干扰。
- 中心线使用主体 mask 的物理质心。
- 覆盖范围使用完整椎体 mask，包括附件和骨刺，而不是只用主体 mask。

按部位配置确定椎体序列：

- 颈椎：C1 到 C7。
- 胸椎：T1 到 T12。
- 腰椎：L1 到 S1。

有效椎体点少于 3 个时，不生成 CPR，降级到现有直线矢状位 MPR。

有效椎体点达到 3 个后，在物理空间拟合一条平滑中心曲线：

- 曲线参数按头脚方向排序。
- 第一版使用 NumPy 可实现的平滑折线：先按椎体中心排序，再对内部点做有限窗口平滑，最后按弧长重采样。
- 曲线必须经过首尾有效椎体主体中心，并接近每个中间有效椎体主体中心。
- 曲线平滑只用于减少局部抖动，不能明显离开椎体主体中心。若平滑后任一中间点距离原中心超过 5 mm，则该点保持原始位置。

## CPR 坐标系

每个曲线采样点都有一个局部坐标系：

- `tangent_dir`：沿曲线头脚方向。
- `left_right_dir`：患者左右方向，来自输入图像方向矩阵或既有解剖坐标。
- `anterior_posterior_dir`：由 `left_right_dir` 和 `tangent_dir` 正交构造，用于矢状 CPR 图像横向显示和深度采样。

CPR 输出图像固定为常规矢状位阅读方向：

- 图像行方向（左到右）沿患者前后方向。
- 图像列方向（上到下）沿曲线从头侧到足侧的弧长方向。
- 每个像素的三维物理点由 `center_curve_point + offset_mm * left_right_dir + ap_mm * anterior_posterior_dir` 得到。

这样输出上下保持头脚一致，左右表达前后深度，避免图像随曲线局部扭转。

左右偏移曲面按 `left_right_dir` 生成：

- 自动计算完整椎体 mask 在左右方向的最小、最大投影。
- 按请求的 `slice_spacing` 生成多条偏移曲面。
- 如果没有专用配置，默认生成覆盖左右范围的奇数张图，保证中间一张经过中心线。

## 阶段四协议

新增 `geometry_type = "curved_stack"`。

第一版 CPR plan 至少包含：

```json
{
  "geometry_type": "curved_stack",
  "curve_points": [{"x": 0, "y": 0, "z": 0}],
  "curve_spacing_mm": 1.0,
  "offset_axis": {"x": 1, "y": 0, "z": 0},
  "offsets_mm": [-20, -15, -10, -5, 0, 5, 10, 15, 20],
  "extent_mm": {"width": 120, "height": 300},
  "output_spacing_mm": {"x": 1, "y": 1, "z": 0},
  "slice_thickness": 3.0,
  "slice_spacing": 5.0
}
```

字段含义：

- `curve_points`：中心曲线物理点，按头脚顺序排列。
- `curve_spacing_mm`：曲线弧长方向输出采样间距。
- `offset_axis`：患者左右方向单位向量。
- `offsets_mm`：每张 CPR 图相对中心曲线的左右偏移。
- `extent_mm.width`：输出图前后方向覆盖。
- `extent_mm.height`：输出图头脚方向弧长覆盖。

`SlicePlan.slices` 对 `curved_stack` 不再表示普通平面切片，而表示每个左右偏移 CPR 图的索引和偏移中心。为避免误用，阶段五必须按 `geometry_type` 分发到专用 `CurvedStackResampler`。

## 阶段五重采样

新增 `CurvedStackResampler`。

它对每个 `offset_mm` 生成一张 CPR 图：

1. 将中心曲线按弧长重采样成均匀点。
2. 对每个曲线点构造局部采样方向。
3. 沿输出图每个像素计算其三维物理坐标。
4. 使用 SimpleITK 线性插值从原始 CT 采样 HU。
5. 输出 size 为 `(columns, rows, 1)` 的 2D 图像。

第一版先做普通单层 CPR。`slice_thickness` 可以保留在 DICOM 元数据中，但不做曲面厚层平均。厚层 CPR 作为后续版本。

## 降级和错误处理

以下情况降级到现有直线矢状位 MPR，并写 warning：

- 有效椎体点少于 3 个。
- 目标分割图缺失。
- 目标 label id 缺失。
- 曲线长度过短。
- 曲线拟合失败。

以下情况可以继续生成 CPR，但写 warning：

- 中间椎体缺失。
- 左右覆盖范围异常大，经过上限裁剪。
- 个别椎体主体 mask 提取失败，退回完整 mask 质心。

CPR 生成失败时，不应输出半成品 DICOM 到正式目录。

## 测试策略

阶段四测试：

- 三个以上椎体质心生成 `curved_stack`。
- 颈椎、胸椎、腰椎均能按配置选择正确椎体序列。
- 缺少中间椎体仍能生成 CPR 并写 warning。
- 少于三个椎体时降级直线矢状位。
- 左右 offset 覆盖完整椎体 mask 投影范围。

阶段五测试：

- `CurvedStackResampler` 对直线曲线输出应等价于普通矢状位采样。
- 弯曲曲线输出中，曲线弧长方向像素随曲线连续采样。
- 多个 offset 生成独立 DICOM 文件，顺序从左到右。
- 未知或缺字段的 `curved_stack` plan 明确报错。

集成测试：

- 腰椎请求横状位和矢状位时，横状位可继续使用当前策略，矢状位生成 CPR。
- 颈椎、胸椎矢状位生成 CPR，并保留现有横状位直线 MPR 行为。

## 迁移策略

区间切相关代码先冻结，不继续扩大改动。CPR 实现完成后再决定：

- 保留区间切作为实验能力。
- 回退区间切到 bbox 简单版本。
- 或将区间切依赖 CPR 中心曲线重新设计。

CPR v1 不要求清理区间切代码，避免误删已有调试资产和未提交工作。
