# 三状位重建参数请求设计

## 当前请求

`Request` 包含输入/输出路径、部位、检查类型、扫描厚度和 `plane_configs`。
外部请求不再传 `cut_mode`；内部切法由部位和状位自动推导。

每个 `PlaneConfig` 包含：

- `plane`：横状位、矢状位或冠状位；
- `slice_thickness`：层厚，必须大于 0；
- `slice_spacing`：层间距，必须大于 0；
- `window_presets`：一个或多个 JSON 配置中存在的窗位名称；
- `line_extent_mode`：定位线范围模式，默认整平面。

同一请求中状位不能重复。未提供 `plane_configs` 时默认只请求横状位、1 mm
层厚、1 mm 层间距和骨窗；矢状位、冠状位虽然已实现，但必须显式请求。

## 外部格式

CLI 使用 `--plane_configs` 接收 JSON 数组，例如：

```json
[
  {
    "plane": "冠状位",
    "slice_thickness": 2.0,
    "slice_spacing": 5.0,
    "window_presets": ["骨窗"],
    "line_extent_mode": "整平面"
  }
]
```

`PlaneConfig.from_dict` 把状位和定位线模式转换为枚举；窗位保持字符串，并通过
`get_window_preset` 检查当前 JSON 配置。`to_dict` 和阶段六报告继续输出稳定的
中文字符串。

## 职责边界

请求层只校验结构和参数，不决定实际切法、目标标签、切片数量或 MPR 几何。
预检确认部位/检查类型/状位组合可执行；阶段三解析目标配置；阶段四产生
`SlicePlan`；阶段五执行采样和 DICOM 写出。
