# 直线切割模块入口

本模块描述阶段四如何把整切、区间切和自动切法推导统一到直线切割流程。

## 当前有效规则

- 整切和区间切只在“生成多少个待切区间”上不同。
- 后续方向、图像范围、层厚、层间距和切片展开复用通用直线流程。
- 部位 planner 负责解析目标区间；阶段五只消费 `SlicePlan`，不重新规划。
- 腰椎区间切优先使用阶段三 `spine_geometry.filtered_annotation_centroids` 的
  `sagittal_body_quadrilateral` 求两个四棱柱最近点对，并以最近连线确定每段斜横切
  方向；输出平面以最近点位置为中心对称扩展，并仍覆盖完整 label 的 bbox 并集。
  旧结果缺少四边形时回退 faces，再回退旧 bbox 规则；存在但无效的四边形直接回退
  bbox，不再使用 faces 绕过失效判定。S1 使用专用左右支撑筛选和一层相连上缘补回。
- 默认整切走通用直线整切；腰椎横状位等特殊切法由切法推导策略决定。

## 当前限制

- 椎体主体 mask 仍由形态启发式生成，不同体型、椎体倾角、退变和原始分割质量可能
  造成边缘少量欠分或过分。
- 主体误差会继续影响矢状四边形、四棱柱最近点和最终切线；调试时应按
  `标签掩膜 → 椎体主体掩膜 → 椎体四棱柱掩膜 → 切片线` 的顺序检查。
- 当前最近点和垂直法向的几何链路已经建立；后续优化重点是主体标注的自适应阈值、
  局部解剖轴和多病例稳定性，而不是重新回到全量 bbox 或面中心法向方案。
