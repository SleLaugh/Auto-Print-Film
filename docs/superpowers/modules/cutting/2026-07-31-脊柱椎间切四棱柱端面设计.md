# 脊柱椎间切四棱柱端面设计

## 目标

为脊柱横状位椎间隙计划使用第五阶段生成的椎体四棱柱几何，解决全量椎体 label
包含横突、棘突等附件而导致相邻 bbox 在头脚方向重叠、椎间区间被全部跳过的
问题。该链路最初用于腰椎，当前也由颈椎椎间隙规划复用。

端面规划决定脊柱椎间区间的起止边界和每段切片方向。其上游主体提取和四棱柱几何
由颈椎、胸椎、腰椎及整段脊柱共用，也供 CPR 曲线、深度取景和解剖坐标参考使用；
修改上游时必须一起检查这些消费者。第七阶段采样接口不变。

## 几何来源与职责

第五阶段 `spine_geometry.filtered_annotation_centroids.<label>` 保存：

- `prism_found`、`prism_centroid_physical`：四棱柱是否成功及规则化主体质心；
- `sagittal_body_faces`：矢状四边形四条边的中心、法向和支撑点数；
- `sagittal_body_quadrilateral`：四棱柱矢状投影四个物理角点及左右挤出范围；

第四阶段 `coords.<label>.bbox` 保存当前工作分割中全量 label 的覆盖范围。

### 单个前方标签空槽的序列修正

第三阶段在构造定位、覆盖范围和 XY 候选之前检查腰椎语义序列。只有 S1/L5/L4
锚点可靠、异常标签缺少独立前体且薄帽贴合相邻端板、上下主体间距只容纳一个
正常步长，并且 CT 中只有一个稳定椎间盘谷时，才按物理主体顺序修正必要的前体
编号。独立薄椎体及两侧盘谷、真实缺体、多处歧义或上方椎体不足均不自动压缩编号。

修正仅重关联原前景中的前方主体走廊，不改下方可靠锚点、走廊外附件及请求范围外
的上游标签。原始缓存保持不变，派生分割写入输出目录
`nifti/seg_spine_sequence_corrected.nii.gz`。它随后参与 XY 校正，第三至第五阶段
以及重建使用同一工作分割；`spine_label_sequence` 保存原路径、派生路径、映射及
CT 证据。正常序列只检查标签计数，提前返回且不加载 CT。

重编号先固定可靠三维主体的归属，剩余薄帽和边缘按完整 Z/Y/X 的物理距离关联；
不能用矢状投影距离替代三维距离，以免侧倾椎体的投影重叠后发生跨椎体串号。
已确认的前帽连通分量以 2 mm 内的三维近邻作为种子，并要求与目标主体有真实
三维网格邻接，逐轴体素索引差均不能超过一格。接触参考使用原邻体标签中位于可信
前体走廊内的体素，避免主体裁剪丢失端板角点后漏掉小帽，也不把后方附件作为种子。
归属一致且完整位于受限前方走廊时整体重关联，避免将同一端板外角拆到两个编号。
种子不足、归属歧义或连接后方附件的分量保持原标签，不放宽全局距离门槛。
最终必须有至少一块可信薄帽归回空槽的紧邻主体，否则丢弃整次重编号结果；仅二维
投影贴合、CT 只有单谷仍不足以触发修正。

### 普通椎体主体选择与包围

普通椎体先在原始 label 内分别考察三维连通块，不再用“原始最大块的 20%”提前
删除其他块，以免后方附件较大时把完整前方主体删掉。逐横状层计算靠近中央的连续
LR 段宽，避免左右分叉之间的空白也被计入宽度；使用层内稳定宽度枚举 AP 候选带。
前方带跨层表现为薄突起，且替代带有足够跨层体量时才跳过；单层薄带面积不足后方
完整候选的 10% 时也按碎行处理。只有一个主体带的端层及本层已有充分 AP 支撑的
主体仍保留，避免端板被截短。两端有宽支撑、仅在少数层出现的内部细桥会被
切开，避免把前后不同结构通过跨层连接合成一个主体。
物理 AP/LR 比不能单独区分前突起时，还比较同一连通块内前后两带的相对 AP
深度、LR 宽度和跨层体量。按 AP 交叠跟踪同一前带，较厚层的体量也计入支撑，
避免真实椎体的薄端部被单独判成前突起；只剩主体的端层不混入前突起评分。

合成候选后，按中央 LR 对齐、AP 深度、体量、截面面积及连续 SI 支撑筛选，再选择
可信的前方主体。SI 支撑参考体量最大的可信候选，避免细长噪声抬高所需高度。
AP 深度与 LR 宽度的跨轴比例按当前图像 spacing 换算为物理尺寸，避免同一解剖结构
仅改变采样间距就被误判为薄突起或后方附件；未提供 spacing 的独立调用按等距处理。
最后继续执行原有的对齐端段保留和薄边缘裁剪。若裁剪后同时剩不到完整 label 的
10% 体量及一半 SI 跨度，按短残块返回空主体，不据此构造四棱柱。

普通椎体完成上述几何裁剪后，再附加连续占据密度验证。每根 SI 柱同时保留首末
跨度、真实占据层数和最长连续支撑链；链允许一层短缺口，但空层不计入支撑，也不
填充原 mask。只有总占据不足跨度的一半，且最长支撑不足跨度的三分之一时，才将
该柱识别为严重空壳并降低可信高度，防止首尾两片残留被误算成全高主体。

密度校验仍以原几何跨度作为参考高度，仅从 AP/LR 外缘向可信核心裁剪；两个方向的
交集也必须保留可信支撑柱。没有可信核心时保留上游结果，不任意选择某一行；密度
只能删除已保留的边缘体素，不能放宽原裁剪或删除内部缺口周围的主体。当前方法名
记录为 `vertebral_body_candidate_v3`，S1 继续使用独立提取规则。这一步统计的是
二值分割的连续占据，不使用 HU 恒定假设，也不能补出原标签中缺失的椎体。

若旧主体明显漏掉原标签内的三维密实核心，可另外执行有限恢复：占据窗口以主体
LR 宽度确定物理尺度，核心限制在中央 LR 带，避免经两侧椎弓根连到后方附件。
核心必须有足够 AP/SI 支撑、与旧主体距离有界，且确有明显遗漏和中心偏移；恢复
仅取原标签中窗口内已有体素。C2 齿突和 S1 不使用该普通主体恢复规则。

恢复结果保存 `body_extraction.method=density_core_recovery`。这类主体的覆盖包络
与端面证据分开：`sagittal_body_endplates` 从原标签多个 LR 切面分别拟合自然 SI
边界，拒绝锯齿错缘，再取具有足够 LR 支撑的角度共识；不把有限恢复窗口截面当作
真实端板。相邻普通椎体也提供原标签端面，只有包含恢复主体的配对才使用这些
独立端面，其他配对不变。端面证据不足、无共同切向区间或无法形成正间隙时回退
原四边形逻辑，不按预设角度强行压平。

原标签边界也可能被固定器械拖到骨内，因此候选 LR 切面还需通过原图密度验证：
沿法向比较内外 0.75–1.25、1–2、2–3 mm 的局部中位数，用局部 P90−P10
归一化。三窗中均至少 80% AP 点呈正下降，且中位归一化下降至少 0.2，才参与
端面共识；不是按绝对 HU 或预设端面角度选边。仅当存在恢复主体时延迟读取一次
当前工作 CT，并核对完整物理空间；无 CT 或验证不通过则保留四边形回退。
端面诊断保存原标签来源、LR 支撑和 CT 相对下降摘要，便于核查。

主体矢状投影仍先求凸包、简化四角并逐边外扩，保留楔形端板及完整包围语义。若
逐边外扩失败，备用包围接受完整多顶点凸包，沿其边方向选择最小面积包围矩形；
最终范围用舍入前的全部投影点计算，避免倒角无故拉斜整块主体或遗漏边界点。
多边形面积在局部坐标中计算，减少大物理原点下的相消误差。

椎间切优先从两个四棱柱矢状凸四边形选择相向端边，并在共同切向覆盖区间内取得
代表性边界点对确定位置和方向。全局最近点仍用于判断四边形是否分离，并在端边
无法形成共同区间时作为保守回退，但不能让单个角点主导正常椎间切线。相邻两个
全量 bbox 的并集确定每张图的平面内覆盖范围。输入没有四边形时才使用
`sagittal_body_faces` 安全回退；四棱柱轴对齐 bbox 不参与椎间距计算。

## 每个椎间的几何算法

对于有序的上位 label、下位 label：

1. 将两个四棱柱投影到同一矢状二维坐标，确认左右挤出范围存在重叠。
2. 枚举两个凸四边形边界的点-边距离，判断两者是否分离；随后按上下椎体中心方向
   选择相向端边。共同覆盖中点仍有正间隙，且间隙不低于正间隙子区间代表值的
   75% 时，优先在共同覆盖中点取得代表性点对，避免轻微相交把切片中心拉向一端；
   否则继续使用最长正间隙子区间中点，避免为居中而明显缩短有效间隙。
   外包络只有局部轻微穿入时，可用同一端边规则恢复有序点对；十字穿越和完整包含
   不允许伪造椎间隙。上位点到下位点的向量归一化后作为切片法向。
3. 保持图像行方向为患者左右轴，使用 `cross(normal, row)` 构造位于切片平面
   内的列方向，形成当前椎间独立的 `StraightPlaneFrame`。
4. 用代表性边界点对作为 `CutSegment.target_start/end`，并关闭通用整幅图中心重定位，
   使切线保持在真实椎体间隙位置；输出平面围绕该位置对称扩展到足以覆盖原投影
   范围，再调用通用等距切片展开逻辑。
5. `target_region_bbox` 仍为相邻全量 label bbox 并集，以覆盖椎弓根、横突、棘突
   和骨刺等完整目标结构。

第五阶段对 S1 不使用普通腰椎的前方主体启发式。S1 先按左右方向的投影支撑度提取
主体，当前阈值为最大支撑的 65%；随后仅补回一层接触已保留主体上缘二维膨胀区的
连通体素，避免短小上缘被阈值截断，同时限制骶翼和后方孤立附件进入四棱柱。主体
调试 overlay、四棱柱和第六阶段保存的矢状四边形必须使用同一份 S1 主体 mask。

四边形顶点、凸性/面积、左右范围、端边间隙和最终正交坐标系均执行有限值和
非退化检查。当前版本不因几何异常静默伪造正常椎间：只有输入完全缺少四边形时
才尝试 faces；存在但失效的四边形直接回退 bbox，若 bbox 仍重叠则沿用原跳过
warning。

## 回退与失败策略

- 输入几何没有 `sagittal_body_quadrilateral` 时，优先使用 faces，再保留
  现有 bbox 区间逻辑。
- 新结果的四边形无效、`prism_found=false`、左右范围不重叠、代表性端边退化且
  最近点也不可用，或
  无法构造正交坐标系时，当前区间直接回退 bbox 并记录带区间名称的 warning，
  不影响其他区间。
- 四棱柱失败不影响 CPR 已有的质心回退策略。
- 若两主体体素数较小者不足较大者的 25%，四棱柱前后投影无交集，且候选法向
  与输入头脚轴的绝对点积小于 0.5，则几何来自缺损主体残块的侧壁，直接跳过该区间。
  三项必须同时成立，不单凭体积小或斜切角度拒绝间隙；缺少有效体积证据的旧输入
  保持兼容。已识别的坏几何不再走同一标签的 bbox/质心回退，也不强行压成横状位。
  其他有效区间继续重建，所有跳过脊柱区间的原因去重写入成功报告 `Message`。
- 第六阶段不改写 `coords.*.bbox`、全量质心或四棱柱掩膜；第三阶段发生序列修正时，
  这些数据统一从修正后的工作分割重新生成，全量覆盖范围语义保持一致。

## 当前状态与已知限制

当前实现已经确认以下总体链路：

1. 从过滤后的椎体主体生成矢状凸四边形和左右挤出范围；
2. 从相邻四棱柱的相向端边共同区间求代表性边界点对；
3. 以代表点连线作为切片法向，并保持切线位于椎体间隙，而不是被角点或整幅图像
   中心拉偏。

但椎体主体标注目前仍是工程启发式，不是稳定的独立椎体主体分割模型。原始 label
质量、椎体旋转、楔形退变、骨赘和附件连接方式变化时，主体边缘可能少量欠分或过分。
这类误差会按“主体 mask → 四边形/四棱柱 → 相向端边 → 切线”逐级传递，因此当前版本
只能说明大的几何方向可行，尚不能认为椎体标注已经完成跨病例稳定性验证。

后续优化优先级：

- 用局部椎体解剖轴替代固定图像 z/y 方向的边缘判断；
- 主体形态筛选仍需继续验证 AP 反向存储；物理方向矩阵和层间距用于几何坐标换算；
- 将固定左右支撑阈值改为按椎体宽度和层间连续性自适应；
- 输出主体边缘、四边形拟合和相向端边的置信度/诊断量；
- 扩充不同倾角、退变程度及分割缺损病例的回归集。

## 测试验收

- 同一物理主体改变 AP/LR 采样后，主体选择和物理质心保持一致；侧倾产生相邻
  主体的矢状投影重叠时，已识别的三维主体仍完整归于各自的修正编号。
- 两个全量 bbox 重叠但端面有效时，仍生成一个有效椎间 `CutSegment`。
- 生成的 frame 法向与相向端边代表点连线一致，列方向与行方向正交。
- 椎间计划保持代表性间隙位置，并通过对称扩展完整覆盖相邻全量 bbox 并集。
- 楔形端边不能因角点最短距离形成锐角；轻微局部穿入仍保持上位到下位的 SI 顺序。
- 缺少端面、端面非法或输入缺字段时，按回退策略处理并写 warning。
- 中间标签只剩后方小残块时，不输出近冠状的侧壁切面；验证正常小主体、45°移位、
  输入旋转及存储轴反转仍保留原几何，且正常邻近间隙的完整 `CutSegment` 不变。
- C/T/L 共用主体提取的回归覆盖大后块、小前突起、分叉后翼、单层/双层细桥、
  偏侧碎片和细长噪声；集成验证真实端面位置、椎间方向和完整 label 覆盖范围。
- 连续密度回归覆盖首尾断续薄片、单/双层内部孔洞、分段但占据充分的边缘、倾斜
  端面、无可信核心及 AP/LR 核心互不重叠；只裁严重空壳，不重新引入已裁体素。
- 对真实 `腰1_1mm` 结果，五个腰椎椎间均不再因 bbox 重叠而被无条件跳过；最终
  计划数量、切片中心和方向通过运行时产物复核。
