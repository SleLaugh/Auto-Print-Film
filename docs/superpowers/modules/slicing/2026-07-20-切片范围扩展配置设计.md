# 切片范围扩展配置设计

## 目标

允许在 `src/config/slice_part_config.json` 中按切割部位、状位和切法配置切片开始端与
结束端的额外覆盖距离。配置单位固定为毫米，整体区域和椎间区域使用同一结构。

## 配置格式

扩展配置放在 `slice_rules.<状位>.<切法>.range_extension`：

```json
{
  "slice_rules": {
    "横状位": {
      "MPR": {
        "regions": ["default"],
        "localizer_plane": "矢状位",
        "range_extension": { "start_mm": 3.0, "end_mm": 3.0 }
      }
    }
  }
}
```

- `横状位`、`矢状位`、`冠状位` 直接使用现有 `PlaneTypeEnum` 的中文值。
- `start_mm` 表示从原始第一张切片方向向外增加的距离，`end_mm` 表示从原始最后一张
  切片方向向外增加的距离。
- 两个字段的单位固定为毫米，必须显式存在；允许零和正数，不允许负数、布尔值或
  非有限数。使用 `0` 表示该端不扩展。
- `regions` 引用 `localization.regions` 中的具名区域。MPR/CPR 当前引用一个
  `whole_range` 区域，椎间隙可以按顺序引用多个 `interspace` 区域。
- 椎间隙对每个有效区域分别应用同一份 `range_extension`，不再固定按 `0mm` 处理。
- 当前仓库为肺部、髋骨横状位配置 `start_mm=3.0`、`end_mm=3.0`，这是当前配置值
  而不是代码允许列表。
- 颈椎整体目标为 C1–T1，仅横状位 MPR 配置 `start_mm=0.0`、`end_mm=5.0`，
  从终点向外补 `5 mm`；冠、矢状位 MPR 保持 `0/0 mm`。固定余量不要求新增 T2 标签，
  也不能补出源 CT 扫描范围外的数据。
- 颅脑横状位 MPR 当前配置 `start_mm=10.0`、`end_mm=0.0`，在脑区物理范围外仅补
  头侧余量，改善脑区边界与骨性颅顶之间的覆盖差；冠、矢状位及其他部位不应用这项
  `10 mm` 余量。它是当前工程默认值，不保证所有病例颅顶完整，也不补出源扫描截断。

## 数据流与职责

第三阶段根据当前部位的 `localization.regions` 和 `slice_rules` 生成内部
`cut_configs`，并把当前部位的完整 `slice_rules` 放入阶段结果。第四阶段连同原始定位
边界转交 `cut_config`、`cut_configs` 和 `resolved_cut_config`，并通过
`resolved_cut_configs` 同时保存全部已解析定位范围方案。

第六阶段在生成等间距中心范围前，按当前 `plane` 和 `SliceType` 读取区域列表及扩展值，
并沿 `target_start -> target_end` 的单位方向分别向两端扩展；随后仍使用现有中心覆盖
算法处理无法整除层间距的余量。椎间隙逐区域独立执行同样计算。
`SlicePlan.target_start/target_end` 保留原始部位边界，`range_start/range_end`
记录扩展和等距补齐后的实际中心范围。

第七阶段只消费第六阶段产生的切片中心，不重新读取该配置或规划层组。
颅脑横状位 MPR 的计划可额外携带 `framing_superior_extension_mm`，作为头侧配置余量的
快照，供第七阶段同步扩展可选骨取景支持的最终 SI 上界；骨支持下界仍是脑区。
该字段只影响取景，不能把整个 `skull`、面部或下颌并入层组。
斜向切片沿自身切片序列方向扩展，因此不依赖固定 XYZ 轴。

覆盖检查使用首末厚层的物理外缘，Localizer 定位线表示中心面，第一条线通常距覆盖
起点仍有半层厚，不能直接把定位线当作厚层边界。层厚、间距和数量仍按公共规则计算；
例如 `5/5 mm` 采样增加 `15 mm` 恰好可增加三层，但其他参数下还会分配整组取整余量，
不能承诺所有配置的末层中心数值完全不变。当前颅脑默认下端配置保持 `0 mm`，不因骨标签下移到下颌。

## 校验与测试

应用启动时统一校验状位、切法、区域引用、对象结构、字段名称和值域。测试覆盖：
零扩展、当前肺部和髋骨横状位 3/3 配置、正向和反向路径、斜向路径、固定层间距、
无效配置，以及整切和椎间隙分别应用扩展。颅脑还覆盖横状位 10/0 默认值、冠矢零扩展、
计划取景余量快照、头侧骨参与取景及远端下颌不改变层组。
