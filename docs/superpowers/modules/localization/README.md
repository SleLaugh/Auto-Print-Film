# 定位模块入口

本模块描述阶段三目标定位、目标范围和回正占位。它不负责阶段四切片展开和阶段五 MPR。

## 当前有效规则

- 阶段三根据目标 label 提取全量 bbox、centroid、目标整体范围和调试 overlay。
- 脊柱整切按配置首尾标签展开完整解剖范围；胸椎默认 `C7 → L1`，腰椎按实际配置，
  不固定裁掉配置首尾椎体。
- 颈椎、胸椎、腰椎额外生成过滤标注和 `spine_geometry.filtered_annotation_centroids`（沟通简称“标注质心”）；它只供阶段四 CPR/区间切几何使用，不覆盖全量 `coords`。
- 过滤主体进一步规则化为四棱柱，CPR 优先使用实际四棱柱 Mask 的体素质心；矢状四边形拟合只使用 LR 支撑合格投影的最大二维连通块，避免碎渣拉歪质心。
- C1 是唯一固定排除项：保留在全量定位和覆盖范围，但不进入过滤标注质心、
  四棱柱和颈椎 CPR；胸椎 C7/L1 等其他配置首尾标签正常参与。
- 回正业务步骤保留，但真实人体回正算法不是当前有效能力。
- 后续阶段依赖阶段三输出的目标范围，不应在阶段五重新定位目标。
