# 回正与区域配置分离设计

修订日期：2026-11-18。本文记录已实现的配置与跨阶段契约；字段明细见
[配置说明](../../../src/config/README.md)，验证证据见
[本轮回归与性能记录](../archive/reviews/2026-11-18-回正与区域框架迁移验证记录.md)。

## 1. 目标与范围

将“依据哪些标签确定方向”和“依据哪些结构确定切割范围”分开，普通 MPR 统一使用
标签边界组合。现有八个启用部位迁移到该结构，保留既有回正算法、模型规则、切法、
外扩、取景参数和输出目录规则。本轮没有新增上腹、下腹、手臂或腿部能力。

`schema_version` 保持 `1`，直接替换配置格式。程序和配置必须配套更新；旧
`whole_range.start_label/end_label` 不再接受，版本号相同不代表新旧配置兼容。

## 2. 配置职责

| 配置 | 决定什么 | 不随它隐式变化的内容 |
| --- | --- | --- |
| `localization.pose` | 回正算法及其参考标签、端点或左右角色 | MPR 边界、CPR 标签序列 |
| `localization.regions` | 具名 MPR 区域、CPR 区间或椎间隙区间 | 回正输入 |
| `slice_rules.<状位>.<切法>` | 引用区域、六方向外扩、定位图状位、可选取景策略 | 区域引用不增加新算法 |

当前回正方法为 `brain`、`lung`、`hip`、`spine`。脑、肺用 `labels`，髋骨用
`roles.left/right`，脊柱用 `labels` 与 `roles.start/end`。这里的回正是既有算法估计
采样坐标方向，并遵循质量不足时的回退规则，不保证自动得到任意部位的临床标准定位。
脑部形态俯仰归入 `brain`；颈椎横状位附加方向仍由代码产生，未增加公开斜切配置。

脊柱的 `fit_excluded_labels` 只排除方向拟合证据，不删除全量标签、端点角色或 MPR
覆盖。CPR 的 `spine_cpr.excluded_labels` 独立控制 CPR 选用标签。共享主体几何只有在
某标签同时被这两者排除、且不被椎间隙使用时才可跳过；恢复的椎间隙专用主体也不能
反过来修改原有回正证据。当前颈椎两项均排除 C1，间隙仍从 C2_C3 开始。

## 3. 普通 MPR 区域与边界

`whole_range` 必须包含非空 `target_labels`、`bounds.upper`、`bounds.lower`。
目标标签提供左右、前后基础覆盖和取景证据，上下界标签提供头脚范围；两者可以不同。
引用一个标签作为边界不会自动将它加入回正或取景目标。

边界按以下顺序求值：

1. 将实际分割体素换算到物理坐标，再投影到该切法使用的解剖头脚轴。
2. `edge=upper/lower` 分别取每个实际标签的最高/最低位置。
3. `reduce=max/min` 再从这些位置中选最大/最小值。别名展开后包含多个标签时必填。
4. 加上 `offset_mm`：正数向头侧，负数向脚侧，默认 `0`，单位 mm。

边界名称与 `edge` 独立，因此“下边界取另一结构的上界”可直接表达。上下界最终为空、
反转、非有限值或必需标签缺失时明确失败，不自动交换或猜测。求值使用当前切法的
解剖方向，不等同于原始数组 Z 索引。

当前默认 MPR 区域对全部目标标签取最高上界、最低下界，保留原有标签并集覆盖；
脊柱目标显式列出所有椎体，不能只写首尾两个标签来假定会自动展开。
默认目标与回正标签一致时直接复用原有坐标边界，保留各算法已有的去噪和体素覆盖规则。
组合区域使用按需投影；相同标签和方向的投影结果在本次区域求解内复用。

区域确定之后，再按 `face_extension_mm` 添加上、下、前、后、左、右六方向余量。
六个字段全部必填，不扩展填 `0`；边界偏移与外扩相加，不应重复填写同一段余量。

## 4. 配置示例与迁移

下面是已有肺部结构的简化示例，展示一个普通区域；模型映射、其他状位及既有取景参数
仍以仓库配置为准。字段名保持可解析 JSON，不把解释写进键名。

```json
{
  "localization": {
    "pose": {"method": "lung", "labels": ["lung"]},
    "regions": {
      "default": {
        "type": "whole_range",
        "target_labels": ["lung"],
        "bounds": {
          "upper": {"labels": ["lung"], "edge": "upper", "reduce": "max", "offset_mm": 0.0},
          "lower": {"labels": ["lung"], "edge": "lower", "reduce": "min", "offset_mm": 0.0}
        }
      }
    }
  },
  "slice_rules": {
    "横状位": {
      "MPR": {
        "regions": ["default"],
        "face_extension_mm": {
          "top_mm": 0.0, "bottom_mm": 0.0,
          "front_mm": 0.0, "back_mm": 0.0,
          "left_mm": 0.0, "right_mm": 0.0
        },
        "localizer_plane": "冠状位"
      }
    }
  }
}
```

| 原结构/行为 | 新结构/迁移操作 |
| --- | --- |
| 由整体区域隐式决定回正输入 | 独立填写 `pose`，保留既有方法和标签 |
| MPR `whole_range` 的首尾标签 | 显式完整 `target_labels`，并填写上下边界 |
| CPR 与 MPR 引用相同区域 | 新建 `type=spine_range` 的 `cpr_range`，CPR 改为引用它 |
| CPR 首尾标签展开 | 保留 `start_label/end_label`，仅属于 `spine_range` |
| 椎间隙区域和顺序 | 保留 `interspace` 首尾结构与规则引用顺序 |
| CPR 排除项同时用于回正 | 在 `pose.fit_excluded_labels` 独立保留原回正排除设置 |
| 六方向外扩、定位图、取景 | 保留原参数；六方向不得省略 |

每条 MPR 规则当前只引用一个区域，不同状位可以引用不同区域。一个部位可以定义多个
MPR 区域，但当前只允许一个 CPR `spine_range`。椎间隙可以引用多个 `interspace`。
定义的区域必须被某条规则引用。定位会检查该部位配置中所需的全部标签，而不只检查
本次请求的状位；增加新区域也可能增加该部位的标签完整性要求。

## 5. 阶段交接与方向例外

| 阶段 | 职责与交接 |
| --- | --- |
| 第三阶段：空间校正 | 解析别名、统一所需标签，按 `pose` 限定回正输入；唯一确定后续 raw/seg 空间 |
| 第四阶段：标签定位 | 在选定空间提取完整坐标证据，保留 `pose_config`、`resolved_pose_config` 和各范围 |
| 第五阶段：解剖分析 | `anatomical_geometry` 保存回正几何；`anatomical_regions` 单独保存各 MPR 区域在全局和可用局部坐标中的边界 |
| 第六阶段：切片规划 | 按规则选择已求解区域；颈椎横状位选 `axial_mpr`，其余普通 MPR 选全局方向，再添加六方向外扩 |
| 第七阶段：重建 | 计划携带 `region_id`、`target_id`、`region_geometry`；对限定区域的取景不得重新被完整回正标签扩大 |

运行时范围分别保存在 `resolved_cut_configs.whole_range.regions`、
`resolved_cut_configs.spine_range`、`resolved_cut_configs.interspace.intervals`。
生产 MPR 配置缺少第五阶段已求解区域时失败，不回退到全量 bbox；显式 CPR 缺少有效
独立区间或排除后无标签时失败，不复用 MPR 目标、不降级为 MPR。

颈椎 `axial_mpr` 方向仍来自 `pose.roles.start/end` 的全量质心连线，只影响横状位。
区域边界会在这个局部方向重新求值，避免拿全局方向的投影值直接套进斜面。
脊柱全局方向仍由可靠左右对称证据与输入 AP 投影构造；普通 MPR 保留既有俯仰规则。
椎间隙端面和 CPR 路径继续使用各自专用几何。

取景中的 `constrained` 是内部派生状态，不是公开配置。默认全目标区域复用原路径；
改变上下界或目标集合的区域使用限定范围。它限制用于取景的证据，并保护已定区域，
不把源 CT 组织按标签抠除。逐层中心可以按策略变化，整组倍率仍保持一致。
限定区域不走肺/髋默认的整幅原 CT 保源画框分支。

## 6. 后续腹部和四肢的接入边界

边界语法已经能表达“双肾最高上界再向头侧 30 mm”或“下边界取另一结构上界”，但本轮
没有确认模型 701 的标签能力，也没有新增腹部配置。添加时仍需核对模型实际标签和扫描
覆盖；不能将“包含肾上腺”仅凭一个固定偏移当成已验证的效果。股骨头边界也不能未经
验证直接替换成整个股骨标签的上界。

四肢通常还需要侧别、长轴、关节端点和方向质量规则。当前 `pose.method` 只有四种已实现
方法，没有通用四肢方法；新增方法需同时接入配置校验和回正注册，并补充真实数据验证。
当前请求部位仍受枚举与能力规则约束，新部位不是仅在 JSON 填一个名字就可上线。
这些扩展可以复用现有边界求解、区域选择、六方向外扩和重建交接，涉及的新解剖算法
仍应单独实现和验证。
