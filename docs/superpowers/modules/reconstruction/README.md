# 重建模块入口

本模块覆盖第六阶段切片规划到第七阶段 MPR 执行，以及各部位直线 MPR 和脊柱 CPR。

## 当前有效规则

- 第七阶段只消费第六阶段输出的 `SlicePlan`，不再按部位或切割方式重新规划。
- `plane_stack` 是当前已实现的直线 MPR 主协议。
- 脊柱冠状位 CPR 已进入当前设计：颈椎、胸椎、腰椎沿椎体中心曲线生成前后偏移的冠状 CPR 序列。
- 脊柱 CPR 标签按第四阶段 `resolved_cut_config` 的首尾完整展开；胸椎默认使用
  C7、T1–T12、L1，非颈椎任务不额外删除配置首尾标签。
- 第五阶段输出的 `spine_geometry.filtered_annotation_centroids`（标注质心）负责 CPR
  中心线和弧度；第四阶段完整 `coords.*.bbox` 负责 CPR/区间切的覆盖范围。
- CPR 中间质心只有形成与相邻趋势相反的局部折返时才回正到双邻点预测位置；正常 C 型弯曲保持不动，L5 可修正而 S1 末端锚点不移动。
- 中间质心回正先于首末端面和原始 label 出口路径构造，避免下游仍读取未回正锚点；
  靠近末端的同向异常残差只允许在相邻间距 `10%` 内保守限幅。
- CPR 首末端面只有越出局部正常弧线区间时才回正到质心外延射线；正常连续弧线保持不动。
- 首末直线端段方向作为曲线样条的端点切向，保证直线与曲线相切连接，不在拼接处
  形成锐角。
- 回正后的首末端线保持方向不变，并沿原始分割搜索到白线穿出首末椎体标签的位置；不使用全量 bbox 极值决定端线长度。
- 脊柱冠状位 CPR 的层厚和层间距按原始标注体素外缘计算 offset 张数；两侧张数可以不同，最外层宁可多覆盖几毫米，也不能少包配置范围内的原始体素。
- 第七阶段会实际写出冠状位 CPR 切片和 Localizer；CPR 曲面使用批量物理坐标换算与三线性插值，保持原有输出间距、厚层子采样数和算术平均语义，不通过降低采样密度换取速度。
- 第六阶段默认只把 CPR 几何写入 `slice_plans.json`，不再额外生成 CPR NIfTI
  切片线、原始网格总览、含原图总览或十字中线调试图；定位核对看第七阶段
  `Localizer.dcm`/`Localizer.png`。
- 脊柱矢状位保持既有直线 MPR 切图逻辑，切片定位线画在冠状位背景上，不走 `curved_stack`。
- 颈椎、胸椎使用配置首尾椎体质心建立三维直线坐标系；只有颈椎 CPR 排除 C1。
- 髋骨横状位由 AB 决定倾斜角度，完整左右髋骨主体在最终法向上的投影决定覆盖范围。
