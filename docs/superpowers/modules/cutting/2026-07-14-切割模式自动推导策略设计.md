# 按部位和状位推导切法设计

## 当前规则

外部请求不接收 `cut_mode`。系统根据部位和状位调用
`src.planning.cut_policy.cut_mode_for_plane` 推导内部切法：

- `腰椎 + 横状位` 使用 `interspace`；
- 其他当前支持的部位和状位使用 `whole_range`。

最终 `SlicePlan.cut_mode` 仍记录实际切法，供目录分组、重建和报告使用。

## 混合状位请求

同一请求可以同时包含不同切法。定位阶段只要发现任一请求状位需要区间切，
就加载该部位的区间标签全集；第六阶段再按每个状位的推导结果分别调用 planner，
最后合并为统一计划列表。

切法策略的唯一特例集合保存在 `src/planning/cut_policy.py`。新增特例时只扩展
该集合及其测试，不能在 CLI、第三阶段、第六阶段或第七阶段重复写部位判断。

## 边界

切法推导只决定整切或区间切，不决定方向、层厚、层间距和覆盖算法。腰椎相邻
椎体 bbox 重叠时区间可能被跳过，仍是当前已知限制，不由本策略伪造区间修复。
