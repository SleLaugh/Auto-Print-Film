# 阶段三脊柱过滤标注与标注质心输出设计

## 定位

该步骤属于**阶段三定位**，不是预处理、全局回正，也不是阶段五重建。它只在颈椎、胸椎、腰椎任务中执行；肺部、头骨、髋骨等部位不生成该结果。

术语固定如下：

- **全量标注**：nnUNet 原始 label；
- **过滤标注**：从全量标注中过滤出的椎体主体 mask；
- **标注质心**：由过滤标注计算出的质心，作为 CPR 中间中心线和后续区间切定位的输入；首末椎体另外保存主体端面几何，供阶段四把中心线首尾约束到椎体表面。

## 输入与输出

阶段三继续读取完整的 nnUNet 分割，并同时输出两套互不覆盖的几何：

```text
完整 seg.nii.gz
  ├─ coords.*.centroid / coords.*.bbox
  │    完整 label 几何：定位、覆盖范围、首尾边界
  │
  └─ spine_geometry.filtered_annotation_centroids
       标注质心：当前 CPR 基准中心线和弧度
       单椎体局部头脚轴/范围：后续局部定位线阶段
```

`coords` 是既有定位契约，必须保持全量 label 的结果；主体提取不能回写其中的 `centroid` 或 `bbox`。

目标标签范围来自本次解析后的整切配置。阶段三把配置首尾按 C1–C7、
T1–T12、L1–L5、S1 的统一解剖顺序展开，并按当前模型实际提供的 label 取值。
胸椎默认配置 `C7 → L1`，因此 C7、T1–T12、L1 都进入本阶段输出；腰椎及其他
非颈椎任务也按配置范围完整使用。不能在阶段三另行固定裁掉配置首尾椎体。

阶段三正式输出的 `spine_geometry` 包含：

- `filtered_annotation`：过滤标注的算法版本、来源和目标结构；
- `filtered_annotation_centroids`：每个可用椎体的标注体素质心、物理质心、局部头脚轴/范围、端面平面内范围中点 `local_superior_inferior_face_centroids.min/max`、首尾端部的一组 `local_superior_inferior_face_candidates`，以及矢状投影轮廓四边形主体 `sagittal_body_faces`；阶段四优先先识别相邻标注质心连线进入椎体的那一面，再取同一轴上的对侧大面中心作为首尾端点，不固定使用内缩距离，也不使用 PCA 外接矩形角边；
- `excluded_from_annotation_centroids`：明确记录排除的 C1；
- 完整几何的来源说明，指向 `coords` 和 `coords.*.bbox`。

## C1 规则

- C1 仍然进入 `coords`、定位 bbox 和切图覆盖范围；
- C1 不进入 `spine_geometry.filtered_annotation_centroids`；
- C1 不参与颈椎 CPR 中心线；
- C1 不参与横状位姿态/回正角度统计；
- 其他状位仍可切到 C1。

C1 是唯一固定排除项。胸椎的 C7/L1、腰椎的配置首尾标签以及其他模型实际提供的
脊柱标签均按配置参与过滤标注质心和后续 CPR。

## 阶段边界

阶段三只负责从全量标注生成过滤标注、计算标注质心、单椎体局部头脚轴、主体端面中心和端部候选平面中心，不负责生成 CPR 曲线、切片数量或重建图像。

阶段四读取 `spine_geometry.filtered_annotation_centroids.*.centroid_physical`，按解剖顺序保留全部标注质心，并在首尾存在端面几何时生成“首端面中点 → 全部标注质心 → 末端面中点”的 CPR 锚点。首尾端面中心和全部标注质心直接写入 `SlicePlan.curve_points`，阶段四不再增加 Hermite 平滑点；阶段五沿该锚点折线按弧长重采样。`coords.*.bbox` 继续负责全量覆盖范围。

过滤标注提取失败时，阶段三不修改原始定位结果；阶段四可以根据缺失标注质心触发降级或回退策略。
