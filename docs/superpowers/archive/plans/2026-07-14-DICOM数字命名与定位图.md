> **供执行人员使用：** 按任务逐项实施本计划，各步骤使用复选框（`- [ ]`）跟踪状态。

**目标：** Name reconstructed slices `1.dcm`, `2.dcm`, and so on, and add an unnumbered `Localizer.dcm` beside each window series.

**架构：** Stage 5 keeps DICOM `InstanceNumber` unchanged while changing only the numbered slice filenames. For each plan independently, it selects the median fixed-axis original CT layer, burns that plan's thickness bands and center lines into the real orthogonal slice, applies the current window, and writes it as a separate localizer DICOM. Stage 6 numerically validates only files whose complete filename is `<positive integer>.dcm` and ignores `Localizer.dcm`.

**技术栈：** Python 3, SimpleITK, NumPy, unittest.

## 全局约束

- Formal slice filenames contain only their one-based decimal index and `.dcm`.
- `InstanceNumber (0020,0013)` remains one-based and continuous.
- `Localizer.dcm` is not counted as a reconstructed slice and is not validated by stage 6.
- The localizer filename is identical for every plane and window.
- Do not commit unless the user explicitly requests it.
