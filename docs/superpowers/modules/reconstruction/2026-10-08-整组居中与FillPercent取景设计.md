# 整组比例与部位居中的 FillPercent 取景设计

2026-10-23 更新：肺部、髋骨三个普通MPR状位统一按原标签整组包络中心取景，每侧余量5mm，
整组固定中心、倍率和矩阵，不再采用肺参考层或髋横/矢逐层中心。保留第六阶段原CT投影画框
的物理宽高比，100容纳所选标签及余量，70/50同心向四周扩大视野，不再将画框收紧成目标窄条。
其他五部位、0/null/省略、CPR、椎间隙、临床切割范围和Localizer保持原行为。

## 概念与协议

每项plane_configs可传FillPercent，有限数字范围[0,100]，拒绝bool、字符串和非有限值。
整数比例回显整数，真实小数保留精度；字段名严格为`FillPercent`，末尾不能带空格。
旧line_extent_mode已移除，传入会报错。
省略、null、0 的目标取景均按整组范围居中，保留基础间距、scale=1，不放大也不缩小；
肺/髋普通MPR必要时扩大共同矩阵保护完整源切面，其他适用模式随后仍执行平面成片上下裁空。

占比的参照物是输出图像，不是屏幕或查看器百分比。100不是原始倍率，0才保留原采样倍率。
目标来自所选分割标签，不是窗化亮像素或完整人体轮廓。高占比允许框外皮肤、肋骨、
腹部、大腿或骶尾结构越框；低占比从完整原CT采样更大范围，80不保证已显示全部体表。
不预裁原CT、不缩小预裁图后补框、不补全扫描外数据。

颅脑配置目标为 `brain`，有可用同次 `skull` 时，只保留其沿最终 SI 与脑区物理支撑
范围正重叠的体素；横状位 MPR 计划用 `framing_superior_extension_mm` 快照同步扩大
取景上界，当前默认为 `10 mm`，下界仍为脑区。筛选后的骨与脑区组成有界取景目标；
骨只影响取景，不能扩大切割范围或
把远处下颌、面部骨加入层组。正数 FillPercent 按有界目标确定共同倍率、逐层居中；
0/null/省略也以有界目标的整组中心居中，保留基础像素间距。骨缺失时只用脑区并警告。
这项有界骨取景对所有 FillPercent 生效，与下文只在正数时应用的脊柱上下文不同。
方向和基础范围仍仅由脑区估计，头侧余量只来自现有 `face_extension_mm`，
详见[颅脑形态斜切设计](2026-10-20-颅脑形态斜切设计.md)。

### 肺/髋所选部位与原画框配置

六条默认规则：肺部和髋骨的横、冠、矢状位普通MPR均配置：

```json
"framing_policy": { "basis": "selected_region", "margin_mm": 5.0, "canvas": "original" }
```

必需字段为basis=selected_region和margin_mm；每侧余量必须非负有限数字，
拒绝bool、字符串、负数、NaN和无穷值。可选`centering`为`group`、`reference_slice`、
`slice_target`，缺省`group`；可选canvas为`target`、`original`，缺省`target`兼容旧紧致画布。
不接受其他字段、null、数组或非对象值，CPR/椎间隙不能配置。该对象不是请求字段。
第六阶段深拷贝到SlicePlan.framing_policy，非None时序列化；第七阶段仅在
正数FillPercent的普通plane_stack MPR启用。其他部位默认配置不变。

### 整组目标与固定中心

以原source_labels对应的全部目标体素物理支撑外缘投影到行、列方向，包含半体素外缘，
得到原标签整组边界[L,U]。全局范围占位标记仍读取定位结果中的原始目标坐标，
不扩充为全部前景或皮肤。不是只挑面积最大的一层，也不逐层追随当前残留标签。

```text
固定面内中心 C = (L+U)/2
共同目标尺寸 T = U-L+2*margin_mm
```

组内所有切片、窗位和正数占比使用同一面内中心C，法向深度保留原值。
末端小标签、肺底少量残留以及空目标层继续用C和共同倍率，不跳位、不单独拉满。
髋横/矢状位也不再逐层追随目标bbox；这使连续层的部位位置保持连贯。
100完整容纳所选标签及余量，不等于所有人体或完整骨盆结构保护。
模型294没有独立sacrum/coccyx，左右髋骨包络不保证保护框外骶尾结构。

### 原画框与双轴同心扩展

canvas=original保留第六阶段基础矩阵Nx、Ny和基础像素纵横比sx:sy。
resolve_projected_extent在image.size_xyz可用时已经用完整源CT中心角点投影建立基础画框，
不能把后续收紧成目标bbox的画布称为原CT画框。此模式保留的是原画框物理宽高比
`(Nx*sx):(Ny*sy)`，不是简单像素数比，也不需要复制原CT中心或强制保全完整源范围。
无原图尺寸时第六阶段原有目标范围回退保持不变。

设正数q=FillPercent/100，沿两轴使用同一个因子：

```text
f = max(Tx/(Nx*sx), Ty/(Ny*sy))/q
output_spacing_mm = (sx*f, sy*f)
scale = 1/f
output_size_xy = (Nx, Ny)
FOV = output_size_xy*output_spacing_mm
extent_mm = (output_size_xy-1)*output_spacing_mm
```

100的FOV是在原画框物理宽高比内完整容纳T的矩形，允许不限制适配的另一轴比T更大；
不能写成每轴都严格等于T/q。FOV按像素外边界N*spacing定义，采样中心跨度为(N-1)*spacing，不能混用。
原矩阵、原像素纵横比与画框比例保持，不再向上取整紧致画布或按目标框改扁；
两轴同倍率，不拉伸解剖、不裁掉所选标签来填满画面。

70和50的实际间距与宽高FOV同时为100的1/0.7、2倍，80为1.25倍。
中心跨层、跨占比均不变，向四周扩展，不只增大一个方向。
每个占比直接从完整原CT重采样，不依赖100已裁输出，也不把图缩小后补框；
原扫描之外仍为正常无数据背景。原CT标签、HU和缓存不改。

整组共用倍率保留小截面的自然尺寸。冠状位等小截面或原画框比例与目标比例不同时仍有空气，
100不承诺零空气或任意胶片格宽高同时铺满；后端不接收胶片格尺寸。
0/null/省略不使用该模式，肺/髋仍保基础间距、scale=1、整组中心及完整源保护，必要时扩共同矩阵，
不通过缩放或裁源内容维持原矩阵，不做上下ROI。

## 分组和中心

| 切法 | 比例依据与正数中心 | 不变部分 |
| --- | --- | --- |
| 肺/髋普通MPR | 原标签整组包络加余量；固定组中心，在原CT投影画框比例内共同适配 | 原切面、法向层位、方向及原画框矩阵 |
| 其他部位普通MPR | 原组投影与逐层原目标加有界上下文共同决定倍率，逐层联合bbox居中 | 原方向、法向层位与上下文规则 |
| 椎间隙 | 同配置共同矩阵、倍率；厚层内相邻完整椎体与有界上下文联合中心，可靠时面内对称居中 | 各间隙斜横角度和层位 |
| CPR | 全部厚层展开掩膜并集定倍率，当前展开掩膜定中心 | 曲面路径、offset与厚层采样 |

除默认肺/髋固定组中心外，其他正数逐层模式按与当前厚层有正厚度重叠的目标物理支撑定bbox，
相交判断含半体素外缘，不能只按体素中心或边界相接筛选。原目标与获准上下文均为空时
回退组中心，原目标为空但上下文存在时按联合范围；CPR当前展开掩膜为空时同样回退。
缺少label_ids、分割无目标或CPR整组掩膜为空时明确失败，不以背景兜底。

## 切割目标与显示上下文

`source_labels` 继续决定第六阶段切面、法向范围及切片数量；第七阶段的显示上下文
只影响取景中心与共同视野，不能回写或扩大切割目标。

肺/髋正数普通MPR仅用原标签整组范围，其他部位沿用正数逐层目标居中；下述脊柱额外
上下文按解剖家族识别。当前识别脊柱椎体家族时，
从本次推理模型的 `dataset.json` 标签表加载同类椎体标签，不硬编码模型数字 ID，
不把全部前景或无关器官当作目标。`sacrum` 仅在原始目标显式选中时保留，不自动加入。
无同类家族或没有可用模型标签表时沿用原目标；存在但损坏的标签表明确报错。

脊柱上下文仅保留与原 `source_labels` 目标沿患者 LPS 头脚轴的物理外边界有正重叠的体素，
范围包含体素物理支撑外缘；该轴是患者物理头脚轴，不是随切面倾角变化的法向或数组轴。
不能加入整条相邻椎体的远端结构来扩大视野。各当前厚层再按原目标与这些有界上下文
体素的联合包围框居中；这样即使计划末端原目标仅剩附件，同层相邻椎体主体仍参与取景。
原目标的法向覆盖、层厚、间距、数量、方向和定位背景取样保持不变；MPR 定位线
仅按背景显示边界裁剪，不使用正式成片视野。

例如胸椎原目标截至 L1，尾层 L1 只剩后方附件，但该厚层的 L2 主体仍实际可见。
只将 L1 残余附件居中会把 L2 主体推到画外；在原目标头脚范围内纳入 L2 显示上下文，
即可对当前可见结构居中。该病例尾六张联合范围均可装入既有约 125.23 mm 视野，无需改变倍率。

CPR 正数时先将有界上下文加入标签取景掩膜，再按原曲面展开；曲面路径和厚层 HU 采样不变。
0、null 或省略不加载上述脊柱显示上下文，保留原目标取景和基础间距；平面成片仍执行下述上下裁空。
颅脑有界骨支持按最终 SI 筛选，对所有 FillPercent 生效，具体规则见前述颅脑段落。

## 其他部位与椎间隙的共同倍率

其他部位普通平面继续逐轴取原整组投影尺寸与各厚层原目标加有界上下文联合尺寸最大值，
不能只移动中心却忽略新增上下文。必要时统一放宽整个计划，不能逐层改变PixelSpacing。
这些部分不使用肺/髋的`5 mm`策略余量。颅脑骨支持与脊柱上下文规则保持原有约束。

可靠椎间对称面仅沿面内LR投影调整中心，不改法向或原前后倾角；预先按新中心到联合边界
最大距离乘二容纳两侧。证据不足、面点超有效范围或LR主要指向法向时保持bbox中心。
不从一般`global_frame.origin`推断面点。极小占比若使视野无法有限表示，采样前明确报错。

### 椎间隙共同画布

椎间隙以前面各组画布为基准：按有效计划顺序，取末组之前各组基础矩阵的逐轴中位数，
按 NumPy rint 取整后作为同一部位、同一配置的共同 Nx、Ny；单个有效间隙使用自身基础矩阵。
再把各间隙的原整组投影尺寸与逐层原目标加有界上下文联合尺寸逐轴取最大值得到共同 Tx、Ty，
正数 FillPercent 按上式计算一次，必要的视野放宽同时应用于同配置所有间隙。
末组的较窄或偏高画布不决定共同矩阵，避免把所有间隙一起缩小；
正数 FillPercent 下，全部目标尺寸仍参与比例计算以保证覆盖，不因末组排除画布参考而裁掉其目标结构。
不能把不同间隙的物理坐标包围框直接合并，否则层位置差会错误扩大视野。
各间隙在上下裁空前共用 Rows、Columns、PixelSpacing 和物理视野，正数时每张按自身厚层内标签居中；
解剖本身大小不同仍会显示大小差异，不通过拉伸改变真实比例。
0、null、省略时同样统一裁空前矩阵，保留原像素间距，scale=1，不额外按目标范围适配；
共同矩阵比某组原矩阵更小时，该组周边视野随之减少。
配置由 config_id、输出状位和部位隔离；旧计划缺 config_id 时按输出状位与部位分组。
仅实际生成的有效间隙参与统计；已生成计划缺少目标标签仍明确报错。

### 平面成片上下无源支持行裁剪

除肺部、髋骨的普通 MPR 外，`plane_stack` MPR 和椎间隙
在完成 HU 厚层采样后、窗化前，调用
`vertical_support.py` 的 `crop_vertical_padding`。它按源 CT 几何、实际输出列和厚层
采样点判断每行是否存在源支持，仅裁掉首个有效行之前和末个有效行之后的完整空行。
常规路径仅通过连续源索引的几何区间判断。半体素边界附近 strict/loose 判断有分歧时，
直接复用实际 source 和完整 `Columns×Rows×1` reference，只读取不确定行的结果；不能
缩成单行或移动 reference 原点，否则 ITK 快速扫描线的浮点舍入可能改变边界支持判定。
复核按实际厚层子平面取支持并集，全部不确定行获得支持后即停止，不重新计算 HU 厚层平均，
也不创建整卷常数掩膜；NaN、+Inf 双越界哨兵区分越界与源像素本身的 NaN/Inf，避免按 HU 值误判。
不按 HU 阈值或窗化后的黑色判断，不能把真实空气、窗位黑色或斜切角部当作无数据带。
裁剪使用 ROI 保留原有效行及其 HU、Columns、PixelSpacing 和采样网格相位，不重新采样、拉伸或补黑框；
左右允许留白，整幅裁后图像的物理中点作为最终显示中心。

肺部、髋骨普通 MPR 跳过此步骤，以保留共同矩阵；正数统一使用原标签固定组中心和原画框，
0/null/省略保留整组目标中心和完整源保护；其余适用平面
在 0/null/省略和正数 FillPercent 下均执行。CPR、Localizer 背景及定位线不执行。各层首尾空行数可能不同，故最终 Rows 和垂直物理视野
可以逐层不同；同层所有窗位仍共用裁后的几何与 HU。同组共同倍率和 PixelSpacing 不变。
不能使用全组最短有效高度统一裁剪，否则会删除其他层的有效内容；也不为恢复共同 Rows 补框。
整张均无源支持的层保持原样，并标记 `vertical_source_support.status=no_source_support`，
不能伪造有效内容。裁空前的普通平面厚层平均只纳入有效源采样，轴对齐按有效重叠厚度、
斜切按有效子平面数归一；真实空气参与，越界填充值不参与。它能恢复部分支持却被填充值
压黑的组织，但不能恢复所有采样点均在源 CT 外的位置，也不改变既定切面、范围或张数。
该裁剪只去掉上下完整无数据带，不能消除首末斜切层图内的局部零支持黑区。
外部查看器的额外黑框仍由 fit 设置和格子
宽高比决定；完整保留内容、保持比例时，后端无法保证任意格子四边均铺满。

## 执行顺序与诊断

第六阶段透传fill_percent，并深拷贝当前普通MPR的可选framing_policy，仍产生原基础视野与切面。
第七阶段从定位结果分割路径读取标签，不能延长第三至五阶段临时label快照生命周期。
普通MPR与间隙先调整几何，再从完整原HU体数据直接重采样；肺/髋保共同画布，其他适用
平面随后裁上下无源行。CPR先按原曲面采样HU和掩膜，再按全组并集统一缩放，当前掩膜居中。
HU线性插值/厚层平均与标签最近邻/厚层并集不得混用；新矢状位CPR仍保留前后曲度，
不能逐行跟随真实三维curve_points的AP坐标消除曲度。

原计划不原地修改。所有模式保留`mode=group`、`source=group_target`表示共同目标来源。
肺/髋所选部位策略另记录：

| 字段 | 含义 |
| --- | --- |
| `selected_region.basis`、`margin_mm`、`centering`、`canvas` | 实际配置值；默认肺/髋为selected_region、5mm、group、original |
| `selected_region.lower_in_plane_mm`、`upper_in_plane_mm` | 未加余量的原标签整组边界，行、列方向 |
| `center_source` | 默认肺/髋始终`group_selected_region`，包含小标签和空目标层 |
| `framing_target_size_mm` | 原标签整组包络尺寸加两侧余量 |
| `slice_target_size_mm` | 当前厚层标签尺寸或空值，仅诊断，不决定逐层倍率 |
| `center`、`output_spacing_mm`、`scale`、`output_size_xy`、`extent_mm` | 实际中心、间距、倍率、矩阵与中心跨度 |

默认肺/髋正数策略没有参考层、人体或自动相邻标签支持，不记录reference字段、`source_preservation`、`skin_edge`或身体工具字段。
其他部位和切法仍记录原有`slice_target`、`slice_symmetry_plane`、`group_fallback`、`group_target`等来源；
`context_label_ids`记录实际获准补充标签，可靠对称面的诊断保留于`symmetry_centering`。

肺/髋0/null/省略仍记录`source_preservation.mode=complete_source_slab`及共同保护尺寸、实际FOV、
`zoom_limited`；矩阵扩展不等于倍率改变。上下裁空时记录`center_source=source_supported_image`、
原`target_center_source`及`vertical_source_support`裁行数/原行数/原中心，并同步实际中心、extent和矩阵。
椎间隙另记`scale_scope=interspace_config`、shared目标/参与计划与画布参考计划。
预计算逐计划释放完整点云，随后逐计划采样HU，不同时持有多组图像。

## DICOM、定位图与已知限制

DICOM逐张写出实际PixelSpacing、ImagePositionPatient、ImageOrientationPatient，
SliceLocation用实际平面的法向投影。中心与上下裁空可使相邻切片有面内位移，
不能忽略逐张几何将所有序列直接当规则直角三维体。CPR是展开图，不能恢复原弯曲解剖体，
不能承诺与原 CT 精确三维联动。取景、范围和姿态分工保持不变；颈椎仍C1–T1，
横状位末端外扩5mm，CPR仍排除C1；脑横位既有10mm头侧范围外扩不因这次取景调整改变。

定位图不应用取景。Localizer保留固定localizer_reference、方向和首末像素物理范围，
粗显示轴在绘线前仅做二维线性细化，见[通用定位图规则](../dicom/2026-10-08-定位图状位配置与取景隔离设计.md)。MPR白线直接按
第六阶段真实无限平面与背景求交，只裁到底图边界或曲面显示网格，不以成片有限视野裁线。
切换FillPercent不改变背景矩阵、间距、参考点、取样或交线端点与长度。
CPR定位线继续投影真实offset中心曲线，绘线不回写计划。

各窗共用实际几何与未取整重建HU，按各自实际窗宽窗位映射uint16灰度并写入对应标签。
派生显示CT窗内有量化、窗外截断，定量应读原始CT；Localizer为合成显示，不用于定量HU。
不新增正式成片PNG，调试定位图PNG保留。旧输出须重新切割才更新。
查看器fit和胶片格比例仍可产生留白；共同倍率不表示每张零空气或固定格子满铺。
不拉伸、不裁所选目标来填满宽高，插值不会增加原始细节。

## 显式兼容模式与内部工具

centering=reference_slice、slice_target或canvas=target仍可显式使用，但不是默认肺/髋六规则。
reference_slice按实际厚层目标bbox面积最大层选共同偏移，并对所有层的目标覆盖需求统一放宽尺寸；
slice_target按每层实际厚层目标bbox居中、空层回退整组，共同比例按实际厚层尺寸最大值确定。
两者仍加配置余量。target按适配后目标FOV向上取整、保持原矩阵奇偶性收紧画布；
original保留原矩阵与物理画框比例，不能把两种画布的公式混用。
显式参考模式可记录group_reference_slice及reference字段，逐层模式为slice_target/group_fallback，
不应据此判断默认肺/髋会逐层移动。

缺少framing_policy的旧肺/髋计划或显式内部API仍保留旧完整人体保护与skin_edge算法，
不属于当前默认正数肺/髋普通MPR。旧人体支持每源提取一次、边界2mm、可靠分离空气/薄床板，
保留肩臂与双腿，未知源层局部回退完整源盒；不能可靠分离的设备保守保留。
旧100可按人体紧致包络修正肺共同偏移或髋合法中心，其他正数以人体限制目标放大；
因此旧100和80可能有不同中心，新默认策略不使用这一分支。
`body_support`、`body_framing.py`、`trunk_framing.py`保留各自工具语义，不能改原HU、
切面、范围、层厚、层间距、张数或Localizer，也不能补全扫描外结构。

`symmetry_framing.py`、`vertical_support.py`、`curved_stack.py`、`dicom.py`与`stage_reconstruction.py`。
