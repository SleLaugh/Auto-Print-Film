# 椎体四棱柱质心设计

> 当前四棱柱外包络、可信端部恢复和相邻分隔规则由
> `2026-08-06-椎体主体外包络四棱柱设计.md` 补充；本文继续作为四棱柱质心与
> 第五阶段几何与第六阶段消费契约的基础设计。

## 背景

第五阶段当前从 nnUNet 全量椎体 label 中提取过滤主体 Mask，并输出
`椎体主体掩膜.nii.gz`。CPR 的中间锚点使用过滤主体体素质心，首末端点则优先
使用过滤主体在矢状投影上抽象出的四面几何。

真实过滤主体仍可能保留不规则边缘、缺口和局部体素密度差异。这些差异会改变体素
质心，因而可能影响第六阶段 CPR 点位。第一版需要在保留原始过滤主体结果的同时，
把每个椎体规则化为填满的三维四棱柱，以实际填充体素的质心作为新的 CPR 中间
锚点来源。

## 目标

- 保留现有 `椎体主体掩膜.nii.gz`，用于观察规则化之前的过滤结果。
- 新增 `椎体四棱柱掩膜.nii.gz`，逐椎体保存填满的三维四棱柱。
- 四棱柱的矢状截面来自现有主体矢状投影四边形。
- 四边形拟合使用 LR 支撑合格投影的核心二维连通块，并允许补回严格对齐的端部
  断连块；远端碎渣仍不得撑歪凸包。
- 四棱柱的左右厚度来自该椎体过滤主体的实际左右最小、最大边界。
- 由实际写入四棱柱 Mask 的体素计算质心，第六阶段 CPR 优先使用该质心。
- 保持全量 label 的质心、bbox、覆盖范围和现有 CPR 曲线平滑逻辑不变。

## 非目标

- 不生成脱离原主体范围的固定尺寸方块。
- 不使用全量 label 的左右范围构造四棱柱，避免横突等附件扩大规则化主体。
- 不改变 C1 排除规则。
- 不在本次调整第六阶段的曲线平滑、首末端面选择或第七阶段重建算法。
- 不用连续空间解析体积中心替代栅格 Mask 质心；该选项留待后续精度比较。

## 数据流

```text
nnUNet 全量椎体 label
  |
  +--> 现有过滤主体 Mask
         |
         +--> 保持输出：椎体主体掩膜.nii.gz
         |
         +--> 统计每个 Y/Z 投影点的 LR 支撑宽度
                 |
                 +--> 保留支撑核心及可信端部断连块
                         |
                         +--> 矢状投影轮廓凸包
                                 |
                                 +--> 四边形主角点
                         |
过滤主体左右最小/最大边界 --+
                         |
                         +--> 在当前 CT 网格内栅格化三维四棱柱
                                  |
                                  +--> 新增输出：椎体四棱柱掩膜.nii.gz
                                  |
                                  +--> 对实际填充体素求质心
                                           |
                                           +--> 第五阶段 spine_geometry
                                                    |
                                                    +--> 第六阶段 CPR 锚点
```

## 第五阶段设计

### 四棱柱构造

每个脊柱目标标签继续先调用现有过滤主体提取逻辑。C1 在构造前排除，其他可用
椎体按以下规则处理：

这里的“目标标签”来自第四阶段定位结果中已经展开的整切配置范围。胸椎默认范围为 C7 至 L1，
所以 C7、T1–T12、L1 都会尝试生成四棱柱；除颈椎 C1 外，不因部位名称再次删减
配置首尾标签。

1. 将过滤主体体素转换到当前图像的物理坐标。
2. 沿当前图像左右轴投影，取得该过滤主体的最小、最大左右范围。
3. 沿当前图像前后轴和头脚轴投影，复用现有矢状轮廓凸包与四边形简化规则，
   获得有序的四个主角点。
4. 在只覆盖该椎体局部范围的候选体素盒内，判断体素中心是否同时满足：
   - 左右投影位于主体最小、最大边界之间；
   - 矢状投影位于闭合四边形内部或边界上。
5. 满足条件的体素全部写入该椎体的四棱柱 Mask，使用原模型 label id 保持
   各椎体可区分。

点在多边形边界上的判定必须包含边界，并使用与当前体素间距相称的数值容差，避免
四棱柱表面因浮点误差出现孔洞。

### 矢状投影碎渣隔离

过滤主体在三维中可能通过很细的体素桥连接远端碎渣，因此仅保留最大三维连通块
仍不能保证矢状凸包输入干净。四边形拟合前增加以下二维核心选择：

1. 按每个 `(z, y)` 投影位置统计其包含的不同 `x` 体素数量，作为 LR 支撑宽度。
2. 继续沿用现有支撑阈值：
   `max(2, ceil(该椎体最大 LR 支撑宽度 × 0.35))`。
3. 对达到阈值的 `(z, y)` 位置按八邻域计算二维连通块。
4. 先选择投影点数量最多的核心连通块。数量相同时，依次选择 LR 支撑总和更大的
   连通块、最接近全部支撑点加权中心的连通块，保证结果确定。
5. 只有与核心头脚端紧邻、体量和 LR 支撑足够、AP 高度重合的断连块可以补回；
   详细阈值见 2026-08-06 补充设计。
6. 将原三维主体体素映射回选中的 `(z, y)` 核心和可信端部，仅这些体素参与物理中心、
   矢状凸包和四边形主角点计算。

该清理只属于四棱柱/四面几何的拟合输入。`椎体主体掩膜.nii.gz`、过滤主体
`centroid_*`、全量 label 和 bbox 均保持不变；因此调试主体 Mask 仍可显示原始
候选碎渣，但碎渣不再影响四边形、四棱柱 Mask 或 CPR 优先质心。

如果支撑合格投影不足四点，沿用现有退化策略，使用原过滤主体拟合；如果只有一个
合格连通块，则选择结果与当前算法一致。

### 质心和契约

四棱柱质心必须从实际栅格化后的非零体素计算，不能直接使用四角平均值，也不能
使用连续空间理论中心。体素索引质心通过当前定位图像转换为物理质心。

`spine_geometry.filtered_annotation_centroids.<label>` 在保留现有主体字段的
基础上新增一组四棱柱字段：

- `prism_found`：是否成功生成非空四棱柱；
- `prism_voxel_count`：实际填充体素数量；
- `prism_centroid_voxel`：四棱柱体素质心；
- `prism_centroid_physical`：四棱柱物理质心。

现有 `centroid_voxel` 和 `centroid_physical` 仍表示过滤主体质心，不改名、不
覆盖，以便同时比较规则化前后的点位。

### 调试输出

第五阶段默认不再写出 `定位框.nii.gz` 和 `目标掩膜.nii.gz`。定位框属于早期范围
检查图，标签覆盖已由保留 label id 的 `标签掩膜.nii.gz` 表达；`目标掩膜.nii.gz`
只是标签掩膜的二值合并版，和当前人工检查需求重复。

第五阶段保留：

- `标签掩膜.nii.gz`；
- `椎体主体掩膜.nii.gz`；

并新增：

- `椎体四棱柱掩膜.nii.gz`。

两份文件均使用原模型 label id 区分椎体。定位结果和阶段元数据增加
`debug_vertebral_body_prism_mask_overlay_path`，其生命周期和现有主体 Mask
调试路径保持一致，只在启用调试文件时写出有效路径。

## 第六阶段设计

第六阶段读取过滤主体几何时，单个椎体按以下优先级取 CPR 中间锚点：

1. `prism_found` 为真且 `prism_centroid_physical` 完整时，使用四棱柱质心；
2. 当前结果明确包含 `prism_found`，但四棱柱不可用，而现有过滤主体
   `found` 为真且 `centroid_physical` 完整时，回退到过滤主体质心，并记录
   该椎体的明确警告；
3. 输入几何没有 `prism_found` 字段时，直接使用现有过滤主体质心，
   不产生“四棱柱生成失败”的误导警告；
4. 四棱柱和过滤主体质心都不可用时，沿用当前缺失过滤主体质心的处理，不回退
   到全量 label 质心。

首末椎体的路径端面继续读取现有 `sagittal_body_faces`。全量 `coords.*.bbox`
继续只负责覆盖范围，不参与四棱柱构造和 CPR 中间锚点计算。

## 失败与回退策略

- 单个椎体无法得到四边形、左右范围无效或栅格结果为空时，将
  `prism_found` 写为假，四棱柱计数为零、质心为 `null`。
- 失败只影响当前椎体；其他椎体继续生成四棱柱和新质心。
- 第六阶段在单椎体回退时输出包含 label 名称的警告，便于从日志定位。
- 输入几何缺少 `prism_found` 字段时，第六阶段使用现有过滤主体质心且不产生
  “四棱柱生成失败”的误导警告。
- 四棱柱生成不得修改原始分割、过滤主体 Mask、全量质心或全量 bbox。
- 二维核心选择失败或有效点不足四个时，回退到现有完整过滤主体拟合，不让新增
  过滤导致单个椎体无计划可用。

## 测试

### 第五阶段单元测试

- 不规则过滤主体能够生成内部填满的四棱柱。
- 与主体高支撑区通过低支撑细丝相连、但自身达到 LR 支撑阈值的远端碎块，不得
  进入四边形拟合。
- 只有一个 LR 支撑合格连通块时，拟合输入和四棱柱结果保持不变。
- 多个合格连通块等大时，选择结果按支撑总和及加权中心距离稳定确定。
- 四棱柱左右范围等于过滤主体的实际左右边界，不使用后方附件或全量 label 范围。
- 四棱柱矢状投影边界由四条直线组成，内部缺口被填满。
- `prism_centroid_voxel` 等于实际四棱柱 Mask 非零体素索引的平均值。
- `prism_centroid_physical` 等于上述体素质心经当前图像变换后的物理坐标。
- 调试输出保留各椎体原 label id，C1 不进入四棱柱 Mask。
- 四边形无效或栅格为空时输出失败契约，不影响其他椎体。

### 第六阶段单元测试

- 可用时 CPR 锚点包含四棱柱质心，而不再使用过滤主体质心。
- 四棱柱不可用时仅该椎体回退到过滤主体质心并产生警告。
- 输入定位结果缺少 `prism_*` 字段时仍能使用过滤主体质心生成 CPR。
- 首末端面、全量覆盖范围和当前曲线平滑结果不因本次改动而改变。

## 验收标准

1. 同一次第五阶段运行同时输出主体 Mask 和四棱柱 Mask。
2. ITK-SNAP 中每个四棱柱的矢状轮廓为直线闭合四边形，内部完全填色。
3. 四棱柱左右厚度不超过对应过滤主体的实际左右边界。
4. 第五阶段记录的新质心与四棱柱输出文件中同 label 体素的实际质心一致。
5. 第六阶段 CPR 中间锚点优先使用四棱柱质心。
6. 任一椎体规则化失败时，其余椎体仍正常工作，失败椎体有明确回退警告。
7. 原主体 Mask、全量定位几何、C1 规则、首末端面和现有 CPR 平滑逻辑保持不变。
8. 2026-07-29 胸椎病例中 C7、T3、T4 的独立高支撑碎块不再进入四边形拟合；
   T1、T2、T5–L1 的单连通块拟合结果保持不变。
