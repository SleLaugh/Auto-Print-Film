**Goal:** 当阶段三成功写出回正候选 raw/seg 时，后续定位几何、规划和重建统一使用回正后的 NIfTI 空间。

**Architecture:** 阶段三仍先用原始分割估计横状位 XY 回正候选并写出候选文件。候选 raw/seg 均存在时，把候选文件提升为本次定位工作输入，重新读取回正后的 seg/image，重新生成 coords、bbox、解剖坐标、椎体主体和四棱柱；阶段四/五继续读取既有 `raw_for_reconstruction_path`、`seg_for_reconstruction_path` 和 `spine_geometry`，无需增加 CPR 专属回正分支。

**Tech Stack:** Python 3.10+、unittest、numpy、SimpleITK。

## Global Constraints

- 只在候选 raw/seg 文件均存在时切换主流程输入。
- 切换后，`coords`、`correction_scope_bbox`、`image`、`anatomical_geometry`、`spine_geometry` 和 debug overlay 必须来自回正后的 seg/image。
- 阶段四/五不重复实现回正判断。
- 原始 raw/seg 不得被覆盖。
