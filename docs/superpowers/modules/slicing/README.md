# 切片模块入口

本模块描述切片中心、区间覆盖、层间距和可配置范围扩展。当前规则以后 2026-07-20 的完整覆盖设计为准。

## 当前有效规则

- 任意直线切片计划的首张和末张切片中心必须到达或越过目标区间边界。
- 层间距控制中心到中心距离；层厚控制第五阶段厚层采样物理覆盖。
- 首尾可允许少量对称外扩，但不能只依靠厚层外边缘覆盖目标。
- 可按部位、切割方式和状位配置额外范围扩展，单位固定为毫米。
