**Goal:** 正常连续弧线端面保持不动，只有越出局部弧线区间的首末端面才最短投影到 `0°` 质心外延线。

**Architecture:** 保留 `_correct_endpoint_face_to_local_arc` 现有正常角度区间判定，仅改变越界后的目标角：不再投影到最近区间边界，而是统一投影到 `0°` 外延射线。中间质心、Hermite 平滑、CPR 标签和重建逻辑均不改变。

**Tech Stack:** Python 3、NumPy、`unittest`

## Global Constraints

- 正常弧线区间内的非零端面转角必须保持原坐标。
- 越界或回折端面触发后，修正目标角严格为 `0°`。
- 回正必须保留图像左右轴分量，并采用正交投影保证移动距离最小。
- 不修改中间 CPR 曲线平滑逻辑。
- 实施阶段先保持未提交，待用户实际病例测试通过后再由用户明确授权提交。

                    },
                },
            },

    }
