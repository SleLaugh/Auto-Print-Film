# 颅脑形态斜切、脑区范围与有界骨取景

## 目标与边界

颅脑横状位默认随脑形态调整前后倾角，整组平面彼此平行。冠状位、矢状位共同使用
同一最终正交坐标，避免只改变横状位而使三状位互不对应。切片范围完整覆盖脑区，
并在脑部范围内通过同次骨标签辅助取景、居中和防裁边。切片基础范围由 `brain`
决定，当前仅横状位 MPR 通过现有范围扩展默认向头侧补 `10 mm`、下侧不补；
不因骨标签扩展到整个头骨、面部或下颌。

本方法从分割形态估计几何方向，没有定位外耳孔、眼外眦、前后连合等解剖标志点，
因此不能声称平行听眦线或 AC-PC 线。脑底形态、异常解剖、分割缺损和扫描截断都会
影响结果。质量检查用于约束工程估计，不能把“通过门槛”解释成标志线定位成功。

继续使用原有 `--slice_part 颅脑`、模型选择和 `plane_configs`，不新增模型、
手工取点参数或 JSON 配置字段。第一、二阶段缓存可复用，旧成片需重新切割；
发布程序需要重新构建并更新应用代码。

## 阶段职责

1. 第三阶段保留颅脑原工作 raw/seg，不先旋转整卷图像。
2. 第四阶段仍解析配置中的 `brain` 整体目标，内存定位结果保持脑区事实。
3. 第五阶段先按脑区左右镜像对称面确定 LR，再估计绕 LR 的形态俯仰；将全部脑区
   体素支撑范围投影到最终三轴，输出坐标、诊断与警告。骨标签另作可选取景支持。
4. 第六阶段按最终坐标和脑区范围生成真实斜切 `plane_stack`，统一范围、层厚、层间距
   与数量规则；三个状位的切割 `source_labels` 均只用 `brain`，横状位 MPR 默认应用
   头侧 `10 mm`、下侧 `0 mm` 配置余量，并用可选 `framing_superior_extension_mm` 快照传递
   当前计划头侧余量。
5. 第七阶段按计划从原始 HU 采样，按脑区最终 SI 范围筛选骨体素辅助取景；横状位
   上界同步加入计划头侧余量，下界仍为脑区。最终方向、位置和间距
   如实写入 DICOM。Localizer 绘制真实切面，不能只倾斜定位线而仍按原轴切图。

第五阶段结束后不向后续阶段保留完整体素快照；第七阶段从已有分割文件解析所需
目标，遵守既有内存生命周期。
第五阶段的 `coords`、`label_targets`、`correction_scope_bbox` 继续保持脑区目标，
不合并骨范围。新增 `framing_source_labels`、`framing_label_ids` 只载明骨标签语义与 ID，
供第七阶段创建有界 `FramingContext`；这些字段不能代替第六阶段的切割 `source_labels`。
`brain.py` 的几何估计器只接收脑区，不接收骨支持。

## 方向估计

基础坐标沿用统一姿态流程：左右轴由可靠镜像对称面给出；镜像质量不足时使用患者
参考左右轴并保留其诊断。参考 AP 投影到 LR 正交平面得到基础 AP，SI 由 LR×AP 构造。
`patient_reference_axes` 负责患者方向符号，原始 origin、spacing、direction 仍用于
体素到物理点的换算。

将完整 `brain` 的体素中心转换为 LPS 物理坐标，投影到基础 AP/SI 平面，以二维协方差
的主特征向量估计前后倾角。计算使用全部脑区体素，不能用少量边界拟合点代替；
体素索引的长轴也不能直接充当物理主轴，尤其不能忽略层间距或 direction。

旋转仅发生在 LR 正交平面内，保持 LR 不变，AP/SI 成对更新并保持右手正交坐标。
主轴符号与基础 AP 对齐，避免特征向量正负不定造成 180° 翻转。该角度相对于基础
AP 投影报告，不是相对于屏幕水平线或任意存储轴的角度。
实际方向逐病例从脑区形态计算，角度是方向的记录值，不是预设切割参数。
不因倾角绝对值大于某个固定度数而回退，也不忽略较小但可信的倾角。

## 质量门槛与回退

以下为当前内部算法门槛，不作为用户配置项暴露：

| 条件 | 当前门槛及处理 |
| --- | --- |
| 脑区体素数量 | 至少 64 个有效体素，过少拒绝估计 |
| AP/SI 主方向可辨识度 | 较大与较小特征值之比至少 1.15，近圆形投影不猜测俯仰 |
| 俯仰幅度 | 不设绝对角度上下限，不限幅，不因倾角大小取消修正 |
| 扫描边界 | `brain` 不能接触源图任一边界，接触时拒绝形态俯仰 |
| 中央带稳定性 | 脑区中心沿 LR 的 ±10 mm 中央带须有有效主方向，中央带与完整脑区估计角差不超过 5° |
| 患者头脚方向 | 旋转后的 SI 必须仍朝患者 LPS `+Z`；与头脚方向冲突时拒绝本次俯仰，保留原 LR 与基础 AP/SI |
| 数值与坐标 | 坐标、协方差及主方向须可用于有限、正交的几何计算 |

任一必要检查不通过时，保留原 AP 投影，不采用中央带角度替代完整脑区估计。
中央带角差检查比较两次形态估计是否一致，约束的是估计误差，不是实际切割倾角。
回退只取消本次俯仰更新，不撤销已可靠的 LR；LR 自身的质量回退仍由统一姿态规则
决定。仅当候选 AP/SI 与基础 AP/SI 在方向余弦 `1e-8` 数值精度内重合时，状态记为
`unchanged`；这用于记录方向未变，不设置小角度死区。

完整脑区与中央带的一致性检查只检测一类形态不稳定，不能消除脑底形态导致的系统
偏差。多病例复核时，应同时检查 Localizer 和正式切片，而不能只比较记录角度。

## 切片范围、居中与骨标签

方向和切片基础范围只使用 `brain`。三个方向的 `frame.bounds` 均重新投影完整脑体素并计入
物理支撑外缘；不能直接复用原轴 bbox、PCA 采样点或镜像拟合点的极值。第六阶段
在脑区范围上应用既有 `face_extension_mm` 和层厚、层间距、数量规则；可选骨标签
不能扩大三状位的法向范围、首末切片位置或数量。

### 横状位的头侧工程余量

本轮四组真实数据中，脑区已经完整覆盖，骨性颅顶仍超出首张厚层上缘约
`6.91–12.47 mm`，相对脑区头侧支撑边界的距离约为 `9.35–12.51 mm`。
因此通过现有 `face_extension_mm` 配置头侧余量。当前颅脑横状位 MPR 为
`top_mm=10.0`、`bottom_mm=0.0`，向当前计划头侧补 `10 mm`，下侧不补；
切割和取景均读取这份配置，不在代码中额外增加固定距离。
冠状位、矢状位和其他部位不增加这项余量；脑区姿态、第五阶段 bounds 和目标标签不变，
不把整个 `skull` 并回切割范围。

`10 mm` 是当前配置的工程余量，不保证覆盖上述观测到的全部颅顶距离，也不保证
所有病例的骨性颅顶都完整包含。源扫描已截断或未采集的部分仍无法恢复。计划先
增加配置的有效范围，再按公共层厚、层间距和数量规则补齐采样余量；例如 `5/5 mm`
采样配置 `15 mm` 时可增加三层，但不能承诺任意采样参数下末层中心都数值不变。
下端配置保持 `0 mm`，不因骨标签下移到面部、下颌。

首张厚层的覆盖上界是中心面外侧半层厚处，Localizer 第一条定位线表示中心面；
例如层厚 `5 mm` 时，两者沿法向相差 `2.5 mm`。应核对首末厚层外缘和实际组织，
不能仅凭第一条中心线是否越过颅顶判断漏切，也不能把中心线人为缩短来伪装范围。

### 有界骨取景

骨取景支持可从本次实际推理模型的 `dataset.json` 读取明确的 `skull`，不能把任务名
`brain` 与模型骨标签混为一谈，也不能硬编码数字 ID、加入全部前景或以 CT 亮像素猜骨。
第七阶段使用最终解剖 SI 作为 `FramingContext` 的筛选轴，计算脑区体素在该轴的完整
物理支撑范围。横状位 MPR 计划通过 `framing_superior_extension_mm` 将取景上界同步增加
头侧配置余量，当前默认 `10 mm`；下界仍停在脑区，冠、矢状位保持原脑区 SI 范围。
只保留其物理支撑与该有界范围正重叠的骨体素，恰好接触边界而没有正重叠的体素不加入。
筛选跟随最终斜轴，不按原始数组 z 轴或固定患者 LPS Z 轴截取；第七阶段消费快照，
不重新读取范围配置，也不因此重新规划层组。

筛选后的骨与脑区仅组成有界取景目标，远离脑区头脚范围的面部、下颌骨不参与取景。
这个范围限制用于取景支持，不是从原始 CT 抹除相应像素；实际切面内可见的组织仍
按原始 HU 采样。骨支持不参与方向估计，也不改变层厚、层间距、数量或法向位置。

正数 FillPercent 按有界目标确定整组共同倍率、逐层目标居中；0/null/省略也按有界
目标的整组中心居中，保留基础像素间距。它与仅在正数 FillPercent 时加入的脊柱
显示上下文不同，但同样不能回写切割目标范围。
上述颅脑目标取景后，颅脑平面成片仍逐张裁去首尾完全无源支持行，以裁后整幅图居中；
0/null/省略也执行，Rows 和垂直中心可逐层变化，有效像素、Columns、PixelSpacing 不变。
Localizer 不参与这一步裁空。

没有明确骨标签或骨体素为空时，仅用脑区取景并告警；骨支持不是完整头骨覆盖要求。
脑区接触源图边界时拒绝俯仰更新并报告扫描截断风险，不补全扫描外缺失组织。
定位图 CT 背景可以显示脸或下颌，定位线仍代表实际切面，不能人为缩短线条来伪装
切片范围；范围是否正确应结合真实首末层、层数和正式 DICOM 共同判断。
Localizer 的底图保留固定 `localizer_reference`、方向和首末像素物理范围，粗显示轴
按[通用定位图规则](../dicom/2026-10-08-定位图状位配置与取景隔离设计.md)在绘线前做二维线性细化，
不随 FillPercent 缩放、裁切或逐层移动。MPR 白线直接按第六阶段真实无限平面与背景求交，仅裁到底图边界，
有效交线保持真实方向横穿底图，长度不随正式取景变化；它不表示成片有限视野。

## 诊断与试跑

开启 `debug_file_enabled` 后，`metadata/localization_result.json` 中的
`anatomical_geometry_diagnostics.pitch` 通过 `status`、`candidate_angle_degrees`、
`angle_degrees`、`reason` 等记录候选角、实际角、采用状态及回退原因。
`status=accepted` 表示采用形态俯仰，`rejected` 表示证据不足或患者方向冲突，
`unchanged` 表示候选方向在数值精度内与基础方向重合，对应
`rejection_code=aligned_with_reference`；拒绝和维持原向时实际 `angle_degrees` 为 0。
俯仰诊断不再写入 `max_angle_degrees` 或 `min_correction_degrees`，避免将方向记录
误读成固定角度准入规则。
`anatomical_geometry_diagnostics.bone_coverage` 记录可选骨取景支持的 `status`
（`available`、`missing`、`empty`）、`source_labels` 和 `voxel_count`；字段名保留，
不代表骨进入切割范围。这里记录原始候选骨标签及体素数量，最终参与取景的部分仍须
经过第七阶段的有界筛选。`coverage` 诊断仅描述脑区的范围、体素支撑与接边情况，
不把头侧配置余量记成脑区自身范围。
LR 镜像诊断与骨取景支持警告独立保留，不能用单一成功标志掩盖降级。
`slice_plans.json` 中的真实行列方向和法向，以及正式 DICOM 的位置和方向标签，
应与最终坐标一致；`applied` 应反映是否实际改变姿态。

用户可沿用原命令跑多组颅脑图，优先核对：

- 矢状 Localizer 上横状位定位线随头部形态倾斜，整组平行，角度无突变。
- 横状位在脑区基础范围上应用头侧 `10 mm`、下侧 `0 mm` 默认余量；核对厚层外缘
  是否包含颅顶，区分中心定位线和覆盖上界。远处面部、下颌不拉长层组。
- 冠状位、矢状位和横状位的方向共同变化，左右、头脚显示及 DICOM 几何保持一致。
- 质量拒绝病例沿用基础前后倾角，并能从诊断解释原因。
- 相同输入、窗位及计划下切换 FillPercent，定位图大小、背景几何和定位线长度保持不变，
  正式切片仍按请求改变取景。

## 回归范围

几何测试覆盖已知倾角（包括超过原上限的大角度及小于原死区的小角度）、方向符号、
非等距体素与斜 direction、近圆形主轴歧义、中央带与全脑不一致、头脚方向冲突、
体素过少、接边及脑区完整范围投影；LR 不应因俯仰
更新发生变化，非颅脑部位的输入俯仰策略应保持不变。

集成测试覆盖本次模型骨标签解析、脑区定义三状位基础范围、横状位读取当前配置余量、
计划 `framing_superior_extension_mm` 快照、骨支持按最终 SI 及计划头侧余量有界筛选、
所有 FillPercent 的脑骨有界取景、诊断序列化及真实斜切 DICOM 方向。
在脑区下方加入远端骨体素，不应改变三状位层数、首末位置或取景；脑部范围内的骨
可影响居中、视野，仍不能延长层组；横状位头侧新增范围中的骨须能参与取景，
冠、矢状位不借用该余量。已有合成与少量病例预览不能替代多病例效果复核。

相关实现入口为 `src/anatomy/brain.py`、第五阶段解剖分析、切片规划和第七阶段取景。
共用规则见[统一姿态设计](2026-10-16-统一解剖姿态与三状位回正设计.md)和
[FillPercent 取景设计](2026-10-08-整组居中与FillPercent取景设计.md)。
