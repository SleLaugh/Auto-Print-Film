# 直线切割模块入口

本模块描述阶段四如何把整切、区间切和自动切法推导统一到直线切割流程。

## 当前有效规则

- 整切和区间切只在“生成多少个待切区间”上不同。
- 后续方向、图像范围、层厚、层间距和切片展开复用通用直线流程。
- 部位 planner 负责解析目标区间；阶段五只消费 `SlicePlan`，不重新规划。
- 脊柱区间切后续可使用阶段三的标注质心确定方向，但区间覆盖仍使用完整 label 的 bbox；非脊柱切法不读取 `spine_geometry`。
- 默认整切走通用直线整切；腰椎横状位等特殊切法由切法推导策略决定。
