# CPR 端点反弧回正设计

## 背景

脊柱 CPR 路径由首端面、全部椎体质心和末端面组成。中间质心链使用现有
Hermite 插值；首末端面在进入曲线前，由
`_correct_endpoint_face_to_local_arc` 判断是否偏离局部质心弧线。

这里的“全部椎体”指第四阶段转交的 `resolved_cut_config` 实际配置范围。胸椎默认
首末标签为 C7/L1，两者都参与质心链和首尾端点计算；只有颈椎固定排除 C1。

2026-07-29 胸椎病例中，首端原始端面相对质心外延方向偏转约
`17.41°`，前三个质心形成的正常局部弧线转角约为 `5.50°`。现逻辑把端面
投影到正常角度区间的边界，最终仍保留 `5.50°` 的端部偏角。新规则要求：
正常连续弧线完全不动；只有端面造成反向弧线或回折时，才最短投影到质心
外延线，使修正后的端部夹角为 `0°`。

## 目标

- 正常连续弧线上的首末端面保持原坐标。
- 只有端面方向越出局部正常弧线区间时才触发回正。
- 触发后把端面最短投影到端部相邻质心连线的外延射线，目标角为 `0°`。
- 保留端面在图像左右轴上的分量。
- 不修改中间质心、Hermite 平滑、CPR 覆盖标签或第七阶段重建。

## 判定与修正

以首端为例，令 `C0`、`C1`、`C2` 为从首端开始的前三个质心：

1. `C0 - C1` 是从首质心向外的基准方向。
2. `C1 - C2` 与基准方向之间的带符号角定义局部正常弧线转角。
3. 端面相对 `C0` 的方向与基准方向之间的带符号角定义端面转角。
4. `0°` 到局部正常弧线转角之间是允许区间，端面转角位于该闭区间时，
   原端面不做任何修改。
5. 端面转角越出允许区间，或端面在基准方向上的投影为负时，判定为反向
   弧线或回折。
6. 触发修正后，移除端面矢状分量中垂直于基准方向的部分，只保留基准方向
   上的非负投影；图像左右轴分量保持不变。
7. 修正结果与质心重合时，不把零长度端点加入 CPR 路径。

末端使用完全对称的规则。

## 回退与边界

- 缺少端面、相邻质心重合或矢状基准方向无效时，沿用现有安全回退。
- 正常弧线即使带有非零转角，也不吸附到 `0°`。
- 本次只改变“越界之后投影到哪里”：由当前最近角度边界改为 `0°`
  外延射线；正常区间判定保持不变。
- 中间曲线仍严格使用现有质心及平滑算法，不引入质心软约束。

## 测试

- 端面转角位于正常区间内部时，输出与输入端面完全相同。
- 端面转角越出正常区间时，修正后矢状方向与质心外延方向夹角为 `0°`。
- 回正采用正交投影，修正位移与外延射线正交，证明移动距离最小。
- 图像左右轴坐标在修正前后保持不变。
- 反向投影长度为零时，不产生重复端点。
- 现有第六阶段和全量测试继续通过。

## 验收标准

1. 2026-07-29 胸椎病例的首端原始 `17.41°` 越界端面修正到 `0°`。
2. 位于 `0°–5.50°` 正常弧线区间内的端面保持不动。
3. CPR 中间质心链和整体平滑结果不因本次修改而变化。
4. 实际病例确认端点不再反弧后，与相关 CPR 改动一并提交。
