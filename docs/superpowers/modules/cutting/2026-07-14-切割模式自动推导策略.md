# 按部位和状位推导切法实施计划

> **供执行人员使用：** 按任务逐项实施本计划，各步骤使用复选框（`- [ ]`）跟踪状态。

**目标：** 外部请求不再传 `cut_mode`，当前自动将腰椎横状位规划为区间切，其余部位和状位规划为整切。

**架构：** 新增唯一切法策略函数，CLI、预检、定位和规划阶段共同使用。定位阶段在请求包含腰椎横状位时加载区间标签全集；规划阶段按推导出的切法分组调用现有 planner，再合并计划。

**技术栈：** Python、dataclasses、argparse、unittest。

## 全局约束

- 外部 CLI 和请求序列化不再暴露 `cut_mode`。
- 当前唯一特例是 `腰椎 + 横状位 -> interspace`。
- 每个最终 `SlicePlan` 继续保存实际 `cut_mode`，供第五、六阶段分组和报告使用。
- 本计划只负责切法推导；真实腰椎数据中相邻椎体 bbox 重叠导致横状位区间被跳过的问题不在本次修复范围。
