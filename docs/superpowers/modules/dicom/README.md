# DICOM 模块入口

肺部、髋骨三状位普通 MPR 默认按所选标签取景，每侧余量 `5 mm`。
肺部、髋骨全部普通MPR状位统一使用原标签整组包络中心，整组固定中心、倍率与矩阵。
保留第六阶段原CT投影画框及物理宽高比，100容纳所选标签+余量；70、50同心向四周扩展视野。
0/null/省略、其他部位、CPR、椎间隙与定位图保留原规则。详见[整组取景设计](../reconstruction/2026-10-08-整组居中与FillPercent取景设计.md)。

本模块只放 DICOM 输出形态相关资料。写盘并发安全的总规则在 `../../architecture/`。

## 当前有效规则

- 重建切片文件名使用数字序号，如 `1.dcm`、`2.dcm`。
- `Localizer.dcm` 放在对应窗位 series 旁边，第八阶段计数时不应把它当作普通切片。
- `InstanceNumber` 仍表达 DICOM 内部序号，文件名变化不应改变重建几何。
- 定位图背景状位由各部位 `slice_rules.<重建状位>.<切法>.localizer_plane` 显式配置，
  不得与重建状位相同。FillPercent 只影响正式切片，定位背景保留固定
  `localizer_reference`、方向和首末像素物理范围，不随取景缩放、裁切或逐层移动。
  粗显示轴在绘线前仅对二维背景线性细化，再在新显示网格绘线；不做全体三维重采样。
  MPR 直接用第六阶段真实平面求交，
  交线仅裁到底图边界，不表示正式切片的有限视野；切换 FillPercent 不改变线长。
  脊柱曲面背景同样只按显示网格裁线；CPR 投影路径保持不变。
- 成片空间标签逐张使用实际取景几何。
  肺/髋正数普通MPR以所选标签整组投影包络加每侧 `5 mm` 为目标，整组固定中心、倍率和矩阵。
  统一使用 `selected_region`、缺省group中心、`canvas=original`，不再逐层追随目标或选择肺参考层。
  保留第六阶段原CT投影画框的Rows、Columns与基础像素纵横比，在原画框物理宽高比内等比适配目标。
  100完整容纳所选标签及余量，70和50在同一组中心宽高同时扩为100的1/0.7、2倍。
  直接从完整原CT采样，不预裁外围组织；不以完整人体限制倍率，目标框外皮肤、肋骨或骶尾结构允许越框。
  所有层、占比及窗位共用固定矩阵，不执行逐张上下ROI；小截面和不限制适配的一轴仍可留空气。
  不拉伸解剖、不将小目标逐张拉满；原切面、法向层位、范围、厚度、间距、张数和定位图不变。
  肺/髋普通 MPR 的 0/null/省略同样保源、不做上下 ROI，保持基础间距、scale=1 和整组目标中心，
  必要时对称扩共同矩阵，保持奇偶性；其他部位和切法保留原规则。
  `framing.output_size_xy` 记录实际行列数，ImagePositionPatient 按实际矩阵及每层真实中心重算。
  详见[整组取景设计](../reconstruction/2026-10-08-整组居中与FillPercent取景设计.md)。
- 除上述肺部、髋骨普通 MPR 外，适用平面成片（含 0/null/省略）在 HU 采样后
  逐张裁去首尾完全无源支持行，保留有效像素、Columns、PixelSpacing，以裁后整幅图居中；
  Rows 和垂直中心可逐层不同，同层各窗几何一致。CPR、Localizer 不执行上下裁空，整张无源
  支持的平面层保持原样并标记 `no_source_support`；不按黑色像素裁剪或拉伸补框。
  取景不改变切面、方向、顺序、层厚、层间距或数量。相邻切片可有面内 ImagePositionPatient
  平移，不能假定为固定面内原点的规则直角三维体；CPR 展开图也不能据此还原原始解剖三维体。
- 新矢状位 CPR 仅在冠状面展开左右侧弯，保留前后生理曲度；纵向为冠状投影弧长，
  不能据此承诺原图 SI 毫米位置逐点不变。其 Localizer 线复用采样投影，冠状背景
  深度仍来自真实三维 `curve_points`，两者不能混用。
- 正式切片按实际窗宽窗位将未取整的重建 HU 映射为 uint16 灰度；GDCM 写盘后补入实际
  `WindowWidth`、`WindowCenter`、`LINEAR_EXACT` 以及对应 Rescale 标签，`RescaleType=HU`。
  普通平面先按有效源支持完成厚层平均，再由各窗共用这份 HU；越界填充值不参与平均，
  源内真实空气仍参与，零支持像素保留空气。`SliceThickness` 记录计划厚层范围，
  不能将边缘像素的实际支持厚度当作整张图的新层厚；切面、层间距及张数不变。
  这些派生显示片的窗外数值已截断，定量数据应读取原始 CT 序列。
- GDCM 写盘必须经由串行保护入口，具体跨模块约束读 `../../architecture/2026-07-20-GDCM写盘串行保护设计.md`。
- 同一计划各窗 Localizer 必须使用主线程冻结的同一份 `ImagePositionPatient` 和
  `ImageOrientationPatient` 串行写出；窗位仅改变定位图的显示像素、显示标签和序列标识。
- Localizer 原显示轴间距大于最细显示轴的两倍或大于 `2 mm` 时，该轴向
  `min(最细显示轴间距, 1 mm)` 细化，保持首末像素物理位置；不改变原本足够细的轴。
  曲面背景先按原深度采样，再细化参考 x/z 显示网格，并保持物理路径映射一致。
  背景插值不增加解剖细节，不改变正式切片厚度、范围、FillPercent 或张数。
- Localizer 定位线在最终显示网格上使用约一像素宽的独立亚像素覆盖率掩膜，
  并在背景完成窗位映射后叠加；正式
  DICOM 使用白线，debug PNG 使用同一掩膜的红线。该显示处理不得进入正式切片
  重采样，也不得改变切片几何、层厚或层间距。
- Localizer 用 Rescale 标签将 uint16 像素换算到对应窗口的显示数值，并写入实际窗宽窗位；
  `RescaleType=US` 表示未指定单位。定位图属于合成显示数据，不能用于定量 HU 测量，
  调试 PNG 显示不变。颈椎、胸椎、腰椎、脊柱矢状位 MPR/CPR 的冠状背景可沿脊柱前后深度
  采样派生曲面，几何不足回退单层；DICOM 的 `DerivationDescription` 注明非平面采样，空间标签只描述显示
  参考网格，不能将其当作普通原始冠状平面做精确三维联动。
- Localizer 缺少必要空间标签时必须失败，不能发布带二维默认方向的文件。
- 第八阶段是最终输出硬门禁：先校验正式切片、Localizer、UID、层厚层间距和
  同计划跨窗几何，再发布成功结果；任一硬错误必须使任务失败。
- 输出校验失败时抛出 `OUTPUT_VALIDATION_ERROR`，日志写明计划、窗位、文件和字段；
  debug 开启时保留 `metadata/处理报告_调试.json`，同时写入 `Success=false`、包含错误
  `Message` 且不含切片结果的交付 `report.json`。
