**Goal:** 在首末端面中心解析完成后，最小移动超出局部质心弧线角区间的端面点，同时保持全部质心不动。

**Architecture:** 在阶段四 CPR 锚点构造层使用无状态几何函数，先检查端面相对端部质心的向外方向，再计算内部质心转角和端面连接转角。端面转角必须位于零角与内部转角之间；超出时把端面正交投影到最近的合法边界射线，合法端点和退化切向保持原样，修正后与质心重合的端面不重复插入。

**Tech Stack:** Python 3、现有 `Point3D`/几何工具、NumPy、`unittest`

## Global Constraints

- 只移动首末端面中心，不移动任何椎体质心。
- 只在 AP–SI 矢状投影上判断和修正，保留左右坐标。
- 方向点积绝对值或带符号转角与合法边界的差值不大于 `1e-6` 时视为位于边界。
- 不改变端面解析优先级、质心选择、配置范围、Hermite 平滑或阶段五重建。
- 本轮不执行 `git add`、`git commit` 或其他提交操作。

```python
def _project_away_from_axis(vector: Point3D, axis: Point3D) -> Point3D:
    unit_axis = normalize_vector(axis)
    return subtract_points(vector, _scale(unit_axis, _dot(vector, unit_axis)))


def _correct_endpoint_face_to_local_arc(
    face: Point3D | None,
    centroid: Point3D,
    adjacent_centroid: Point3D,
    left_right_axis: Point3D,
) -> Point3D | None:
    if face is None:
        return None
    toward_neighbor = _project_away_from_axis(
        subtract_points(adjacent_centroid, centroid),
        left_right_axis,
    )
    if vector_length(toward_neighbor) <= 1e-6:
        return face
    outward = normalize_vector(_scale(toward_neighbor, -1.0))
    sagittal_face_delta = _project_away_from_axis(
        subtract_points(face, centroid),
        left_right_axis,
    )
    outward_component = _dot(sagittal_face_delta, outward)
    if outward_component >= -1e-6:
        return face
    return _add(face, _scale(outward, -outward_component))
```

首端调用时 `adjacent_centroid` 传第二个质心，末端调用时传倒数第二个质心。
因此两个端点的向外方向统一为“从端部质心背离相邻质心”，不需要首末符号分支，
也不修改质心输入列表。

在 `_build_annotation_centroid_path` 解析出 `first_face`、`last_face` 后读取：

```python

```

然后分别执行首末修正。插入前用
`vector_length(subtract_points(face, centroid)) > 1e-6`

```python
def _signed_angle_around_axis(
    first: Point3D,
    second: Point3D,
    axis: Point3D,
) -> float:
    return math.atan2(
        _dot(_cross(first, second), axis),
        _dot(first, second),
    )


def _rotate_around_axis(
    vector: Point3D,
    axis: Point3D,
    angle_radians: float,
) -> Point3D:
    cosine = math.cos(angle_radians)
    sine = math.sin(angle_radians)
    return _add(
        _add(
            _scale(vector, cosine),
            _scale(_cross(axis, vector), sine),
        ),
        _scale(axis, _dot(axis, vector) * (1.0 - cosine)),
    )
```

在 `_correct_endpoint_face_to_local_arc` 中计算：

```python
inner_angle = _signed_angle_around_axis(
    normalize_vector(inner_segment),
    outward,
    left_right,
)
face_angle = _signed_angle_around_axis(
    outward,
    normalize_vector(sagittal_face_delta),
    left_right,
)
minimum_angle = min(0.0, inner_angle)
maximum_angle = max(0.0, inner_angle)
if face_angle < minimum_angle - 1e-6:
    target_angle = minimum_angle
elif face_angle > maximum_angle + 1e-6:
    target_angle = maximum_angle
```

端面直接折返时令 `target_angle = 0.0`。需要修正时把 `outward` 绕左右轴旋转
`target_angle` 得到边界射线，再把端面矢状位移正交投影到该射线，负投影长度
夹紧为零；左右轴分量继续原样保留。

```python
) -> List[Point3D]:
    curve_points = _smooth_cpr_anchor_path(
        centroid_points,
        spacing_mm,
        longitudinal_axis,
    )
    if not centroid_points:
        return curve_points

    terminal_spacing = max(float(spacing_mm) * 0.5, 1e-6)
    if (
        anchor_points
        and vector_length(
            subtract_points(anchor_points[0], centroid_points[0])
        ) > 1e-6
    ):
        prefix = _resample_straight_segment(
            anchor_points[0],
            centroid_points[0],
            terminal_spacing,
        )
        curve_points = prefix[:-1] + curve_points

    if (
        anchor_points
        and vector_length(
            subtract_points(anchor_points[-1], centroid_points[-1])
        ) > 1e-6
    ):
        suffix = _resample_straight_segment(
            centroid_points[-1],
            anchor_points[-1],
            terminal_spacing,
        )
        curve_points = curve_points + suffix[1:]
    return curve_points
```

把 `build_spine_sagittal_cpr_plan` 中对全部 `anchor_points` 的 Hermite 调用替换为
该函数，并把 `annotation_centers` 作为 `centroid_points` 传入。端面不存在时
`anchor_points` 的首尾等于质心首尾，因此不会生成额外直线。
