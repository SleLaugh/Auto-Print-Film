# 重建模块入口

本模块覆盖第六阶段切片规划到第七阶段 MPR 执行，以及各部位直线 MPR 和脊柱 CPR。

## 当前有效规则

- 第七阶段消费第六阶段输出的 `SlicePlan`，不再按部位或切割方式重新规划切面、层厚、间距和张数。
- `FillPercent` 对所有部位的 MPR、椎间隙和 CPR 统一采用整组倍率、正数逐层目标居中；
  普通平面按当前厚层内原目标加有界上下文居中，CPR 按当前展开掩膜居中；
  联合范围为空才回退整组中心，仅原目标为空但上下文存在时仍逐层居中。
  椎间隙同一部位、同一项状位配置共用矩阵与物理比例；
  共同矩阵取末组之前各组基础矩阵的逐轴中位数并取整，末组沿用，单组回退自身矩阵；
  投影目标尺寸取全部间隙逐轴最大值，正数 FillPercent 统一适配并确保目标覆盖。
  CPR 在展开图上求整组掩膜并集决定比例。0、null 或省略保持既有整组居中和基础像素间距，
  正数使宽或高先达到指定图像占比，不保证每张都达到该占比。定位图不应用此取景。
- 切割 `source_labels` 与显示上下文分开。脊柱正数取景从本次模型标签表补充同类椎体，
  并限定在原目标沿 LPS 头脚轴的物理外边界内；不混入无关器官或未显式选中的 sacrum。
  当前厚层按原目标与有界上下文联合居中，倍率逐轴覆盖原组投影与各层联合尺寸，
  必要时只统一放宽整计划或同配置所有间隙。CPR 先加入有界上下文再沿原路径展开。
  0/null/省略不应用上下文，保留原像素几何。
- 椎间隙在 0、null 或省略时也统一图片行列数，但保留基础像素间距。
  同配置各间隙及各窗的 Rows、Columns、PixelSpacing、物理视野一致；真实解剖大小
  差异仍保留，不能强行把椎体拉成相同大小。不同配置、普通 MPR 和 CPR 独立计算。
  预计算逐计划释放目标点云，仅保存公共几何，HU 图像仍逐计划串行采样。
- 取景后的实际位置、像素间距和方向逐张写入 DICOM；正数逐层居中可能使相邻切片出现
  面内位置平移，不能假定为固定面内原点的规则直角三维体。CPR 是展开图，不能据此恢复原解剖三维结构。
- `plane_stack` 是当前已实现的直线 MPR 主协议。
- 当前启用部位的整切三状位共用第五阶段解剖坐标。头骨、髋骨和可靠双侧肺使用
  左右对称面；颈椎、胸椎、腰椎使用首尾轴及可靠逐椎体左右方向。胸椎横状位不再
  固定输入轴，髋骨冠/矢状位也使用最终坐标。质量不足时记录警告和回退原因。
- 头骨、髋骨和肺部保留输入前后倾斜基准；头骨不会自动校正低头、仰头。回正只改变
  刚性采样方向，不强行镜像、变形或拉平真实解剖。肺部通过镜像质量后还须验证
  两主体分居对称面两侧、沿 LR 分离且反射跨主体对应；两个连通域本身不能证明双侧。
  统一规则见[统一姿态设计](2026-10-16-统一解剖姿态与三状位回正设计.md)。
- 患者方向符号由 `patient_reference_axes` 统一确定，SI 朝 LPS `+Z`，冠状、矢状
  成片头侧向上；体素物理坐标仍按原 direction 换算，不改变斜扫描角或头部俯仰基准。
- LR 方向唯一性检查识别涉及 LR 的近重根、圆柱角向信息不足和许可范围内等价面；
  LR 独立、仅 AP/SI 等谱不因此拒绝。拒绝结果保留质量原因与回退告警。
- `SliceType` 省略时默认 `MPR`；颈椎、胸椎、腰椎冠状位只有显式请求 `CPR`
  才沿椎体中心曲线生成前后偏移序列。
- 显式 CPR 规划条件不足时任务失败，不允许静默降级为 MPR。
- 脊柱 CPR 标签按第四阶段 `resolved_cut_configs["whole_range"]` 的首尾完整展开；胸椎默认使用
  C7、T1–T12、L1，非颈椎任务不额外删除配置首尾标签。
- S1 标准配置不改写，运行时按实际 `label_targets` 优先选择 `vertebrae_S1`、否则
  使用 `sacrum`；整体轴诊断、椎间主体配对及 `L5_S1` 的 `source_labels` 使用实际名，
  第七、八阶段消费已解析的计划，不重新按标准终点名寻找标签。
- 第五阶段输出的 `spine_geometry.filtered_annotation_centroids`（标注质心）负责 CPR
  中心线和弧度；第四阶段完整 `coords.*.bbox` 负责 CPR/区间切的覆盖范围。
- CPR 中间质心只有形成与相邻趋势相反的局部折返时才回正到双邻点预测位置；正常 C 型弯曲保持不动，L5 可修正而 S1 末端锚点不移动。
- 中间质心回正先于首末端面和原始 label 出口路径构造，避免下游仍读取未回正锚点；
  靠近末端的同向异常残差只允许在相邻间距 `10%` 内保守限幅。
- CPR 首末端面只有越出局部正常弧线区间时才回正到质心外延射线；正常连续弧线保持不动。
- 首末直线端段方向作为曲线样条的端点切向，保证直线与曲线相切连接，不在拼接处
  形成锐角。
- 回正后的首末端线保持方向不变，并沿原始分割搜索到白线穿出首末椎体标签的位置；不使用全量 bbox 极值决定端线长度。
- MPR、CPR 和椎间隙统一使用层厚、层间距、数量三选二规则；三项齐全时按有效范围
  执行对称外扩或保持数量后重算层厚、层间距。
- 脊柱冠状位 CPR 的有效范围由原始标注体素外缘决定，再使用统一规则计算偏移位置。
- 椎间隙数量按每个有效间隙计算，例如 5 个间隙、每个 20 张会生成 100 张；缺失
  间隙不会把数量转移给其他间隙。
- 颈椎横状位椎间隙按统一切割部位配置生成；当前只生成 `C2_C3` 至 `C6_C7`。C1
  继续参与原始分割、整体定位和普通 MPR，但不生成 `C1_C2` 椎间隙计划。
- 颈椎、腰椎椎间隙以相邻椎体可靠的局部左右方向处理侧倾，并保留局部斜切位置；
  方向质量不足时记录警告并回退。区间几何解析及颈椎法向约束完成后统一确定显示坐标；必要时
  同时反转上下轴和法向，像素采样与 DICOM 几何同步改变，保留切面倾角、位置、
  层厚、层间距、张数以及上位到下位的排列顺序。已有输出需重新切割才会更新。
- CPR 全部 offset 共用一套经过紧弯约束的单位偏移方向场，对应行严格保持配置
  层间距；层厚等于层间距时相邻曲面不能留下未采样间隙。
- 偏移方向场使用固定 `80 mm` 标准支撑范围；全量范围增加常见外层时，不会改变
  主体范围中已经存在的 CPR 曲面，也不会让远层逐层变直形成扇形。
- 第七阶段 Localizer 和实际 CPR 重采样复用同一个偏移曲线入口，不能只修正
  定位线外观。
- 第七阶段会实际写出冠状位 CPR 切片和 Localizer；CPR 曲面使用批量物理坐标换算与三线性插值，保持原有输出间距、厚层子采样数和算术平均语义，不通过降低采样密度换取速度。
- 第七阶段为每个 CPR 计划只准备一次共享偏移方向场和全部 offset 曲线；计划内
  各切片复用该几何，不能逐张重复平滑和搜索方向场。该复用不得改变像素、
  `Origin`、`Spacing` 或 `Direction`，日志以 `[CPR几何准备]` 标记一次性耗时。
- CPR Localizer 对投影曲线使用与 SimpleITK 等价的 NumPy 批量仿射坐标换算，
  不逐线段重复进入 SimpleITK 原生单点转换；日志以 `[CPR定位图性能]`
  记录曲线数、点数与转换方式，正式切片几何和采样不受影响。
- Localizer 的背景图和定位线覆盖率分开保存。定位线按连续体素坐标做亚像素采样和
  双线性覆盖，窗位映射完成后再叠加到背景；DICOM 白线与 debug PNG 红线共用同一
  掩膜，避免斜直线显示成逐像素台阶。该掩膜只用于显示，不参与正式 MPR/CPR
  重采样、层厚融合或切片计划；定位线退化时也不能阻断正式切片写出。
- 同一计划的正式切片可按窗并行写出；各窗 Localizer 必须复用主线程冻结的三维
  位置和行列方向并串行写出，不能因窗位线程不同而退回二维默认方向。
- 正式切片各窗共用未取整的重建 HU，再按实际窗宽窗位分别生成 uint16 灰度；
  GDCM 写盘后补入实际窗位、`LINEAR_EXACT` 及对应 Rescale 标签。窗外数值已截断，
  定量数据应读取原始 CT 序列。Localizer 保留窗化背景与白线，以 Rescale 标签配合实际窗位显示；
  它是合成显示数据，不能用于定量 HU 测量，调试 PNG 显示不变。
- 第七阶段输出摘要必须随每个计划透传 `geometry_type`、`slice_thickness` 和
  `slice_spacing`，供第八阶段把最终 DICOM 标签与实际计划做硬校验。
- 第六阶段只把全部 MPR、CPR 和椎间隙计划写入 `slice_plans.json`，不再生成任何
  规划 NIfTI 调试图；定位核对看第七阶段 `Localizer.dcm`/`Localizer.png`。
- 脊柱矢状位保持既有直线 MPR 切图逻辑，切片定位线画在冠状位背景上，不走 `curved_stack`。
- 腰椎直线矢状整切的冠状定位图使用 L1-S1 椎体主体共同中心层；腰椎五个横状位
  椎间计划共享同一张矢状位主体中心层，只保留各计划自己的定位线。
- `localizer_plane` 和 `localizer_reference` 只选择定位图背景，不得改变
  `slices`、切片方向、切片范围、层厚或层间距。
- 颈椎、胸椎、腰椎使用配置首尾椎体质心和可靠逐椎体左右方向建立三维直线坐标系；当前颈椎配置使 CPR 和
  椎间隙规划排除 C1，整体坐标仍保留 C1。
- 髋骨三状位方向由双侧主体边界镜像拟合决定，AB 仅作诊断；三个方向的覆盖边界
  均投影完整保留主体计算，不能用拟合采样点代替完整范围。
- CPR 规划的基础三维向量运算集中在 `planning/spine_cpr_math.py`；
  `spine_cpr.py` 保留规划流程和兼容的私有辅助名称，拆分不改变 SlicePlan 契约。

- 只改直线整切/区间切生成流程时，先读 `../cutting/README.md`。
- 只改 DICOM 文件名或定位图时，先读 `../dicom/README.md`。
